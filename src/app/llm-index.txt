# src/app
ROLE: 웹 라우트 · App Router 페이지와 전역 스타일
언어별 html lang 때문에 [lang]과 blog/[lang]이 각각 루트 레이아웃을 갖는다.

## dirs
[lang]/ → [lang]/llm-index.txt
blog/ → blog/llm-index.txt

## files
fonts.ts — 손글씨 아이브로 글꼴
globals.css — 3색 토큰과 전체 스타일
icon.png — 사이트 아이콘, 앱 아이콘 축소본
robots.ts — 크롤러 허용 규칙과 사이트맵 주소
sitemap.ts — 홈·지원·블로그와 언어별 대체 링크를 담은 사이트맵, 개인정보 처리방침은 제외
