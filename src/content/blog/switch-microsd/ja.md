## この記事の要点

Switch SDカードとして使えるのはmicroSDカードです。Nintendo Switch、Switch Lite、Switch(有機ELモデル)はmicroSD、microSDHC、microSDXCに対応し、microSDXCは2TBまで使えます。通常サイズのSDカードはスロットに入りません。

カードには、ダウンロード版ソフト、更新データ、追加コンテンツ、画面写真と動画が保存されます。セーブデータは本体保存メモリーに保存され、カードには移せません。

Nintendo Switch 2でゲームの保存に使えるのはmicroSD Expressカードだけです。Switchで使っていた通常のmicroSDをSwitch 2に挿すと、画面写真と動画の読み込みだけができます。

「カードを挿したら本体更新が必要と出た」「カードを替えたらソフトをダウンロードし直すの?」。Switchに初めてカードを入れるときや、カードを替えるときによく出る疑問です。この記事では、Switch SDカードの規格、入れかた、フォーマット、データの移しかたを任天堂の案内で確かめます。ほかの機器での使い方は[マイクロSDカードの使い方](/blog/ja/how-to-use-microsd)にまとめました。

## Switch SDカードはどれを使えばいいですか?

microSD系のカードを使います。[任天堂サポートのmicroSDカードの案内](https://support.nintendo.com/jp/switch/data_management/microsdcard/index.html)によるものです。

| カードの種類 | 容量 | Switchでは |
| --- | --- | --- |
| microSD | ~2GB | 使えます |
| microSDHC | 4GB~32GB | 使えます |
| microSDXC | 64GB~2TB | 使えます。先に本体更新が必要です |
| SD、miniSD | - | スロットの大きさが合わず使えません |

SD、miniSDが使えないことは[任天堂(米国)のmicroSDカードFAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq)に書かれています。microSDXCを使うには、インターネットに接続して本体更新をします。

同じ任天堂の案内は、高速なカードの目安としてUHS-I対応、読み込み速度60~95MB/秒を挙げています。UHS-II規格には対応していません。UHS-IIのカードも使えますが、UHS-IIの速度では読み込めません。

速度の表示は[SDカードのV30とは?](/blog/ja/sd-card-speed-class)に、バス方式の違いは[UHSスピードクラスとは?](/blog/ja/uhs-sd-card)に、容量規格は[SDXCとは?](/blog/ja/sdhc-vs-sdxc)にまとめました。この記事は特定のカードを試しておらず、推奨もしません。

## Switch SDカードには何が保存されますか?

セーブデータ以外のソフトのデータと、画面写真・動画です。[任天堂のmicroSDカードの案内](https://support.nintendo.com/jp/switch/data_management/microsdcard/index.html)によるものです。

| データ | microSDカードへの保存 |
| --- | --- |
| ダウンロード版ソフト | できます |
| ソフトの更新データ | できます |
| 追加コンテンツ | できます |
| キャプチャーボタンで撮影した画面写真・動画 | できます。保存数に上限があります |
| セーブデータ | できません。本体保存メモリーに保存されます |

セーブデータは本体に残るので、カードを替えたりフォーマットしたりしても、ゲームの進行状況はカードと一緒に消えません。

[任天堂(米国)のFAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq)によると、カードを挿すとダウンロード版ソフトの保存先がカードになります。同じFAQは、本体1台にカード1枚で使うよう勧めています。複数のカードに分けて保存したソフトは、あとで1枚にまとめられません。

## SwitchにmicroSDカードはどう入れますか?

電源を切ってから入れます。[任天堂のmicroSDカードの案内](https://support.nintendo.com/jp/switch/data_management/microsdcard/index.html)によると、電源ONのまま挿しても問題はありませんが、挿したあとに本体の再起動が必要です。

1. 本体の電源をOFFにします。
2. モデルに合ったスロットを開けます。下の表を見てください。
3. カードの向きに注意して、カチッと音がするまで差し込みます。
4. 本体の電源を入れます。microSDXCなら、画面の案内に従って本体更新をします。

| モデル | スロットの場所 |
| --- | --- |
| Nintendo Switch [HAC-001] | 本体背面のスタンドを開いた中 |
| Nintendo Switch(有機ELモデル)[HEG-001] | 本体背面のスタンドを開いた中 |
| Nintendo Switch Lite [HDH-001] | 本体底面のスロットカバーを開けた中 |

抜くときは本体の電源をOFFにして、カードを一度奥に押し込んでから抜きます。

## Switch SDカードはどうフォーマットしますか?

本体の設定でフォーマットします。[任天堂のフォーマット方法のQ&A](https://support-jp.nintendo.com/app/answers/detail/a_id/34179/)の手順です。

1. HOMEメニューで「設定」を選びます。
2. 「本体」→「初期化」を選びます。みまもり設定をしている場合は暗証番号を入力します。
3. 「SDカードのフォーマット」を選びます。
4. 「つづける」を選びます。
5. 「フォーマットする」を選びます。

フォーマットすると、ソフトのデータ、画面写真・動画、ほかの機器で保存したデータなど、カード内のすべてのデータが消えます。画面写真や動画は、先に本体保存メモリーやパソコンに移してください。ダウンロード版ソフトと追加コンテンツは、フォーマット後に再ダウンロードできます。

パソコンでフォーマットする方法は[マイクロSDカードフォーマット方法](/blog/ja/format-microsd)にあります。Switchで使うカードは、本体でフォーマットするほうが任天堂の案内に合っています。

## 本体保存メモリーのソフトをSDカードに移せますか?

移せます。[任天堂のQ&A](https://support-jp.nintendo.com/app/answers/detail/a_id/33844/)によると、移せるかどうかはデータの種類で決まります。

| データ | 移しかた |
| --- | --- |
| セーブデータ | 移せません。必ず本体保存メモリーに保存されます |
| ソフトのデータ(ダウンロードしたソフト、追加コンテンツ) | HOMEメニューの「設定」→「データ管理」でソフトを選んで移動します |
| 画面写真・動画 | 「設定」→「データ管理」→「画面写真と動画の管理」でコピーします |

画面写真と動画をカードにコピーする手順です。HOMEメニューの「アルバム」からもコピーできます。

1. HOMEメニューの「設定」を選びます。
2. 「データ管理」→「画面写真と動画の管理」を選びます。
3. 「本体保存メモリー」を選びます。
4. 「すべての画面写真と動画をSDカードにコピー」を選びます。

[任天堂(米国)のデータ移動の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/49231/)によると、一部の更新データも移せません。この機能はインストール先を決める機能ではありません。移動後に遊び続けると、更新データが選んでいない場所に保存されることがあります。

## もっと大きいSDカードに替えるには?

Windowsパソコンでデータを丸ごとコピーします。[任天堂(米国)のカード間のデータ移動の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/27595/)の手順です。

1. 本体の電源を切り、元のカードを抜きます。
2. 元のカードをパソコンのカードスロットかカードリーダーに入れます。
3. エクスプローラーでカードを開き、フォルダーを丸ごとデスクトップにドラッグします。
4. 新しいカードを任天堂の案内どおりにフォーマットします。
5. デスクトップのフォルダーを新しいカードにドラッグします。
6. 新しいカードをSwitchに挿し、動くか確かめます。

| 注意すること | 任天堂の案内 |
| --- | --- |
| OS | Windows以外の環境(Macなど)では正しくコピーできない場合があります |
| フォルダー | 必ずフォルダー全体をコピーし、中のファイルを変更・削除しません |
| 元のカード | 新しいカードが正しく動くと確かめるまで、消去やフォーマットをしません |
| 読み込めないソフト | ニンテンドーeショップから再ダウンロードします |

カードをパソコンにつなぐ方法は[SDカードをパソコンにつなぐ方法](/blog/ja/sd-card-to-pc)に、新しいカードの容量が怪しいときの確認は[SDカードの偽物の見分け方](/blog/ja/fake-sd-card)にあります。

## ほかのSwitchで使っていたSDカードを挿すとどうなりますか?

カードのソフトのデータを消去すると使えます。[任天堂のmicroSDカードの案内](https://support.nintendo.com/jp/switch/data_management/microsdcard/index.html)によると、ほかの本体で使っていたカードを挿すと消去の画面が出ます。「消去する」を選ぶと、古い本体でダウンロードしたソフト、更新データ、追加コンテンツが消えます。

このとき画面写真と動画はカードに残ります。カードをフォーマットすると画面写真と動画も消えます。消去したソフトは、購入時のニンテンドーアカウントを新しい本体のユーザーに連携し、バーチャルゲームカードをセットすると新しい本体でも使えます。

## Switch 2でも同じSDカードを使えますか?

ゲームの保存には使えません。[任天堂(米国)のSwitch 2カード互換の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68425/)の表です。

| カード | Nintendo Switch 2 | Nintendo Switch |
| --- | --- | --- |
| microSD | 使えません。Switchで撮った画面写真・動画の読み込みだけできます | 使えます |
| microSD Express | 使えます。2TBまで。初めて使うときにインターネットでの本体更新が必要 | 使えます。速度は通常のmicroSDと同じ |

同じ案内によると、Switchで使っていたmicroSDをSwitch 2に挿しても、ダウンロード版ソフトとセーブデータの保存・読み込みはできません。microSD Expressのしくみは[microSD Expressとは?](/blog/ja/microsd-express)にまとめました。

## Switchの画面写真をiPhoneに移すには?

USBケーブルでiPhoneに直接移す方法はありません。[任天堂(米国)のUSB転送の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/53664/)によると、パソコンへのUSBコピーはWindowsで使え、iOSのようにMTPに対応していないOSでは使えません。同じ案内は、USBコピーが使えないときはmicroSDカードで移す方法を挙げています。

画面写真をカードにコピーし、カードリーダーでiPhoneにつなぐ方法があります。[Appleの外部ストレージの案内](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)によると、iPhoneはAPFS、Mac OS拡張、exFAT、FAT32、FAT形式を読めます。この記事は、SwitchでフォーマットしたカードをiPhoneで試していません。任天堂はカード内のファイルを変更しないよう案内しているので、写真は移動ではなくコピーにします。つなぎかたは[micro SDをiPhoneで使う方法](/blog/ja/iphone-microsd)と[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)にあります。

## SwitchがSDカードを認識しないときは?

[任天堂(米国)の認識しないときの案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22482/)の手順です。

1. 本体の電源を切り、カードを抜きます。
2. スロットとカードの端子にほこりや異物がないか見ます。汚れがあれば、カードの交換と本体の修理が必要な場合があります。
3. カードがSwitchの対応規格か確かめます。
4. microSDXCなら、カードを挿したまま本体の電源を入れ、本体更新をします。
5. カードをフォーマットします。画面写真と動画は先にパソコンへ移します。
6. それでも認識しなければカードを替えます。複数のカードが読めないなら本体の修理が必要です。

カード側の確認は[microSDが認識しない・フォーマットできないときの確認手順](/blog/ja/sd-card-not-working)にあります。

## Switch SDカードのよくある質問

### Switch SDカードは何TBまで使えますか?

任天堂の案内ではmicroSDXCの2TBまでです。microSDXCを使うには先に本体更新が必要です。

### 通常サイズのSDカードをアダプターで使えますか?

使えません。任天堂は、スロットの大きさの関係でSDカードとminiSDカードはSwitchで使えないと案内しています。

### SDカードをフォーマットするとセーブデータも消えますか?

消えません。セーブデータは本体保存メモリーに保存されています。ダウンロード版ソフトは再ダウンロードできます。

### MacでSwitchのSDカードを新しいカードにコピーしてもいいですか?

任天堂は、Windows以外の環境(Macなど)では正しくコピーできない場合があると案内しています。カードを移すときはWindowsパソコンを使ってください。

### 複数のSDカードを入れ替えて使ってもいいですか?

任天堂は本体1台にカード1枚で使うよう勧めています。複数のカードに分けたソフトは、あとで1枚にまとめられません。容量が足りなくなったら、大きいカードに丸ごとコピーします。
