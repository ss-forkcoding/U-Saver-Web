## 핵심 요약

닌텐도 스위치 SD 카드는 microSD 카드입니다. 스위치, 스위치 Lite, 스위치 OLED 모델은 microSD, microSDHC, microSDXC를 받고, microSDXC는 2TB까지 씁니다. 크기가 큰 SD 카드는 슬롯에 들어가지 않습니다.

카드에는 다운로드 소프트웨어, 업데이트 데이터, 추가 콘텐츠, 화면 사진과 동영상이 저장됩니다. 게임 저장 데이터는 본체 저장 메모리에만 저장되고 카드로 옮길 수 없습니다.

닌텐도 스위치 2는 microSD Express 카드만 게임 저장에 씁니다. 스위치에서 쓰던 일반 microSD를 스위치 2에 넣으면 화면 사진과 동영상만 불러옵니다.

"스위치에 SD 카드를 넣었는데 업데이트하라고 나와요." "카드를 바꾸면 게임을 다시 받아야 하나요?" 스위치에 카드를 처음 넣거나 바꿀 때 자주 나오는 질문입니다. 이 글은 닌텐도 스위치 SD 카드의 규격, 넣는 법, 포맷, 데이터 옮기기를 닌텐도 공식 안내로 확인합니다. 다른 기기의 microSD 사용법은 [마이크로 SD 카드 사용법](/blog/ko/how-to-use-microsd)에 있습니다.

## 닌텐도 스위치 SD 카드는 어떤 걸 써야 하나요?

microSD 계열 카드를 씁니다. [닌텐도 microSD 카드 FAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq) 기준입니다.

| 카드 종류 | 용량 | 스위치에서 |
| --- | --- | --- |
| microSD | 2GB까지 | 쓸 수 있음 |
| microSDHC | 4GB~32GB | 쓸 수 있음 |
| microSDXC | 64GB~2TB | 쓸 수 있음. 먼저 본체 업데이트 필요 |
| SD, miniSD | - | 슬롯 크기가 달라 쓸 수 없음 |

[한국닌텐도의 microSD 카드 안내](https://www.nintendo.co.kr/support/switch/data_management/microsdcard/index.html)도 microSDXC를 쓰려면 인터넷에 접속해 본체를 업데이트해야 한다고 적습니다. 같은 안내는 고속 카드의 기준으로 UHS-I 대응, 읽어 들이는 속도 60~95MB/초를 제시합니다.

[닌텐도 일본 안내](https://support.nintendo.com/jp/switch/data_management/microsdcard/index.html)에 따르면 스위치는 UHS-II 규격을 지원하지 않습니다. UHS-II 카드도 쓸 수는 있지만 UHS-II 속도로 읽지는 않습니다. 속도 표시는 [SD 카드 속도 등급 보는 법](/blog/ko/sd-card-speed-class)에, 버스 방식 차이는 [UHS-I·UHS-II 차이](/blog/ko/uhs-sd-card)에, 용량 규격은 [SDHC·SDXC·SDUC 차이](/blog/ko/sdhc-vs-sdxc)에 정리했습니다. 이 글은 특정 카드를 시험하거나 추천하지 않습니다.

## 스위치 SD 카드에는 무엇이 저장되나요?

게임 저장 데이터를 뺀 소프트웨어 데이터와 화면 사진·동영상이 저장됩니다. [닌텐도 microSD 카드 FAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq)의 목록입니다.

| 데이터 | microSD 카드에 저장 |
| --- | --- |
| 다운로드 소프트웨어 | 됩니다 |
| 소프트웨어 업데이트 데이터 | 됩니다 |
| 추가 콘텐츠(DLC) | 됩니다 |
| 화면 사진, 촬영한 동영상 | 됩니다 |
| 게임 저장 데이터 | 안 됩니다. 본체 저장 메모리에만 저장 |

[한국닌텐도 FAQ](https://nintendo.co.kr/support/switch/qna/view.php?cateType=&no=119&page=1)도 게임 소프트웨어의 저장 데이터는 본체 저장 메모리에 저장되고 microSD 카드에는 저장할 수 없다고 답합니다. 카드를 바꾸거나 포맷해도 게임 진행 기록은 카드와 함께 사라지지 않습니다.

닌텐도 FAQ에 따르면 카드를 넣으면 다운로드 소프트웨어의 기본 저장 위치가 카드로 바뀝니다. 같은 FAQ는 카드 한 장만 쓰기를 권합니다. 여러 카드에 나눠 받은 소프트웨어는 나중에 한 카드로 합칠 수 없습니다.

## 스위치에 microSD 카드는 어떻게 넣나요?

전원을 끄고 넣습니다. [닌텐도의 카드 인식 문제 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22482/)는 카드를 넣거나 뺄 때 항상 본체를 끄라고 적습니다. 켜진 상태나 절전 모드에서 넣거나 빼면 재시작하라는 안내가 뜹니다.

1. POWER 버튼을 3초 이상 누르고, 전원 옵션에서 전원을 끕니다.
2. 모델에 맞는 슬롯을 엽니다. 아래 표를 봅니다.
3. 카드 라벨 방향을 확인하고 딸깍 소리가 날 때까지 밀어 넣습니다.
4. 본체를 켭니다. microSDXC 카드라면 화면 안내에 따라 본체를 업데이트합니다.

| 모델 | 슬롯 위치 |
| --- | --- |
| Nintendo Switch | 본체 뒷면 스탠드를 열면 있음 |
| Nintendo Switch OLED 모델 | 본체 뒷면의 각도 조절 스탠드를 열면 있음 |
| Nintendo Switch Lite | 본체 아래쪽의 슬롯 커버를 열면 있음 |

슬롯 위치는 닌텐도 일본 안내 기준입니다. 뺄 때는 전원을 끈 뒤 카드를 한 번 눌렀다가 꺼냅니다.

## 스위치 SD 카드는 어떻게 포맷하나요?

본체 설정에서 포맷합니다. [한국닌텐도 포맷 FAQ](https://www.nintendo.co.kr/support/switch/qna/58)에 따르면 시스템 버전 2.0.0 이후 본체에서 포맷할 수 있습니다.

1. HOME 메뉴에서 설정을 고릅니다.
2. 시스템 > 초기화를 고릅니다. 보호자 설정을 했다면 PIN을 입력합니다.
3. microSD 카드 포맷을 고르고 화면 안내에 따라 진행합니다.
4. 마지막 확인 화면에서 포맷을 고르면 본체가 다시 시작됩니다.

포맷하면 카드의 소프트웨어 데이터, 화면 사진·동영상, 다른 기기에서 저장한 데이터가 모두 지워집니다. [닌텐도 카드 인식 문제 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22482/)는 지운 데이터를 되돌릴 수 없으니 화면 사진과 동영상을 먼저 컴퓨터에 옮기라고 적습니다. 다운로드 소프트웨어는 구매한 닌텐도 어카운트로 다시 받을 수 있습니다.

컴퓨터에서 카드를 포맷하는 방법은 [마이크로 SD 카드 포맷 방법](/blog/ko/format-microsd)에 있습니다. 스위치용 카드는 본체에서 포맷하는 편이 닌텐도 안내와 맞습니다.

## 본체 저장 메모리의 게임을 SD 카드로 옮길 수 있나요?

옮길 수 있습니다. [닌텐도의 데이터 이동 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/49231/)의 순서입니다. 닌텐도 FAQ는 시스템 버전 10.0.0 이상에서 다운로드 소프트웨어를 옮길 수 있다고 적습니다.

1. HOME 메뉴에서 설정을 고릅니다.
2. 데이터 관리를 고릅니다.
3. 본체와 microSD 카드 사이의 데이터 이동 메뉴를 고릅니다. 영문 메뉴 이름은 Move Data Between System / microSD Card입니다.
4. 옮길 소프트웨어를 고르고 확인을 누릅니다.

저장 데이터와 일부 업데이트 데이터는 옮겨지지 않습니다. 같은 안내는 이 기능이 설치 위치를 정하는 기능이 아니라고 적습니다. 옮긴 뒤에 게임을 계속하면 업데이트 데이터가 고르지 않은 위치에 저장될 수 있습니다.

화면 사진과 동영상은 복사합니다. [한국닌텐도 FAQ](https://www.nintendo.co.kr/support/switch/qna/134)에 따르면 설정 > 데이터 관리 > 저장 데이터/화면 사진 및 동영상 관리 > 화면 사진 및 동영상 관리에서 카드와 본체 사이에 복사합니다. HOME 메뉴의 앨범에서도 복사할 수 있습니다.

## 더 큰 SD 카드로 바꾸려면 어떻게 하나요?

Windows 컴퓨터로 카드 내용을 통째로 옮깁니다. [닌텐도의 카드 간 데이터 이동 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/27595/) 순서입니다.

1. 본체 전원을 끄고 기존 카드를 뺍니다.
2. 기존 카드를 컴퓨터의 카드 슬롯이나 카드 리더기에 넣습니다.
3. Windows 탐색기에서 카드를 열고 폴더 전체를 바탕화면으로 끌어 옵니다.
4. 새 카드를 닌텐도 안내대로 포맷합니다.
5. 바탕화면의 폴더를 새 카드로 끌어 옮깁니다.
6. 새 카드를 스위치에 넣고 동작을 확인합니다.

| 주의할 점 | 닌텐도 안내 |
| --- | --- |
| 운영체제 | Mac 등 Windows 이외 환경에서는 제대로 복사되지 않을 수 있습니다 |
| 폴더 | 항상 폴더 전체를 복사하고, 안의 파일을 고치거나 지우지 않습니다 |
| 기존 카드 | 새 카드가 정상 동작하는지 확인하기 전에는 지우거나 포맷하지 않습니다 |
| 읽히지 않는 소프트웨어 | 닌텐도 e숍에서 다시 받습니다 |

컴퓨터에 카드를 연결하는 방법은 [SD 카드 컴퓨터 연결 방법](/blog/ko/sd-card-to-pc)에 있습니다. 새 카드의 실제 용량이 의심되면 [가짜 SD 카드 구별법](/blog/ko/fake-sd-card)으로 먼저 확인하세요.

## 다른 스위치에서 쓰던 SD 카드를 넣으면 어떻게 되나요?

카드의 소프트웨어 데이터를 지워야 씁니다. [닌텐도 일본 안내](https://support.nintendo.com/jp/switch/data_management/microsdcard/index.html)에 따르면 다른 본체에서 쓰던 카드를 넣으면 지우라는 화면이 나옵니다. 지우기를 고르면 이전 본체에서 받은 다운로드 소프트웨어, 업데이트 데이터, 추가 콘텐츠가 지워집니다.

이때 화면 사진과 동영상은 카드에 남습니다. 카드를 포맷하면 화면 사진과 동영상도 지워집니다. [닌텐도 카드 간 이동 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/27595/)도 한 본체에서 받은 소프트웨어는 다른 본체에서 실행되지 않는다고 적습니다.

## 스위치 2에서도 같은 SD 카드를 쓸 수 있나요?

게임 저장에는 쓸 수 없습니다. [닌텐도의 스위치 2 카드 호환 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68425/)의 표입니다.

| 카드 | Nintendo Switch 2 | Nintendo Switch |
| --- | --- | --- |
| microSD | 쓸 수 없음. 스위치에서 찍은 화면 사진·동영상 불러오기만 가능 | 쓸 수 있음 |
| microSD Express | 쓸 수 있음. 2TB까지, 처음 쓸 때 인터넷 업데이트 필요 | 쓸 수 있음. 속도는 일반 microSD와 같음 |

같은 안내는 스위치에서 쓰던 microSD를 스위치 2에 넣으면 다운로드 게임과 저장 데이터를 저장하거나 불러올 수 없다고 적습니다. microSD Express의 구조는 [microSD Express란?](/blog/ko/microsd-express)에 정리했습니다.

## 스위치 화면 사진을 아이폰으로 옮기려면?

USB 케이블로 아이폰에 바로 옮기는 방법은 없습니다. [닌텐도의 USB 전송 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/53664/)에 따르면 컴퓨터로 복사 기능은 Windows에서 쓰고, iOS처럼 MTP를 지원하지 않는 운영체제에서는 쓸 수 없습니다. 같은 안내는 이 기능을 쓸 수 없으면 microSD 카드로 옮기라고 적습니다.

화면 사진을 카드에 복사한 뒤 카드 리더기로 아이폰에 연결하는 방법이 있습니다. [Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)에 따르면 아이폰은 APFS, macOS 확장, exFAT, FAT32, FAT 형식을 읽습니다. 이 글은 스위치가 포맷한 카드를 아이폰에서 시험하지 않았습니다. 카드 안의 파일을 고치거나 지우면 닌텐도 안내에 어긋나니 사진은 복사만 합니다. 연결 순서는 [아이폰 마이크로 SD 쓰는 법](/blog/ko/iphone-microsd)과 [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader)에 있습니다.

## 스위치가 SD 카드를 인식하지 못하면?

[닌텐도 카드 인식 문제 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22482/)의 순서입니다.

1. 본체 전원을 끄고 카드를 뺍니다.
2. 슬롯과 카드 단자에 먼지나 이물질이 있는지 봅니다. 오염이 보이면 카드 교체와 본체 수리가 필요할 수 있습니다.
3. 카드가 스위치 지원 규격인지 확인합니다.
4. microSDXC 카드라면 카드를 넣은 채로 본체를 켜고 시스템 업데이트를 합니다.
5. 카드를 포맷합니다. 화면 사진과 동영상은 먼저 컴퓨터에 옮깁니다.
6. 그래도 안 되면 카드를 바꿉니다. 여러 카드가 모두 읽히지 않으면 본체 수리가 필요합니다.

카드 자체를 점검하는 순서는 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)에 있습니다.

## 닌텐도 스위치 SD 카드 자주 묻는 질문

### 닌텐도 스위치 SD 카드는 몇 TB까지 되나요?

닌텐도 FAQ 기준 microSDXC 2TB까지입니다. microSDXC를 쓰려면 먼저 본체를 업데이트해야 합니다.

### 일반 SD 카드를 어댑터로 넣을 수 있나요?

안 됩니다. 닌텐도는 슬롯 크기 때문에 SD 카드와 miniSD 카드는 스위치와 호환되지 않는다고 안내합니다.

### SD 카드를 포맷하면 게임 진행 기록도 지워지나요?

지워지지 않습니다. 게임 저장 데이터는 본체 저장 메모리에 저장됩니다. 카드의 다운로드 소프트웨어는 구매한 닌텐도 어카운트로 다시 받을 수 있습니다.

### Mac으로 스위치 SD 카드를 새 카드에 복사해도 되나요?

닌텐도는 Mac 등 Windows 이외 환경에서 카드 내용이 제대로 복사되지 않을 수 있다고 안내합니다. 카드를 옮길 때는 Windows 컴퓨터를 쓰세요.

### SD 카드를 여러 장 번갈아 써도 되나요?

닌텐도는 본체 하나에 카드 한 장을 쓰라고 안내합니다. 여러 카드에 나눠 받은 소프트웨어는 나중에 한 카드로 합칠 수 없습니다. 용량이 부족하면 더 큰 카드로 통째로 옮깁니다.
