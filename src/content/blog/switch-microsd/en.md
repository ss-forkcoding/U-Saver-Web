## Key takeaways

A Nintendo Switch micro SD card can be a microSD, microSDHC, or microSDXC card. The Switch, Switch Lite, and Switch OLED Model accept microSDXC cards up to 2 TB. Full-size SD cards don't fit the slot.

The card holds downloadable software, update data, downloadable content (DLC), and screenshots and videos. Game save data stays in the system memory and can't be copied to the card.

The Nintendo Switch 2 takes only microSD Express cards for games. A regular microSD card from a Switch can only load screenshots and videos on a Switch 2.

"I put the card in and it says I need a system update." "If I switch cards, do I have to download my games again?" These are the questions people ask the first time they add or replace a card. This guide covers which Nintendo Switch micro SD card works, how to insert and format it, and how to move your data, using Nintendo's own support pages. For other devices, see [how do I use a micro SD card?](/blog/en/how-to-use-microsd)

## Which Nintendo Switch micro SD card should I use?

Use a card from the microSD family. This table follows the [Nintendo microSD Card FAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq).

| Card type | Capacity | On a Switch |
| --- | --- | --- |
| microSD | Up to 2 GB | Supported |
| microSDHC | 4 GB–32 GB | Supported |
| microSDXC | 64 GB–2 TB | Supported after a system update |
| SD, miniSD | - | Not compatible because of the slot size |

For better gameplay, the same FAQ suggests a UHS-I card with a transfer speed of 60–95 MB/s. [Nintendo Japan's microSD page](https://support.nintendo.com/jp/switch/data_management/microsdcard/index.html) adds that the Switch doesn't support the UHS-II standard. A UHS-II card still works, but not at UHS-II speed.

Speed markings are explained in [SD card speed classes](/blog/en/sd-card-speed-class), bus types in [UHS-I vs UHS-II vs SD Express](/blog/en/uhs-sd-card), and capacity standards in [SDHC vs SDXC vs SDUC](/blog/en/sdhc-vs-sdxc). This guide hasn't tested any card and doesn't recommend one.

## What does a Switch store on the micro SD card?

Everything except game save data. This list comes from the [Nintendo microSD Card FAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq).

| Data | Saved to the microSD card |
| --- | --- |
| Downloadable software | Yes |
| Software update data | Yes |
| Downloadable content (DLC) | Yes |
| Screenshots and captured videos | Yes |
| Game save data | No. Stored in the system memory only |

Because save data stays on the console, swapping or formatting the card doesn't take your game progress with it.

According to the FAQ, an inserted card becomes the default save location for downloadable software. Nintendo recommends using a single card with your console. Software saved across several cards can't be combined onto one card later.

## How do I insert a micro SD card into a Switch?

Turn the console off first. [Nintendo's page on cards that aren't recognized](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22482/) says to always shut off the console before inserting or removing a card. If you do it while the console is on or in sleep mode, you'll be asked to restart.

1. Hold the POWER Button for at least three seconds, select Power Options, then Turn Off.
2. Open the slot for your model (see the table below).
3. Check which way the card faces, then push it in until it clicks.
4. Turn the console on. For a microSDXC card, follow the on-screen prompt to update the system.

| Model | Where the slot is |
| --- | --- |
| Nintendo Switch | Behind the stand |
| Nintendo Switch OLED Model | Behind the adjustable stand |
| Nintendo Switch Lite | Under the slot cover |

To remove the card, turn the console off, push down gently on the card until it clicks, then slide it out.

## How do I format a Switch micro SD card?

Format it in System Settings. These steps follow the same [Nintendo page](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22482/).

1. From the HOME Menu, select System Settings.
2. Select System, then Formatting Options. Enter your Parental Controls PIN if asked.
3. Select Format microSD Card, then Continue.
4. Select Format. The console restarts.

Nintendo warns that formatted data can't be brought back. Copy screenshots and videos to a computer first. Downloadable software can be downloaded again with the Nintendo Account that bought it. Save data is in the system memory, so formatting doesn't touch it.

To format a card on a computer instead, see [how to format a micro SD card](/blog/en/format-microsd). For a card you'll use in a Switch, formatting it on the console matches Nintendo's instructions.

## Can I move games from the system memory to the SD card?

Yes. Nintendo's FAQ says downloadable software can be moved on system version 10.0.0 or later. These steps follow [Nintendo's data move guide](https://en-americas-support.nintendo.com/app/answers/detail/a_id/49231/).

1. From the HOME Menu, select System Settings.
2. Select Data Management.
3. Select Move Data Between System / microSD Card.
4. Choose the data to move, then select OK.

Save data and some update data can't be moved. The same guide says this isn't a way to choose where data installs. If you keep playing after the move, update data may be saved to the location you didn't pick.

Screenshots and videos are copied instead. Go to System Settings > Data Management > Manage Screenshots and Videos. With a card inserted, [Nintendo's screenshot guide](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22409/) lets you set the save location and copy everything between the system memory and the card.

## How do I move to a bigger micro SD card?

Copy the whole card with a Windows PC. These steps follow [Nintendo's guide to transferring data between microSD cards](https://en-americas-support.nintendo.com/app/answers/detail/a_id/27595/).

1. Turn off the console and remove the original card.
2. Put it in your PC's card slot or a card reader.
3. Open the card in Windows Explorer and drag the entire folder to the desktop.
4. Format the new card as Nintendo recommends.
5. Drag the folder from the desktop to the new card.
6. Insert the new card into the Switch and check that it works.

| Watch out for | What Nintendo says |
| --- | --- |
| Operating system | The copy may not work correctly outside Windows, such as on a Mac |
| The folder | Always copy the entire folder; never alter or erase the files inside |
| The original card | Don't delete, format, or change it until the new card works |
| Software that won't load | Download it again from Nintendo eShop |

Connecting a card to a computer is covered in [SD card reader for PC](/blog/en/sd-card-to-pc). If you doubt the new card's real capacity, check it first with [how to spot a fake SD card](/blog/en/fake-sd-card).

## What happens if I use a card from another Switch?

You have to erase its software data first. According to [Nintendo Japan's microSD page](https://support.nintendo.com/jp/switch/data_management/microsdcard/index.html), a card from another console brings up an erase screen. Erasing removes the downloadable software, update data, and DLC from the old console.

Screenshots and videos stay on the card after that erase. Formatting the card removes them too. Nintendo's [card-to-card guide](https://en-americas-support.nintendo.com/app/answers/detail/a_id/27595/) also says software downloaded on one system won't play on a different system.

## Can I use the same micro SD card in a Switch 2?

Not for games. This table comes from [Nintendo's Switch 2 card compatibility page](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68425/).

| Card | Nintendo Switch 2 | Nintendo Switch |
| --- | --- | --- |
| microSD | No. Can only load Switch screenshots and videos | Yes |
| microSD Express | Yes. Up to 2 TB; needs an internet system update the first time | Yes, at the same speed as a microSD card |

The same page says a microSD card used on a Switch won't let a Switch 2 save or load digital games or save data. How microSD Express works is covered in [what is microSD Express?](/blog/en/microsd-express)

## How do I get Switch screenshots onto an iPhone?

There's no USB cable route straight to an iPhone. [Nintendo's USB transfer guide](https://en-americas-support.nintendo.com/app/answers/detail/a_id/53664/) says Copy to a Computer via USB Connection works with Windows, but not with systems that don't support MTP, such as iOS. The same guide suggests using a microSD card if the USB option doesn't work for you.

You can copy screenshots to the card, then connect the card to an iPhone with a card reader. [Apple's external storage guide](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios) says an iPhone reads APFS, Mac OS Extended, exFAT, FAT32, and FAT. This guide hasn't tested a Switch-formatted card on an iPhone. Nintendo says not to alter files on the card, so copy the photos rather than moving them. For the steps, see [micro SD for iPhone](/blog/en/iphone-microsd) and [iPhone SD card reader](/blog/en/iphone-sd-card-reader).

## What if my Switch doesn't recognize the micro SD card?

These steps follow [Nintendo's troubleshooting page](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22482/).

1. Turn off the console and remove the card.
2. Check the slot and the card's contacts for dirt or debris. If you see any, the card may need replacing and the console may need service.
3. Confirm the card is a type the Switch supports.
4. For a microSDXC card, reinsert it, turn on the console, and run a system update.
5. Format the card. Copy screenshots and videos to a computer first.
6. Replace the card if it still isn't detected. If several cards fail, the console needs service.

More card checks are in [SD card not working](/blog/en/sd-card-not-working).

## Nintendo Switch micro SD card FAQ

### What's the largest Nintendo Switch micro SD card?

Nintendo's FAQ lists microSDXC up to 2 TB. You need a system update before the Switch can use a microSDXC card.

### Can I use a full-size SD card with an adapter?

No. Nintendo says SD and miniSD cards aren't compatible with the Switch because of the slot size.

### Does formatting the SD card delete my game progress?

No. Save data is stored in the system memory. Downloadable software can be downloaded again with the Nintendo Account that bought it.

### Can I copy my Switch card to a new one on a Mac?

Nintendo says the copy may not work correctly outside Windows, such as on a Mac. Use a Windows PC for the move.

### Can I swap between several micro SD cards?

Nintendo recommends one card per console. Software saved across several cards can't be combined later. If you run out of space, copy everything to a larger card.
