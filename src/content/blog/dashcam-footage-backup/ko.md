## 핵심 요약

블랙박스 SD 카드 복구를 찾는 경우는 대개 필요한 영상이 덮어쓰였거나 카드가 읽히지 않을 때입니다. 블랙박스는 카드가 차면 저장하지 않은 오래된 영상부터 지웁니다. 그래서 필요한 영상은 먼저 저장하고, 카드에서 다른 곳으로 복사합니다.

영상이 안 보이면 그 카드로 더 녹화하지 않습니다. 포맷하라는 창이 떠도 포맷하지 않습니다. 읽히는 파일부터 복사합니다.

지운 영상을 되살리는 방법은 SD Association도 카드 제조사 안내를 보라고 답합니다. 이 글은 복구 프로그램을 추천하거나 시험하지 않았고, 복구 결과를 약속하지 않습니다.

"사고 영상을 남기고 싶은데 어떻게 꺼내나요?" "어제 영상이 카드에 없어요." 이 글은 블랙박스 영상이 사라지는 이유와 꺼내는 순서를 다룹니다. 카드를 고르고 포맷하는 법은 [블랙박스 SD 카드 고르는 법과 관리](/blog/ko/dashcam-sd-card)에 정리했습니다. 아래 기종은 설명서를 읽는 예로만 씁니다.

## 블랙박스 영상은 왜 사라지나요?

블랙박스는 시동을 켜면 녹화를 시작하고 카드가 차면 덮어씁니다. 영상이 사라지는 경우는 아래 네 가지입니다.

| 경우 | 무슨 일이 생기나요 | 근거 |
| --- | --- | --- |
| 카드가 꽉 참 | 저장하지 않은 영상 중 가장 오래된 것을 자동으로 지웁니다 | [Garmin 설명서](https://www8.garmin.com/manuals/webhelp/dashcam45-55/EN-US/GUID-39BB7445-FF9C-4CC2-89AF-07311CAF07C9.html) |
| 저장하지 않은 영상 즉시 삭제 설정 | 3분이 지난 미저장 영상을 계속 지우고, 전원을 끌 때마다 미저장 영상을 모두 지웁니다 | [Garmin 46/56/66W 카메라 설정](https://www8.garmin.com/manuals/webhelp/dashcam46-56-66w/EN-US/GUID-59420DC0-4EBA-400F-9B2F-0DBD0C3FC266.html) |
| 카드 포맷 | 카드의 영상이 모두 지워집니다. 잠근 이벤트 영상도 지워집니다 | [BlackVue 설명서](https://manual.blackvue.com/docs/dr770x-series-ii/system-updates-and-sd-card-maintenance/formatting-the-microsd-card-2/) |
| 카드 이상 | 녹화 중으로 보여도 영상이 기록되지 않을 수 있습니다 | [일본 국민생활센터](https://www.kokusen.go.jp/news/data/n-20180802_2.html) |

Garmin은 즉시 삭제 설정이 일부 지역에서만 있고, 일부 지역에서는 기본으로 켜져 있다고 적습니다. 내 블랙박스 설정에서 미저장 영상을 언제 지우는지 확인합니다.

국민생활센터 시험에서는 읽고 쓸 수 없는 카드를 넣었을 때 3개 제품이 이상을 감지하지 못했습니다. 센터는 이 결과가 특정 조건의 예라고 밝히며, 녹화된 영상을 정기적으로 확인하라고 권합니다.

## 필요한 영상을 덮어쓰기에서 지키려면?

영상을 "저장"하면 덮어쓰기를 피할 수 있습니다. Garmin 설명서는 저장한 영상은 덮어쓰거나 지우지 않는다고 적습니다. 저장 방법은 기종마다 다르니 설명서를 봅니다. Garmin과 BlackVue 설명서가 적은 방식은 아래와 같습니다.

| 방식 | Garmin 46/56/66W | BlackVue DR770X Series II |
| --- | --- | --- |
| 충격 감지 자동 저장 | 감지 전·중·후 영상을 저장합니다 | 이벤트 녹화는 감지 5초 전부터 저장합니다 |
| 직접 저장 | 버튼을 길게 누르면 누른 시점 전·중·후 영상을 저장합니다 | 터치 센서를 켜 두면 센서를 눌러 수동 녹화합니다 |
| 지나간 영상 저장 | 갤러리 > 저장하지 않은 영상에서 구간을 골라 저장합니다 | 설명서에서 확인하지 못했습니다 |

Garmin 내용은 [Garmin 46/56/66W 사용 설명서(PDF)](https://www8.garmin.com/manuals/webhelp/dashcam46-56-66w/EN-US/Dash_Cam_46-56-66W_OM_EN-US.pdf), BlackVue 내용은 [BlackVue 앱 사용 안내](https://manual.blackvue.com/docs/dr770x-series-ii/viewing-and-managing-videos/%f0%9f%93%b1-using-the-blackvue-app-3/) 기준입니다.

저장한 영상도 카드 안에 있습니다. Garmin 설명서는 카드 용량이 한정되어 있으니 저장한 영상을 컴퓨터나 스마트폰으로 옮기라고 적습니다. 같은 설명서는 영상이나 사진을 보는 동안 녹화가 멈춘다고 적습니다. 운전 중에는 갤러리를 열지 않습니다.

## 블랙박스 영상은 어떻게 꺼내나요?

꺼내는 방법은 세 가지입니다. 내 블랙박스가 지원하는 방법을 설명서에서 확인합니다.

| 방법 | 이럴 때 씁니다 | 설명서 예 |
| --- | --- | --- |
| 카드를 빼서 컴퓨터에 연결 | 영상을 한꺼번에 옮길 때 | Garmin은 카드나 본체를 컴퓨터에 연결해 영상을 옮긴다고 적습니다 |
| 블랙박스를 데이터 케이블로 컴퓨터에 연결 | 카드를 빼기 어려울 때 | Garmin 46/56/66W는 동봉된 짧은 데이터 케이블을 쓰고, 긴 전원 케이블로는 연결할 수 없다고 적습니다 |
| 제조사 앱으로 스마트폰에 받기 | 한두 개 영상만 옮길 때 | BlackVue 앱은 블랙박스 Wi-Fi에 연결한 뒤 "Download to my device"로 받습니다 |

데이터 케이블 내용은 [Garmin의 컴퓨터 연결 안내](https://www8.garmin.com/manuals/webhelp/dashcam46-56-66w/EN-US/GUID-8839611D-E8FB-4848-9289-E1AC71DD302A.html)에 있습니다. 연결하면 컴퓨터에 이동식 드라이브로 나타납니다.

## 컴퓨터로 블랙박스 영상을 옮기는 순서

[Garmin 46/56/66W 안내](https://www8.garmin.com/manuals/webhelp/dashcam46-56-66w/EN-US/GUID-E75CB7BE-ACAB-4427-A608-A4D9F919A911.html)에 따르면 영상은 카드의 DCIM 폴더에 MP4 파일로 저장됩니다. 이 기종을 예로 든 순서입니다.

1. 카드를 리더기에 넣어 컴퓨터에 연결하거나, 데이터 케이블로 블랙박스를 연결합니다.
2. 윈도우 파일 탐색기나 Mac Finder에서 카드 드라이브를 엽니다.
3. DCIM 폴더에서 필요한 폴더를 찾습니다. Garmin 기종은 100EVENT(충격 감지), 102SAVED(직접 저장), 103PARKM(주차 중), 105UNSVD(미저장)로 나눕니다.
4. 영상 파일을 컴퓨터 폴더로 복사합니다. 카드 안에서 파일을 옮기거나 지우지 않습니다.
5. 복사한 영상을 컴퓨터에서 재생해 봅니다.
6. 카드를 꺼내기로 분리한 뒤 뺍니다.

폴더 이름은 기종마다 다릅니다. Garmin은 일부 플레이어가 고해상도 재생을 지원하지 않을 수 있다고 적습니다. 재생되지 않으면 제조사 뷰어나 다른 플레이어로 확인합니다.

[Microsoft 안내](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)는 데이터 손실을 막으려면 USB 장치를 빼기 전에 항상 안전 제거를 하라고 적습니다. 카드 연결과 안전 제거 순서는 [SD 카드 컴퓨터 연결 방법](/blog/ko/sd-card-to-pc)과 [Mac SD 카드 사용법](/blog/ko/sd-card-on-mac)에 있습니다.

## 블랙박스 SD 카드 복구가 필요해 보이면 무엇부터 하나요?

카드에 남은 영상을 더 잃지 않는 것이 먼저입니다. 아래 순서로 확인합니다.

1. 그 카드로 더 녹화하지 않습니다. 블랙박스는 카드가 차면 미저장 영상을 덮어씁니다.
2. 카드를 컴퓨터에 연결해 읽히는 파일부터 다른 저장장치로 복사합니다.
3. 컴퓨터가 포맷하라는 창을 띄워도 포맷하지 않습니다. 포맷하면 영상이 모두 지워집니다.
4. 카드가 인식되지 않으면 리더기, 단자, SD 어댑터의 잠금 스위치를 점검합니다. 점검 순서는 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)에 있습니다.
5. 지운 파일을 되살리려면 카드 제조사 안내를 봅니다.

[SD Association FAQ](https://www.sdcard.org/consumers/faq/)는 지운 사진을 되찾는 방법은 카드 제조사 안내를 보라고 답하고, SD Association은 복구 도구를 제공하지 않는다고 적습니다. 이미 덮어쓰인 영상이나 즉시 삭제 설정으로 지워진 영상은 되찾지 못할 수 있습니다. 사고 영상처럼 중요한 자료라면 카드를 그대로 보관하고 블랙박스·카드 제조사 고객센터에 먼저 문의합니다.

## 옮긴 영상은 어디에 보관하나요?

블랙박스 카드는 다시 덮어쓰이고, 국민생활센터는 SD 카드를 소모품이라고 적습니다. 남길 영상은 카드 밖에 둡니다.

| 보관 위치 | 확인할 것 |
| --- | --- |
| 컴퓨터 폴더 | 날짜와 상황을 폴더 이름에 적어 둡니다 |
| 외부 저장장치(USB 메모리 등) | 컴퓨터가 고장 나도 남도록 한 곳에 더 복사합니다 |
| 스마트폰 | 앱으로 받은 영상은 사진 보관함이나 앱 안 목록에 있습니다(BlackVue 앱 기준) |

카드를 블랙박스에 다시 넣기 전에 복사한 영상이 재생되는지 확인합니다. 카드 포맷 주기와 방법은 [블랙박스 SD 카드 고르는 법과 관리](/blog/ko/dashcam-sd-card)와 [마이크로 SD 카드 포맷 방법](/blog/ko/format-microsd)에 있습니다.

## 아이폰으로 블랙박스 영상을 옮기려면?

아이폰에는 카드 슬롯이 없어 SD 카드 리더기로 연결합니다. [Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)에 따르면 저장장치는 데이터 파티션이 하나여야 하고 exFAT, FAT32 같은 형식이어야 합니다. 파일 앱의 둘러보기에서 위치 아래 카드 이름을 누르면 파일을 봅니다.

| 하려는 일 | 읽을 글 |
| --- | --- |
| microSD를 아이폰에 연결 | [아이폰 마이크로 SD 쓰는 법](/blog/ko/iphone-microsd) |
| 리더기로 파일 복사 | [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader) |
| 옮긴 영상을 USB 메모리에 따로 보관 | [아이폰 동영상 옮기기](/blog/ko/iphone-videos-to-usb) |

## 블랙박스 SD 카드 복구 자주 묻는 질문

### 덮어쓰인 블랙박스 영상을 되살릴 수 있나요?

이 글은 그 방법을 확인하지 못했습니다. SD Association은 지운 파일을 되찾는 방법을 카드 제조사 안내에서 보라고 답합니다. 중요한 영상이면 카드를 더 쓰지 말고 제조사에 문의합니다.

### 이벤트 영상은 포맷해도 남나요?

남지 않습니다. BlackVue 설명서는 포맷하면 잠근 이벤트 영상도 지워진다고 적습니다. 포맷 전에 컴퓨터로 복사합니다.

### 시동을 끄면 영상이 지워지나요?

기본 설정에서는 카드가 찰 때 오래된 미저장 영상을 지웁니다. Garmin의 즉시 삭제 설정을 켜면 전원을 끌 때마다 미저장 영상을 모두 지웁니다. 내 블랙박스 설정을 확인합니다.

### 블랙박스 화면에서 영상을 봐도 되나요?

Garmin 설명서는 영상을 보는 동안 녹화가 멈춘다고 적습니다. 정차한 뒤에 보고, 보고 나면 녹화가 다시 시작되는지 확인합니다.

### 카드를 컴퓨터에 꽂았더니 포맷하라고 나와요.

포맷하지 않습니다. 포맷하면 카드의 영상이 지워집니다. 먼저 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)의 점검 순서를 따릅니다.
