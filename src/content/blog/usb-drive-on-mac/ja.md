## この記事の要点

MacでUSBメモリを使う手順は4ステップです。合う端子に挿し、許可を求める通知が出たら許可し、Finderでファイルをコピーし、取り出してから抜きます。

Appleシリコン搭載のMacノートブックは、新しいUSBアクセサリをつなぐと接続の許可を求めます。「許可しない」を選ぶと、MacはUSBメモリを認識しません。

WindowsパソコンやiPhoneでも使うUSBメモリは、exFATかFAT32でフォーマットします。APFSはMac用の形式です。FAT32は4GBを超えるファイルを保存できません。

「MacBookにUSBメモリを挿したのに何も起きない」「ディスクを取り出せないと出る」。この記事では、MacでUSBメモリを使う手順だけを扱います。Windowsパソコンもあわせて知りたい方は、[USBメモリの使い方](/blog/ja/usb-flash-drive-basics)を読んでください。

## Macにはどの端子とアダプターが必要ですか?

USBメモリの端子とMacのポートを照らし合わせます。ポートの種類は[AppleのMacのポートの案内](https://support.apple.com/en-us/109523)で確かめます。

| USBメモリの端子 | Macのポート | すること |
| --- | --- | --- |
| USB-C | USB-CまたはThunderbolt(USB-C) | そのまま挿します |
| USB-A | USB-A | そのまま挿します |
| USB-A | USB-CかThunderbolt(USB-C)しかない | USB-C - USBアダプターを使います |

[AppleのUSB-Cケーブルの案内](https://support.apple.com/guide/mac-help/use-usb-c-cables-mchl447b9239/mac)は、USB-C - USBアダプターをUSBメモリなどの一般的なUSB機器向けとして紹介しています。[Appleのストレージデバイス接続の案内](https://support.apple.com/guide/mac-help/connect-storage-devices-mac-mchl027f1d66/mac)も、ケーブルがポートに合わなければアダプターを使える場合があると説明しています。この記事では特定の製品をすすめません。

## MacがUSBメモリの接続を許可するよう求めるのはなぜですか?

[Appleの案内](https://support.apple.com/en-us/102282)によると、Appleシリコン搭載のMacノートブックは、新しいか不明なUSBアクセサリ、Thunderboltアクセサリ、SDカードをつなぐと、接続の許可を求める通知を出します。

| 状況 | 結果 |
| --- | --- |
| 「許可」を選ぶ | MacがUSBメモリを認識します |
| 「許可しない」を選ぶ | Macは認識しません。次につないだときにもう一度たずねます |
| Macがロックされている | ロックを解除しないと許可できません |
| Macが3日以上ロックされていた | 以前に許可したアクセサリも、ロックを解除しないと使えない場合があります |

設定を変えるには、アップルメニュー > システム設定 > プライバシーとセキュリティ > アクセサリへ進みます。「アクセサリの接続を許可」の初期設定は「新しいアクセサリの場合は確認」です。ほかに「常に確認」「ロック解除時に自動的に許可」「常に許可」を選べます。

## MacでUSBメモリにファイルをコピーする手順は?

[Appleのストレージデバイス接続の案内](https://support.apple.com/guide/mac-help/connect-storage-devices-mac-mchl027f1d66/mac)に沿った手順です。

1. USBメモリをMacに挿します。許可を求める通知が出たら許可します。
2. DockのFinderアイコンをクリックして、Finderウインドウを開きます。
3. USBメモリに移すときは、デスクトップやフォルダでファイルを選び、Finderサイドバーの「場所」の下にあるUSBメモリへドラッグします。
4. Macに移すときは、「場所」の下のUSBメモリを選び、ファイルをMacのフォルダへドラッグします。
5. コピーが終わったらUSBメモリを取り出してから抜きます。

アクセス権のためにUSBメモリのファイルが開けないときは、管理者として認証するか、ファイルの「共有とアクセス権」を変えるようAppleは案内しています。管理者でなければ、管理者にアクセス権を頼みます。

## MacでUSBメモリを取り出す方法は?

Appleは同じ案内で3つの方法を挙げています。

| 場所 | 取り出し方 |
| --- | --- |
| Finderのメニュー | USBメモリを選び、「ファイル」>「取り出す」を選びます |
| Finderのサイドバー | USBメモリの名前の横にある取り出しボタンをクリックします |
| デスクトップ | USBメモリのアイコンをゴミ箱にドラッグします |

コピーが終わるまで待ってから取り出し、その後で抜きます。

## 「ディスクを取り出せません」と出たらどうしますか?

[Appleの案内](https://support.apple.com/guide/mac-help/eject-a-disk-mac-app-mh27076/mac)によると、アプリがディスクを使っていると取り出せないことがあります。

1. 警告の文面を読みます。ディスクを使っているアプリの名前が出ることがあります。
2. Command-Tabを押して、開いているアプリを確かめます。
3. ディスクを使っているアプリを終了し、もう一度取り出します。
4. アプリを終了できないときは、USBメモリ上の書類を閉じてから取り出します。

同じMacの別のユーザーがUSBメモリを使っているときは、[Appleの別のユーザーが使っているディスクの案内](https://support.apple.com/guide/mac-help/eject-a-disk-user-mac-mh27077/mac)に従ってください。

## USBメモリがMacに表示されないときは何を確認しますか?

| 症状 | 確認すること |
| --- | --- |
| 挿しても何も起きない | 許可を求める通知が出ていないか確かめます。「許可しない」を選んだなら、抜いてからつなぎ直します |
| Finderのサイドバーにない | Finder > 設定の「一般」と「サイドバー」タブで外部ディスクの表示をオンにします |
| アダプターやハブを通すとつながらない | USBメモリかアダプターをMacに直接挿します |
| ファイルがコピーできない、開けない | ディスクユーティリティのFirst Aidで検査します |
| 4GBを超えるファイルだけコピーできない | USBメモリがFAT32か確かめます。大きなファイルはexFATのUSBメモリに保存します |

Finderの設定は[Appleの接続されたデバイスを表示する案内](https://support.apple.com/guide/mac-help/see-the-devices-connected-to-your-mac-mchlp1039/mac)にあります。

## USBメモリにFirst Aidをかけるには?

[Appleのストレージデバイス修復の案内](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac)によると、First Aidはストレージデバイスのフォーマットとディレクトリ構造のエラーを調べて直します。すべての問題を見つけたり直したりできるわけではありません。

1. ディスクユーティリティを開き、「表示」>「すべてのデバイスを表示」を選びます。
2. サイドバーでUSBメモリのボリュームを選び、First Aidをクリックしてから「実行」をクリックします。
3. コンテナがあれば、コンテナごとに同じ手順で実行します。
4. 最後にUSBメモリ本体(いちばん上の項目)を選んで実行します。

失敗したらもう一度試すようAppleは案内しています。それでも直らなければ、できるだけデータをバックアップしてからフォーマットし直すよう書いています。ディスクが故障しかけていると表示されたら修復できないので、ファイルを移してUSBメモリを交換するよう案内しています。

## MacではUSBメモリをどの形式で使いますか?

USBメモリをどこで使うかで選びます。形式の説明は[Appleのファイルシステムフォーマットの案内](https://support.apple.com/guide/disk-utility/file-system-formats-dsku19ed921c/mac)、FAT32の制限は[Microsoftのファイルシステム比較表](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison)に沿っています。

| 形式 | Appleの案内 | 選ぶとき |
| --- | --- | --- |
| APFS | macOS 10.13以降のMacの標準ファイルシステム | Macだけで使う |
| APFS(暗号化) | ボリュームを暗号化したAPFS | Macだけで使い、パスワードをかけたい |
| ExFAT | 32GBを超えるWindowsボリューム向け | WindowsやiPhoneでも使い、4GBを超えるファイルも移す |
| MS-DOS(FAT) | 32GB以下のWindowsボリューム向け | FAT32が必要で、4GBを超えるファイルがない |

フォーマットするには、FinderのサイドバーでUSBメモリをControlキーを押しながらクリックし、「ディスクを消去」を選びます。形式を選んで「消去」をクリックします。より細かい設定はディスクユーティリティでできます。フォーマットするとUSBメモリのファイルはすべて消えるので、先にコピーしてください。くわしい手順は[exFATフォーマット方法](/blog/ja/format-usb-exfat)と[USB FAT32フォーマットの方法](/blog/ja/format-usb-fat32)にあります。

## MacでUSBメモリにパスワードをかけられますか?

かけられます。ただし、先にUSBメモリを消去する必要があります。[Appleの暗号化の案内](https://support.apple.com/guide/disk-utility/encrypt-protect-storage-device-password-dskutl35612/mac)に沿った手順です。

1. 残したいファイルを別のストレージにコピーします。
2. ディスクユーティリティを開き、「表示」>「すべてのデバイスを表示」を選びます。
3. USBメモリを選び、「消去」をクリックします。
4. 名前を入力し、「方式」で「GUIDパーティションマップ」を選びます。
5. 「フォーマット」でAPFS(暗号化)などの暗号化された形式を選びます。
6. パスワードを2回入力し、「選択」をクリックします。
7. 「消去」をクリックし、「完了」をクリックします。

その後は、USBメモリをつなぐたびにパスワードを入力します。APFSは、Appleが挙げるWindows互換の形式ではありません。Windowsパソコンでも使うUSBメモリには、この方法を使わないでください。

## MacでのUSBメモリについてよくある質問

### MacでUSBメモリはどこで開きますか?

Finderウインドウを開き、サイドバーの「場所」の下を見ます。なければ、Finder > 設定で外部ディスクの表示をオンにします。

### USB-CしかないMacBookでUSB-AのUSBメモリを使えますか?

アダプターを使えば使えます。AppleはUSB-C - USBアダプターを、USBメモリなどの一般的なUSB機器向けとして案内しています。

### 間違えて「許可しない」を選びました。

USBメモリを抜いて、もう一度つなぎます。Appleは、次につないだときにもう一度たずねると説明しています。

### 取り出し操作をせずに抜いてもいいですか?

おすすめしません。コピーが終わるまで待ち、Finderで取り出してから抜きます。

### MacとWindowsの両方で使うにはどの形式がいいですか?

exFATを選んでください。AppleはWindowsと共用するディスクについて、32GB以下ならMS-DOS(FAT)、32GBを超えるならExFATをすすめています。4GBを超えるファイルを移すなら、容量にかかわらずexFATが合います。

### MacのUSBメモリは暗号化されますか?

初期状態では暗号化されません。Microsoftの比較表では、exFATとFAT32はファイルシステムレベルの暗号化に対応していません。MacではAPFS(暗号化)で消去すればパスワードをかけられますが、APFSはAppleが挙げるWindows互換の形式ではありません。
