## 핵심 요약

가짜 SD 카드는 포장에 적힌 용량이나 속도를 지키지 않는 위조 카드입니다. [SD Association 글](https://www.sdcard.org/press/thoughtleadership/keeping-it-real-how-sd-3c-fights-counterfeit-sd-memory-cards/)은 256GB로 포장했지만 실제로는 16GB만 담는 카드를 예로 듭니다.

겉모양만으로는 가려내기 어렵습니다. 가짜 SD 카드 구별법은 세 단계입니다. 표시가 규격과 맞는지 보고, 컴퓨터가 읽은 용량을 보고, 실제로 파일을 채워 열어 봅니다.

이미 사진을 담았다면 의심이 드는 즉시 다른 저장장치로 옮깁니다. 카드에 더 쓰지 않습니다.

"256GB라는데 사진이 중간부터 깨져요." "표시보다 복사가 훨씬 느려요." 저렴한 카드를 산 뒤 자주 나오는 이야기입니다. 이 글은 가짜 SD 카드가 무엇인지, 사기 전과 산 뒤에 무엇을 확인하는지 정리합니다. 카드에 적힌 표시 전체는 [에스디 카드란?](/blog/ko/what-is-sd-card)에 있습니다.

## 가짜 SD 카드는 무엇이 문제인가요?

SD Association은 위조 카드를 만들거나 파는 쪽이 SD 규격을 지킬 의무가 없다는 점을 문제로 꼽습니다. 같은 글이 드는 문제는 아래와 같습니다.

| 문제 | SD Association 설명 |
| --- | --- |
| 용량 | 256GB로 포장했지만 실제로 16GB만 담는 카드가 있음 |
| 용량 표시 | 일부 위조 카드는 컴퓨터가 실제보다 큰 용량으로 읽게 만듦 |
| 속도 | 읽기·쓰기 속도가 포장 표시와 다름 |
| 영상 | 스피드 클래스를 속인 카드는 콘텐츠 품질 저하나 낮은 전송 속도를 겪을 수 있음 |

용량을 속인 카드는 처음에는 정상으로 보입니다. 컴퓨터가 큰 용량으로 읽기 때문입니다. 문제는 실제 용량을 넘겨 쓸 때 드러납니다. 그래서 산 직후 확인이 중요합니다.

## 사기 전에 무엇을 확인하나요?

1. **판매처를 봅니다.** SD Association 글은 SD-3C 웹사이트에 나온 라이선스 업체나 SD-3C를 이루는 회사에서 사라고 권합니다. 오픈마켓은 판매자를 걸러내지 않는 경우가 많아 제3자 판매자에게 살 때 주의하라고 적습니다.
2. **용량과 용량 규격이 맞는지 봅니다.** SDHC는 32GB까지, SDXC는 32GB 초과 2TB까지, SDUC는 2TB 초과 128TB까지입니다([SD Association 용량 규격](https://www.sdcard.org/developers/sd-standard-overview/capacity-sd-sdhc-sdxc-sduc/)). "SDHC 128GB"처럼 규격과 용량이 맞지 않으면 사지 않습니다. 자세한 차이는 [SDHC·SDXC·SDUC 차이](/blog/ko/sdhc-vs-sdxc)에 있습니다.
3. **용량 규격 표시가 있는지 봅니다.** 카드 이름이 TF 카드여도 SDHC·SDXC 표시로 용량 규격을 확인합니다. TF 카드와 microSD의 관계는 [TF 카드란?](/blog/ko/tf-card)에 정리했습니다.

포장 확인만으로 진품을 보장할 수는 없습니다. 산 뒤에 아래 확인을 꼭 합니다. 이 글은 특정 판매처나 제품을 추천하지 않습니다.

## 컴퓨터에 보이는 용량이 표시보다 작으면 가짜인가요?

조금 작은 것은 정상입니다. [Apple의 저장 용량 안내](https://support.apple.com/en-us/102119)에 따르면 제조사는 1GB를 10억 바이트로 셉니다. 포맷이 공간 일부를 쓰므로 실제 포맷 용량은 더 작습니다. 이진법으로 셀 때 1GB는 1,073,741,824바이트입니다.

| 보이는 현상 | 판단 |
| --- | --- |
| 표시보다 조금 작음 | 10진법·2진법 차이와 포맷 공간 때문에 생기는 정상 차이 |
| 표시보다 크게 작음 | 판매처와 제조사에 문의 |
| 표시와 같은데 파일이 깨짐 | 용량을 속였을 수 있으므로 채워 쓰기 확인 |

반대로 표시 용량이 그대로 보인다고 진품이라는 뜻은 아닙니다. SD Association은 일부 위조 카드가 컴퓨터에 실제보다 큰 용량을 보이게 한다고 설명합니다.

## 산 카드가 진짜 용량인지 어떻게 확인하나요?

보이는 용량만큼 실제로 쓰고 읽어 봐야 합니다. 새 카드는 데이터가 없을 때 확인합니다.

1. 카드를 컴퓨터에 넣고 다른 곳에 원본이 있는 파일만 준비합니다. 사진이나 영상처럼 열어서 확인하기 쉬운 파일이 좋습니다.
2. 카드가 거의 찰 때까지 파일을 복사합니다.
3. 복사 중 오류가 나거나 속도가 갑자기 떨어지는지 봅니다.
4. 카드를 뺐다가 다시 넣습니다.
5. 처음에 복사한 파일과 마지막에 복사한 파일을 모두 열어 봅니다.
6. 파일이 깨지거나 열리지 않으면 카드를 쓰지 않고 판매처에 문의합니다.

용량을 채우는 쓰기·읽기 확인용 프로그램도 있습니다. 이 글은 그런 프로그램을 시험하지 않았으므로 이름을 적지 않습니다. 파일 시스템 오류는 [Mac 디스크 유틸리티 First Aid](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac)나 [Windows chkdsk](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/chkdsk)로 검사합니다. 이 도구들은 파일 시스템을 검사하며, 진품 여부를 판정하지는 않습니다.

## 제조사 인증 도구로 확인할 수 있나요?

일부 제조사는 인증 도구를 냅니다. 대상이 제한적이라 모든 카드에 쓸 수는 없습니다.

예를 들어 [Samsung 인증 유틸리티 매뉴얼](https://download.semiconductor.samsung.com/resources/user-manual/Samsung_Card-UFD_Authentication_Utility_Manual_English_1.3.pdf)(개정 1.3)은 이 도구가 Samsung 정품을 다른 제품과 구별한다고 적습니다. 메모리 카드는 V 표시가 있는 제품만 지원합니다. 매뉴얼의 시스템 요구사항은 Windows 7, 8, 8.1, 10입니다. 결과는 보통 5초 안에 나온다고 적습니다.

다른 제조사 카드는 해당 제조사 고객지원에 문의합니다. [SD Association FAQ](https://www.sdcard.org/consumers/faq/)도 SD 제품 문제는 제조사에 직접 문의하라고 안내합니다.

## 가짜 SD 카드에 사진을 이미 담았다면?

1. 카드에 새 파일을 더 쓰지 않습니다.
2. 열리는 파일부터 컴퓨터나 다른 저장장치로 복사합니다.
3. 복사한 파일을 열어 깨지지 않았는지 확인합니다.
4. 카드는 판매처나 제조사에 문의한 뒤 처리합니다.

카드가 인식되지 않거나 포맷이 되지 않으면 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)를 봅니다. 포맷하면 카드 안의 파일이 지워집니다. 포맷 전에 필요한 파일을 옮깁니다.

## 아이폰 사진을 USB 메모리에 저장하려면?

아래 앱은 USB 메모리를 기준으로 안내합니다. USB 메모리 연결 조건은 [아이폰 USB 메모리 사용법](/blog/ko/iphone-flash-drive-guide)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비하고 있으며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## 가짜 SD 카드 자주 묻는 질문

### 겉모양으로 가짜 SD 카드를 구별할 수 있나요?

어렵습니다. 포장과 인쇄를 비교하는 방법이 알려져 있지만 제조사 공식 기준은 아닙니다. 표시가 규격과 맞는지 보고, 실제로 채워 쓰는 확인을 함께 합니다.

### 컴퓨터에 256GB로 보이면 진짜인가요?

그것만으로는 알 수 없습니다. SD Association은 일부 위조 카드가 실제보다 큰 용량으로 보이게 한다고 설명합니다. 파일을 채워 열어 보는 확인이 필요합니다.

### 표시보다 용량이 조금 작게 보이는데 가짜인가요?

조금 작은 것은 정상입니다. Apple은 제조사가 1GB를 10억 바이트로 세고, 포맷이 공간 일부를 쓴다고 설명합니다.

### 속도가 표시보다 느리면 가짜인가요?

속도는 리더기, 연결 방식, 기기에 따라서도 달라집니다. 느린 것만으로 가짜라고 단정할 수 없습니다. SD Association은 위조 카드의 속도가 포장 표시와 다를 수 있다고 설명합니다. 같은 리더기에서 다른 카드와 비교해 봅니다. 속도 표시의 뜻은 [SD 카드 속도 표시 읽는 법](/blog/ko/sd-card-speed-class)에 있습니다.

### 가짜 카드의 사진을 되살릴 수 있나요?

결과를 약속할 수 없습니다. SD Association FAQ는 지운 사진을 되살리는 방법은 카드 제조사 안내를 따르라고 적습니다. 카드에 더 쓰지 말고 열리는 파일부터 옮깁니다.
