## 要点まとめ

SDカードの偽物は、パッケージに書かれた容量や速度を満たさない偽造カードです。[SD Associationの記事](https://www.sdcard.org/press/thoughtleadership/keeping-it-real-how-sd-3c-fights-counterfeit-sd-memory-cards/)は、256GBとして売られていても実際には16GBしか入らないカードを例に挙げています。

見た目だけで見分けるのは難しいです。確認は3段階です。表示が規格と合っているかを見て、パソコンが読み取った容量を見て、実際にファイルを書き込んで開いてみます。

すでに写真を入れているなら、疑わしいと思った時点でほかの保存先にコピーします。カードにはそれ以上書き込みません。

「256GBのはずなのに、途中から写真が壊れる」「表示よりコピーがずっと遅い」。安いカードを買ったあとによく聞く声です。この記事では、SDカードの偽物とは何か、買う前と買ったあとに何を確かめるかをまとめます。カードに書かれた表示の全体は[SDカードとは?](/blog/ja/what-is-sd-card)にあります。

## SDカードの偽物は何が問題ですか?

SD Associationは、偽造カードを作ったり売ったりする側にはSD規格を守る義務がない点を問題に挙げています。同じ記事が挙げる問題は次のとおりです。

| 問題 | SD Associationの説明 |
| --- | --- |
| 容量 | 256GBとして包装されていても、実際は16GBしか入らないカードがある |
| 表示される容量 | 一部の偽造カードは、パソコンに実際より大きな容量として読ませる |
| 速度 | 読み書きの速度がパッケージの表示と合わない |
| 動画 | スピードクラスを偽ったカードでは、内容の劣化や想定より遅い転送が起こりうる |

容量を偽ったカードは、最初は正常に見えます。パソコンが大きな容量として読むからです。問題は実際の容量を超えて書き込んだときに表れます。だから買った直後の確認が大切です。

## SDカードを買う前に何を確かめますか?

1. **販売元を見ます。** SD Associationの記事は、SD-3Cのウェブサイトに載っているライセンス企業か、SD-3Cを構成する企業から買うよう勧めています。マーケットプレイスは出品者を管理していないことが多いため、第三者の出品者から買うときは注意するよう書いています。
2. **容量と容量規格が合っているかを見ます。** SDHCは32GBまで、SDXCは32GB超から2TBまで、SDUCは2TB超から128TBまでです([SD Associationの容量規格](https://www.sdcard.org/developers/sd-standard-overview/capacity-sd-sdhc-sdxc-sduc/))。「SDHC 128GB」のように規格と容量が合わないカードは買いません。詳しくは[SDXCとは?](/blog/ja/sdhc-vs-sdxc)にあります。
3. **容量規格の表示があるかを見ます。** 商品名がTFカードでも、SDHCかSDXCの表示で容量規格を確かめます。TFカードとmicroSDの関係は[TFカードとは?](/blog/ja/tf-card)にまとめました。

パッケージの確認だけでは本物とは言い切れません。買ったあとに次の確認を必ず行います。この記事は特定の販売元や製品をおすすめしません。

## 表示より容量が小さく見えたらSDカードの偽物ですか?

少し小さいのは正常です。[Appleのストレージ容量の説明](https://support.apple.com/en-us/102119)によると、メーカーは1GBを10億バイトとして数えます。フォーマットが領域の一部を使うため、実際にフォーマットされた容量はもっと小さくなります。2進法で数えると1GBは1,073,741,824バイトです。

| 見えている状態 | 判断 |
| --- | --- |
| 表示より少し小さい | 10進法と2進法の違い、フォーマット領域による正常な差 |
| 表示よりかなり小さい | 販売元とメーカーに問い合わせる |
| 表示どおりなのにファイルが壊れる | 容量を偽っている可能性があるため、書き込みで確認する |

反対に、表示どおりの容量が見えても本物とは限りません。SD Associationは、一部の偽造カードがパソコンに実際より大きな容量を見せると説明しています。

## SDカードの偽物かどうか、実際の容量はどう確かめますか?

表示された容量のぶんだけ、実際に書き込んで読み出す必要があります。新しいカードはデータを入れる前に確かめます。

1. カードをパソコンに入れ、ほかにも元のデータがあるファイルだけを用意します。写真や動画は開いて確かめやすいので向いています。
2. カードがほぼいっぱいになるまでファイルをコピーします。
3. コピー中にエラーが出ないか、速度が急に落ちないかを見ます。
4. カードを取り出して、もう一度入れます。
5. 最初にコピーしたファイルと最後にコピーしたファイルの両方を開きます。
6. ファイルが壊れていたり開けなかったりしたら、カードを使うのをやめて販売元に問い合わせます。

この書き込みと読み出しを自動で行うソフトもあります。この記事ではそれらを試していないため、名前は挙げません。ファイルシステムのエラーは[MacのディスクユーティリティのFirst Aid](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac)や[Windowsのchkdsk](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/chkdsk)で調べます。これらはファイルシステムを調べる道具で、本物かどうかは判定しません。

## メーカーの認証ツールで確かめられますか?

認証ツールを出しているメーカーもあります。対象が限られるため、すべてのカードには使えません。

たとえば[Samsungの認証ユーティリティのマニュアル](https://download.semiconductor.samsung.com/resources/user-manual/Samsung_Card-UFD_Authentication_Utility_Manual_English_1.3.pdf)(改訂1.3)は、このツールがSamsungの正規品をほかの製品と区別すると書いています。メモリーカードはVマークのある製品だけに対応します。マニュアルのシステム要件はWindows 7、8、8.1、10で、結果はふつう5秒以内に出ると書いています。

ほかのメーカーのカードは、そのメーカーのサポートに問い合わせます。[SD AssociationのFAQ](https://www.sdcard.org/consumers/faq/)も、SD製品の不具合はメーカーに直接問い合わせるよう案内しています。

## SDカードの偽物にすでに写真を入れていたら?

1. カードに新しいファイルを書き込みません。
2. 開けるファイルから、パソコンやほかの保存先にコピーします。
3. コピーしたファイルを開いて、壊れていないか確かめます。
4. カードの扱いは、販売元かメーカーに問い合わせてから決めます。

カードが認識されない、フォーマットできないときは[microSDが認識しない・フォーマットできないときの確認手順](/blog/ja/sd-card-not-working)を見てください。フォーマットするとカード内のファイルは消えます。先に必要なファイルを移します。

## iPhoneの写真をUSBメモリに保存するには?

次のアプリはUSBメモリを前提に案内します。USBメモリをつなぐ条件は[iPhoneでのUSBメモリの使い方](/blog/ja/iphone-flash-drive-guide)にあります。

NextGenAIが作ったU-Saverは、exFATかFAT32の一般的なUSBメモリに写真、ビデオ、連絡先を保存するアプリで、iOS 26以降で動作します。U-SaverはApp Storeでの公開を準備しており、韓国での価格は4,900ウォンの買い切りです。U-Saverはメッセージ、アプリのデータ、iPhoneの設定は保存せず、U-Saverで保存したUSBメモリの内容は暗号化されません。購入前に[U-Saverを使う前に確認したい6つのこと](/blog/ja/before-you-buy)をご確認ください。

## SDカードの偽物のよくある質問

### 見た目でSDカードの偽物を見分けられますか?

難しいです。パッケージや印刷を比べる方法は知られていますが、メーカーの公式な基準ではありません。表示が規格と合っているかの確認と、実際に書き込む確認をあわせて行います。

### パソコンで256GBと表示されれば本物ですか?

それだけではわかりません。SD Associationは、一部の偽造カードが実際より大きな容量に見せると説明しています。ファイルを書き込んで開く確認が必要です。

### 表示より少し容量が小さいのは偽物ですか?

少し小さいのは正常です。Appleは、メーカーが1GBを10億バイトとして数え、フォーマットが領域の一部を使うと説明しています。

### 表示より遅いのは偽物ですか?

速度はリーダー、接続方式、機器によっても変わるため、遅いだけでは偽物と言い切れません。SD Associationは、偽造カードの速度がパッケージの表示と合わないことがあると説明しています。同じリーダーでほかのカードと比べてみます。速度表示の意味は[SDカードのV30とは?](/blog/ja/sd-card-speed-class)にあります。

### 偽物のカードの写真は取り戻せますか?

結果は約束できません。SD AssociationのFAQは、消した写真を取り戻す方法はカードメーカーの案内に従うよう書いています。カードにそれ以上書き込まず、開けるファイルから移します。
