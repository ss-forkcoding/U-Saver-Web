## 핵심 요약

닌텐도 스위치 SD 카드 용량은 "지금 쓰는 공간 + 앞으로 받을 게임의 필요 용량 + 업데이트 여유"로 정합니다. 남은 공간은 설정 > 데이터 관리 화면 위쪽에 나오고, 게임별 필요 용량은 닌텐도 e숍과 Nintendo Store의 소프트 페이지에 나옵니다.

스위치와 스위치 Lite의 본체 저장 메모리는 32GB, 스위치 OLED 모델은 64GB입니다. 이 중 일부는 시스템이 씁니다. 카드는 microSDHC(4GB~32GB)나 microSDXC(64GB~2TB)를 고르고, microSDXC는 먼저 본체를 업데이트해야 씁니다.

닌텐도는 본체 하나에 카드 한 장을 권합니다. 여러 카드에 나눠 받은 소프트는 나중에 한 장으로 합칠 수 없으니, 처음부터 넉넉한 용량을 고르는 편이 닌텐도 안내와 맞습니다.

"64GB면 충분할까요, 256GB를 사야 할까요?" "게임을 몇 개나 넣을 수 있나요?" 카드를 사기 전에 자주 나오는 질문입니다. 게임마다 크기가 달라서 정답 하나는 없습니다. 이 글은 닌텐도 스위치 SD 카드 용량을 직접 계산하는 순서를 닌텐도 공식 안내로 정리합니다. 카드를 넣는 법과 포맷은 [닌텐도 스위치 SD 카드 사용법](/blog/ko/switch-microsd)에 있습니다.

## 스위치 본체 저장 공간은 얼마나 되나요?

모델마다 다릅니다. [닌텐도 일본의 본체 저장 메모리 Q&A](https://support-jp.nintendo.com/app/answers/detail/a_id/34000/)의 수치입니다.

| 모델 | 본체 저장 메모리 |
| --- | --- |
| Nintendo Switch | 32GB |
| Nintendo Switch Lite | 32GB |
| Nintendo Switch OLED 모델 | 64GB |
| Nintendo Switch 2 (참고) | 256GB |

같은 Q&A는 데이터를 저장할 수 있는 공간이 이 용량에서 시스템 영역을 뺀 크기라고 적습니다. [닌텐도 미국의 스위치 사양](https://www.nintendo.com/us/gaming-systems/switch/tech-specs/)도 32GB 중 일부를 시스템이 쓴다고 표시합니다. 표의 숫자를 모두 게임에 쓸 수는 없습니다.

## 스위치 SD 카드에는 무엇이 용량을 차지하나요?

게임 저장 데이터를 뺀 소프트 데이터와 화면 사진·동영상입니다. [닌텐도 microSD 카드 FAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq)의 목록입니다.

| 데이터 | 카드 용량을 차지하나요? |
| --- | --- |
| 다운로드 소프트웨어 | 차지합니다 |
| 소프트웨어 업데이트 데이터 | 차지합니다 |
| 추가 콘텐츠(DLC) | 차지합니다 |
| 화면 사진, 촬영한 동영상 | 저장 위치를 카드로 정하면 차지합니다 |
| 게임 저장 데이터 | 차지하지 않습니다. 본체 저장 메모리에만 저장 |

[닌텐도 일본의 데이터 관리 안내](https://support.nintendo.com/jp/switch/data_management/index.html)에 따르면 카드를 넣으면 다운로드 소프트의 저장 위치가 카드가 됩니다. 카드가 가득 차면 자동으로 본체 저장 메모리에 저장됩니다. 같은 안내는 화면 사진·동영상에 저장 공간과 별개로 저장 개수 상한이 있다고 적습니다.

## 지금 남은 공간은 어떻게 확인하나요?

데이터 관리 화면에서 봅니다. [닌텐도의 남은 공간 확인 안내](https://www.nintendo.com/au/support/articles/how-to-check-available-space-on-nintendo-switch/) 순서입니다.

1. HOME 메뉴에서 설정을 고릅니다.
2. 왼쪽 메뉴를 내려 데이터 관리를 고릅니다.
3. 화면 위쪽에서 본체 저장 메모리와 microSD 카드의 남은 공간을 봅니다.

[닌텐도 일본 Q&A](https://support-jp.nintendo.com/app/answers/detail/a_id/33841/)는 이 화면에 SD 카드의 남은 공간이 보이면 카드가 인식된 것이라고 적습니다. "꽂혀 있지 않습니다"라고 나오면 전원을 끄고 카드를 다시 넣습니다.

## 닌텐도 스위치 SD 카드 용량은 어떻게 계산하나요?

지금 쓰는 양과 앞으로 받을 양을 더합니다. 게임별 크기는 닌텐도 안내를 봅니다. [닌텐도의 다운로드 용량 안내](https://www.nintendo.com/au/support/articles/will-i-need-extra-storage-space-to-download-the-games/)는 필요한 공간이 닌텐도 e숍에 표시된다고 적습니다. [닌텐도 일본의 다운로드판 안내](https://www.nintendo.com/jp/games/howtodl/index.html)는 필요 용량이 소프트마다 다르고, Nintendo Store의 각 소프트 페이지에서 확인한다고 적습니다.

1. 데이터 관리 화면에서 지금 쓰고 있는 공간을 확인합니다.
2. 앞으로 받을 게임과 DLC의 필요 용량을 e숍이나 Nintendo Store에서 찾아 더합니다.
3. 업데이트 데이터가 들어갈 여유를 더합니다. 닌텐도 일본 안내는 업데이트 배포로 필요 용량이 표시보다 커질 수 있다고 적습니다.
4. 화면 사진과 동영상을 카드에 저장할 계획이면 그 공간도 더합니다.
5. 합계보다 큰 용량 단계의 카드를 고릅니다.

예를 들어 지금 카드에 20GB를 쓰고, 필요 용량이 10GB·15GB·7GB인 게임 세 개를 더 받을 계획이라고 가정합니다. 합계는 52GB입니다. 업데이트 여유를 더하면 64GB 카드는 빠듯하고, 그보다 한 단계 큰 카드가 계산에 맞습니다. 이 숫자는 계산 순서를 보여 주는 가정이며 실제 게임 크기가 아닙니다.

## microSDHC와 microSDXC 중 무엇을 골라야 하나요?

64GB 이상이 필요하면 microSDXC입니다. [닌텐도 microSD 카드 FAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq) 기준입니다.

| 카드 종류 | 용량 범위 | 스위치에서 |
| --- | --- | --- |
| microSD | 2GB까지 | 쓸 수 있음 |
| microSDHC | 4GB~32GB | 쓸 수 있음 |
| microSDXC | 64GB~2TB | 쓸 수 있음. 먼저 본체 업데이트 필요 |

[한국닌텐도의 microSD 카드 안내](https://www.nintendo.co.kr/support/switch/data_management/microsdcard/index.html)도 microSDXC를 쓰려면 인터넷에 접속해 본체를 업데이트해야 한다고 적습니다. microSDHC의 최대 용량 32GB는 스위치와 스위치 Lite의 본체 저장 메모리와 같은 크기입니다. 공간을 크게 늘리려면 microSDXC를 봅니다. 용량 규격의 차이는 [SDHC·SDXC·SDUC 차이](/blog/ko/sdhc-vs-sdxc)에 정리했습니다.

용량과 속도는 별개입니다. 닌텐도 FAQ는 고속 카드의 기준으로 UHS-I 대응, 전송 속도 60~95MB/초를 제시합니다. 속도 표시는 [SD 카드 속도 표시 읽는 법](/blog/ko/sd-card-speed-class)에 있습니다. 이 글은 특정 카드를 시험하거나 추천하지 않습니다.

## 작은 카드를 사고 나중에 바꿔도 되나요?

바꿀 수 있지만 Windows 컴퓨터가 필요합니다. [닌텐도 일본의 용량 부족 Q&A](https://support-jp.nintendo.com/app/answers/detail/a_id/33842/)는 카드가 부족해지면 두 가지를 권합니다.

| 방법 | 닌텐도 안내 |
| --- | --- |
| 안 하는 게임 정리 | 다운로드 소프트를 지워도 저장 데이터는 본체에 남고, 다시 받으면 이어서 합니다 |
| 큰 카드로 교체 | Windows 컴퓨터로 기존 카드의 데이터를 새 카드에 복사합니다 |

카드 두 장을 번갈아 쓰는 방법은 권하지 않습니다. [닌텐도 microSD 카드 FAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq)는 카드 한 장을 쓰고, 공간이 부족하면 큰 카드로 모두 옮기라고 적습니다. 여러 카드에 나눈 소프트는 나중에 한 장으로 합칠 수 없습니다. 옮기는 순서는 [닌텐도 스위치 SD 카드 사용법](/blog/ko/switch-microsd)의 "더 큰 SD 카드로 바꾸려면" 항목에 있습니다.

정리 순서는 [닌텐도 일본의 데이터 관리 안내](https://support.nintendo.com/jp/switch/data_management/index.html)에 있습니다. 설정 > 데이터 관리에서 여러 소프트를 한꺼번에 정리할 수 있고, 정리해도 저장 데이터와 소프트 아이콘은 남습니다. 같은 안내는 배포가 끝난 소프트는 다시 받지 못할 수 있다고 적습니다.

## 스위치 2로 바꿀 계획이면 용량을 어떻게 보나요?

일반 microSD는 스위치 2에서 게임 저장에 쓸 수 없습니다. [닌텐도의 스위치 2 카드 호환 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68425/)의 내용입니다.

| 카드 | Nintendo Switch 2 | Nintendo Switch |
| --- | --- | --- |
| microSD | 게임 저장 불가. 스위치에서 찍은 화면 사진·동영상 불러오기만 가능 | 쓸 수 있음 |
| microSD Express | 2TB까지 쓸 수 있음. 처음 쓸 때 인터넷 업데이트 필요 | 쓸 수 있음. 속도는 일반 microSD와 같음 |

곧 스위치 2로 옮길 계획이라면 큰 일반 microSD를 사도 스위치 2에서는 게임용으로 다시 쓰지 못합니다. 이 점을 용량 결정에 넣습니다. microSD Express의 구조는 [microSD Express란?](/blog/ko/microsd-express)에 있습니다.

## 큰 용량 카드를 살 때 무엇을 확인하나요?

실제 용량과 인식 여부를 확인합니다.

1. 표시 용량이 실제와 맞는지 확인합니다. 순서는 [가짜 SD 카드 구별법](/blog/ko/fake-sd-card)에 있습니다.
2. 전원을 끈 상태로 카드를 넣고 본체를 켭니다. microSDXC라면 화면 안내에 따라 업데이트합니다.
3. 데이터 관리 화면에서 SD 카드의 남은 공간이 보이는지 확인합니다.
4. 기존 카드에서 옮겼다면 새 카드가 정상 동작하는 것을 확인할 때까지 기존 카드를 지우지 않습니다.

스위치 화면 사진을 아이폰으로 옮기려는 경우는 카드 리더기로 카드를 연결합니다. 순서는 [아이폰 마이크로 SD 쓰는 법](/blog/ko/iphone-microsd)에 있습니다.

## 닌텐도 스위치 SD 카드 용량 자주 묻는 질문

### 닌텐도 스위치 SD 카드는 최대 몇 TB까지 되나요?

닌텐도 FAQ 기준 microSDXC 2TB까지입니다. microSDXC를 쓰려면 먼저 본체를 업데이트해야 합니다.

### 게임 저장 데이터 때문에 카드 용량을 더 잡아야 하나요?

아닙니다. 게임 저장 데이터는 본체 저장 메모리에만 저장되고 카드에는 저장되지 않습니다.

### 카드가 가득 차면 다운로드가 멈추나요?

닌텐도 일본 안내에 따르면 카드가 가득 차면 본체 저장 메모리에 자동으로 저장됩니다. 두 곳이 모두 부족하면 안 하는 게임을 정리하거나 큰 카드로 바꿉니다.

### 게임 하나가 몇 GB인지 어디서 보나요?

닌텐도 e숍이나 Nintendo Store의 소프트 페이지에서 필요 용량을 봅니다. 업데이트가 배포되면 표시보다 커질 수 있습니다.

### 패키지 게임만 하면 SD 카드가 필요 없나요?

이 글에서 확인한 닌텐도 안내에는 패키지 게임 업데이트 데이터의 크기가 나오지 않습니다. 데이터 관리 화면에서 본체 저장 메모리가 얼마나 남는지 보고 정합니다.
