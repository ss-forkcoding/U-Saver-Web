## Key takeaways

Choose a Nintendo Switch SD capacity by adding the space you use now, the required space of the games you plan to download, and room for updates. Free space shows at the top of System Settings > Data Management. Each game's required space is listed in Nintendo eShop.

The Switch and Switch Lite have 32 GB of system memory, and the Switch OLED Model has 64 GB. Part of it is reserved for the system. For a card, pick microSDHC (4 GB–32 GB) or microSDXC (64 GB–2 TB). A microSDXC card needs a system update first.

Nintendo recommends one card per console. Software saved across several cards can't be combined later, so buying enough capacity up front matches Nintendo's advice.

"Is 64 GB enough, or should I get 256 GB?" "How many games will fit?" People ask this before buying a card. Game sizes vary, so there's no single answer. This guide shows how to work out your own Nintendo Switch SD capacity using Nintendo's own support pages. Inserting and formatting a card is covered in the [Nintendo Switch micro SD card guide](/blog/en/switch-microsd).

## How much system memory does a Switch have?

It depends on the model. These figures come from [Nintendo Japan's system memory Q&A](https://support-jp.nintendo.com/app/answers/detail/a_id/34000/).

| Model | System memory |
| --- | --- |
| Nintendo Switch | 32 GB |
| Nintendo Switch Lite | 32 GB |
| Nintendo Switch OLED Model | 64 GB |
| Nintendo Switch 2 (for reference) | 256 GB |

The same Q&A says the space you can save to is this capacity minus the system area. [Nintendo's Switch tech specs](https://www.nintendo.com/us/gaming-systems/switch/tech-specs/) also note that a portion of the 32 GB is reserved for the system. You can't use the full number for games.

## What uses space on a Switch micro SD card?

Everything except game save data. This list comes from the [Nintendo microSD Card FAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq).

| Data | Uses card space? |
| --- | --- |
| Downloadable software | Yes |
| Software update data | Yes |
| Downloadable content (DLC) | Yes |
| Screenshots and captured videos | Yes, if the card is the save location |
| Game save data | No. Stored in the system memory only |

According to [Nintendo Japan's data management page](https://support.nintendo.com/jp/switch/data_management/index.html), an inserted card becomes the save location for downloadable software. When the card is full, data is saved to the system memory automatically. The same page says screenshots and videos have a limit on the number you can save, separate from free space.

## How do I check how much space is left?

Open Data Management. These steps follow [Nintendo's guide to checking available space](https://www.nintendo.com/au/support/articles/how-to-check-available-space-on-nintendo-switch/).

1. From the HOME Menu, select System Settings.
2. Scroll down the left-hand menu and select Data Management.
3. Read the available space for the system memory and microSD card at the top of the screen.

[Nintendo Japan's Q&A](https://support-jp.nintendo.com/app/answers/detail/a_id/33841/) says the card is recognized if its free space shows on this screen. If it says the card isn't inserted, turn the console off and reinsert the card.

## How do I work out the Nintendo Switch SD capacity I need?

Add what you use now to what you plan to download. For game sizes, use Nintendo's listings. [Nintendo's download storage page](https://www.nintendo.com/au/support/articles/will-i-need-extra-storage-space-to-download-the-games/) says the space needed is displayed in Nintendo eShop. [Nintendo Japan's download guide](https://www.nintendo.com/jp/games/howtodl/index.html) says the required space varies by game and is listed on each game's Nintendo Store page.

1. Check the space you use now in Data Management.
2. Look up the required space for the games and DLC you plan to get, and add them up.
3. Add room for update data. Nintendo Japan says updates can push the required space above the listed figure.
4. If you save screenshots and videos to the card, add space for them too.
5. Pick the next card size above the total.

Say your card holds 20 GB now and you plan to add three games that need 10 GB, 15 GB, and 7 GB. That's 52 GB. With room for updates, a 64 GB card is tight, and the next size up fits the math better. These are made-up numbers to show the steps, not real game sizes.

## Should I get microSDHC or microSDXC?

If you need 64 GB or more, it's microSDXC. This table follows the [Nintendo microSD Card FAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq).

| Card type | Capacity | On a Switch |
| --- | --- | --- |
| microSD | Up to 2 GB | Supported |
| microSDHC | 4 GB–32 GB | Supported |
| microSDXC | 64 GB–2 TB | Supported after a system update |

The top microSDHC size, 32 GB, matches the system memory of the Switch and Switch Lite. To add a lot of space, look at microSDXC. Capacity standards are explained in [SDHC vs SDXC vs SDUC](/blog/en/sdhc-vs-sdxc).

Capacity and speed are separate choices. The same FAQ suggests a UHS-I card with a transfer speed of 60–95 MB/s. Speed markings are covered in [SD card speed classes](/blog/en/sd-card-speed-class). This guide hasn't tested any card and doesn't recommend one.

## Can I buy a smaller card now and upgrade later?

Yes, but you'll need a Windows PC. [Nintendo Japan's Q&A on running out of card space](https://support-jp.nintendo.com/app/answers/detail/a_id/33842/) suggests two options.

| Option | What Nintendo says |
| --- | --- |
| Delete games you don't play | Save data stays on the console; download the game again to continue |
| Move to a bigger card | Copy the old card's data to the new card with a Windows PC |

Switching between two cards isn't recommended. The [Nintendo microSD Card FAQ](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22481/~/microsd-card-faq) says to use one card and copy everything to a larger card when you run out. Software split across cards can't be combined later. The copy steps are in the [Nintendo Switch micro SD card guide](/blog/en/switch-microsd), under moving to a bigger card.

[Nintendo Japan's data management page](https://support.nintendo.com/jp/switch/data_management/index.html) explains archiving. You can archive several games at once in System Settings > Data Management, and the save data and game icons stay. The same page warns that software no longer offered may not be available to download again.

## How does a planned Switch 2 upgrade affect capacity?

A regular microSD card can't store games on a Switch 2. This table comes from [Nintendo's Switch 2 card compatibility page](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68425/).

| Card | Nintendo Switch 2 | Nintendo Switch |
| --- | --- | --- |
| microSD | No games. Can only load Switch screenshots and videos | Yes |
| microSD Express | Yes, up to 2 TB. Needs an internet system update the first time | Yes, at the same speed as a microSD card |

If you plan to move to a Switch 2 soon, a large regular microSD card won't carry over for games. Factor that into the size you buy. How microSD Express works is covered in [what is microSD Express?](/blog/en/microsd-express)

## What should I check when I buy a large card?

Check the real capacity and that the console sees it.

1. Confirm the card's real capacity matches the label. See [how to spot a fake SD card](/blog/en/fake-sd-card).
2. Insert the card with the console off, then turn it on. For microSDXC, follow the on-screen update prompt.
3. Check that the card's free space shows in Data Management.
4. If you copied from an old card, don't erase the old one until the new card works.

To get Switch screenshots onto an iPhone, connect the card with a card reader. The steps are in [micro SD for iPhone](/blog/en/iphone-microsd).

## Nintendo Switch SD capacity FAQ

### What's the largest SD card a Nintendo Switch supports?

Nintendo's FAQ lists microSDXC up to 2 TB. You need a system update before the Switch can use a microSDXC card.

### Do I need extra card space for save data?

No. Save data is stored only in the system memory, not on the card.

### What happens when the card is full?

Nintendo Japan says data is saved to the system memory automatically. If both are short on space, delete games you don't play or move to a larger card.

### Where can I see how big a game is?

Check the required space in Nintendo eShop or on the game's Nintendo Store page. Updates can make it larger than listed.

### Do I need an SD card if I only play physical games?

The Nintendo pages checked for this guide don't give update data sizes for physical games. Check how much system memory is left in Data Management and decide from there.
