## 要点まとめ

USBが認識しないときにデータ取り出しを考えるなら、まずフォーマットしないことです。「ディスクをフォーマットする必要があります」のような画面が出ても閉じます。フォーマットするとUSBメモリのデータはすべて消えます。

次に接続を確認します。別のポート、別のケーブルやアダプタ、別のパソコンの順です。ハブを経由しているなら外して、パソコンに直接挿します。

USBメモリがまた表示されたら、いちばん大事なファイルから別の保存先にコピーします。検査や修復はコピーが終わってから行います。この記事はデータが戻ることを約束するものではありません。

「昨日まで使えていたUSBメモリが、今日は表示されない」「挿すとフォーマットの画面だけが出る」。USBメモリに写真や書類を入れていたなら、いちばん焦る場面です。この記事は公式資料で確認できる手順だけを扱い、特定のUSBメモリや復旧ソフトを試したり勧めたりはしません。

## USBが認識しないとき、まず何を確認しますか?

症状に合う行を探し、その部分から読んでください。

| 症状 | まず疑うこと | この記事の該当部分 |
| --- | --- | --- |
| 挿すとフォーマットを求める画面が出る | ファイルシステムの破損 | フォーマットの画面 |
| 挿しても何も反応しない | ポート、ケーブル、ハブ、電源 | 接続の確認 |
| Windowsの「ディスクの管理」にはあるのにエクスプローラーにない | ドライブ文字、オフライン、RAW | ディスクの管理 |
| Macに挿してもFinderに出ない | 接続の許可、Finderの設定 | Mac |
| パソコンでは使えるのにiPhoneだけで表示されない | ロック、形式、パーティションの数 | iPhone |
| どの機器でも表示されない | USBメモリ自体の故障 | それでも認識しないとき |

## フォーマットの画面が出たら、なぜ閉じるのですか?

フォーマットはUSBメモリを空にして作り直す操作です。[Microsoftの「ディスクの管理」のトラブルシューティング](https://learn.microsoft.com/en-us/troubleshoot/windows-server/backup-and-storage/troubleshoot-disk-management)は、ディスクをフォーマットするとすべてのデータが消えると説明しています。ファイルを取り戻したい場合は、フォーマットの手順を飛ばすよう書いています。

1. フォーマットを求める画面が出たら、キャンセルを選びます。
2. USBメモリに新しいファイルを保存しません。
3. エラーメッセージが出たら、そのまま書き留めます。
4. 次の順番で接続から確認します。

同じ資料は、パーティションがRAWや「未割り当て」と表示されても、ファイルを取り戻したいならフォーマットや新しいボリュームの作成をしないよう説明しています。

## 接続の問題かどうかは、どう見分けますか?

Microsoftの資料の手順を、USBメモリ向けに並べ直しました。途中で表示されたら、残りは飛ばします。

1. USBメモリを抜いて、挿し直します。
2. パソコンをシャットダウンしてから電源を入れ直し、もう一度挿します。
3. ハブを経由しているなら外し、パソコン本体のポートに直接挿します。
4. 別のポートに挿します。
5. アダプタや延長ケーブルを使っているなら、別のものに替えます。
6. 別のパソコンに挿します。

Microsoftは、USBのディスクはポートによって十分な電力を受け取れないことがあり、USBハブでは特によく起きると説明しています。ケーブルもよく故障すると書いています。別のパソコンでも使えなければ、パソコンよりUSBメモリ側の問題である可能性が高くなります。

## Windowsで認識しないとき、「ディスクの管理」で何を見ますか?

エクスプローラーに出なくても、「ディスクの管理」には表示されることがあります。[Microsoftの資料](https://learn.microsoft.com/en-us/troubleshoot/windows-server/backup-and-storage/troubleshoot-disk-management)のとおり、タスクバーの検索で「コンピューターの管理」を管理者として開き、「記憶域」>「ディスクの管理」に進みます。

| 「ディスクの管理」での表示 | すること | しないこと |
| --- | --- | --- |
| ディスクがオフライン | ディスクを右クリックして「オンライン」を選びます | なし |
| パーティションは正常だがドライブ文字がない | ドライブ文字を追加します | なし |
| パーティションがRAW | 別のポートと別のパソコンで先に確認します | フォーマット |
| 未割り当て | 別のポートと別のパソコンで先に確認します | 新しいシンプルボリュームの作成 |
| 初期化されていない | 別のポートと別のパソコンで先に確認します | ディスクの初期化 |
| 「ディスクの管理」にも出ない | 抜き挿ししてから「操作」>「ディスクの再スキャン」を選びます | なし |

ドライブ文字は[Microsoftのドライブ文字の変更の案内](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/change-a-drive-letter)に沿って割り当てます。

1. 「ディスクの管理」でUSBメモリのボリュームを右クリックします。
2. 「ドライブ文字とパスの変更」を選びます。
3. 「追加」を選び、「次のドライブ文字を割り当てる」を選びます。
4. 一覧から文字を選び、「OK」を選びます。

「ディスクの管理」にまったく出ないなら、デバイスマネージャーを開きます。Microsoftは、感嘆符の付いたデバイスがないかを見て、そのデバイスをアンインストールしてから「操作」>「ハードウェア変更のスキャン」を選ぶ方法を挙げています。ディスクが見つからない、初期化できない原因でいちばん多いのはディスクの故障だとも説明しています。

## MacでUSBメモリが認識しないときは何を確認しますか?

Appleシリコン搭載のMacノートブックなら、まず接続の許可を確認します。[Appleのアクセサリの接続を許可する案内](https://support.apple.com/en-us/102282)によると、「許可しない」をクリックするとMacはそのアクセサリを認識しません。次に接続したときにもう一度確認されます。Macが3日以上ロックされていた場合は、以前に許可したアクセサリでもロックを解除しないと使えないことがあります。

| 症状 | 確認すること |
| --- | --- |
| 挿しても反応がない | 許可の画面を見逃していないか確認します。抜き挿しして「許可」をクリックします |
| Finderのサイドバーに出ない | 「Finder」>「設定」の「サイドバー」タブで「外部ディスク」をオンにします |
| ディスクユーティリティにはあるのに開けない | ファイルをコピーできるか確かめてから、First Aidで検査します |

Finderの設定は[Appleの接続中のデバイスを表示する案内](https://support.apple.com/guide/mac-help/see-the-devices-connected-to-your-mac-mchlp1039/mac)にあります。ディスクユーティリティで「表示」>「すべてのデバイスを表示」を選ぶと、USBメモリの下のボリュームが見えます。Macでの基本の使い方は[MacでUSBメモリを使う方法](/blog/ja/usb-drive-on-mac)にまとめました。

## iPhoneだけでUSBメモリが認識しないときは?

パソコンでは開けるのにiPhoneだけで表示されないなら、iPhone側の条件を確認します。[Appleのアクセサリの接続を許可する案内](https://support.apple.com/en-us/111806)によると、ストレージアクセサリを使う前には必ずiPhoneのロックを解除する必要があります。

[Appleの外部ストレージデバイスの案内](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)によると、ストレージデバイスのデータパーティションは1つだけでなければなりません。形式はAPFS、APFS(暗号化)、macOS拡張(HFS+)、exFAT、FAT32、FATのいずれかです。WindowsでNTFSとして使っていたUSBメモリは、iPhoneのファイルアプリに表示されません。

この場合はUSBメモリの故障ではないので、まずパソコンでデータを取り出します。その後[exFATフォーマット方法](/blog/ja/format-usb-exfat)のとおりにフォーマットすれば、iPhoneで使えます。ロック、電源、ケーブルを順に確認する手順は[iPhoneで外付けHDD・SSDが認識しないとき](/blog/ja/iphone-drive-not-detected)にあります。USBメモリでも同じ順番で確認できます。

## USBメモリがまた表示されたら、データをどう取り出しますか?

表示が戻った瞬間がいちばん大事です。いつまた消えるかわからないので、検査よりコピーを先にします。

1. いちばん大事なフォルダから、パソコンか別の保存先にコピーします。
2. USBメモリ上のファイルを開いて編集したり、上書き保存したりしません。
3. コピーが終わったら、次の方法で検査します。

Appleは、ディスクユーティリティでディスクを修復できない場合、できるだけ多くのデータをバックアップしてから再フォーマットするよう案内しています。ディスクがまもなく故障すると表示されたら修復はできないので、データをバックアップしてディスクを交換するよう書いています。

| 検査ツール | 出典 | 知っておくこと |
| --- | --- | --- |
| MacのディスクユーティリティのFirst Aid | [Appleのストレージデバイスの修復の案内](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac) | ボリューム、コンテナ、最上位のデバイスの順に実行します。すべての問題を検出・修復できるわけではありません |
| Windowsの`chkdsk` | [Microsoftのchkdskの資料](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/chkdsk) | パラメーターなしでは状態を表示するだけです。`/f`を付けるとエラーを修正します。管理者権限が必要です |

`chkdsk E: /f`のように入力します。Eは例なので、USBメモリのドライブ文字に置き換えてください。Microsoftは`chkdsk`を途中で止めることを勧めていません。検査の手順は[microSDが認識しない・フォーマットできないときの確認手順](/blog/ja/sd-card-not-working)に詳しく書きました。SDカードを例にしていますが、USBメモリでも手順は同じです。

## それでもUSBメモリが認識しないときは?

別のパソコンでも「ディスクの管理」でも表示されないなら、USBメモリ自体の故障を疑います。Microsoftは、この段階ではMicrosoftコミュニティで質問するか、ディスクのメーカーに問い合わせるよう案内しています。同じ資料は、故障したディスクからデータの取り出しを試みるアプリや、有料のデータ復旧業者もあると書いています。

この記事は特定のソフトや業者を試したり勧めたりはしません。まずメーカーの保証とサポートの範囲を確認してください。ファイルが見えなくなったときの順番は[壊れたSDカードの復元を試す前に](/blog/ja/sd-card-corrupted)にもあります。

## 同じことを繰り返さないためには?

USBメモリは抜く前に取り出し操作をします。[Microsoftのハードウェアの安全な取り外しの案内](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)は、データの損失を防ぐため、USBメモリを外す前に必ず安全な取り外しを行うよう説明しています。

データをUSBメモリ1本だけに置かないことも大切です。Microsoftは、ディスクはよく故障するので大事なファイルは定期的にバックアップするよう勧めています。ときどき表示されなくなったりエラーを出したりするディスクは、バックアップを見直す合図だと書いています。iPhoneの写真や連絡先をUSBメモリに分けて保存する手順は[iPhoneバックアップをUSBメモリに取る方法](/blog/ja/backup-iphone-to-usb)にあります。

## iPhoneの写真をUSBメモリに別に保存するには?

NextGenAIが作ったU-Saverは、一般的なUSBメモリに写真、ビデオ、連絡先を保存するアプリで、exFATかFAT32のUSBメモリを使い、iOS 26以降で動作します。U-SaverはApp Storeでの公開を準備しており、韓国での価格は4,900ウォンの買い切りです。U-Saverはメッセージ、アプリのデータ、iPhoneの設定は保存せず、U-Saverで保存したUSBメモリの内容は暗号化されません。購入前に[U-Saverを使う前に確認したい6つのこと](/blog/ja/before-you-buy)をご確認ください。

## USBが認識しないときのよくある質問

### フォーマットの画面で「フォーマット」を押すとどうなりますか?

USBメモリのデータがすべて消えます。Microsoftの資料も、ディスクをフォーマットするとすべてのデータが消えると説明しています。データを取り出したいなら画面を閉じてください。

### USBメモリを何度も抜き挿ししてもいいですか?

抜き挿しはMicrosoftの資料の最初の手順です。ただし、コピーの途中で抜くとファイルが最後までコピーされないことがあります。進行状況の表示が消えてから取り出し操作をして抜いてください。

### 先にchkdskを実行してもいいですか?

`chkdsk /f`とFirst Aidは、ディスクのエラーを修正するツールです。Appleは、修復に失敗したらできるだけ多くのデータをバックアップするよう案内しています。ファイルが見えるなら、先にコピーしてください。

### 別のパソコンでは表示されるのに、自分のパソコンだけで表示されません。

USBメモリよりも、パソコンのポート、ハブ、設定を疑います。Windowsなら「ディスクの管理」でドライブ文字を、Macなら接続の許可とFinderの設定を確認してください。

### iPhoneだけでUSBメモリが表示されません。

ロックを解除しているか、形式がNTFSではないか、データパーティションが1つだけかを確認してください。NTFSはAppleの外部ストレージの形式一覧にありません。
