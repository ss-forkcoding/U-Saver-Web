## 핵심 요약

갑자기 USB 인식 안됨 증상이 나오면 먼저 포맷하지 않습니다. "디스크를 포맷해야 합니다" 같은 창이 떠도 닫습니다. 포맷하면 USB의 자료가 모두 지워집니다.

그다음 연결 쪽을 확인합니다. 다른 포트, 다른 케이블이나 어댑터, 다른 컴퓨터 순서입니다. 허브를 거쳤다면 빼고 컴퓨터에 바로 꽂습니다.

USB가 다시 보이면 가장 중요한 파일부터 다른 저장장치에 복사합니다. 검사와 수리는 복사가 끝난 뒤에 합니다. 이 글은 자료를 되찾는 결과를 약속하지 않습니다.

"어제까지 잘 쓰던 USB가 오늘은 안 떠요." "꽂으면 포맷하라는 창만 나와요." USB 메모리에 사진이나 문서를 넣어 두었다면 가장 당황스러운 순간입니다. 이 글은 확인 가능한 절차만 다루고, 특정 USB 메모리나 복구 프로그램을 시험하거나 추천하지 않습니다.

## 갑자기 USB 인식 안됨, 무엇부터 확인하나요?

증상에 맞는 줄을 찾아 그 부분부터 보세요.

| 증상 | 먼저 의심할 것 | 이 글의 해당 부분 |
| --- | --- | --- |
| 꽂으면 포맷하라는 창이 뜸 | 파일 시스템 손상 | 포맷 창 |
| 꽂아도 아무 반응이 없음 | 포트, 케이블, 허브, 전원 | 연결 확인 |
| 윈도우 디스크 관리에는 있는데 탐색기에 없음 | 드라이브 문자, 오프라인, RAW | 윈도우 디스크 관리 |
| Mac에 꽂아도 Finder에 없음 | 연결 허용, Finder 설정 | Mac |
| 컴퓨터에서는 되는데 아이폰에서만 안 보임 | 잠금, 형식, 파티션 수 | 아이폰 |
| 어느 기기에서도 보이지 않음 | USB 자체의 고장 | 그래도 안 될 때 |

## 포맷하라는 창이 뜨면 왜 닫아야 하나요?

포맷은 USB를 비우고 새로 만드는 작업입니다. [Microsoft의 디스크 관리 문제 해결 안내](https://learn.microsoft.com/en-us/troubleshoot/windows-server/backup-and-storage/troubleshoot-disk-management)는 포맷하면 디스크의 모든 데이터가 지워진다고 설명합니다. 파일을 되찾으려는 경우에는 포맷 단계를 건너뛰라고 적습니다.

1. 포맷을 묻는 창이 뜨면 취소를 누릅니다.
2. USB에 새 파일을 저장하지 않습니다.
3. 오류 문구가 나왔다면 그대로 적어 둡니다.
4. 아래 순서로 연결부터 확인합니다.

같은 안내는 파티션이 RAW나 할당되지 않음으로 나와도, 파일을 되찾으려 한다면 포맷이나 새 볼륨 만들기를 하지 말라고 설명합니다.

## 연결 문제인지 어떻게 가려내나요?

Microsoft 안내의 순서를 USB 메모리에 맞춰 옮겼습니다. 한 단계에서 USB가 보이면 나머지는 건너뜁니다.

1. USB를 뺐다가 다시 꽂습니다.
2. 컴퓨터를 종료한 뒤 다시 켜고 꽂습니다.
3. 허브를 거쳤다면 빼고 컴퓨터 본체의 포트에 바로 꽂습니다.
4. 다른 포트에 꽂습니다.
5. 어댑터나 연장 케이블을 썼다면 다른 것으로 바꿉니다.
6. 다른 컴퓨터에 꽂습니다.

Microsoft는 USB 디스크가 일부 포트에서 전원을 충분히 받지 못할 수 있고, 허브에서 이런 문제가 특히 흔하다고 설명합니다. 케이블도 자주 고장 난다고 적습니다. 다른 컴퓨터에서도 안 되면 컴퓨터보다 USB 쪽 문제일 가능성이 높습니다.

## 윈도우에서 USB가 안 보이면 디스크 관리에서 무엇을 보나요?

파일 탐색기에 없어도 디스크 관리에는 보일 수 있습니다. [Microsoft 안내](https://learn.microsoft.com/en-us/troubleshoot/windows-server/backup-and-storage/troubleshoot-disk-management)대로 작업 표시줄 검색에서 컴퓨터 관리를 관리자 권한으로 열고 저장소 > 디스크 관리로 갑니다.

| 디스크 관리에 보이는 상태 | 해야 할 일 | 하지 말 것 |
| --- | --- | --- |
| 디스크가 오프라인 | 디스크를 마우스 오른쪽 버튼으로 누르고 온라인을 고릅니다 | 없음 |
| 파티션이 정상이고 드라이브 문자가 없음 | 드라이브 문자를 추가합니다 | 없음 |
| 파티션이 RAW | 다른 포트와 다른 컴퓨터에서 먼저 확인합니다 | 포맷 |
| 할당되지 않음 | 다른 포트와 다른 컴퓨터에서 먼저 확인합니다 | 새 단순 볼륨 만들기 |
| 초기화되지 않음 | 다른 포트와 다른 컴퓨터에서 먼저 확인합니다 | 디스크 초기화 |
| 디스크 관리에도 없음 | 뺐다 꽂은 뒤 동작 > 디스크 다시 검색을 누릅니다 | 없음 |

드라이브 문자는 [Microsoft의 드라이브 문자 변경 안내](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/change-a-drive-letter)대로 붙입니다.

1. 디스크 관리에서 USB의 볼륨을 마우스 오른쪽 버튼으로 누릅니다.
2. 드라이브 문자 및 경로 변경을 고릅니다.
3. 추가를 누르고 다음 드라이브 문자 할당을 고릅니다.
4. 목록에서 문자를 고르고 확인을 누릅니다.

디스크 관리에 아예 없다면 장치 관리자를 엽니다. Microsoft는 느낌표가 붙은 장치가 있는지 보고, 그 장치를 제거한 뒤 동작 > 하드웨어 변경 사항 검색을 눌러 보라고 안내합니다. Microsoft는 초기화되지 않은 디스크의 가장 흔한 원인이 디스크 고장이라고 설명합니다.

## Mac에서 USB가 안 보이면 무엇을 확인하나요?

Apple 실리콘 Mac 노트북이라면 연결 허용 창부터 확인합니다. [Apple의 액세서리 연결 허용 안내](https://support.apple.com/en-us/102282)에 따르면 허용 안 함을 누르면 Mac이 USB를 인식하지 않습니다. 다음에 연결할 때 다시 묻습니다. Mac이 3일 이상 잠겨 있었다면 전에 허용한 기기도 잠금을 풀어야 다시 쓸 수 있습니다.

| 증상 | 확인할 것 |
| --- | --- |
| 꽂아도 반응이 없음 | 허용 창을 놓쳤는지 봅니다. 뺐다가 다시 꽂고 허용을 누릅니다 |
| Finder 사이드바에 없음 | Finder > 설정의 사이드바 탭에서 외장 디스크를 켭니다 |
| 디스크 유틸리티에는 있는데 열리지 않음 | 파일을 복사할 수 있는지 본 뒤 First Aid로 검사합니다 |

Finder 설정은 [Apple의 연결된 기기 보기 안내](https://support.apple.com/guide/mac-help/see-the-devices-connected-to-your-mac-mchlp1039/mac)에 있습니다. 디스크 유틸리티에서는 보기 > 모든 기기 보기를 고르면 USB 아래의 볼륨이 보입니다. Mac에서 USB를 쓰는 기본 순서는 [Mac에서 USB 메모리 쓰는 방법](/blog/ko/usb-drive-on-mac)에 정리했습니다.

## 아이폰에서만 USB가 안 보일 때는?

컴퓨터에서는 열리는데 아이폰에서만 안 보이면 아이폰 쪽 조건을 확인합니다. [Apple의 액세서리 연결 허용 안내](https://support.apple.com/en-us/111806)에 따르면 저장장치를 쓰려면 항상 아이폰 잠금을 먼저 풀어야 합니다.

[Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)에 따르면 저장장치는 데이터 파티션이 하나여야 합니다. 형식은 APFS, APFS(암호화), macOS 확장(HFS+), exFAT, FAT32, FAT 중 하나여야 합니다. 윈도우에서 NTFS로 쓰던 USB는 아이폰 파일 앱에 나타나지 않습니다.

이 경우는 USB 고장이 아니므로 컴퓨터에서 자료를 먼저 꺼냅니다. 그 뒤 [exFAT 포맷 방법](/blog/ko/format-usb-exfat)대로 포맷하면 아이폰에서 쓸 수 있습니다. 잠금, 전원, 케이블을 차례로 보는 순서는 [아이폰 외장하드 인식 안 될 때](/blog/ko/iphone-drive-not-detected)에 있습니다. USB 메모리에도 같은 순서를 씁니다.

## USB가 다시 보이면 자료를 어떻게 꺼내나요?

다시 보이는 순간이 가장 중요합니다. 언제 다시 사라질지 모르니 검사보다 복사를 먼저 합니다.

1. 가장 중요한 폴더부터 컴퓨터나 다른 저장장치에 복사합니다.
2. USB에 있는 파일을 USB 안에서 열어 고치거나 저장하지 않습니다.
3. 복사가 끝나면 아래 방법으로 검사합니다.

Apple은 First Aid가 디스크를 고치지 못하면 가능한 한 많은 자료를 백업한 뒤 다시 포맷하라고 안내합니다. 디스크가 곧 고장 난다는 보고가 나오면 고칠 수 없으니 자료를 백업하고 디스크를 바꾸라고 적습니다.

| 검사 도구 | 출처 | 알아 둘 것 |
| --- | --- | --- |
| Mac 디스크 유틸리티 First Aid | [Apple 저장장치 복구 안내](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac) | 볼륨, 컨테이너, 맨 위 저장장치 순서로 실행합니다. 모든 문제를 찾거나 고치지는 못합니다 |
| 윈도우 `chkdsk` | [Microsoft chkdsk 문서](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/chkdsk) | 매개변수 없이 실행하면 상태만 보여 줍니다. `/f`를 붙여야 오류를 고칩니다. 관리자 권한이 필요합니다 |

`chkdsk E: /f`처럼 입력합니다. E는 예시이므로 USB의 드라이브 문자로 바꾸세요. Microsoft는 `chkdsk`를 도중에 멈추지 말라고 권합니다. 검사 순서는 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)에 자세히 적었습니다. SD 카드를 예로 들었지만 USB 메모리에도 순서가 같습니다.

## 그래도 USB가 인식되지 않으면?

다른 컴퓨터에서도, 디스크 관리에서도 보이지 않으면 USB 자체의 고장을 의심합니다. Microsoft는 이때 Microsoft 커뮤니티나 디스크 제조사에 문의하라고 안내합니다. 같은 안내는 고장 난 디스크에서 자료를 꺼내려는 앱이나 유료 데이터 복구 업체도 있다고 적습니다.

이 글은 특정 프로그램이나 업체를 시험하거나 추천하지 않습니다. 제조사 보증과 지원 범위를 먼저 확인하세요. 파일이 사라졌을 때의 순서는 [SD 카드 손상 증상과 대처](/blog/ko/sd-card-corrupted)에도 있습니다.

## 같은 일을 다시 겪지 않으려면?

USB는 뽑기 전에 꺼냅니다. [Microsoft의 하드웨어 안전 제거 안내](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)는 데이터 손실을 막으려면 USB 메모리를 분리하기 전에 항상 안전하게 제거하라고 설명합니다.

자료를 USB 한 곳에만 두지 않습니다. Microsoft는 디스크가 자주 고장 나니 중요한 파일을 정기적으로 백업하라고 권합니다. 가끔 사라지거나 오류를 내는 디스크는 백업을 다시 확인하라는 신호라고 적습니다. 아이폰 사진과 연락처를 USB에 나눠 두는 순서는 [아이폰 USB 백업 방법](/blog/ko/backup-iphone-to-usb)에 있습니다.

## 아이폰 사진을 USB에 따로 저장하려면?

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비 중이며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## 갑자기 USB 인식 안됨 자주 묻는 질문

### 포맷하라는 창에서 포맷을 누르면 어떻게 되나요?

USB의 자료가 모두 지워집니다. Microsoft 안내도 포맷하면 디스크의 모든 데이터가 지워진다고 설명합니다. 자료를 꺼내려면 창을 닫으세요.

### USB를 계속 뺐다 꽂아도 되나요?

뺐다 꽂기는 Microsoft 안내의 첫 단계입니다. 다만 복사 중에 뽑으면 파일이 다 옮겨지지 않을 수 있습니다. 진행 표시가 사라진 뒤 꺼내고 뽑으세요.

### chkdsk를 먼저 실행해도 되나요?

`chkdsk /f`와 First Aid는 디스크의 오류를 고치는 도구입니다. Apple은 수리가 실패하면 가능한 자료를 먼저 백업하라고 안내합니다. 파일이 보인다면 복사를 먼저 하세요.

### 다른 컴퓨터에서는 보이는데 내 컴퓨터에서만 안 보여요.

USB보다 컴퓨터의 포트, 허브, 설정 쪽을 의심합니다. 윈도우라면 디스크 관리에서 드라이브 문자를 확인하고, Mac이라면 연결 허용과 Finder 설정을 확인하세요.

### 아이폰에서만 USB가 안 보여요.

잠금을 풀었는지, 형식이 NTFS가 아닌지, 데이터 파티션이 하나인지 확인하세요. NTFS는 Apple의 외부 저장장치 형식 목록에 없습니다.
