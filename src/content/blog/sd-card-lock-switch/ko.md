## 핵심 요약

SD 카드 잠금 스위치는 카드에 붙은 작은 쓰기 방지 탭입니다. 탭을 잠금 쪽으로 두면 카드 내용을 고치거나 지울 수 없습니다.

Mac에서 잠긴 카드를 쓰면 "cannot be modified" 메시지가 뜰 수 있습니다. 카드를 꺼내기 한 뒤 빼고, 탭을 잠금 해제 쪽으로 밀고, 다시 넣습니다.

microSD 카드에는 잠금 스위치가 없습니다. microSD를 SD 크기 어댑터에 넣어 쓴다면 어댑터의 탭을 확인합니다.

"사진을 옮기려는데 카드가 읽기 전용이래요." "SD 카드 잠금을 걸면 남이 못 보나요?" 카드 옆의 작은 탭 때문에 자주 나오는 질문입니다. 이 글은 SD 카드 잠금이 무엇을 막고 무엇을 막지 않는지, 잠그고 푸는 순서를 정리합니다.

## SD 카드 잠금 스위치는 무엇인가요?

쓰기를 막는 기계식 스위치입니다. Kingston은 [SD 카드 데이터시트](https://www.kingston.com/datasheets/SD4_en.pdf)에서 내장 쓰기 방지 스위치가 실수로 인한 데이터 손실을 막는다고 설명합니다.

[Apple의 Mac SD 카드 슬롯 안내](https://support.apple.com/en-us/102352)는 "cannot be modified" 메시지가 나오면 SD 카드가 잠겨 있을 수 있다고 적습니다. 잠긴 카드는 내용을 수정할 수 없다는 뜻입니다.

| 구분 | SD 카드 잠금 스위치가 하는 일 |
| --- | --- |
| 막는 것 | 새 파일 저장, 파일 수정, 파일 삭제 |
| 막지 않는 것 | 카드를 다른 기기에 꽂아 내용을 보는 일 |
| 하지 않는 것 | 비밀번호 설정, 암호화 |

잠금 스위치는 카드 내용을 숨기지 않습니다. 카드를 잃어버리면 다른 사람이 내용을 볼 수 있습니다.

## 어떤 카드에 SD 카드 잠금 스위치가 있나요?

일반 크기 SD 카드에 있습니다. microSD에는 없습니다. [SD Association FAQ](https://www.sdcard.org/consumers/faq/)는 microSD와 SD 카드가 모양, 크기, 핀 수, 쓰기 방지 스위치 유무만 다르고 내부 논리와 전자 구조는 같다고 설명합니다.

| 카드 | 잠금 스위치 | 근거 |
| --- | --- | --- |
| 일반 SD 카드 | 있음 | [Kingston SD 카드 데이터시트](https://www.kingston.com/datasheets/SD4_en.pdf) |
| microSD 카드 | 없음 | [Kingston microSDXC 데이터시트](https://www.kingston.com/datasheets/SDCIT-specsheet-64gb_us.pdf) |
| SD 어댑터에 넣은 microSD | 어댑터의 탭을 확인 | [microSD와 SD 차이](/blog/ko/microsd-vs-sd) |

Kingston microSDXC 데이터시트는 "microSDXC 카드에는 기계식 쓰기 방지 스위치가 없다"고 적습니다. 카드 크기 차이는 [에스디 카드란?](/blog/ko/what-is-sd-card)에 정리했습니다.

## SD 카드 잠금은 언제 거나요?

카드 내용을 그대로 두고 싶을 때 겁니다.

1. 촬영을 마친 카드를 컴퓨터에 옮기기 전, 실수로 지우지 않으려 할 때
2. 카드를 다른 사람에게 건네 사진을 보여 줄 때
3. 다 쓴 카드를 보관해 둘 때

잠긴 카드에는 사진을 새로 찍어 저장할 수 없습니다. 카메라에 다시 넣기 전에 잠금을 풉니다.

## SD 카드 잠금은 어떻게 푸나요?

[Apple 안내](https://support.apple.com/en-us/102352)를 따른 순서입니다.

1. 카드를 꺼내기 합니다. Mac은 Finder 사이드바에서 카드를 고르고 파일 > 꺼내기를 선택합니다.
2. 카드를 기기에서 뺍니다.
3. 카드의 잠금 탭을 잠금 해제 쪽으로 밉니다.
4. 카드를 슬롯이나 리더기에 다시 넣습니다.

탭 위치는 카드마다 다릅니다. Apple은 제조사 안내에서 탭 위치를 확인하라고 적습니다.

윈도우에서는 빼기 전에 하드웨어 안전 제거를 합니다. [Microsoft 안내](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)는 데이터 손실을 막으려면 USB 저장장치를 빼기 전에 안전 제거를 하라고 설명합니다. 꽂은 채로 탭을 밀지 말고, 뺀 뒤에 바꿉니다.

## 아이폰에서 SD 카드에 저장이 안 되면 잠금을 확인하나요?

확인합니다. 아이폰 사진을 SD 카드에 복사하려면 카드가 잠금 해제 상태여야 합니다. Apple의 아이폰 외부 저장장치 안내는 잠긴 카드의 동작을 따로 적지 않습니다. 저장이 안 되면 리더기에서 카드를 빼고 탭 위치부터 봅니다.

| 확인할 것 | 볼 곳 |
| --- | --- |
| SD 카드 잠금 탭 | 카드의 탭이 잠금 해제 쪽인지 |
| microSD 어댑터 탭 | 어댑터를 쓰면 어댑터의 탭 |
| 리더기 연결 | [C 타입 SD 카드 리더기 사용법](/blog/ko/usb-c-sd-card-reader) |
| 복사 순서 | [아이폰 사진 SD 카드로 옮기기](/blog/ko/iphone-photos-to-sd-card) |

## 잠금을 풀었는데도 SD 카드에 저장이 안 되면?

다른 원인을 봅니다.

1. 카드를 다시 넣고 메시지가 그대로인지 봅니다.
2. 다른 리더기나 다른 컴퓨터에서 같은 카드를 확인합니다.
3. 그래도 쓰기가 안 되면 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)의 순서로 카드를 검사합니다.
4. 포맷은 카드 자료를 지웁니다. 포맷 전에 필요한 사진을 다른 저장장치로 복사합니다. 포맷 순서는 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에 있습니다.

## 아이폰 사진을 USB 메모리에 저장하려면?

아래 앱은 USB 메모리를 기준으로 안내합니다. USB 메모리 연결 조건은 [아이폰 USB 메모리 사용법](/blog/ko/iphone-flash-drive-guide)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비하고 있으며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## SD 카드 잠금 자주 묻는 질문

### SD 카드 잠금을 걸면 다른 사람이 사진을 못 보나요?

볼 수 있습니다. 잠금 스위치는 쓰기를 막는 장치입니다. 비밀번호나 암호화 기능이 없습니다.

### microSD 카드의 잠금은 어디서 푸나요?

microSD 카드에는 잠금 스위치가 없습니다. SD 크기 어댑터에 넣어 쓴다면 어댑터의 탭을 잠금 해제 쪽으로 밉니다.

### 카드를 꽂은 채로 잠금 탭을 밀어도 되나요?

권하지 않습니다. Apple 안내는 카드를 꺼내기 하고 뺀 뒤에 탭을 바꾸고 다시 넣는 순서를 적습니다.

### SD 카드 잠금을 걸면 포맷도 막히나요?

포맷도 카드 내용을 바꾸는 작업입니다. 포맷이 안 되면 잠금 탭부터 확인하세요. 자세한 순서는 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)에 있습니다.

### Mac에 "cannot be modified"가 뜨면 무엇부터 하나요?

Apple은 카드가 잠겨 있을 수 있다고 설명합니다. 카드를 꺼내기 하고 빼서 잠금 탭을 푼 뒤 다시 넣습니다.
