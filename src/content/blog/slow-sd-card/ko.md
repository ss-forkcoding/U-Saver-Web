## 핵심 요약

SD 카드 느려짐을 겪으면 카드부터 의심하기 쉽습니다. 하지만 속도는 카드, 리더기, 연결한 기기가 함께 정합니다. 그중 가장 느린 쪽이 전체 속도를 묶습니다.

먼저 카드의 사진과 영상을 다른 곳에 복사합니다. 그다음 리더기와 연결 단자, 윈도우의 제거 정책을 확인합니다. 카드를 지우는 포맷은 마지막에 합니다.

SD Association은 파일을 지우고 쓰기를 반복하면 카드의 빈 공간이 조각나 쓰기 속도가 느려진다고 설명합니다. 이때는 자료를 옮긴 뒤 카드를 다시 포맷하라고 안내합니다.

"예전보다 사진 복사가 한참 걸려요." "카메라가 연속 촬영 중에 멈춰요." SD 카드 느려짐을 검색하는 분들이 자주 하는 말입니다. 이 글은 원인을 좁히는 순서를 다룹니다. 카드에 적힌 속도 표시의 뜻은 [SD 카드 속도 표시 읽는 법](/blog/ko/sd-card-speed-class)에, 카드 기초는 [SD 카드 기초 가이드](/blog/ko/sd-card-basics-guide)에 있습니다.

## SD 카드가 느려졌을 때 무엇부터 확인하나요?

원인은 크게 다섯 갈래입니다. 아래 표의 위에서부터 확인하면 카드를 지우지 않고 원인을 좁힐 수 있습니다.

| 원인 | 확인할 것 | 근거 |
| --- | --- | --- |
| 연결 경로 | 리더기와 기기가 지원하는 USB 속도·버스 방식 | Apple 카메라 어댑터·Mac SD 슬롯 안내 |
| 윈도우 제거 정책 | 빠른 제거 정책에서는 쓰기 캐시를 쓰지 않습니다 | Microsoft 제거 정책 안내 |
| 카드 조각화 | 지우고 쓰기를 오래 반복했는지 | SD Association 스피드 클래스 안내 |
| 운영체제 포맷 | 컴퓨터 기본 도구로 포맷했는지 | SD Association 포맷 프로그램 안내 |
| 카드 오류·가짜 카드 | 파일이 깨지거나 용량이 이상한지 | Apple 디스크 유틸리티 안내 |

이 글은 특정 카드나 리더기의 속도를 측정하지 않았습니다. 표의 내용은 각 공식 문서의 설명입니다.

## 카드를 점검하기 전에 사본부터 만들어야 하나요?

만들어야 합니다. 느려진 카드는 오류의 신호일 수도 있습니다. 포맷이나 검사를 하기 전에 사진과 영상을 다른 저장장치에 복사합니다.

1. 카드를 컴퓨터나 아이폰에 연결합니다.
2. 남길 사진과 영상을 다른 저장장치로 복사합니다.
3. 복사한 파일 몇 개가 제대로 열리는지 확인합니다.
4. 카드를 뺄 때는 꺼내기를 먼저 합니다.

[Apple의 Mac SD 카드 슬롯 안내](https://support.apple.com/en-us/102352)는 Mac이 잠자기 상태일 때 카드를 빼면 데이터를 잃을 수 있다고 설명합니다. 컴퓨터 연결 순서는 [SD 카드 컴퓨터 연결 방법](/blog/ko/sd-card-to-pc)에 있습니다.

## 리더기와 연결 단자가 속도를 막고 있지는 않나요?

카드가 빨라도 리더기나 기기가 느린 방식만 지원하면 그 속도에 묶입니다. Apple 문서에 적힌 조건은 아래와 같습니다.

| 기기 | Apple 안내 |
| --- | --- |
| 아이폰 | [Apple 카메라 어댑터 안내](https://support.apple.com/en-us/118280)는 iPhone 15 Pro, iPhone 15 Pro Max, iPhone 16 Pro, iPhone 16 Pro Max가 USB 3 전송 속도를 지원한다고 적습니다. 그 밖의 어댑터와 기기는 USB 2 속도를 씁니다 |
| Mac SD 슬롯 | [Apple의 Mac SD 카드 슬롯 안내](https://support.apple.com/en-us/102352)는 UHS-II를 2022년 이후 Mac Studio, 2021년 이후 MacBook Pro, 2020년 iMac, iMac Pro에서만 지원한다고 적습니다. 다른 모델의 슬롯은 UHS-I까지입니다 |

확인 순서는 이렇습니다.

1. 같은 카드를 다른 리더기나 다른 단자에 꽂아 봅니다.
2. 같은 리더기에 다른 카드를 꽂아 비교합니다.
3. 한쪽에서만 느리면 그 리더기나 단자의 지원 방식을 확인합니다.

버스 방식의 차이는 [UHS-I·UHS-II·SD Express 차이](/blog/ko/uhs-sd-card)에, 리더기 확인 항목은 [SD 카드 리더기 고르는 법](/blog/ko/choose-sd-card-reader)에 있습니다.

## 윈도우에서만 복사가 느리다면 어떤 설정을 보나요?

외부 저장장치의 제거 정책을 확인합니다. [Microsoft의 제거 정책 안내](https://learn.microsoft.com/en-us/windows/client-management/change-default-removal-policy-external-storage-media)에 따르면 윈도우 10 버전 1809부터 기본값은 빠른 제거입니다.

| 정책 | Microsoft 설명 |
| --- | --- |
| 빠른 제거 | 언제든 뺄 수 있게 쓰기 캐시를 쓰지 않습니다. 성능이 떨어질 수 있습니다 |
| 더 나은 성능 | 쓰기 작업을 캐시해 성능을 높입니다. 뺄 때 반드시 하드웨어 안전하게 제거를 거쳐야 합니다 |

바꾸는 순서는 아래와 같습니다.

1. 장치를 컴퓨터에 연결합니다.
2. 시작 단추를 마우스 오른쪽 버튼으로 누르고 파일 탐색기에서 장치의 드라이브 문자를 확인합니다.
3. 시작 단추를 다시 마우스 오른쪽 버튼으로 누르고 디스크 관리를 엽니다.
4. 창 아래쪽에서 장치 이름을 마우스 오른쪽 버튼으로 누르고 속성을 고릅니다.
5. 정책 탭에서 원하는 정책을 고릅니다. 정책 탭이 없으면 하드웨어 탭에서 장치를 고른 뒤 속성을 누릅니다.

Microsoft는 더 나은 성능을 고른 상태에서 안전하게 제거를 거치지 않고 빼면 데이터를 잃을 수 있다고 경고합니다. 카드를 자주 빼는 환경이라면 빠른 제거를 유지하는 편이 안전합니다.

## 오래 쓴 SD 카드는 왜 느려지나요?

[SD Association의 스피드 클래스 안내](https://www.sdcard.org/developers/sd-standard-overview/speed-class/)는 조각화를 원인으로 듭니다.

- 파일을 지우고 쓰기를 반복하면 데이터 영역이 조금씩 조각납니다.
- 플래시 메모리 특성상 조각난 영역에 쓰는 속도는 연속 쓰기보다 느립니다.
- 스피드 클래스 쓰기는 조각나지 않은 빈 영역에 연속으로 쓰는 것을 전제로 합니다.
- 그래서 남은 용량이 충분해도 기기가 스피드 클래스 녹화를 하지 못할 수 있습니다.

같은 안내는 이때 데이터를 다른 저장장치로 옮기고 카드를 다시 포맷하라고 설명합니다.

## 포맷으로 SD 카드 속도를 되찾으려면?

포맷하면 카드의 자료가 모두 지워집니다. 앞에서 만든 사본이 열리는지 확인한 뒤 진행합니다.

[SD Association의 포맷 프로그램 안내](https://www.sdcard.org/downloads/formatter/)는 운영체제의 포맷 도구 대신 SD Memory Card Formatter를 쓰라고 강하게 권합니다. 운영체제 도구는 SD 카드에 맞게 최적화되지 않아 성능이 낮아질 수 있다는 이유입니다.

| 항목 | SD Association 안내 |
| --- | --- |
| 지원 운영체제 | 윈도우 10 22H2, 윈도우 11 22H2·23H2·24H2, macOS 11~15 |
| 보호 영역 | 이 프로그램은 카드의 보호 영역(Protected Area)을 포맷하지 않습니다 |
| BitLocker To Go | 암호화된 카드는 잠금을 푼 뒤 포맷합니다 |

설치와 빠른 포맷·덮어쓰기 포맷의 차이는 [SD 카드 포맷 프로그램 사용법](/blog/ko/sd-card-formatter)에 있습니다. 카메라에서 쓸 카드라면 기기에서 포맷하는 순서도 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에서 확인하세요.

## 포맷 뒤에도 느리거나 파일이 깨진다면?

카드 오류를 의심합니다. Mac에서는 디스크 유틸리티의 응급 처치로 검사합니다. [Apple의 디스크 유틸리티 복구 안내](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac)는 응급 처치가 포맷과 디렉터리 구조의 오류를 확인하고 고친다고 설명합니다.

1. 디스크 유틸리티를 열고 보기, 모든 기기 보기를 고릅니다.
2. 사이드바에서 카드의 볼륨을 고르고 응급 처치를 누릅니다.
3. 실행을 누르고 화면 안내를 따릅니다.
4. 볼륨이 끝나면 컨테이너, 저장장치 순서로 같은 검사를 반복합니다.

같은 안내는 디스크 유틸리티가 모든 문제를 찾거나 고치지는 못한다고 적습니다. 디스크가 곧 고장 날 것이라는 보고가 나오면 자료를 옮기고 교체하라고 안내합니다. 증상별 대처는 [손상된 SD 카드 복구 전에](/blog/ko/sd-card-corrupted)에 있습니다.

새로 산 카드부터 느리고 용량도 이상하다면 [가짜 SD 카드 구별법](/blog/ko/fake-sd-card)을 확인하세요.

## 아이폰 사진을 USB 메모리에도 저장해 두려면?

느려진 카드에만 사진을 두면 오류가 날 때 함께 잃을 수 있습니다. 다른 저장장치에 사본을 하나 더 만들어 두세요. 아래 앱은 USB 메모리를 기준으로 안내합니다. USB 형식을 바꾸는 순서는 [exFAT 포맷 방법](/blog/ko/format-usb-exfat)에, 옮기는 순서는 [아이폰 사진 USB로 옮기기](/blog/ko/iphone-photos-to-usb)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비 중이며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## SD 카드 느려짐 자주 묻는 질문

### SD 카드가 느려지면 고장 난 건가요?

꼭 그렇지는 않습니다. 리더기, 연결 단자, 윈도우 제거 정책, 조각화도 속도를 낮춥니다. 다른 리더기와 다른 카드로 비교해 원인을 좁히세요.

### 포맷하면 SD 카드 속도가 돌아오나요?

조각화가 원인이면 도움이 됩니다. SD Association은 자료를 옮긴 뒤 카드를 다시 포맷하라고 안내합니다. 연결 경로가 원인이면 포맷으로는 달라지지 않습니다.

### 컴퓨터 기본 도구로 포맷해도 되나요?

포맷은 됩니다. 다만 SD Association은 운영체제 도구가 SD 카드에 최적화되지 않아 성능이 낮아질 수 있다며 SD Memory Card Formatter를 권합니다.

### 아이폰에서 SD 카드 읽기가 느린 이유는 무엇인가요?

Apple 안내에 따르면 iPhone 15 Pro, iPhone 15 Pro Max, iPhone 16 Pro, iPhone 16 Pro Max만 USB 3 전송 속도를 지원합니다. 그 밖의 어댑터와 기기는 USB 2 속도를 씁니다.

### 윈도우에서 더 나은 성능 정책을 켜도 되나요?

켤 수 있습니다. 다만 Microsoft는 이 정책에서는 하드웨어 안전하게 제거를 반드시 거쳐야 하고, 그냥 빼면 데이터를 잃을 수 있다고 경고합니다.
