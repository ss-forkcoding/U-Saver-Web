## この記事の要点

Insta360のSDカードは、マニュアルが決めた表示で選びます。Insta360 Xシリーズは、UHS-I・V30以上で、exFATでフォーマットしたmicroSDカードを求めます。GoPro MAX2とLIT HEROのマニュアルは、A2とV30以上のカードを求めます。

2社の条件は重なりますが、同じではありません。GoProはA2を挙げ、Insta360はUHS-II・UHS-IIIのカードを使わないよう書いています。両方のカメラで使うカードなら、UHS-I、V30、A2の表示をすべて確かめます。

カードは長く使うと性能が落ちます。映像を別の場所にコピーしてから、カメラで定期的にフォーマットし、問題が出たら新しいカードに替えます。

「Insta360のSDカードはおすすめのものを買えばいいですか?」「V90のほうが速いから良いのでは?」アクションカメラを買うときによく出る疑問です。この記事では、Insta360とGoProの公式マニュアルからカードの条件を読む方法と、管理の手順をまとめます。特定の製品はおすすめせず、カードを実際に試してもいません。

## Insta360のSDカードはどんな条件を満たせばいいですか?

[Insta360 Xシリーズのメモリーカード互換性FAQ](https://onlinemanual.insta360.com/x6/en-us/specs/compatibility/sdcard)は、ONE XからX6までの条件をまとめています。

| 項目 | Insta360 XシリーズFAQ |
| --- | --- |
| スピードクラス | UHS-I、V30以上 |
| ファイルシステム | exFAT |
| 使わないカード | UHS-II、UHS-III(録画が止まることがある) |
| 最大容量 | X6・X5・X4 Air・X4・X3・X2は1TB、ONE Xは256GB |
| 遅いカード | 録画の中断やファイルの破損が起きることがある |

[Insta360 X4のストレージFAQ](https://onlinemanual.insta360.com/x4/ja-jp/faq/compatibility/storage)も、スピードクラスがV30以上でexFAT形式のUHS-I microSDカードを使うよう書いています。UHS-II/UHS-IIIのカードと、1TBより大きなカードは使わないよう注意しています。

## Insta360のSDカードおすすめはどう探しますか?

まずInsta360の案内を見ます。[Insta360 X5のマニュアル](https://onlinemanual.insta360.com/x5/en-us/camera/basicuse/filestorage)は、Insta360の公式カードを勧め、ほかに互換性を確かめたカードの一覧も載せています。

一覧にはA1のカードも入っています。Insta360はA2を必須としていません。一覧にないカードを選ぶときは、UHS-I、V30以上、容量1TB以下という条件で選びます。

表示の意味は次のとおりです。

| 表示 | 意味 | 詳しい記事 |
| --- | --- | --- |
| V30 | 動画録画用の最低書き込み速度クラス | [SDカードのV30とは?](/blog/ja/sd-card-speed-class) |
| A2 | 小さなファイルの読み書きを示すアプリ性能クラス | [SDカードのA1・A2とは?](/blog/ja/sd-card-a1-a2) |
| UHS-I | カードの端子(バス)規格 | [UHSスピードクラスとは?](/blog/ja/uhs-sd-card) |

パッケージの「最大OOMB/s」は最低保証の値ではありません。マニュアルが書いた表示を基準に選びます。

## V60やV90のカードはInsta360に使えますか?

Insta360 XシリーズのFAQは勧めていません。V60・V90は主にUHS-IIやUHS-IIIのカードに付くクラスで、Xシリーズと互換性の問題が起きることがあると書いています。数字が大きいほど合うカードというわけではありません。

## GoProのSDカードとはどこが違いますか?

[GoPro MAX2のマニュアル](https://static.gopro.com/assets/blta2b8522e5372af40/blte32e2783ff44e36a/68c27e50d9e51a0e3481b803/MAX2_UM_en-US_REVA.pdf)は、microSD・microSDHC・microSDXCで、A2とV30以上、容量1TBまでのブランド品を求めます。おすすめのカード一覧はgopro.com/microsdcardsで案内しています。[GoPro LIT HEROのマニュアル](https://static.gopro.com/assets/blta2b8522e5372af40/blt5746f0817192c74e/68d4faef911e5d128655a6a3/LITHERO_UM_en-US_REVA.pdf)もA2とV30以上を求めます。

| 条件 | GoPro MAX2・LIT HERO | Insta360 Xシリーズ |
| --- | --- | --- |
| V30以上 | 必要 | 必要 |
| A2 | 必要 | 記載なし |
| UHS-I | 記載なし | 必要(UHS-II・III不可) |
| exFAT | 記載なし | 必要 |
| 最大容量 | 1TB(MAX2) | 1TB(X2~X6) |

GoProは、A2・V30に届かないカードや、使い続けて性能が落ちたカードを入れると知らせます。両方のカメラで1枚を使うなら、UHS-I、V30、A2の表示がすべてあるカードを選びます。カメラを替えるときは、新しいカメラでフォーマットします。フォーマットするとデータが消えるので、先にコピーします。

## アクションカメラのSDカードの容量はどれくらいですか?

録画の解像度とビットレートで決めます。Insta360 X4のストレージFAQは、1分あたりのファイルサイズをこう書いています。

| 解像度 | ビットレート | 1分あたり |
| --- | --- | --- |
| 8K 30fps | 高 | 1.5GB |
| 8K 30fps | 標準 | 1GB |
| 5.7K 30fps | 高 | 700MB |
| 5.7K 30fps | 標準 | 500MB |

同じFAQは、録画のキャッシュ用に1~2GBほど使うと書いています。表から割り算すると、128GBのカードで8K・高ビットレートを80分台ほど録画できます。これは単純な計算で、実際の時間はカードの実容量と設定で変わります。

上限も守ります。GoPro MAX2とInsta360 X2~X6は1TBまでです。ONE Xのような古い機種は上限がもっと低くなります。

## アクションカメラのSDカードはどの順で選びますか?

1. カメラのマニュアルでSDカードの項目を探します。
2. スピードクラス(V30)、アプリ性能クラス(A2)、バス規格(UHS-I)の条件をメモします。
3. 最大容量を確かめ、その範囲で録画時間に合う容量を選びます。
4. メーカーの推奨カード一覧を見ます。GoProはgopro.com/microsdcards、Insta360はマニュアルの一覧です。
5. 信頼できる店で買います。GoProのマニュアルはブランド品を使うよう書いています。容量を偽ったカードは[SDカードの偽物の見分け方](/blog/ja/fake-sd-card)で確かめます。
6. 新しいカードをカメラに入れ、カメラでフォーマットします。

一般的なカメラ用カードとの違いは[カメラ用SDカードの選び方](/blog/ja/camera-sd-card)にあります。録画を繰り返す機器なら[ドラレコのSDカードの選び方](/blog/ja/dashcam-sd-card)も比べてみてください。

## アクションカメラのSDカードはどうフォーマットしますか?

カメラの中でフォーマットします。GoPro MAX2のマニュアルの手順は次のとおりです。

1. 画面を下にスワイプしてダッシュボードを開きます。
2. 左にスワイプし、Preferences > Reset > Format SD Cardをタップします。
3. Formatをタップして、すべてのファイルを消してフォーマットします。

GoProのマニュアルは、定期的なフォーマットがカードを良い状態に保つのに役立つと書いています。Insta360のFAQも、ファイルを定期的にバックアップし、カードをフォーマットするよう勧めています。フォーマットするとデータはすべて消えるので、先に移します。

パソコンでフォーマットするなら、Insta360ではexFATを選びます。パソコンでの手順は[マイクロSDカードフォーマット方法](/blog/ja/format-microsd)にあります。

## SDカードはいつ交換しますか?

GoProのマニュアルは、SDカードは時間とともに劣化し、メディアの保存に影響することがあると書いています。問題が出たら、古いカードを新しいカードに替えてみるよう勧めています。

次のときは交換を考えます。

1. カメラがカードのクラス不足や性能低下を知らせます。
2. カメラにSD Card Errorが出ます。GoPro MAX2のマニュアルは、カメラを再起動するよう案内しています。
3. フォーマットしても録画が途切れたり、ファイルが開けなかったりします。
4. パソコンがカードを認識しません。確かめる順番は[microSDが認識しない・フォーマットできないときの確認手順](/blog/ja/sd-card-not-working)にあります。

## アクションカメラの映像をiPhoneに移すには?

iPhoneにはカードスロットがないので、SDカードリーダーでつなぎます。[Appleの外部ストレージの案内](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)によると、iPhoneはexFAT、FAT32などの形式を読み込めます。Insta360が求めるexFATもこの一覧に入っています。

つなぐ手順は[micro SDをiPhoneで使う方法](/blog/ja/iphone-microsd)に、リーダーから写真アプリに読み込む方法は[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)にまとめました。移した映像を確かめてから、カメラでカードをフォーマットします。

## Insta360のSDカードについてよくある質問

### Insta360にA2のカードは必要ですか?

Insta360 XシリーズのFAQはA2を条件に挙げていません。X5の互換カード一覧にはA1のカードもあります。GoProと共用するならA2を選びます。

### 1TBより大きなカードは使えますか?

Insta360 X2~X6とGoPro MAX2のマニュアルは、上限を1TBとしています。Insta360 X4のFAQは、1TBより大きなカードを使わないよう書いています。

### スマホで使っていたmicroSDをInsta360に入れてもいいですか?

マニュアルの条件(UHS-I、V30以上など)を満たせば使えます。先にカードのデータを移し、カメラでフォーマットします。フォーマットするとスマホのデータは消えます。

### ドラレコ用の高耐久カードをアクションカメラに使えますか?

カードの表示がアクションカメラのマニュアルの条件に合うかで判断します。「高耐久」という表示だけでは、V30やA2かどうかはわかりません。パッケージの表示を確かめます。

### GoPro用に買ったカードをInsta360で使えますか?

UHS-Iのカードなら使える条件に入ります。GoPro用のA2・V30カードでも、UHS-IIやUHS-IIIならInsta360のFAQは使わないよう書いています。カード裏の端子が1列ならUHS-Iです。
