## 핵심 요약

고프로 SD 카드는 설명서가 정한 표시로 고릅니다. GoPro MAX2와 LIT HERO 설명서는 A2와 V30 이상 등급의 microSD 카드를 요구합니다. Insta360 X 시리즈는 UHS-I, V30 이상이고 exFAT으로 포맷한 카드를 요구합니다.

두 회사 조건은 겹치지만 같지 않습니다. GoPro는 A2를 적고, Insta360은 UHS-II·UHS-III 카드를 쓰지 말라고 적습니다. 두 카메라에 같이 쓸 카드라면 UHS-I, V30, A2 표시를 모두 확인합니다.

카드는 오래 쓰면 성능이 떨어집니다. 영상을 다른 곳에 복사한 뒤 카메라에서 정기적으로 포맷하고, 문제가 생기면 새 카드로 바꿉니다.

"고프로 SD 카드는 아무거나 넣어도 되나요?" "V90 카드가 더 빠르니 더 좋지 않나요?" 액션캠을 살 때 자주 나오는 질문입니다. 이 글은 GoPro와 Insta360 공식 설명서로 카드 조건을 읽는 법과 관리 순서를 정리합니다. 특정 제품을 추천하지 않으며, 카드를 직접 시험하지 않았습니다.

## 고프로 SD 카드는 어떤 조건을 맞춰야 하나요?

GoPro 설명서의 SD 카드 항목을 봅니다. [GoPro MAX2 설명서](https://static.gopro.com/assets/blta2b8522e5372af40/blte32e2783ff44e36a/68c27e50d9e51a0e3481b803/MAX2_UM_en-US_REVA.pdf)는 조건을 이렇게 적습니다.

| 항목 | GoPro MAX2 설명서 |
| --- | --- |
| 카드 종류 | microSD, microSDHC, microSDXC |
| 속도 등급 | Class A2와 V30 이상 |
| 최대 용량 | 1TB |
| 제조사 | 브랜드 제품 사용 |
| 권장 카드 | gopro.com/microsdcards 목록 안내 |

[GoPro LIT HERO 설명서](https://static.gopro.com/assets/blta2b8522e5372af40/blt5746f0817192c74e/68d4faef911e5d128655a6a3/LITHERO_UM_en-US_REVA.pdf)도 A2와 V30 이상을 요구합니다. 기종마다 조건이 다를 수 있으니 내 카메라 설명서를 먼저 봅니다.

GoPro 카메라는 등급이 모자란 카드를 알려 줍니다. 두 설명서 모두 A2·V30 미만 카드나 오래 써서 성능이 떨어진 카드를 넣으면 카메라가 알린다고 적습니다.

## A2와 V30은 무슨 뜻인가요?

두 표시는 서로 다른 성능을 가리킵니다.

| 표시 | 뜻 | 자세한 글 |
| --- | --- | --- |
| V30 | 영상 녹화용 최소 쓰기 속도 등급 | [SD 카드 속도 표시 읽는 법](/blog/ko/sd-card-speed-class) |
| A2 | 작은 파일을 읽고 쓰는 앱 성능 등급 | [SD 카드 A1·A2 뜻](/blog/ko/sd-card-a1-a2) |
| UHS-I | 카드 단자(버스) 규격 | [UHS-I·UHS-II·SD Express 차이](/blog/ko/uhs-sd-card) |

포장의 "최대 OOMB/s"는 최소 보장값이 아닙니다. 설명서가 적은 등급 표시를 기준으로 고릅니다.

## Insta360 SD 카드는 고프로와 무엇이 다른가요?

[Insta360 X 시리즈 메모리 카드 FAQ](https://onlinemanual.insta360.com/x6/en-us/specs/compatibility/sdcard)는 ONE X부터 X6까지의 조건을 정리합니다.

| 항목 | Insta360 X 시리즈 FAQ |
| --- | --- |
| 속도 등급 | UHS-I, V30 이상 |
| 파일 시스템 | exFAT |
| 쓰지 말 카드 | UHS-II, UHS-III (녹화가 멈출 수 있음) |
| 최대 용량 | X6·X5·X4 Air·X4·X3·X2는 1TB, ONE X는 256GB |
| 느린 카드 | 녹화가 끊기거나 파일이 손상될 수 있음 |

같은 FAQ는 V60·V90 카드도 다룹니다. V60·V90은 대개 UHS-II나 UHS-III 카드에 붙는 등급이라 X 시리즈와 호환 문제가 생길 수 있다고 적습니다. 속도 숫자가 크다고 더 맞는 카드가 아닙니다.

[Insta360 X5 설명서](https://onlinemanual.insta360.com/x5/en-us/camera/basicuse/filestorage)는 Insta360 공식 카드를 권하고, 그 밖에 호환을 시험한 카드 목록을 함께 둡니다. 목록에는 A1 카드도 있어 Insta360은 A2를 필수로 적지 않습니다.

## 고프로와 Insta360에 같은 카드를 써도 되나요?

두 설명서 조건을 모두 맞추면 씁니다. 비교하면 이렇습니다.

| 조건 | GoPro MAX2·LIT HERO | Insta360 X 시리즈 |
| --- | --- | --- |
| V30 이상 | 필요 | 필요 |
| A2 | 필요 | 적지 않음 |
| UHS-I | 적지 않음 | 필요(UHS-II·III 금지) |
| exFAT | 적지 않음 | 필요 |
| 최대 용량 | 1TB(MAX2) | 1TB(X2~X6) |

두 카메라에 같이 쓸 카드라면 UHS-I, V30, A2 표시가 모두 있는 카드를 고릅니다. 카메라를 바꿔 끼울 때는 새 카메라에서 포맷합니다. 포맷하면 카드 자료가 지워지므로 먼저 복사합니다.

## 액션캠 SD 카드 용량은 얼마로 하나요?

녹화 해상도와 비트레이트로 정합니다. [Insta360 X4 저장 FAQ](https://onlinemanual.insta360.com/x4/en-us/faq/compatibility/storage)는 1분당 파일 크기를 이렇게 적습니다.

| 해상도 | 비트레이트 | 1분당 크기 |
| --- | --- | --- |
| 8K 30fps | 높음 | 1.5GB |
| 8K 30fps | 표준 | 1GB |
| 5.7K 30fps | 높음 | 700MB |
| 5.7K 30fps | 표준 | 500MB |

같은 FAQ는 녹화 캐시로 1~2GB를 따로 쓴다고 적습니다. 위 표로 계산하면 128GB 카드에 8K 높은 비트레이트로 대략 80분대를 녹화합니다. 이 값은 표를 나눈 계산이며 실제 시간은 카드의 실제 용량과 설정에 따라 다릅니다.

용량의 상한도 지킵니다. GoPro MAX2와 Insta360 X2~X6은 1TB까지입니다. ONE X처럼 오래된 기종은 상한이 더 낮습니다.

## 액션캠 SD 카드는 어떤 순서로 고르나요?

1. 카메라 설명서에서 SD 카드 항목을 찾습니다.
2. 속도 등급(V30), 앱 성능 등급(A2), 버스 규격(UHS-I) 조건을 메모합니다.
3. 최대 용량을 확인하고 그 안에서 촬영 시간에 맞는 용량을 고릅니다.
4. 제조사의 권장 카드 목록이 있는지 봅니다. GoPro는 gopro.com/microsdcards를, Insta360은 설명서 안 목록을 안내합니다.
5. 믿을 수 있는 판매처에서 삽니다. GoPro 설명서는 브랜드 카드를 쓰라고 적습니다. 용량을 속인 카드는 [가짜 SD 카드 구별법](/blog/ko/fake-sd-card)으로 확인합니다.
6. 새 카드를 카메라에 넣고 카메라에서 포맷합니다.

일반 카메라용 카드와의 차이는 [카메라 SD 카드 고르는 법](/blog/ko/camera-sd-card)에 있습니다. 반복 녹화가 많은 기기라면 [블랙박스 SD 카드 고르는 법](/blog/ko/dashcam-sd-card)도 비교해 봅니다.

## 고프로 SD 카드는 어떻게 포맷하나요?

카메라 안에서 포맷합니다. GoPro MAX2 설명서의 순서는 이렇습니다.

1. 화면을 아래로 쓸어 대시보드를 엽니다.
2. 왼쪽으로 쓸어 Preferences > Reset > Format SD Card를 누릅니다.
3. Format을 눌러 모든 파일을 지우고 카드를 포맷합니다.

GoPro 설명서는 정기적으로 다시 포맷하면 카드 상태를 좋게 유지하는 데 도움이 된다고 적습니다. Insta360 FAQ도 파일을 정기적으로 백업하고 카드를 포맷하라고 권합니다. 포맷하면 카드 자료가 모두 지워지므로 먼저 옮깁니다.

컴퓨터에서 포맷해야 한다면 Insta360은 exFAT을 고릅니다. 컴퓨터 포맷 순서는 [마이크로 SD 카드 포맷 방법](/blog/ko/format-microsd)에 있습니다.

## 고프로 SD 카드는 언제 바꾸나요?

GoPro 설명서는 SD 카드가 시간이 지나면 성능이 떨어져 영상 저장에 영향을 줄 수 있다고 적습니다. 문제가 생기면 오래된 카드를 새 카드로 바꿔 보라고 권합니다.

아래 상황이면 교체를 검토합니다.

1. 카메라가 카드 등급이나 성능 저하를 알립니다.
2. 카메라가 SD Card Error를 띄웁니다. GoPro MAX2 설명서는 이때 카메라를 다시 켜라고 안내합니다.
3. 포맷한 뒤에도 녹화가 끊기거나 파일이 열리지 않습니다.
4. 컴퓨터에서 카드를 인식하지 못합니다. 점검 순서는 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)에 있습니다.

## 액션캠 영상을 아이폰으로 옮기려면?

아이폰에는 카드 슬롯이 없어 SD 카드 리더기로 연결합니다. [Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)에 따르면 아이폰은 exFAT, FAT32 등의 형식을 읽습니다. Insta360이 요구하는 exFAT 카드는 이 목록에 들어 있습니다.

연결 순서는 [아이폰 마이크로 SD 쓰는 법](/blog/ko/iphone-microsd)에, 리더기에서 사진 앱으로 가져오는 법은 [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader)에 정리했습니다. 옮긴 영상을 확인한 뒤 카메라에서 카드를 포맷합니다.

## 고프로 SD 카드 자주 묻는 질문

### 고프로에 A1 카드를 넣어도 되나요?

GoPro MAX2와 LIT HERO 설명서는 A2와 V30 이상을 요구합니다. 기준보다 낮은 카드를 넣으면 카메라가 알립니다. 다른 기종은 그 기종 설명서를 봅니다.

### V90 카드가 V30보다 좋은가요?

Insta360 X 시리즈에서는 아닙니다. Insta360 FAQ는 V60·V90 카드가 대개 UHS-II·UHS-III라 호환 문제가 생길 수 있다고 적고 UHS-I, V30 이상을 권합니다.

### 1TB보다 큰 카드를 써도 되나요?

GoPro MAX2와 Insta360 X2~X6 설명서의 상한은 1TB입니다. Insta360 X4 FAQ는 1TB보다 큰 카드를 쓰지 말라고 적습니다.

### 휴대폰에서 쓰던 microSD를 액션캠에 넣어도 되나요?

설명서 조건(V30, A2, UHS-I 등)에 맞으면 넣을 수 있습니다. 카드 자료를 먼저 옮기고 카메라에서 포맷합니다. 포맷하면 휴대폰 자료가 지워집니다.

### 블랙박스용 고내구성 카드를 액션캠에 써도 되나요?

카드 표시가 액션캠 설명서 조건에 맞는지로 판단합니다. 고내구성이라는 표시만으로는 V30이나 A2를 알 수 없습니다. 카드 포장의 등급 표시를 확인합니다.
