## 핵심 요약

갤럭시 사진을 SD 카드로 옮기려면 내 파일 앱에서 내장 메모리의 DCIM > Camera 폴더를 열고, 사진을 길게 눌러 이동합니다. 갤러리 앱에서는 이 방법으로 옮길 수 없습니다.

이동은 휴대폰에서 원본을 지웁니다. 중요한 사진은 복사로 하나 더 남기거나, 옮긴 뒤 컴퓨터에도 보관합니다.

앞으로 찍을 사진은 카메라 설정의 저장 위치를 SD 카드로 바꿉니다. 일부 촬영 모드는 이 설정과 관계없이 내장 메모리에 저장됩니다.

"휴대폰 용량이 꽉 차서 사진을 카드로 넘기고 싶어요." "카드를 넣었는데 사진은 그대로 휴대폰에 있어요." 갤럭시에 SD 카드를 넣은 분들이 자주 하는 말입니다. 카드를 넣는다고 기존 사진이 저절로 옮겨지지 않습니다. 이 글은 이미 찍은 사진을 카드로 옮기는 순서와 앞으로 찍을 사진의 저장 위치를 바꾸는 방법을 다룹니다. 카드를 넣고 포맷하는 단계는 [핸드폰 SD 카드 사용법](/blog/ko/android-microsd)에 정리했습니다.

## 갤럭시 사진을 SD 카드로 옮기기 전에 무엇을 확인하나요?

세 가지를 먼저 봅니다.

| 확인할 것 | 이유 | 출처 |
| --- | --- | --- |
| 휴대폰에 microSD 자리가 있는지 | 모든 휴대폰이 microSD를 지원하지는 않습니다 | [Samsung 미국 지원 안내](https://www.samsung.com/us/support/answer/ANS10001928/) |
| 카드가 휴대용 저장공간인지 | 내부 저장공간으로 포맷한 카드는 다른 기기로 옮겨 쓸 수 없습니다 | [Google 안드로이드 도움말](https://support.google.com/android/answer/12153449?hl=ko) |
| 카드 형식이 exFAT이나 FAT32인지 | Samsung은 exFAT을 권하고, FAT32는 4GB가 넘는 파일을 담지 못한다고 적습니다 | [Samsung 미국 지원 안내](https://www.samsung.com/us/support/answer/ANS10001928/) |

같은 Samsung 안내는 NTFS와 APFS가 호환되지 않는다고 적습니다. 긴 영상까지 옮길 계획이면 exFAT 카드가 맞습니다. 카드를 다시 포맷해야 한다면 [마이크로 SD 카드 포맷 방법](/blog/ko/format-microsd)을 보세요. 포맷하면 카드의 자료가 지워집니다.

## 이동과 복사는 무엇이 다른가요?

원본이 휴대폰에 남는지가 다릅니다.

| 방법 | 휴대폰의 원본 | 휴대폰 용량 | 어울리는 경우 |
| --- | --- | --- | --- |
| 이동 | 지워집니다 | 늘어납니다 | 휴대폰 공간을 비우고 싶을 때 |
| 복사 | 남습니다 | 그대로입니다 | 카드에 사본을 하나 더 두고 싶을 때 |

[삼성전자서비스 안내](https://www.samsungsvc.co.kr/solution/39687)는 파일 이동이 끝나기 전에 취소를 누르거나 예기치 못한 현상이 생기면 이동 중인 파일이 삭제될 수 있다고 적습니다. 같은 안내는 서비스센터가 데이터 이동을 대신해 주지 않으니 직접 백업하라고 안내합니다. 아끼는 사진은 먼저 복사하고, 카드에서 열리는지 본 뒤 휴대폰 쪽을 지우는 편이 안전합니다.

## 갤럭시 내 파일 앱으로 사진을 SD 카드로 옮기려면?

카메라로 찍은 사진은 내장 메모리의 DCIM > Camera 폴더에 있습니다. [삼성전자서비스 안내](https://www.samsungsvc.co.kr/solution/39687)의 안드로이드 9~12 기준 순서입니다.

1. Samsung 폴더에서 내 파일 앱을 엽니다.
2. 내장 메모리를 누릅니다.
3. DCIM, Camera 폴더를 차례로 엽니다.
4. 옮길 사진을 길게 누르고 이동을 누릅니다.
5. 상위 폴더로 나가 SD 카드를 누릅니다.
6. 옮길 폴더를 고릅니다. 안내 예시는 SD 카드의 DCIM > Camera입니다.
7. 여기로 이동을 누릅니다.

[Samsung 미국 지원 안내](https://www.samsung.com/us/support/answer/ANS10001928/)의 순서도 같습니다. 파일을 길게 누르고 이동이나 복사를 고른 뒤 내 파일 홈으로 돌아가 SD 카드, 폴더, 여기로 이동 또는 여기에 복사를 차례로 누릅니다. SD 카드 항목은 카드를 넣었을 때만 보입니다.

새 폴더에 따로 모으고 싶다면 [Samsung 일본 지원 안내](https://www.samsung.com/jp/support/mobile-devices/how-do-i-move-data-between-the-external-sd-card-and-the-console-of-galaxy)처럼 내 파일에서 SD 카드를 열고 더보기(점 세 개) > 폴더 만들기로 폴더를 만든 뒤 그곳으로 옮깁니다. 메뉴 이름은 모델과 One UI 버전에 따라 다를 수 있습니다.

## Files by Google로 사진을 SD 카드로 옮기려면?

카테고리에서 사진을 고르거나 정리 메뉴를 씁니다. [Files by Google 도움말](https://support.google.com/files/answer/9712028?hl=ko)에 나온 두 방법입니다.

| 방법 | 순서 |
| --- | --- |
| 카테고리에서 옮기기 | 카테고리 선택 → 사진 찾기 → 더보기 → 다음으로 이동 또는 다음으로 복사 → SD 카드 → 폴더 선택 → 여기로 이동 또는 여기에 복사 |
| 정리 메뉴에서 옮기기 | 메뉴 → 정리 → 'SD 카드로 이동' 카드의 파일 선택 → 옮길 파일 선택 → SD 카드로 이동 |

여러 장을 한 번에 옮길 때는 오른쪽 위 더보기에서 선택을 누르고 파일마다 원을 체크합니다. 같은 도움말에 따르면 Files by Google은 Android 8.0 이상에서 동작합니다.

## 갤러리 앱에서는 왜 SD 카드로 옮길 수 없나요?

[Samsung 미국 지원 안내](https://www.samsung.com/us/support/answer/ANS10001928/)는 이 이동·복사 방법이 내 파일 앱에서만 되고 갤러리 같은 다른 앱에서는 되지 않는다고 적습니다. 갤러리에서 사진을 보다가 옮기고 싶다면 내 파일 앱을 열어 같은 사진을 찾습니다. [Samsung 일본 지원 안내](https://www.samsung.com/jp/support/mobile-devices/how-do-i-move-data-between-the-external-sd-card-and-the-console-of-galaxy)의 폴더 설명에 따르면 내장 메모리의 DCIM 폴더에는 카메라로 찍은 사진·영상과 화면 캡처가 저장됩니다. 폴더 구성은 쓰는 앱에 따라 다릅니다.

## 앞으로 찍을 사진을 SD 카드에 바로 저장하려면?

카메라 앱의 저장 위치를 SD 카드로 바꿉니다. [Samsung 영국 지원 안내](https://www.samsung.com/uk/support/mobile-devices/using-an-sd-card/)의 순서입니다.

1. 카메라 앱을 엽니다.
2. 설정 톱니바퀴를 누릅니다.
3. 저장 위치를 누릅니다.
4. SD 카드를 누릅니다.

이 설정을 켜도 내장 메모리에 저장되는 촬영이 있습니다. [Samsung 일본 지원 안내](https://www.samsung.com/jp/support/mobile-devices/how-do-i-set-the-location-of-the-galaxy-camera-to-an-external-sd-card)는 아래 항목을 예외로 적습니다.

| 촬영 종류 | 저장 위치 |
| --- | --- |
| 8K 동영상 | 내장 메모리 |
| UHD(60fps) 동영상 | 내장 메모리 |
| GIF 촬영 | 내장 메모리 |
| 연속 촬영 | 내장 메모리 |
| RAW 파일 | 내장 메모리 |

같은 안내는 이렇게 저장된 파일도 촬영 뒤 SD 카드로 옮길 수 있다고 적습니다. 위의 내 파일 순서를 따르면 됩니다. 대상 모델은 안내 페이지의 목록에서 확인하세요.

## 옮기려는데 SD 카드가 안 보이면?

설정에서 카드가 인식되는지부터 봅니다. [Files by Google 도움말](https://support.google.com/files/answer/9712028?hl=ko)의 순서입니다.

1. 설정을 열고 기기 유지관리(디바이스 케어) > 저장공간을 누릅니다.
2. 설정에서도 카드가 안 보이면 카드를 빼고 다시 넣습니다.
3. 설정에는 보이는데 앱에 없으면 카드가 내부 저장공간으로 포맷되었을 수 있습니다. 휴대용 저장공간으로 다시 포맷합니다.

[삼성전자서비스 안내](https://www.samsungsvc.co.kr/solution/39687)는 카드를 넣었는데 없다고 나오면 다시 장착하거나 다른 휴대폰에 넣어 인식되는지 보라고 적습니다. 다른 휴대폰에서도 같으면 카드 점검이 필요합니다. 자세한 점검 순서는 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)에 있습니다.

## 옮긴 사진은 어떻게 한 벌 더 보관하나요?

카드를 컴퓨터에 연결해 사진 폴더를 복사합니다. 카드는 잃어버리거나 고장 날 수 있습니다. 사진이 휴대폰에서 카드로 이동만 되어 있다면 사본은 카드 한 곳뿐입니다. 카드를 빼기 전에는 설정에서 마운트 해제를 먼저 합니다. 컴퓨터 연결 방법은 [SD 카드 컴퓨터 연결 방법](/blog/ko/sd-card-to-pc)에 정리했습니다.

## 아이폰 사진도 SD 카드로 옮길 수 있나요?

아이폰에는 카드 슬롯이 없어 카드 리더를 연결해 옮깁니다. 순서와 카드 형식은 [아이폰 사진 SD 카드로 옮기기](/blog/ko/iphone-photos-to-sd-card)에 따로 정리했습니다.

## 갤럭시 사진 SD 카드로 옮기기 자주 묻는 질문

### 갤러리에 있는 앨범을 통째로 SD 카드로 옮길 수 있나요?

Samsung 미국 지원 안내는 이동·복사가 내 파일 앱에서만 된다고 적습니다. 내 파일에서 앨범의 사진이 든 폴더를 열고, 사진을 길게 눌러 여러 장을 고른 뒤 이동합니다.

### 카메라 저장 위치를 SD 카드로 바꾸면 기존 사진도 옮겨지나요?

Samsung 안내의 저장 위치 설정은 이후에 찍는 사진에 적용됩니다. 이미 찍은 사진은 내 파일이나 Files by Google로 따로 옮깁니다.

### 이동 중에 취소하면 어떻게 되나요?

삼성전자서비스 안내는 이동이 끝나기 전에 취소하거나 예기치 못한 현상이 생기면 파일이 삭제될 수 있다고 적습니다. 중요한 사진은 복사를 먼저 쓰세요.

### 4GB가 넘는 영상이 SD 카드로 옮겨지지 않아요.

카드가 FAT32인지 확인합니다. Samsung 안내에 따르면 FAT32는 4GB가 넘는 파일을 지원하지 않습니다. 카드의 자료를 다른 곳에 복사한 뒤 exFAT으로 포맷합니다.

### 카드에 옮긴 사진을 다시 휴대폰으로 가져올 수 있나요?

같은 파일 관리 앱에서 SD 카드를 열고 사진을 고른 뒤 내장 메모리로 이동하거나 복사합니다. 순서는 휴대폰에서 카드로 옮길 때와 같습니다.
