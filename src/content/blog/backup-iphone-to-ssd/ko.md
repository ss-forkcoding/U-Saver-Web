## 핵심 요약

아이폰 외장 SSD 백업은 사진, 영상, 연락처, 파일을 항목별로 SSD에 복사하는 방식입니다. 사진 앱, 연락처 앱, 파일 앱에서 저장 위치로 SSD를 고릅니다.

Apple의 아이폰 백업 기능은 저장 위치로 iCloud와 컴퓨터를 씁니다. 아이폰에서 백업 기능으로 외장 SSD를 바로 고르는 방법은 Apple 안내에 없습니다.

메시지, 앱 데이터, 아이폰 설정은 SSD로 옮기는 기본 방법이 없습니다. 세 항목은 iCloud 백업이나 컴퓨터 백업으로 보관하세요.

"사진과 영상이 수백 GB인데 USB 메모리로는 모자라요." "SSD에 옮겨 두면 아이폰 사진을 지워도 되나요?" 대용량 영상을 찍는 분들이 외장 SSD를 찾는 이유입니다. 이 글은 SSD를 백업용으로 준비하는 방법, 항목별 저장 순서, 지우기 전에 확인할 항목을 차례로 정리합니다.

## 아이폰 외장 SSD 백업으로 무엇을 저장할 수 있나요?

파일 앱이 외장 SSD를 위치로 보여 주면 사진, 영상, 연락처, 파일을 저장할 수 있습니다. 항목마다 쓰는 앱이 다릅니다.

| 항목 | SSD 저장 | 쓰는 앱 |
| --- | --- | --- |
| 사진, 영상 | 할 수 있습니다 | 사진 앱에서 수정되지 않은 원본 내보내기 |
| 연락처 | 할 수 있습니다 | 연락처 앱에서 연락처 카드로 내보내기 |
| 문서, 다운로드한 파일 | 할 수 있습니다 | 파일 앱에서 복사 |
| 메시지 | 기본 방법이 없습니다 | iCloud 또는 컴퓨터 백업 |
| 앱 데이터, 아이폰 설정 | 기본 방법이 없습니다 | iCloud 또는 컴퓨터 백업 |

항목 구성은 [아이폰 USB 백업](/blog/ko/backup-iphone-to-usb)과 같습니다. SSD는 저장장치의 종류만 다르고 아이폰에서 쓰는 앱은 같습니다.

## 아이폰 외장 SSD를 백업용으로 준비하는 방법

[Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)에 따르면 외부 저장장치는 데이터 파티션이 하나여야 합니다. 형식은 APFS, APFS(암호화), macOS 확장(HFS+), exFAT, FAT32, FAT 중 하나여야 합니다.

| 확인할 것 | 기준 | 해야 할 일 |
| --- | --- | --- |
| 형식 | Apple 목록의 형식 | NTFS라면 자료를 옮긴 뒤 다시 포맷합니다 |
| 파티션 | 데이터 파티션 하나 | 여럿이면 Mac이나 PC에서 하나로 만듭니다 |
| 파일 크기 | FAT32는 파일 하나가 4GiB까지 | 긴 영상은 exFAT이나 APFS에 저장합니다 |
| 용량 | 옮길 사진과 영상보다 커야 합니다 | 설정 앱의 일반, iPhone 저장 공간에서 사진 용량을 확인합니다 |

FAT32의 4GiB 제한은 [Microsoft의 파일 시스템 비교표](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison) 기준입니다. 윈도우 PC에서도 SSD를 열어 볼 계획이면 exFAT이 맞습니다. 포맷 순서는 [exFAT 포맷 방법](/blog/ko/format-usb-exfat)에 있습니다. USB 메모리를 예로 들었지만 아이폰 파일 앱과 Mac 디스크 유틸리티의 순서는 외장 SSD에도 같습니다.

케이블, 어댑터, 전원 조건은 [아이폰 SSD 연결 방법](/blog/ko/iphone-external-ssd-connect)에 정리했습니다. 이 글은 특정 SSD를 시험하지 않았고 추천하지 않습니다.

## 아이폰 외장 SSD 백업 항목별 순서

### 사진과 영상을 SSD에 저장합니다

[Apple의 iCloud 사진 다운로드 안내](https://support.apple.com/en-us/111762)를 따른 순서입니다.

1. 사진 앱에서 보관함을 엽니다.
2. 선택을 누르고 저장할 사진과 영상을 고릅니다.
3. 공유 버튼을 누른 뒤 수정되지 않은 원본 내보내기를 누릅니다.
4. 파일 앱 화면에서 뒤로 화살표를 눌러 위치 아래의 SSD를 고릅니다.
5. 저장을 누릅니다.

iCloud 사진을 쓰면 원본을 내려받는 데 Wi-Fi가 필요합니다. Apple 안내는 iOS를 최신 버전으로 업데이트하고 Wi-Fi에 연결하라고 설명합니다. 큰 영상을 옮기는 요령은 [아이폰 동영상 옮기기](/blog/ko/iphone-videos-to-usb)에 있습니다.

### 연락처를 SSD에 저장합니다

[Apple의 연락처 내보내기 안내](https://support.apple.com/guide/iphone/export-contacts-iph075ddebf2/ios)를 따른 순서입니다.

1. 연락처 앱에서 목록 화면으로 갑니다.
2. 내보낼 목록을 길게 누릅니다.
3. 내보내기를 누르고 포함할 항목을 고릅니다.
4. 공유 방법에서 파일에 저장을 누르고 위치 아래의 SSD를 고릅니다.

메뉴 이름은 iOS 버전에 따라 조금 다를 수 있습니다.

### 문서와 파일을 SSD에 복사합니다

파일 앱에서 옮길 파일을 길게 눌러 복사를 고릅니다. SSD 폴더를 열고 빈 곳을 길게 눌러 붙여넣기를 고릅니다. 출처는 [Apple의 파일 전송 안내](https://support.apple.com/guide/iphone/transfer-files-iphone-a-storage-device-iphe9aff429a/ios)입니다.

## 아이폰 외장 SSD 백업과 Apple 백업은 무엇이 다른가요?

SSD 백업은 파일 사본을 따로 두는 일입니다. Apple 백업은 아이폰의 정보와 설정을 함께 저장합니다.

| 구분 | 외장 SSD에 복사 | iCloud 백업 | 컴퓨터 백업 |
| --- | --- | --- | --- |
| 저장 위치 | 외장 SSD | iCloud | Mac 또는 Windows 기기 |
| 담기는 항목 | 사진, 영상, 연락처, 파일 | 기기 설정, 홈 화면 배치 등 iCloud에 동기화되지 않는 정보 | 아이폰의 데이터 |
| 메시지, 앱 데이터 | 담기지 않습니다 | Apple 백업 범위를 따릅니다 | Apple 백업 범위를 따릅니다 |
| 새 아이폰으로 옮기기 | 파일을 하나씩 다시 넣습니다 | 백업으로 옮길 수 있습니다 | 백업으로 옮길 수 있습니다 |

출처는 [Apple의 아이폰 백업 안내](https://support.apple.com/guide/iphone/back-up-iphone-iph3ecf67d29/ios)입니다. 아이폰을 새 기기로 그대로 옮기려면 Apple 백업을 쓰세요. 사진과 영상의 사본을 내 손에 따로 두려면 SSD가 맞습니다. 컴퓨터가 없다면 [컴퓨터 없이 아이폰 백업하는 방법](/blog/ko/backup-iphone-without-computer)을 보세요.

## 아이폰 외장 SSD 백업 뒤 확인할 다섯 가지

아래 다섯 가지 중 하나라도 "아니요"라면 아이폰의 사진을 지우지 마세요.

1. 파일 앱에서 SSD의 사진이 열립니다.
2. 가장 긴 영상이 끝까지 재생됩니다.
3. SSD에 저장한 사진과 영상의 개수가 아이폰에서 고른 개수와 같습니다.
4. 연락처 카드 파일이 SSD에 들어 있습니다.
5. SSD를 잃어버려도 괜찮도록 다른 곳에 사본이 하나 더 있습니다.

exFAT과 FAT32는 [Microsoft 비교표](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison)에서 파일 시스템 수준 암호화를 지원하지 않음으로 나옵니다. SSD를 가진 사람은 누구나 내용을 열 수 있으니 보관 장소에 신경 쓰세요.

## USB 메모리에 정기적으로 저장하려면?

아래 앱은 USB 메모리를 기준으로 안내합니다. 외장 SSD에서의 동작은 확인하지 않았습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비 중이며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## 아이폰 외장 SSD 백업 자주 묻는 질문

### 아이폰 전체를 외장 SSD에 백업할 수 있나요?

Apple 안내에서 아이폰 백업의 저장 위치는 iCloud와 컴퓨터입니다. 외장 SSD에는 사진, 영상, 연락처, 파일을 항목별로 저장합니다.

### 외장 SSD 백업에 메시지도 들어가나요?

들어가지 않습니다. 메시지를 보관하려면 iCloud나 컴퓨터로 아이폰을 백업하세요.

### NTFS 외장 SSD에 바로 백업할 수 있나요?

NTFS는 Apple의 외부 저장장치 형식 목록에 없습니다. 자료를 다른 곳에 옮긴 뒤 exFAT으로 포맷하세요.

### 4GB가 넘는 영상이 SSD에 저장되지 않아요.

SSD가 FAT32일 가능성이 큽니다. FAT32는 파일 하나가 4GiB를 넘을 수 없습니다. exFAT이나 APFS로 포맷한 뒤 다시 저장하세요.

### 외장 SSD에 전원을 따로 연결해야 하나요?

Apple 안내는 외장 하드디스크에 외부 전원이 필요한 경우가 많다고 설명합니다. SSD가 보이지 않거나 연결이 끊기면 USB-C 아이폰은 전원이 공급되는 USB 허브를, Lightning 아이폰은 Lightning to USB 3 Camera Adapter에 USB 전원 어댑터를 연결해 시험하세요.
