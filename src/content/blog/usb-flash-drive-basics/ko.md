## 핵심 요약

USB 메모리 사용법은 세 단계입니다. 컴퓨터의 USB 포트에 꽂고, 파일 탐색기나 Finder에서 열어 파일을 복사하고, 꺼내기를 한 뒤 뺍니다.

윈도우와 Mac을 오가며 쓸 USB라면 exFAT이나 FAT32 형식이어야 합니다. FAT32는 4GB가 넘는 파일을 저장하지 못합니다. 큰 영상을 옮기려면 exFAT을 고르세요.

빼기 전에는 꺼내기를 합니다. Microsoft는 데이터 손실을 막으려면 USB 메모리를 빼기 전에 항상 안전 제거를 하라고 안내합니다.

"USB를 꽂았는데 어디서 열어요?" "그냥 뽑아도 되나요?" 이 글은 컴퓨터에서 USB 메모리를 쓰는 기본 순서를 다룹니다. 아이폰에 USB를 연결하려는 분은 [아이폰 USB 메모리 사용법](/blog/ko/iphone-flash-drive-guide)을 읽으세요.

## USB 메모리 사용법, 무엇부터 확인하나요?

꽂기 전에 단자 모양과 USB 형식을 봅니다.

| 확인할 것 | 이유 |
| --- | --- |
| USB 단자 모양 | 컴퓨터 포트(USB-A, USB-C)와 맞아야 꽂을 수 있습니다. 맞지 않으면 어댑터를 거칩니다 |
| USB 형식 | 윈도우와 Mac에서 함께 쓰려면 exFAT이나 FAT32가 필요합니다 |
| 남은 용량 | 옮길 파일 크기보다 빈 공간이 커야 합니다 |
| 파일 크기 | FAT32 USB에는 4GB가 넘는 파일 하나를 저장할 수 없습니다 |

Apple은 Mac에 저장장치를 연결할 때 기기와 함께 온 케이블을 쓰고, 단자가 맞지 않으면 어댑터를 쓸 수 있다고 안내합니다([Apple의 저장장치 연결 안내](https://support.apple.com/guide/mac-help/connect-storage-devices-mac-mchl027f1d66/mac)).

## 윈도우 PC에서 USB 메모리를 쓰는 순서

1. USB 메모리를 PC의 USB 포트에 꽂습니다.
2. 자동 실행 창이 뜨면 원하는 동작을 고르거나 창을 닫습니다.
3. 파일 탐색기를 열고 내 PC에서 USB 드라이브를 엽니다.
4. 옮길 파일을 USB 드라이브로 끌어 놓거나 복사해 붙여 넣습니다.
5. 복사가 끝나면 아래 안전 제거 순서대로 꺼낸 뒤 뺍니다.

꽂을 때 뜨는 창은 자동 실행 설정을 따릅니다. [Microsoft 안내](https://support.microsoft.com/en-us/windows/apps/how-to-install-programs-from-a-disc)에 따르면 시작 > 설정 > Bluetooth 및 장치 > 자동 실행에서 켜고 끕니다. 이동식 드라이브의 기본 동작도 같은 화면에서 고릅니다.

## Mac에서 USB 메모리를 쓰는 순서

[Apple의 저장장치 연결 안내](https://support.apple.com/guide/mac-help/connect-storage-devices-mac-mchl027f1d66/mac)를 따른 순서입니다.

1. USB 메모리를 Mac의 포트에 꽂습니다.
2. Dock에서 Finder를 눌러 Finder 창을 엽니다.
3. Mac의 파일을 고른 뒤 사이드바의 위치 아래에 있는 USB로 끌어 놓습니다.
4. USB의 파일을 Mac으로 옮기려면 사이드바에서 USB를 고르고 파일을 Mac 폴더로 끌어 놓습니다.
5. 다 쓰면 꺼내기를 한 뒤 뺍니다.

사이드바에 USB가 보이지 않으면 Finder 설정에서 외장 디스크 표시를 켭니다. 방법은 [Apple의 연결된 기기 보기 안내](https://support.apple.com/guide/mac-help/see-the-devices-connected-to-your-mac-mchlp1039/mac)에 있습니다.

## USB 메모리는 어떻게 안전하게 빼나요?

| 컴퓨터 | 꺼내는 방법 |
| --- | --- |
| 윈도우 | 작업 표시줄 알림 영역의 하드웨어 안전 제거 및 미디어 꺼내기 아이콘을 마우스 오른쪽 버튼으로 누르고 USB의 꺼내기를 고릅니다 |
| Mac | USB를 고르고 파일 > 꺼내기를 고르거나, Finder 사이드바에서 USB 이름 옆의 꺼내기 단추를 누릅니다 |

윈도우는 [Microsoft 하드웨어 안전 제거 안내](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)를 따릅니다. 아이콘이 없으면 숨겨진 아이콘 표시를 먼저 누릅니다. 하드웨어를 안전하게 제거할 수 있다는 알림이 뜨면 뺍니다.

Mac에서 꺼내기가 안 되면 다른 앱이 USB의 파일을 쓰고 있을 수 있습니다. 열린 파일과 앱을 닫고 다시 꺼냅니다.

## 꺼내기 없이 뽑아도 되나요?

권하지 않습니다. 윈도우에는 이동식 저장장치의 제거 정책이 두 가지 있습니다. [Microsoft의 제거 정책 안내](https://learn.microsoft.com/en-us/windows/client-management/change-default-removal-policy-external-storage-media) 기준입니다.

| 정책 | 동작 |
| --- | --- |
| 빠른 제거 | 언제든 뺄 수 있게 쓰기 캐시를 쓰지 않습니다. 윈도우 10 버전 1809부터 기본값입니다 |
| 더 나은 성능 | 쓰기 캐시를 씁니다. 빼기 전에 반드시 안전 제거를 해야 하고, 그냥 빼면 데이터를 잃을 수 있습니다 |

기본값이 빠른 제거여도 복사 중에 빼면 파일이 망가질 수 있습니다. 복사가 끝났는지 보고 꺼내기를 한 뒤 빼는 습관을 들이세요.

## USB 메모리 형식은 무엇을 골라야 하나요?

어느 기기에서 쓸지에 맞춰 고릅니다. 파일 크기는 [Microsoft의 파일 시스템 비교표](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison), 아이폰 형식은 [Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios) 기준입니다.

| 형식 | 파일 하나의 최대 크기 | 이럴 때 고릅니다 |
| --- | --- | --- |
| exFAT | 2^64-1바이트 | 윈도우, Mac, 아이폰에서 함께 쓰고 큰 영상도 옮길 때 |
| FAT32 | 4GiB | 오래된 기기와 함께 쓰고 4GB 넘는 파일이 없을 때 |
| NTFS | 2^64-1바이트 | 윈도우 PC에서만 쓸 때. Apple의 아이폰 형식 목록에는 없습니다 |
| APFS | - | Mac에서만 쓸 때. Apple은 macOS 10.13 이후 Mac의 기본 파일 시스템이라고 적습니다 |

APFS 설명은 [Apple의 파일 시스템 형식 안내](https://support.apple.com/guide/disk-utility/file-system-formats-dsku19ed921c/mac)에 있습니다. 포맷 순서는 [exFAT 포맷 방법](/blog/ko/format-usb-exfat)과 [USB FAT32 포맷 방법](/blog/ko/format-usb-fat32)에 정리했습니다. 포맷하면 USB의 파일이 모두 지워지니 먼저 다른 곳에 복사하세요.

## 컴퓨터에서 USB 메모리가 안 보이면 무엇을 확인하나요?

| 증상 | 확인할 것 |
| --- | --- |
| 꽂아도 아무 반응이 없습니다 | 다른 포트에 꽂아 봅니다. 허브나 어댑터를 거쳤다면 컴퓨터에 바로 꽂아 봅니다 |
| Mac 사이드바에 USB가 없습니다 | Finder 설정에서 외장 디스크 표시를 켭니다 |
| 윈도우 안전 제거 아이콘이 없습니다 | Microsoft는 장치가 연결되지 않았거나 윈도우가 장치를 인식하지 못하면 아이콘이 없을 수 있다고 적습니다 |
| 큰 파일만 복사되지 않습니다 | USB가 FAT32인지 확인합니다. 4GB가 넘는 파일은 exFAT USB에 저장합니다 |
| 포맷하라는 창이 뜹니다 | 바로 포맷하지 않습니다. 다른 컴퓨터에서 먼저 열어 보고, 남길 파일이 있으면 옮깁니다 |

## USB 메모리 사용법 자주 묻는 질문

### USB 메모리를 꽂으면 어디서 여나요?

윈도우는 파일 탐색기의 내 PC에서, Mac은 Finder 사이드바의 위치 아래에서 엽니다.

### USB 메모리를 그냥 뽑아도 되나요?

권하지 않습니다. Microsoft는 데이터 손실을 막으려면 빼기 전에 항상 안전 제거를 하라고 안내합니다. Mac도 꺼내기를 한 뒤 뺍니다.

### 4GB가 넘는 영상이 USB에 복사되지 않아요.

USB가 FAT32일 가능성이 큽니다. FAT32는 파일 하나를 4GiB까지만 저장합니다. 파일을 옮긴 뒤 exFAT으로 포맷하세요.

### 윈도우와 Mac에서 함께 쓰려면 어떤 형식이 좋나요?

exFAT을 고르세요. Apple은 윈도우와 함께 쓸 디스크가 32GB 이하면 MS-DOS(FAT), 32GB를 넘으면 ExFAT을 고르라고 안내합니다([Apple의 윈도우용 포맷 안내](https://support.apple.com/guide/disk-utility/format-a-disk-for-windows-computers-dskutl1010/mac)). 4GB가 넘는 파일을 옮길 계획이면 용량과 관계없이 exFAT이 맞습니다.

### USB 메모리 내용은 암호화되나요?

Microsoft 비교표에서 exFAT과 FAT32는 파일 시스템 수준 암호화를 지원하지 않습니다. USB를 잃어버리면 다른 사람이 내용을 볼 수 있으니 보관 장소에 신경 쓰세요.
