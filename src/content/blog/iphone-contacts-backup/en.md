## Key takeaways

There are two ways to backup contacts on iPhone. Turn on Contacts in iCloud to keep them on Apple's servers, or export them as a vCard file and keep it on a storage device such as a USB drive.

iCloud keeps your contacts the same on every device signed in to your Apple Account. If you delete a contact by mistake, you can go back to an earlier version on iCloud.com.

A vCard file gives you one more copy of your contacts that you hold yourself. You create it with the Export option in the Contacts app and save it to the drive from the Files app.

"I want to keep my phone numbers safe before I switch phones." "I deleted a contact. Can I get it back?" "Is leaving everything in iCloud enough?" These are common questions from people looking for a way to back up iPhone contacts. This guide walks through each method and what to check afterward.

## What's the difference between the ways to backup contacts on iPhone?

The methods differ in where your contacts live. iCloud keeps them on Apple's servers. A vCard file goes wherever you save it.

| Criteria | Contacts in iCloud | vCard file |
| --- | --- | --- |
| Where it's stored | Apple's servers | A USB drive or another location in Files |
| How it updates | Changes sync automatically | Stays as it was when you exported it |
| Deleted contacts | Go back to an earlier version on iCloud.com | Import the file again |
| What you need | Apple Account, internet connection | A storage device, plus an adapter if needed |
| Where you set it up | Settings app | Contacts app, Files app |

Keep Contacts in iCloud turned on day to day, and make a vCard file before you change or reset a phone. If one copy goes wrong, the other is still there.

## How to backup contacts on iPhone with iCloud

These steps follow [Apple's guide to syncing contacts](https://support.apple.com/guide/iphone/sync-contacts-across-devices-iphdfe5a59f5/ios).

1. Open the Settings app.
2. Tap your name at the top, then tap iCloud.
3. Tap See All next to Saved to iCloud.
4. Turn on Contacts.

With Contacts in iCloud turned on, your contacts stay up to date on every device signed in to the same Apple Account. In that case, no options appear for syncing contacts with your computer.

According to [Apple's iCloud Backup guide](https://support.apple.com/guide/icloud/what-is-icloud-backup-mm085db3a8d6/icloud), an iCloud backup only includes information that isn't otherwise stored in iCloud. If Contacts in iCloud is on, your contacts are stored in iCloud Contacts, not in the iCloud backup.

## How do you get back contacts you deleted by mistake?

If you use Contacts in iCloud, you can go back to an earlier version that iCloud archived automatically. These steps follow [Apple's guide to restoring contacts on iCloud.com](https://support.apple.com/guide/icloud/restore-contacts-mm1d9cfdb498/icloud).

1. In a web browser, go to icloud.com/contacts and sign in to your Apple Account.
2. Select the button in the toolbar, then select Data Recovery.
3. Select Restore Contacts.
4. Versions are listed by date and time. Select Restore next to the one you want.

If you deleted the contact recently, the archive may take up to 24 hours to appear. Your current version is archived first, so you can go back to it if you change your mind. Don't edit your contacts until iCloud finishes. Changes made during the process aren't saved.

## How to back up iPhone contacts to a USB drive as a file

The Export option in the Contacts app saves your contacts as a vCard file. These steps follow [Apple's guide to exporting contacts](https://support.apple.com/guide/iphone/export-contacts-iph075ddebf2/ios).

1. Connect the USB drive to your iPhone.
2. In the Contacts app, tap the button at the top left to go to the Lists screen.
3. Touch and hold the list you want to export. To include only some contacts, tap Add List to create a new list first.
4. Tap Export and choose the fields to include.
5. Choose Save to Files as the method, then choose the drive under Locations.

Menu names may differ slightly between iOS versions. If the drive doesn't appear in Files, check the connection steps in [how to use a flash drive with an iPhone](/blog/en/iphone-flash-drive-guide). Formatting the drive as exFAT, as shown in [how to format a USB drive to exFAT](/blog/en/format-usb-exfat), also lets the same drive hold large photos and videos.

To move photos and files at the same time, see [how to back up an iPhone to a USB drive](/blog/en/backup-iphone-to-usb), which covers each item.

## How to export all iCloud contacts at once from a computer

If you use Contacts in iCloud, you can also download a vCard file from iCloud.com. These steps follow [Apple's guide to contacts on iCloud.com](https://support.apple.com/guide/icloud/import-export-and-print-contacts-mmfba748b2/icloud).

1. Go to icloud.com/contacts and sign in to your Apple Account.
2. Select the button above the list, then choose Select All Contacts.
3. Select the menu button, then choose Export vCard.

When you select multiple contacts, iCloud exports a single vCard that contains all of them. You can then copy the file from your computer to a USB drive.

## How do you bring a contacts file back?

You can bring a vCard file back in two ways.

| Method | Steps | Source |
| --- | --- | --- |
| On iPhone | Tap a .vcf attachment in an email or message | [Apple's guide to importing contacts](https://support.apple.com/guide/iphone/import-contacts-iph356499f31/ios) |
| On iCloud.com | Select the button on the right, choose Import vCard, then select the file | [Apple's guide to contacts on iCloud.com](https://support.apple.com/guide/icloud/import-export-and-print-contacts-mmfba748b2/icloud) |

Contacts imported on iCloud.com are added to the All Contacts list. If one vCard holds several people, each becomes a separate entry. If they overlap with existing contacts, clean up the duplicates in the Contacts app.

## Four things to check after you back up iPhone contacts

If any of these is a "no," don't delete contacts from your iPhone or reset it yet.

- The USB drive has a .vcf file on it.
- The file size isn't 0 bytes.
- You've compared the number of contacts in the Contacts app on another device or on iCloud.com.
- The drive is somewhere safe in case it gets lost. Anyone with the file can read the names and phone numbers in it.

## FAQ: backup contacts on iPhone

### Are iPhone contacts included in an iCloud backup?

Not if Contacts in iCloud is on. Apple says an iCloud backup only includes information that isn't otherwise stored in iCloud, and in that case your contacts are stored in iCloud Contacts.

### What format is an iPhone contacts backup file?

It's a vCard, with the .vcf file extension. One file can hold one contact or many.

### Can I back up iPhone contacts without a computer?

Yes. Turn on Contacts in iCloud in the Settings app, or save a vCard file straight to a USB drive from the Contacts app. For a comparison that covers other items too, see [how to back up an iPhone without a computer](/blog/en/backup-iphone-without-computer).

### A contact I deleted isn't in the iCloud.com version list.

For a recently deleted contact, the archive may take up to 24 hours to appear. Check again after about a day.

### Does a contacts backup include messages?

No. A contacts backup holds contact information such as names and phone numbers. To keep messages, use an iCloud backup or a computer backup.
