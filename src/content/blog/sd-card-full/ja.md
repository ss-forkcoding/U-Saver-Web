## この記事の要点

SDカードがいっぱいと表示されると、すぐに削除やフォーマットをしたくなります。けれども、カードが本当に満杯とは限りません。削除したファイルがゴミ箱に残っていたり、1つのファイルが4GBを超えていたり、カードの容量がもともと表示より小さかったりすることもあります。

まずカードの写真とビデオを別のストレージデバイスにコピーします。次に、何が容量を使っているかを確かめます。フォーマットはコピーが開けることを確かめてから、最後にします。

「写真を消したのに空き容量が変わらない」「空きがあるのにビデオが入らない」。SDカードがいっぱいと表示されて検索する人からよく聞く声です。この記事では、原因を絞り込む順番を扱います。カードの基本は[SDカードの基礎総まとめ](/blog/ja/sd-card-basics-guide)に、容量の規格は[SDHC・SDXC・SDUCの違い](/blog/ja/sdhc-vs-sdxc)にあります。

## SDカードがいっぱいと表示される原因は何ですか?

原因は大きく5つに分かれます。上から確かめると、カードを消さずに原因を絞り込めます。

| 原因 | 見える症状 | 根拠 |
| --- | --- | --- |
| カードが本当に満杯 | 写真とビデオが容量のほとんどを使っている | カードのフォルダのファイルサイズ |
| ゴミ箱に残ったファイル | Macで削除したのに空き容量が増えない | Appleのファイル削除の案内 |
| FAT32のファイルサイズ制限 | 空きがあるのに大きいビデオだけコピーできない | Microsoftのファイルシステム比較表、SD Associationの容量規格 |
| 表示容量とフォーマット後の容量の差 | パソコンに表示される容量がパッケージより少し小さい | Appleのストレージ容量の案内 |
| 容量を偽ったカード | 表示容量よりずっと早くいっぱいになる、ファイルが壊れる | SD Associationの偽造カードの記事 |

この記事では特定のカードや機器を試していません。表の内容は各公式ドキュメントの説明です。カメラやドライブレコーダーが出すメッセージの文言は機器ごとに違うので、機器の説明書もあわせて確認してください。

## カードを空ける前にコピーを作るべきですか?

作るべきです。空き容量を作るために削除やフォーマットをすると、そのファイルはカードから消えます。残したい写真とビデオを先に別のストレージデバイスへコピーします。

1. カードをパソコンかiPhoneにつなぎます。
2. 残したい写真とビデオを別のストレージデバイスにコピーします。
3. コピーしたファイルをいくつか開き、問題なく開けるか確かめます。
4. カードを抜くときは、先に取り出しの操作をします。

パソコンにつなぐ手順は[SDカードをパソコンにつなぐ方法](/blog/ja/sd-card-to-pc)にあります。

## 何がSDカードの容量を使っているか、どう調べますか?

Windowsでは、エクスプローラーでファイルをサイズ順に並べます。[Microsoftのドライブの空き領域を増やす案内](https://support.microsoft.com/en-us/windows/free-up-drive-space-in-windows-85529ccb-c365-490d-b548-831022bc9b32)が、大きいファイルを探す方法として説明している手順です。

1. タスクバーからエクスプローラーを開きます。
2. カードのフォルダを開きます。
3. 表示から詳細を選びます。
4. 何もないところを右クリックし、並べ替え、サイズを選びます。

いちばん大きいファイルが一覧の上に来ます。同じ案内は、不要なファイルを削除するか、USBドライブやSDカードなどの外部ストレージに移すよう説明しています。削除したあとはごみ箱を空にしないと空き領域が完全には増えない、とも書いています。

長いビデオは写真よりずっと大きくなります。カメラやドライブレコーダーで使ったカードなら、ビデオのフォルダから確かめてください。ドライブレコーダーのカードの管理は[ドライブレコーダーのSDカードの選び方と管理](/blog/ja/dashcam-sd-card)にあります。

## Macで削除したのに空き容量が変わらないときは?

ゴミ箱を確かめます。[Appleのファイル削除の案内](https://support.apple.com/guide/mac-help/delete-files-and-folders-mac-mchlp1093/mac)は、項目をゴミ箱に入れても、ゴミ箱を空にするまでは削除されないと説明しています。

1. Dockのゴミ箱アイコンをクリックします。
2. 残したいファイルがないか確かめます。
3. Finderウインドウの右上にある「空にする」をクリックします。
4. 警告メッセージで「ゴミ箱を空にする」をクリックします。

Appleは、ゴミ箱から空にした項目は完全に削除されると警告しています。空にする前に、必要なファイルが混ざっていないか確かめます。考えが変わったら、項目を選んで「ファイル」>「戻す」を選びます。

## 空きがあるのに大きいビデオだけ入らないときは?

カードのファイルシステムを確かめます。FAT32は1つのファイルを4GiBまでしか保存できません([Microsoftのファイルシステム比較表](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison))。この場合、空き容量があっても大きいビデオはコピーできません。

| 容量の規格 | 容量の範囲 | 標準のファイルシステム |
| --- | --- | --- |
| SDHC | 2GB超〜32GB | FAT32 |
| SDXC | 32GB超〜2TB | exFAT |
| SDUC | 2TB超〜128TB | exFAT |

容量の範囲とファイルシステムは[SD Associationの容量規格](https://www.sdcard.org/developers/sd-standard-overview/capacity-sd-sdhc-sdxc-sduc/)によります。32GB以下のSDHCカードに4GBを超えるビデオを移すと、この制限にかかることがあります。

対処は2つです。ビデオをexFATのストレージデバイスに移すか、使う機器が対応していれば、より大きいSDXCカードを使います。カメラや機器が対応するカードの種類は、先に機器の説明書で確かめてください。規格ごとの互換性の確かめ方は[SDHC・SDXC・SDUCの違い](/blog/ja/sdhc-vs-sdxc)にあります。

## カードの容量がパッケージの表示より小さく見えるときは?

少し小さいのは正常です。[Appleのストレージ容量の案内](https://support.apple.com/en-us/102119)によると、メーカーは1GBを10億バイトとして数えます。フォーマットが容量の一部を使うので、実際のフォーマット後の容量はさらに小さくなります。2進法で数えると、1GBは1,073,741,824バイトです。

表示容量よりずっと早くいっぱいになる、一定の量を超えるとファイルが壊れる、という場合は別です。[SD Associationの記事](https://www.sdcard.org/press/thoughtleadership/keeping-it-real-how-sd-3c-fights-counterfeit-sd-memory-cards/)は、256GBとしてパッケージされているのに実際は16GBしか入らない偽造カードを例に挙げています。そうしたカードにはそれ以上書き込まず、先にデータを移します。確かめ方は[偽物のSDカードの見分け方](/blog/ja/fake-sd-card)にあります。

## iPhoneに写真を移してSDカードを空けるには?

iPhoneの写真アプリで、カードの写真とビデオを読み込めます。[Appleの写真の読み込みの案内](https://support.apple.com/guide/iphone/import-and-export-photos-and-videos-iph480caa1f3/ios)に沿った手順です。

1. カードリーダーをiPhoneの充電ポートにつなぎ、カードを入れます。
2. 写真アプリを開き、「読み込む」をタップします。
3. 読み込む項目と読み込み先を選びます。
4. 「すべてを読み込む」をタップするか、項目を選んで「読み込む」、「選択項目を読み込む」をタップします。
5. 読み込みが終わったら、カードの写真を残すか削除するかを選びます。

カードから削除する前に、iPhoneで写真が開けるか確かめます。iPhoneの空き容量が足りなければ、先に[iPhoneのストレージがいっぱいのとき](/blog/ja/iphone-storage-full)をご覧ください。反対にiPhoneの写真をカードに書き出す手順は[iPhoneの写真をSDカードに移す方法](/blog/ja/iphone-photos-to-sd-card)にあります。

## フォーマットでSDカードを空ける必要があるときは?

フォーマットすると、カードのデータはすべて消えます。先に作ったコピーが開けることを確かめてから進めます。

[SD Associationのフォーマッターの案内](https://www.sdcard.org/downloads/formatter/)は、OSに付属のフォーマットツールではなくSD Memory Card Formatterを使うよう強く勧めています。OSのツールはSDカード向けに最適化されておらず、性能が下がることがあるという理由です。使い方は[SDカードフォーマッターの使い方](/blog/ja/sd-card-formatter)に、カメラでフォーマットする手順は[SDカードのフォーマット方法](/blog/ja/format-sd-card)にあります。

カードがいっぱいなうえに書き込みも遅くなったなら、[SDカードの読み込みが遅いときに確かめる順番](/blog/ja/slow-sd-card)もあわせて確認してください。

カードを空ける前にもう1つコピーを作っておけば、安心して削除できます。下のアプリはUSBメモリを前提に案内します。USBメモリの形式を変える手順は[exFATにフォーマットする方法](/blog/ja/format-usb-exfat)に、移す手順は[iPhoneの写真をUSBメモリに移す方法](/blog/ja/iphone-photos-to-usb)にあります。

## SDカードがいっぱいのときのよくある質問

### 写真を消したのにSDカードの空き容量が増えません。

Macで削除したなら、ゴミ箱を確かめてください。Appleは、ゴミ箱を空にするまで項目は削除されないと説明しています。WindowsでもMicrosoftは、削除したあとにごみ箱を空にするよう案内しています。

### 空きがあるのにビデオがコピーできないのはなぜですか?

カードがFAT32なら、4GiBを超えるファイルは保存できません。SD Associationの規格では、SDHCカードの標準のファイルシステムはFAT32です。

### 64GBのカードがパソコンで64GBより小さく表示されます。故障ですか?

少し小さいのは正常です。Appleの案内によると、メーカーは10進法で容量を数え、フォーマットが容量の一部を使います。ずっと早くいっぱいになる、ファイルが壊れるという場合は偽造カードを疑ってください。

### いっぱいになったSDカードはフォーマットするのがいちばん早いですか?

早いですが、データはすべて消えます。コピーを作って開けることを確かめてからフォーマットしてください。SD AssociationはSD Memory Card Formatterを勧めています。

### iPhoneに読み込んだあと、カードの写真を削除してもいいですか?

Appleの案内は、読み込みが終わったらカードの写真を残すか削除するかを選べると説明しています。削除する前に、iPhoneで写真が問題なく開けるか確かめてください。
