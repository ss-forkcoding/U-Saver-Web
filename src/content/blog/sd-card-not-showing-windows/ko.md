## 핵심 요약

윈도우에서 SD 카드 인식 안됨 증상이 나오면 먼저 포맷하지 않습니다. 포맷하면 카드의 자료가 모두 지워집니다.

확인은 세 곳에서 합니다. 카드와 리더기가 서로 맞는지, 장치 관리자에 리더기가 정상으로 보이는지, 디스크 관리에 카드가 보이는지입니다. 어느 단계에서 막혔는지에 따라 할 일이 다릅니다.

다른 PC와 다른 리더기에서도 보이지 않으면 카드 자체를 의심하고 카드 제조사에 문의합니다.

"카메라에서는 되는 SD 카드가 노트북에서 안 떠요." "리더기에 꽂아도 파일 탐색기에 아무것도 없어요." 이 글은 윈도우 PC에서 카드가 보이지 않을 때 확인할 순서를 다룹니다. 특정 카드나 리더기를 시험하거나 추천하지 않습니다. 카드는 보이는데 포맷이 막힌다면 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)를 보세요.

## SD 카드 인식 안됨, 어디서 막혔는지 어떻게 가리나요?

파일 탐색기, 디스크 관리, 장치 관리자를 차례로 열어 카드가 어디까지 보이는지 확인합니다. 아래 표에서 내 상태를 찾으세요.

| 보이는 곳 | 의심할 것 | 이 글의 해당 부분 |
| --- | --- | --- |
| 어디에도 없음 | 리더기, 포트, 케이블, 규격 | 연결과 규격 |
| 장치 관리자에 느낌표가 붙은 장치가 있음 | 리더기 드라이버 | 장치 관리자 |
| 디스크 관리에는 있고 탐색기에는 없음 | 드라이브 문자, 오프라인 | 디스크 관리 |
| 디스크 관리에 RAW나 할당되지 않음으로 보임 | 파일 시스템 손상 | 디스크 관리 |
| 탐색기에 보이지만 포맷하라는 창이 뜸 | 파일 시스템 손상 | 포맷 창 |
| 다른 PC와 다른 리더기에서도 없음 | 카드 고장 | 그래도 안 보일 때 |

## 포맷하라는 창이 뜨면 눌러도 되나요?

누르지 않습니다. [Microsoft의 디스크 관리 문제 해결 안내](https://learn.microsoft.com/en-us/troubleshoot/windows-server/backup-and-storage/troubleshoot-disk-management)는 포맷하면 디스크의 모든 데이터가 지워진다고 설명합니다. 파일을 되찾으려면 이 단계를 건너뛰라고 적습니다.

1. 포맷을 묻는 창이 뜨면 취소를 누릅니다.
2. 카드에 새 파일을 저장하지 않습니다.
3. 오류 문구가 나왔다면 그대로 적어 둡니다.

카드에 남길 자료가 없을 때만 포맷합니다. 포맷 순서는 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에 있습니다.

## 연결과 규격에서 무엇을 확인하나요?

Microsoft 안내의 순서를 SD 카드에 맞춰 옮겼습니다. 한 단계에서 카드가 보이면 나머지는 건너뜁니다.

1. 카드를 뺐다가 다시 꽂고, 디스크 관리에서 동작 > 디스크 다시 검색을 누릅니다.
2. PC를 종료한 뒤 다시 켜고 카드를 꽂습니다.
3. USB 리더기를 허브에 꽂았다면 빼고 PC 본체의 포트에 바로 꽂습니다.
4. 리더기를 다른 포트에 꽂습니다.
5. 리더기에 케이블이 있다면 다른 케이블로 바꿉니다.
6. 다른 PC에 꽂습니다.

Microsoft는 USB 디스크가 일부 포트에서 전원을 충분히 받지 못할 수 있고, 허브에서 이런 문제가 특히 흔하다고 설명합니다. 케이블도 자주 고장 난다고 적습니다.

카드와 슬롯·리더기의 용량 규격도 맞춰 봅니다. [SD Association의 용량 규격 안내](https://www.sdcard.org/consumers/about-sd-memory-card-choices/sd-sdhc-sdxc-and-sduc-card-capacity-choices/)는 호환을 이렇게 정리합니다.

| 슬롯·리더기 | 읽을 수 있는 카드 |
| --- | --- |
| SD | SD |
| SDHC | SD, SDHC |
| SDXC | SD, SDHC, SDXC |
| SDUC | SD, SDHC, SDXC, SDUC |

카드 라벨의 SDHC, SDXC 표시와 노트북이나 리더기 사양표를 비교하세요. 오래된 노트북 슬롯이 SDHC까지만 지원하면 SDXC 카드를 읽지 못합니다. 이때는 SDXC를 지원하는 USB 리더기를 씁니다. 규격별 차이는 [SDHC·SDXC·SDUC 차이](/blog/ko/sdhc-vs-sdxc)에, 리더기 고르는 기준은 [SD 카드 리더기 고르는 법](/blog/ko/choose-sd-card-reader)에 정리했습니다.

## 장치 관리자에서 리더기를 어떻게 확인하나요?

카드가 디스크 관리에도 없다면 장치 관리자를 엽니다. [Microsoft 안내](https://learn.microsoft.com/en-us/troubleshoot/windows-server/backup-and-storage/troubleshoot-disk-management)는 느낌표가 붙은 장치가 있는지 보고, 장치를 골라 상태를 읽으라고 설명합니다.

1. 시작 단추를 마우스 오른쪽 버튼으로 누르고 장치 관리자를 고릅니다.
2. 범주 옆의 화살표를 눌러 펼치고 느낌표가 붙은 장치를 찾습니다.
3. 그 장치를 마우스 오른쪽 버튼으로 누르고 장치 제거를 고릅니다.
4. 동작 > 하드웨어 변경 사항 검색을 누릅니다.

그래도 안 되면 드라이버를 다시 설치하거나 업데이트합니다. [Microsoft의 장치 관리자 드라이버 안내](https://support.microsoft.com/en-us/windows/update-drivers-manually-in-windows-ec62f46c-ff14-c91d-eead-d7126dc1f7b6)가 적은 방법입니다.

| 상황 | 할 일 | 알아 둘 것 |
| --- | --- | --- |
| 드라이버가 꼬였을 때 | 장치 제거 뒤 PC를 다시 시작합니다 | 다시 시작하면 윈도우가 드라이버를 다시 설치하려고 합니다 |
| 최근 업데이트 뒤 안 보일 때 | 속성 > 드라이버 탭 > 드라이버 롤백을 누릅니다 | 관리자 권한이 필요합니다 |
| 드라이버가 오래되었을 때 | 드라이버 업데이트 > 드라이버 자동 검색을 고릅니다 | 못 찾으면 Windows 업데이트에서 찾는 옵션이 나옵니다 |
| 제조사 드라이버가 있을 때 | 제조사 사이트에서 내려받아 수동으로 설치합니다 | 윈도우 버전과 아키텍처에 맞는 파일을 고릅니다 |

Microsoft는 대부분의 드라이버가 Windows 업데이트로 자동 설치된다고 설명합니다. 노트북 내장 슬롯이라면 PC 제조사 지원 사이트에서 카드 리더 드라이버를 찾습니다.

## 디스크 관리에는 보이는데 탐색기에 없으면?

디스크 관리는 작업 표시줄 검색에서 컴퓨터 관리를 관리자 권한으로 열고 저장소 > 디스크 관리로 가면 나옵니다. Microsoft 안내 기준으로 상태별 할 일은 아래와 같습니다.

| 디스크 관리에 보이는 상태 | 해야 할 일 | 하지 말 것 |
| --- | --- | --- |
| 디스크가 오프라인 | 디스크를 마우스 오른쪽 버튼으로 누르고 온라인을 고릅니다 | 없음 |
| 파티션이 정상이고 드라이브 문자가 없음 | 드라이브 문자를 추가합니다 | 없음 |
| 파티션이 RAW | 다른 리더기와 다른 PC에서 먼저 확인합니다 | 포맷 |
| 할당되지 않음 | 다른 리더기와 다른 PC에서 먼저 확인합니다 | 새 단순 볼륨 만들기 |
| 초기화되지 않음 | 다른 리더기와 다른 PC에서 먼저 확인합니다 | 디스크 초기화 |

드라이브 문자는 [Microsoft의 드라이브 문자 변경 안내](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/change-a-drive-letter)대로 붙입니다. 관리자 계정이 필요합니다.

1. 디스크 관리에서 카드의 볼륨을 마우스 오른쪽 버튼으로 누릅니다.
2. 드라이브 문자 및 경로 변경을 고릅니다.
3. 추가를 누르고 드라이브 문자를 고른 뒤 확인을 누릅니다.

Microsoft는 디스크나 메모리 카드가 보이지 않거나 초기화되지 않는 가장 흔한 원인이 디스크 고장이라고 설명합니다. 카드가 다시 보이면 검사보다 복사를 먼저 하세요. 복사 뒤 검사하는 순서는 [SD 카드 손상 증상과 대처](/blog/ko/sd-card-corrupted)에 있습니다.

## 그래도 SD 카드가 안 보이면?

다른 PC와 다른 리더기에서도 같다면 카드 쪽을 의심합니다. [SD Association FAQ](https://www.sdcard.org/consumers/faq/)는 표준 단체라 제품을 만들거나 팔지 않으므로, 기술 문제는 카드 제조사에 직접 문의하라고 안내합니다.

Microsoft 안내는 고장 난 디스크에서 자료를 꺼내려는 앱이나 유료 데이터 복구 업체도 있다고 적습니다. 이 글은 특정 프로그램이나 업체를 시험하거나 추천하지 않습니다. 제조사 보증과 지원 범위를 먼저 확인하세요.

USB 메모리가 안 보일 때도 순서는 거의 같습니다. [갑자기 USB 인식 안됨](/blog/ko/usb-data-rescue)에 자료를 지키는 순서를 정리했습니다.

## 카드가 다시 보이면 어떻게 빼야 하나요?

[Microsoft의 하드웨어 안전 제거 안내](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)는 데이터 손실을 막으려면 빼기 전에 항상 안전 제거를 하라고 설명합니다.

1. 작업 표시줄 알림 영역의 하드웨어 안전 제거 및 미디어 꺼내기 아이콘을 누릅니다.
2. 카드 드라이브의 꺼내기를 고릅니다.
3. 안전하게 제거할 수 있다는 알림이 뜨면 카드나 리더기를 뺍니다.

카드를 PC에 연결해 파일을 옮기는 기본 순서는 [SD 카드 컴퓨터 연결 방법](/blog/ko/sd-card-to-pc)에 있습니다.

이 글은 윈도우 PC 기준입니다. 아이폰에 리더기로 카드를 연결했는데 파일 앱에 보이지 않으면 잠금, 카드 형식, 데이터 파티션 수가 원인일 수 있습니다. 아래 글을 보세요.

| 상황 | 읽을 글 |

| 아이폰에 리더기를 연결해도 카드가 안 보임 | [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader) |
| 리더 종류와 카드 형식을 한눈에 보기 | [아이폰 SD 카드 총정리](/blog/ko/iphone-sd-card-guide) |
| PC가 아이폰 자체를 인식하지 못함 | [핸드폰 컴퓨터 USB 연결 안됨](/blog/ko/phone-not-recognized-pc) |

## SD 카드 인식 안됨 자주 묻는 질문

### 카메라에서는 되는데 PC에서만 SD 카드 인식이 안 돼요.

카드보다 PC의 슬롯, 리더기, 드라이버 쪽을 의심합니다. 슬롯이나 리더기가 카드 규격을 지원하는지 보고, 장치 관리자에서 느낌표가 붙은 장치가 있는지 확인하세요.

### 디스크 관리에 RAW로 나오면 바로 포맷해야 하나요?

남길 자료가 있다면 포맷하지 않습니다. Microsoft는 파일을 되찾으려면 RAW 파티션을 포맷하지 말라고 안내합니다. 다른 리더기와 다른 PC에서 먼저 확인하세요.

### 드라이버를 지우면 PC에 문제가 생기지 않나요?

Microsoft 안내에 따르면 장치를 제거한 뒤 PC를 다시 시작하면 윈도우가 드라이버를 다시 설치하려고 합니다. 다시 설치되지 않으면 드라이버 업데이트나 제조사 드라이버 설치로 넘어갑니다.

### microSD를 어댑터에 끼웠는데 안 보여요.

어댑터를 바꾸거나 microSD 전용 리더기로 확인하세요. 어댑터를 써도 카드의 용량 규격은 그대로이므로 리더기가 그 규격을 지원해야 합니다.

### 다른 PC에서도 SD 카드가 안 보이면요?

카드 고장을 의심합니다. SD Association은 기술 문제를 카드 제조사에 문의하라고 안내합니다. 구입처와 제조사의 보증 조건을 확인하세요.
