## 要点まとめ

SDカードをパソコンが認識しないときは、まずフォーマットしないことです。フォーマットするとカードのデータはすべて消えます。

確認する場所は三つです。カードとスロットやカードリーダーの規格が合っているか、デバイス マネージャーでカードリーダーが正常に表示されるか、「ディスクの管理」にカードが表示されるかです。どこで止まっているかで、やることが変わります。

別のパソコンと別のカードリーダーでも表示されないなら、カード自体を疑い、カードのメーカーに問い合わせます。

「カメラでは使えるSDカードが、ノートパソコンでは表示されない」「カードリーダーに挿してもエクスプローラーに何も出ない」。この記事は、WindowsパソコンでSDカードが表示されないときの確認手順を扱います。特定のカードやカードリーダーを試したり勧めたりはしません。カードは表示されるのにフォーマットできないなら、[microSDが認識しない・フォーマットできないとき](/blog/ja/sd-card-not-working)を読んでください。

## SDカードを認識しないとき、どこで止まっているかを見分けるには?

エクスプローラー、「ディスクの管理」、デバイス マネージャーを順に開き、カードがどこまで表示されるかを確かめます。下の表で自分の状態を探してください。

| 表示される場所 | 疑うこと | この記事の該当部分 |
| --- | --- | --- |
| どこにもない | カードリーダー、ポート、ケーブル、規格 | 接続と規格 |
| デバイス マネージャーに「!」の付いたデバイスがある | カードリーダーのドライバー | デバイス マネージャー |
| 「ディスクの管理」にはあるがエクスプローラーにない | ドライブ文字、オフライン | ディスクの管理 |
| 「ディスクの管理」でRAWや「未割り当て」と表示される | ファイルシステムの破損 | ディスクの管理 |
| エクスプローラーに出るがフォーマットを求められる | ファイルシステムの破損 | フォーマットの画面 |
| 別のパソコンや別のカードリーダーでも出ない | カードの故障 | それでも表示されないとき |

## フォーマットを求める画面が出たら、押してもいいですか?

押しません。[Microsoftの「ディスクの管理」のトラブルシューティング](https://learn.microsoft.com/en-us/troubleshoot/windows-server/backup-and-storage/troubleshoot-disk-management)は、ディスクをフォーマットするとすべてのデータが消えると説明しています。ファイルを取り戻したい場合は、この手順を飛ばすよう書いています。

1. フォーマットを求める画面が出たら、キャンセルを選びます。
2. カードに新しいファイルを保存しません。
3. エラーメッセージが出たら、そのまま書き留めます。

フォーマットするのは、カードに残したいデータがないときだけです。手順は[SDカードのフォーマット方法](/blog/ja/format-sd-card)にまとめました。

## 接続と規格では何を確認しますか?

Microsoftの資料の手順をSDカード向けに置き換えました。どこかの手順でカードが表示されたら、残りは飛ばします。

1. カードを抜いて挿し直し、「ディスクの管理」で「操作」>「ディスクの再スキャン」を選びます。
2. パソコンをシャットダウンしてから電源を入れ直し、カードを挿します。
3. USBカードリーダーをハブにつないでいるなら、外してパソコン本体のポートに直接挿します。
4. カードリーダーを別のポートに挿します。
5. カードリーダーにケーブルがあるなら、別のケーブルに替えます。
6. 別のパソコンに挿します。

Microsoftは、USBディスクは一部のポートで十分な電力を得られないことがあり、USBハブでは特によく起きると説明しています。ケーブルもよく故障すると書いています。

次に、カードとスロットやカードリーダーの容量規格を照らし合わせます。[SD Associationの容量規格の案内](https://www.sdcard.org/consumers/about-sd-memory-card-choices/sd-sdhc-sdxc-and-sduc-card-capacity-choices/)は、互換性を次のようにまとめています。

| スロット・カードリーダー | 使えるカード |
| --- | --- |
| SD | SD |
| SDHC | SD、SDHC |
| SDXC | SD、SDHC、SDXC |
| SDUC | SD、SDHC、SDXC、SDUC |

カードのラベルにあるSDHC・SDXCの表示と、ノートパソコンやカードリーダーの仕様表を比べてください。古いノートパソコンのスロットがSDHCまでしか対応していなければ、SDXCカードは読めません。その場合はSDXCに対応したUSBカードリーダーを使います。規格の違いは[SDHCとSDXCの違い](/blog/ja/sdhc-vs-sdxc)に、カードリーダーの選び方は[SDカードリーダーの選び方](/blog/ja/choose-sd-card-reader)にまとめました。

## デバイス マネージャーでカードリーダーをどう確認しますか?

カードが「ディスクの管理」にもないなら、デバイス マネージャーを開きます。[Microsoftの資料](https://learn.microsoft.com/en-us/troubleshoot/windows-server/backup-and-storage/troubleshoot-disk-management)は、「!」の付いたデバイスがないかを見て、そのデバイスを選んで状態を読むよう説明しています。

1. スタートボタンを右クリックし、デバイス マネージャーを選びます。
2. カテゴリの横の矢印を選んで展開し、「!」の付いたデバイスを探します。
3. そのデバイスを右クリックし、「デバイスのアンインストール」を選びます。
4. 「操作」>「ハードウェア変更のスキャン」を選びます。

それでも直らなければ、ドライバーを再インストールするか更新します。[Microsoftのデバイス マネージャーでのドライバー更新の案内](https://support.microsoft.com/en-us/windows/update-drivers-manually-in-windows-ec62f46c-ff14-c91d-eead-d7126dc1f7b6)に書かれた方法です。

| 状況 | やること | 知っておくこと |
| --- | --- | --- |
| ドライバーがおかしいとき | デバイスをアンインストールし、パソコンを再起動します | 再起動するとWindowsがドライバーを再インストールしようとします |
| 最近の更新のあとに表示されなくなったとき | プロパティ >「ドライバー」タブ >「ドライバーを元に戻す」を選びます | 管理者権限が必要です |
| ドライバーが古いとき | 「ドライバーの更新」>「ドライバーを自動的に検索」を選びます | 見つからなければWindows Updateで探す選択肢が出ます |
| メーカーのドライバーがあるとき | メーカーのサイトからダウンロードして手動でインストールします | Windowsのバージョンとアーキテクチャに合うものを選びます |

Microsoftは、ほとんどのハードウェアのドライバーはWindows Updateで自動的にインストールされると説明しています。ノートパソコン内蔵のスロットなら、パソコンメーカーのサポートサイトでカードリーダーのドライバーを探します。

## 「ディスクの管理」にはあるのにエクスプローラーにないときは?

「ディスクの管理」は、タスクバーの検索で「コンピューターの管理」を管理者として実行し、「記憶域」>「ディスクの管理」と進むと開きます。Microsoftの資料による、状態ごとの対処は次のとおりです。

| 「ディスクの管理」での状態 | やること | しないこと |
| --- | --- | --- |
| ディスクがオフライン | ディスクを右クリックし「オンライン」を選びます | なし |
| パーティションが正常でドライブ文字がない | ドライブ文字を追加します | なし |
| パーティションがRAW | 別のカードリーダーと別のパソコンで先に確認します | フォーマット |
| 未割り当て | 別のカードリーダーと別のパソコンで先に確認します | 新しいシンプル ボリュームの作成 |
| 初期化されていない | 別のカードリーダーと別のパソコンで先に確認します | ディスクの初期化 |

ドライブ文字は[Microsoftのドライブ文字の変更の案内](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/change-a-drive-letter)に沿って付けます。管理者のアカウントが必要です。

1. 「ディスクの管理」でカードのボリュームを右クリックします。
2. 「ドライブ文字とパスの変更」を選びます。
3. 「追加」を選び、ドライブ文字を選んで「OK」を押します。

Microsoftは、ディスクやメモリーカードが表示されない・初期化できない原因として最も多いのはディスクの故障だと説明しています。カードがまた表示されたら、検査より先にコピーしてください。コピーのあとに検査する順番は[壊れたSDカードの復元を試す前に](/blog/ja/sd-card-corrupted)にあります。

## それでもSDカードが表示されないときは?

別のパソコンと別のカードリーダーでも同じなら、カードを疑います。[SD AssociationのFAQ](https://www.sdcard.org/consumers/faq/)は、規格団体でありSD製品を製造・販売していないため、技術的な問題はメーカーに直接問い合わせるよう案内しています。

Microsoftの資料は、故障したディスクからデータを取り出そうとするアプリや、有料のデータ復旧業者もあると書いています。この記事は特定のソフトや業者を試したり勧めたりはしません。まずメーカーの保証とサポート範囲を確かめてください。

USBメモリが表示されないときも、順番はほぼ同じです。データを守る順番は[USBが突然認識しないときのデータ取り出し](/blog/ja/usb-data-rescue)にまとめました。

## カードがまた表示されたら、どう取り外しますか?

[Microsoftのハードウェアの安全な取り外しの案内](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)は、データの損失を防ぐため、取り外す前に必ず安全な取り外しを行うよう説明しています。

1. タスクバーの通知領域にある「ハードウェアの安全な取り外しとメディアの取り出し」のアイコンを選びます。
2. カードのドライブの「取り出し」を選びます。
3. 安全に取り外せるという通知が出たら、カードやカードリーダーを抜きます。

カードをパソコンにつないでファイルを移す基本の手順は、[SDカードをパソコンにつなぐ方法](/blog/ja/sd-card-to-pc)にあります。

## SDカードを認識しないパソコンについてよくある質問

### カメラでは使えるのに、パソコンだけSDカードを認識しません。

カードよりも、パソコンのスロット、カードリーダー、ドライバーを疑います。スロットやカードリーダーがカードの規格に対応しているかを確かめ、デバイス マネージャーで「!」の付いたデバイスがないか見てください。

### 「ディスクの管理」でRAWと出たら、すぐフォーマットすべきですか?

残したいデータがあるなら、フォーマットしません。Microsoftは、ファイルを取り戻したいならRAWのパーティションをフォーマットしないよう案内しています。先に別のカードリーダーと別のパソコンで確認してください。

### ドライバーをアンインストールしてもパソコンに問題は出ませんか?

Microsoftの案内では、デバイスをアンインストールしてパソコンを再起動すると、Windowsがドライバーを再インストールしようとします。再インストールされなければ、ドライバーの更新かメーカーのドライバーのインストールに進みます。

### アダプターに入れたmicroSDが表示されません。

別のアダプターか、microSD用のカードリーダーで確かめてください。アダプターを使ってもカードの容量規格は変わらないので、カードリーダーがその規格に対応している必要があります。

### 別のパソコンでもSDカードが表示されないときは?

カードの故障を疑います。SD Associationは、技術的な問題はカードのメーカーに問い合わせるよう案内しています。購入店とメーカーの保証条件を確かめてください。
