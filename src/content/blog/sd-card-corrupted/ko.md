## 핵심 요약

손상된 SD 카드 복구는 순서가 중요합니다. 먼저 카드에 새 파일을 쓰지 않습니다. 그다음 열리는 파일을 다른 저장장치로 복사합니다. 검사와 포맷은 그 뒤에 합니다.

검사 도구는 Mac의 디스크 유틸리티 응급 처치와 윈도우의 `chkdsk`입니다. 두 도구 모두 모든 문제를 고치지는 못합니다. 고쳐지지 않으면 SD Association 포맷 프로그램으로 다시 포맷합니다.

다시 포맷해도 같은 증상이 나오면 카드 제조사에 문의합니다. 이 글은 특정 복구 프로그램을 다루지 않고, 파일을 되찾는다고 약속하지 않습니다.

"카메라에서 찍은 사진 몇 장이 회색으로 깨져 보여요." "어제까지 열리던 카드가 갑자기 포맷하라고 해요." 손상된 SD 카드 복구 방법을 찾는 분들이 자주 하는 말입니다. 카드가 아예 보이지 않거나 포맷이 끝나지 않는 경우는 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)에 정리했습니다. 이 글은 카드가 손상된 것 같을 때 무엇을 먼저 하고 무엇을 나중에 할지를 다룹니다.

## SD 카드 손상 증상에는 어떤 것이 있나요?

손상 증상은 크게 세 갈래입니다. 일부 파일만 깨지는 경우, 카드 전체가 열리지 않는 경우, 저장이 막히는 경우입니다.

| 증상 | 의심할 것 | 먼저 할 일 |
| --- | --- | --- |
| 사진 일부가 깨지거나 열리지 않음 | 파일이나 폴더 구조 손상 | 열리는 파일부터 복사 |
| 카드를 꽂으면 포맷하라는 메시지가 나옴 | 파일 시스템 손상 | 포맷을 누르지 않고 검사 |
| 카메라나 기기가 카드 오류를 표시함 | 기기와 카드의 호환, 카드 손상 | 오류 메시지를 기록하고 설명서 확인 |
| "cannot be modified"나 읽기 전용 메시지 | 잠금 스위치 | [SD 카드 쓰기 금지 해제](/blog/ko/sd-card-write-protected) |
| 어느 기기에서도 카드가 보이지 않음 | 연결, 리더, 카드 고장 | [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working) |

이 글은 특정 카드나 리더를 시험하지 않았고 특정 제품을 추천하지 않습니다.

## SD 카드는 왜 손상되나요?

원인을 하나로 단정할 수는 없습니다. 다만 공식 안내가 경고하는 습관이 있습니다.

[Apple의 Mac SD 카드 슬롯 안내](https://support.apple.com/en-us/102352)는 Mac이 잠자기 상태일 때 카드를 빼면 데이터를 잃을 수 있다고 설명합니다. 카드를 뺄 때는 컴퓨터를 깨우고 먼저 꺼내기를 하라고 안내합니다.

[Microsoft의 하드웨어 안전하게 제거 안내](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)도 데이터를 잃지 않으려면 USB 메모리 같은 장치를 빼기 전에 항상 안전하게 제거하라고 권합니다.

| 습관 | 공식 안내 |
| --- | --- |
| 복사 중이나 잠자기 중에 카드를 뺌 | Apple: 깨운 뒤 꺼내기를 하고 뺀다 |
| 윈도우에서 꺼내기 없이 카드를 뺌 | Microsoft: 작업 표시줄의 하드웨어 안전하게 제거 아이콘을 쓴다 |
| 카드를 억지로 밀어 넣음 | Apple: 힘으로 넣으면 손상될 수 있다 |

Mac과 PC에서 카드를 다루는 기본 순서는 [Mac SD 카드 사용법](/blog/ko/sd-card-on-mac)과 [SD 카드 컴퓨터 연결 방법](/blog/ko/sd-card-to-pc)에 있습니다.

## 손상된 SD 카드 복구 전에 무엇부터 하나요?

카드를 더 쓰지 않는 것이 먼저입니다. 새 사진을 찍거나 파일을 옮기면 카드에 다시 씁니다. 포맷도 카드에 쓰는 작업이고, 카드의 자료를 모두 지웁니다.

1. 카메라나 휴대폰에서 카드를 빼고 그 기기로 더 촬영하지 않습니다.
2. 기기에 오류 메시지가 나왔다면 적어 둡니다. [SD Association FAQ](https://www.sdcard.org/consumers/faq/)는 오류 메시지를 기록하고 기기 설명서를 확인하라고 안내합니다.
3. 카드를 컴퓨터에 연결합니다. 포맷하라는 창이 뜨면 포맷을 누르지 않고 닫습니다.
4. 열리는 사진과 영상을 컴퓨터나 다른 저장장치로 복사합니다.
5. 복사한 파일 몇 개를 열어 제대로 열리는지 확인합니다.

열리지 않는 파일은 복사가 멈출 수 있습니다. 그 파일은 건너뛰고 나머지를 먼저 옮기세요.

## Mac에서 손상된 SD 카드를 검사하려면?

디스크 유틸리티의 응급 처치를 씁니다. [Apple의 응급 처치 안내](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac)는 이 도구가 파일 손상이나 외부 장치 오작동 같은 문제를 고칠 수 있지만 모든 문제를 찾거나 고치지는 못한다고 설명합니다.

1. 디스크 유틸리티를 열고 보기, 모든 기기 보기를 선택합니다.
2. 사이드바에서 카드의 볼륨을 고르고 응급 처치를 실행합니다.
3. 컨테이너가 있으면 컨테이너에도 실행합니다.
4. 카드 맨 위 항목을 고르고 응급 처치를 실행합니다.

| 결과 | Apple 안내 |
| --- | --- |
| 정상이거나 복구됨 | 작업이 끝났습니다 |
| 응급 처치 실패 | 한 번 더 시도합니다. 그래도 안 되면 가능한 만큼 백업하고 다시 포맷합니다 |
| 디스크가 곧 고장 난다는 경고 | 자료를 백업하고 교체합니다. 고칠 수 없습니다 |
| 계속 문제가 생기거나 고칠 수 없음 | 물리적으로 손상되어 교체가 필요할 수 있습니다 |

## 윈도우에서 손상된 SD 카드를 검사하려면?

`chkdsk`를 씁니다. [Microsoft의 chkdsk 문서](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/chkdsk)에 따르면 매개변수 없이 실행하면 상태만 보여 주고 고치지 않습니다. 관리자 권한이 필요합니다.

1. 시작 메뉴에서 명령 프롬프트를 마우스 오른쪽 버튼으로 누르고 관리자 권한으로 실행을 고릅니다.
2. `chkdsk E:`를 입력해 상태만 먼저 봅니다. E는 예시이므로 카드의 드라이브 문자로 바꾸세요.
3. 오류가 보이면 `chkdsk E: /f`로 고칩니다.
4. 잃어버린 조각을 파일로 바꿀지 물으면 Y를 누릅니다.

| 옵션 | Microsoft 문서의 설명 |
| --- | --- |
| 옵션 없음 | 상태만 보여 주고 오류를 고치지 않습니다 |
| `/f` | 디스크의 오류를 고칩니다 |
| `/r` | 불량 섹터를 찾아 읽을 수 있는 정보를 되살립니다. `/f` 기능을 포함합니다 |

같은 문서는 FAT 파일 시스템을 고치면 파일 할당 테이블이 바뀌어 데이터가 사라질 수 있다고 설명합니다. Y를 누르면 잃어버린 조각이 루트 폴더에 `File<nnnn>.chk` 형식의 파일로 남습니다. Microsoft는 실행 중에 중단하지 말라고 권합니다. 그래서 2단계와 3단계 사이에 열리는 파일을 먼저 복사해 두세요.

## 검사로 고쳐지지 않으면 다시 포맷해야 하나요?

열리는 파일을 모두 옮겼다면 다시 포맷합니다. [SD Association의 포맷 프로그램 페이지](https://www.sdcard.org/downloads/formatter/)는 운영체제의 포맷 도구보다 SD Memory Card Formatter를 쓰라고 강하게 권합니다. 운영체제 도구는 SD 카드에 최적화되지 않아 성능이 떨어질 수 있다는 이유입니다.

1. 카드의 파일을 다른 곳에 복사했는지 다시 확인합니다.
2. SD Memory Card Formatter를 내려받아 설치합니다.
3. 카드를 고르고 이름과 용량을 확인합니다.
4. 포맷을 실행합니다.

빠른 포맷과 덮어쓰기 포맷의 차이는 [SD Card Formatter 사용법](/blog/ko/sd-card-formatter)에, 운영체제 도구로 포맷하는 순서는 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에 있습니다.

## 포맷한 SD 카드를 계속 써도 되나요?

포맷 뒤 정상으로 보여도 중요한 촬영에 바로 쓰기 전에 확인합니다. 아래 표는 공식 안내를 바탕으로 판단 순서를 정리한 것입니다.

| 상황 | 판단 |
| --- | --- |
| 포맷 뒤 여러 기기에서 정상으로 읽고 씀 | 사진 몇 장을 찍어 컴퓨터에서 열어 보고 씁니다 |
| 포맷 뒤에도 같은 오류가 다시 나옴 | 카드 제조사에 문의합니다 |
| 응급 처치가 곧 고장 난다고 경고함 | Apple 안내대로 교체합니다 |
| 교환이나 반품이 필요함 | SD Association FAQ대로 구입처에 문의합니다 |

SD Association은 표준 단체이고 카드를 만들거나 팔지 않습니다. 그래서 FAQ에서 제품 문제는 제조사에 직접 문의하라고 안내합니다. 지운 사진을 되찾는 방법도 카드 제조사의 안내를 보라고 답합니다.

## 아이폰 사진을 USB 메모리에도 저장해 두려면?

카드 하나에만 사진을 두면 카드가 손상될 때 함께 잃을 수 있습니다. 아이폰 사진은 다른 저장장치에도 따로 저장해 두세요. 아래 앱은 USB 메모리를 기준으로 안내합니다. USB 형식을 바꾸는 순서는 [exFAT 포맷 방법](/blog/ko/format-usb-exfat)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비 중이며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## 손상된 SD 카드 복구 자주 묻는 질문

### 포맷하라는 메시지가 나오면 눌러도 되나요?

누르지 마세요. 포맷하면 카드의 자료가 모두 지워집니다. 먼저 열리는 파일을 복사하고, 응급 처치나 `chkdsk`로 검사합니다.

### chkdsk를 실행하면 사진이 지워지나요?

옵션 없이 실행하면 상태만 보여 줍니다. `/f`로 고칠 때 Microsoft는 FAT 파일 시스템에서 데이터가 사라질 수 있다고 설명합니다. 남길 사진은 실행 전에 복사하세요.

### 응급 처치가 실패하면 카드를 버려야 하나요?

Apple은 한 번 더 시도하고, 그래도 안 되면 가능한 만큼 백업한 뒤 다시 포맷하라고 안내합니다. 포맷 뒤에도 문제가 계속되면 물리적 손상일 수 있습니다.

### 손상된 SD 카드의 사진을 SD Association이 되살려 주나요?

아닙니다. SD Association은 사진을 되찾는 도구를 제공하지 않습니다. 카드 제조사의 안내를 확인하세요.

### 손상을 줄이려면 어떻게 하나요?

카드를 빼기 전에 Mac에서는 꺼내기를, 윈도우에서는 하드웨어 안전하게 제거를 합니다. Apple은 Mac이 잠자기 상태일 때 카드를 빼지 말라고 안내합니다.
