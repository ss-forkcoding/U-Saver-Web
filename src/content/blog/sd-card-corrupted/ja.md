## この記事の要点

壊れたSDカードの復元は、順番が大切です。まずカードに新しいファイルを書き込まないようにします。次に、開けるファイルを別の記憶装置へコピーします。検査とフォーマットはそのあとです。

検査に使うのは、Macのディスクユーティリティの First Aid と、Windowsの`chkdsk`です。どちらもすべての問題を直せるわけではありません。直らなければ、SD Associationのフォーマットソフトでフォーマットし直します。

フォーマットし直しても同じ症状が出るなら、カードメーカーに問い合わせます。この記事では特定の復元ソフトを扱わず、ファイルが戻ると約束しません。

「カメラで撮った写真の一部が灰色に崩れて表示される」「昨日まで開けたカードが、急にフォーマットしてくださいと出る」。壊れたSDカードの復元方法を探す人からよく聞く声です。カードがまったく表示されない、フォーマットが終わらないといった場合は[microSDが認識しない・フォーマットできないとき](/blog/ja/sd-card-not-working)にまとめました。この記事では、カードが壊れたように見えるときに、何を先にして何をあとにするかを扱います。

## SDカードが壊れたときはどんな症状が出ますか?

症状は大きく3つに分かれます。一部のファイルだけが壊れる、カード全体が開けない、保存ができない、の3つです。

| 症状 | 疑うこと | 先にすること |
| --- | --- | --- |
| 写真の一部が崩れる、開けない | ファイルやフォルダー構造の破損 | 開けるファイルからコピー |
| カードを挿すとフォーマットを求められる | ファイルシステムの破損 | フォーマットせずに検査 |
| カメラや機器がカードのエラーを表示する | 機器との互換性、カードの破損 | エラーメッセージを控えて説明書を確認 |
| 「cannot be modified」や読み取り専用と出る | ロックのつまみ | [SDカードの書き込み禁止を解除する方法](/blog/ja/sd-card-write-protected) |
| どの機器でもカードが表示されない | 接続、リーダー、カードの故障 | [microSDが認識しない・フォーマットできないとき](/blog/ja/sd-card-not-working) |

この記事では特定のカードやカードリーダーを試しておらず、特定の製品をすすめません。

## SDカードはなぜ壊れるのですか?

原因を1つに決めることはできません。ただ、公式の案内が注意している使い方があります。

[AppleのMac SDカードスロットの案内](https://support.apple.com/en-us/102352)は、Macがスリープ中にカードを抜くとデータを失うおそれがあると説明しています。カードを抜くときは、コンピュータを起こしてから先に取り出すよう案内しています。

[Microsoftのハードウェアを安全に取り外す案内](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)も、データを失わないように、USBメモリなどの機器は外す前に必ず安全に取り外すよう書いています。

| 使い方 | 公式の案内 |
| --- | --- |
| コピー中やスリープ中にカードを抜く | Apple:起こして取り出してから抜く |
| Windowsで取り出さずにカードを抜く | Microsoft:タスクバーの「ハードウェアを安全に取り外してメディアを取り出す」アイコンを使う |
| カードを無理に押し込む | Apple:無理に入れると損傷するおそれがある |

Macとパソコンでカードを扱う基本は、[MacでSDカードを使う方法](/blog/ja/sd-card-on-mac)と[SDカードをパソコンにつなぐ方法](/blog/ja/sd-card-to-pc)にあります。

## 壊れたSDカードの復元を試す前に何をしますか?

まずカードを使うのをやめます。新しく写真を撮ったりファイルを移したりすると、カードにまた書き込みます。フォーマットもカードに書き込む作業で、カードのデータをすべて消します。

1. カメラやスマホからカードを抜き、その機器でこれ以上撮影しません。
2. 機器にエラーメッセージが出ていたら控えておきます。[SD Associationのよくある質問](https://www.sdcard.org/consumers/faq/)は、エラーメッセージを控えて機器の説明書を確認するよう案内しています。
3. カードをパソコンにつなぎます。フォーマットを求める画面が出たら、フォーマットせずに閉じます。
4. 開ける写真とビデオを、パソコンや別の記憶装置にコピーします。
5. コピーしたファイルがいくつか開けるか確かめます。

開けないファイルがあるとコピーが止まることがあります。そのファイルは飛ばして、残りを先に移してください。

## Macで壊れたSDカードを検査するには?

ディスクユーティリティの First Aid を使います。[Appleの First Aid の案内](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac)は、このツールがファイルの破損や外部機器の不具合などの問題を直せる一方で、すべての問題を見つけたり直したりはできないと説明しています。

1. ディスクユーティリティを開き、「表示」から「すべてのデバイスを表示」を選びます。
2. サイドバーでカードのボリュームを選び、First Aid を実行します。
3. コンテナがあれば、コンテナにも実行します。
4. カードのいちばん上の項目を選び、First Aid を実行します。

| 結果 | Appleの案内 |
| --- | --- |
| 問題がない、または修復された | 作業は終わりです |
| First Aid が失敗した | もう一度試します。それでもだめなら、できるだけバックアップしてフォーマットし直します |
| ディスクがまもなく故障するという警告 | データをバックアップして交換します。修復はできません |
| 問題が続く、または修復できない | 物理的に損傷していて交換が必要な可能性があります |

## Windowsで壊れたSDカードを検査するには?

`chkdsk`を使います。[Microsoftのchkdskの説明](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/chkdsk)によると、パラメーターなしで実行すると状態を表示するだけで、エラーは直しません。管理者権限が必要です。

1. スタートメニューでコマンドプロンプトを右クリックし、「管理者として実行」を選びます。
2. `chkdsk E:`と入力して、まず状態だけを見ます。Eは例なので、カードのドライブ文字に置き換えてください。
3. エラーが見つかったら、`chkdsk E: /f`で直します。
4. 失われたチェーンをファイルに変換するか聞かれたら、Yを押します。

| オプション | Microsoftの説明 |
| --- | --- |
| オプションなし | 状態を表示するだけで、エラーは直しません |
| `/f` | ディスクのエラーを直します |
| `/r` | 不良セクターを探し、読み取れる情報を回復します。`/f`の機能を含みます |

同じ説明は、FATファイルシステムの修復ではファイルアロケーションテーブルが変わり、データが失われることがあると書いています。Yを押すと、失われたチェーンはルートフォルダーに`File<nnnn>.chk`という形式のファイルとして残ります。Microsoftは実行中に中断しないようすすめています。手順2と3のあいだに、開けるファイルを先にコピーしておきましょう。

## 検査で直らなければフォーマットし直しますか?

開けるファイルをすべて移したら、フォーマットし直します。[SD Associationのフォーマットソフトのページ](https://www.sdcard.org/downloads/formatter/)は、OSに付いているフォーマットツールよりSD Memory Card Formatterを使うよう強くすすめています。OSのツールはSDカードに最適化されておらず、性能が下がることがあるためです。

1. カードのファイルを別の場所にコピーしたか、もう一度確かめます。
2. SD Memory Card Formatterをダウンロードしてインストールします。
3. カードを選び、名前と容量を確かめます。
4. フォーマットを実行します。

クイックフォーマットと上書きフォーマットの違いは[SDカードフォーマッターの使い方](/blog/ja/sd-card-formatter)に、OSのツールでフォーマットする手順は[SDカードフォーマット方法](/blog/ja/format-sd-card)にあります。

## フォーマットし直したSDカードは使い続けられますか?

フォーマット後に問題がなさそうでも、大切な撮影の前に確かめます。下の表は、公式の案内をもとに判断の順番をまとめたものです。

| 状況 | 判断 |
| --- | --- |
| フォーマット後、複数の機器で問題なく読み書きできる | 写真を何枚か撮り、パソコンで開いて確かめてから使います |
| フォーマット後も同じエラーが出る | カードメーカーに問い合わせます |
| First Aid がまもなく故障すると警告した | Appleの案内どおり交換します |
| 交換や返品が必要 | SD Associationのよくある質問のとおり、購入店に問い合わせます |

SD Associationは規格を作る団体で、カードを作ったり売ったりしていません。そのため、製品の問題はメーカーに直接問い合わせるよう案内しています。消した写真を取り戻す方法についても、カードメーカーの案内を見るよう答えています。

## iPhoneの写真をUSBメモリにも保存しておくには?

写真を1枚のカードだけに置いていると、カードが壊れたときに一緒に失うおそれがあります。iPhoneの写真は別の記憶装置にも保存しておきましょう。以下のアプリはUSBメモリを前提に説明します。形式を変える手順は[exFATフォーマット方法](/blog/ja/format-usb-exfat)にあります。

NextGenAIが作ったU-Saverは、一般的なUSBメモリに写真、ビデオ、連絡先を保存するアプリで、exFATかFAT32のUSBメモリを使い、iOS 26以降で動作します。U-SaverはApp Storeでの公開を準備しており、韓国での価格は4,900ウォンの買い切りです。U-Saverはメッセージ、アプリのデータ、iPhoneの設定は保存せず、U-Saverで保存したUSBメモリの内容は暗号化されません。購入前に[U-Saverを使う前に確認したい6つのこと](/blog/ja/before-you-buy)をご確認ください。

## 壊れたSDカードの復元のよくある質問

### フォーマットを求められたら押してもいいですか?

押さないでください。フォーマットするとカードのデータはすべて消えます。先に開けるファイルをコピーし、First Aid や`chkdsk`で検査します。

### chkdskを実行すると写真は消えますか?

オプションなしなら状態を表示するだけです。`/f`で直すとき、MicrosoftはFATファイルシステムではデータが失われることがあると説明しています。残したい写真は実行前にコピーしてください。

### First Aid が失敗したらカードは捨てるべきですか?

Appleは、もう一度試し、それでもだめならできるだけバックアップしてフォーマットし直すよう案内しています。そのあとも問題が続くなら、物理的な損傷の可能性があります。

### 壊れたカードの写真をSD Associationが復元してくれますか?

いいえ。SD Associationは写真を取り戻すツールを提供していません。カードメーカーの案内を確認してください。

### 壊れにくくするにはどうすればいいですか?

カードを抜く前に、Macでは取り出しを、Windowsでは「ハードウェアの安全な取り外し」をします。Appleは、Macがスリープ中にカードを抜かないよう案内しています。
