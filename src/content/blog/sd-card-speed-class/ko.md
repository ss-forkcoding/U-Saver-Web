## 핵심 요약

SD 카드 속도는 두 가지로 표시합니다. 스피드 클래스는 영상 녹화 때 카드가 보장하는 최소 쓰기 속도입니다. 포장에 적힌 "최대 OOMB/s"는 제조사가 밝힌 최고 속도입니다.

스피드 클래스는 네 계열입니다. Class 2~10, U1·U3, V6~V90, E150~E600입니다. Class 10, U1, V10은 모두 초당 10MB 쓰기를 뜻합니다.

기기 설명서가 요구하는 표시와 같거나 더 높은 카드를 고릅니다. 표시 계열도 맞춥니다. 설명서가 V30을 요구하면 V30 이상 카드를 씁니다.

"Class 10이면 충분한가요?" "U3와 V30은 뭐가 달라요?" 카드를 고를 때 자주 나오는 질문입니다. 이 글은 SD 카드 속도 표시를 하나씩 풀고, 내 기기에 맞는 카드를 고르는 순서를 정리합니다. 크기·용량·속도 표시 전체는 [에스디 카드란?](/blog/ko/what-is-sd-card)에 있습니다.

## SD 카드 속도 표시는 무엇을 뜻하나요?

카드에는 성격이 다른 속도 표시가 함께 붙습니다.

| 표시 | 뜻 | 예 |
| --- | --- | --- |
| 스피드 클래스 | 영상 녹화 때 보장하는 최소 쓰기 속도 | Class 10, U3, V30 |
| 버스 방식 | 카드와 기기 사이 통로의 최대 속도 | UHS-I, UHS-II, SD Express |
| 앱 성능 클래스 | 카드에 설치한 앱을 실행할 때의 성능 | A1, A2 |
| 제조사 표기 속도 | 제조사가 밝힌 최대 읽기·쓰기 속도 | 최대 OOMB/s |

[SD Association의 스피드 클래스 안내](https://www.sdcard.org/developers/sd-standard-overview/speed-class/)는 스피드 클래스가 정해진 조건에서 최소 연속 쓰기 성능을 보장한다고 설명합니다. 영상은 일정한 속도로 계속 써야 프레임이 빠지지 않습니다. 그래서 스피드 클래스는 영상 녹화에서 가장 중요합니다.

제조사 표기 속도는 최소 보장값이 아닙니다. SanDisk 데이터시트는 표기 속도가 내부 시험 기준이며 기기와 사용 조건에 따라 더 낮을 수 있다고 적습니다.

## Class 10, U3, V30은 각각 무엇인가요?

SD Association은 스피드 클래스를 네 계열로 나눕니다. 기호에 붙은 숫자는 최소 쓰기 속도를 나타냅니다.

| 계열 | 표시 | 적용 버스 |
| --- | --- | --- |
| Speed Class | Class 2, 4, 6, 10 | Class 10은 High Speed 이상 |
| UHS Speed Class | U1, U3 | UHS-I, UHS-II, UHS-III |
| Video Speed Class | V6, V10, V30, V60, V90 | V30은 UHS, V60·V90은 UHS-II 이상 |
| SD Express Speed Class | E150, E300, E450, E600 | SD Express |

수치는 이렇게 확인했습니다.

- **Class 10, U1, V10:** SD Association은 세 표시가 같은 초당 10MB 쓰기 속도라고 적습니다.
- **V30:** [Samsung 데이터시트](https://download.semiconductor.samsung.com/resources/data-sheet/2023_samsung_data_sheet_microsd_card_pro_plus_v1.1.pdf)는 V10을 초당 10MB, V30을 초당 30MB의 지속 녹화 속도로 설명합니다.
- **U3:** [SanDisk 데이터시트](https://documents.sandisk.com/content/dam/asset-library/en_us/assets/public/sandisk/product/memory-cards/high-endurance-uhs-i-microsd/data-sheet-high-endurance-uhs-i-microsd.pdf)는 U3와 V30을 초당 30MB 지속 녹화를 위한 성능 표시로 함께 설명합니다.

Video Speed Class는 4K·8K 고화질 녹화와 3D NAND 같은 새 플래시 메모리에 맞춰 정한 규격입니다.

## 어떤 영상에 어떤 SD 카드 속도가 필요한가요?

[SD Association FAQ](https://www.sdcard.org/consumers/faq/)는 클래스별 대표 용도를 이렇게 적습니다.

| 표시 | 대표 용도 |
| --- | --- |
| Class 2 | H.264, MPEG-4, MPEG-2 영상 녹화 |
| Class 4 | MPEG-2(HDTV) 영상 녹화 |
| Class 6, V6 | SD~HD 영상 녹화 |
| Class 10, U1, V10 | HD~풀HD 영상 녹화 |
| U3, V30 | 풀HD~4K 영상 녹화 |
| V60 | 4K~8K 영상 녹화 |
| V90 | 8K 영상 녹화 |

이 표는 대표 용도입니다. 같은 4K라도 기기의 화질 설정에 따라 필요한 속도가 다릅니다. 최종 기준은 기기 설명서입니다.

## Class 10 SD 카드면 4K 녹화에 충분한가요?

설명서가 Class 10을 요구하면 충분합니다. 설명서가 U3나 V30을 요구하면 Class 10 카드로는 부족합니다.

SD Association은 기기와 카드의 표시 계열이 다르면 기대한 쓰기 속도가 나오지 않는다고 설명합니다. 예로 든 조합은 이렇습니다.

| 기기 요구 | 카드 표시 | 결과 |
| --- | --- | --- |
| Class 4 | Class 4, 6, 10 | 사용 가능 |
| U1 | U1, U3 | 사용 가능 |
| V10 | V10, V30 | 사용 가능 |
| Class 10 | U1 | 숫자는 같아도 기대 속도가 나오지 않음 |
| U1 | V10 | 숫자는 같아도 기대 속도가 나오지 않음 |

같은 계열 안에서 같거나 높은 숫자를 고르면 됩니다. 위 Samsung, SanDisk 데이터시트의 카드처럼 Class 10, U3, V30을 함께 표시하는 카드도 있습니다. 카드 앞면과 포장의 표시를 모두 확인하세요.

## 내 기기에 맞는 SD 카드 속도는 어떻게 고르나요?

1. 기기 설명서의 메모리 카드 항목에서 권장 스피드 클래스를 찾습니다. SD Association은 기기 본체, 포장, 설명서에 스피드 클래스 기호를 표시할 수 있다고 안내합니다.
2. 같은 항목에서 지원하는 용량 규격(SDHC, SDXC)을 확인합니다. 규격 차이는 [SDHC·SDXC·SDUC 차이](/blog/ko/sdhc-vs-sdxc)에 있습니다.
3. 카드 크기가 SD인지 microSD인지 확인합니다. 차이는 [microSD와 SD 카드 차이](/blog/ko/microsd-vs-sd)에 있습니다.
4. 설명서가 요구하는 표시와 같은 계열에서 같거나 높은 숫자의 카드를 고릅니다.
5. V60이나 V90이 필요하면 기기가 UHS-II를 지원하는지도 확인합니다. SD Association 표에서 UHS-I 방식은 V30까지만 씁니다.

## 카드 표시보다 느리게 녹화되는 이유는 무엇인가요?

SD Association은 두 가지 원인을 설명합니다.

| 원인 | 설명 | 할 일 |
| --- | --- | --- |
| 버스 방식이 느림 | Class 10은 High Speed 이상, U1·U3는 SDR50·DDR50 이상, V60·V90은 UHS-II 이상 방식에서 씁니다 | 기기가 지원하는 버스 방식을 확인합니다 |
| 카드 조각화 | 파일을 지우고 쓰기를 반복하면 빈 공간이 흩어져 쓰기 속도가 느려집니다 | 자료를 옮긴 뒤 카드를 포맷합니다 |

스피드 클래스 쓰기는 조각나지 않은 빈 영역에 연속으로 쓰는 것을 전제로 합니다. 남은 용량이 충분해도 조각화가 심하면 기기가 스피드 클래스 녹화를 하지 못할 수 있습니다. SD Association은 이때 데이터를 다른 저장장치로 옮기고 카드를 다시 포맷하라고 안내합니다.

포맷하면 카드 자료가 모두 지워집니다. 사진과 영상을 먼저 다른 곳에 복사하세요. 순서는 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에 있습니다.

## 아이폰에서 SD 카드 속도가 차이를 만드나요?

아이폰은 카드 리더로 SD 카드를 읽습니다. 이때 전송 속도는 리더와 아이폰의 USB 속도에도 묶입니다.

[Apple 카메라 어댑터 안내](https://support.apple.com/en-us/118280)는 iPhone 15 Pro, iPhone 15 Pro Max, iPhone 16 Pro, iPhone 16 Pro Max가 USB 3 전송 속도를 지원한다고 적습니다. 그 밖의 어댑터와 기기는 USB 2 속도를 씁니다. 이 글은 실제 전송 속도를 측정하지 않았습니다.

리더 연결 순서는 [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader)에 있습니다.

## 아이폰 사진을 USB 메모리에 저장하려면?

아래 앱은 USB 메모리를 기준으로 안내합니다. USB 메모리 연결 조건은 [아이폰 USB 메모리 사용법](/blog/ko/iphone-flash-drive-guide)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비하고 있으며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## SD 카드 속도 자주 묻는 질문

### Class 10과 U1은 같은 속도인가요?

둘 다 초당 10MB 쓰기를 뜻합니다. 다만 계열이 다릅니다. SD Association은 Class 10을 요구하는 기기에 U1 카드를 쓰면 기대한 속도가 나오지 않는다고 설명합니다.

### U3와 V30은 무엇이 다른가요?

U3는 UHS Speed Class, V30은 Video Speed Class입니다. SD Association FAQ는 둘을 풀HD~4K 녹화 용도로 함께 분류합니다. 기기 설명서가 적은 표시를 따르세요.

### 스피드 클래스가 높으면 사진 복사도 빨라지나요?

꼭 그렇지는 않습니다. 스피드 클래스는 최소 연속 쓰기 속도입니다. 복사 속도는 버스 방식, 카드 리더, 연결한 기기의 USB 속도에도 달려 있습니다.

### 포장에 적힌 최대 속도는 믿어도 되나요?

제조사가 내부 시험으로 잰 최대값입니다. SanDisk 데이터시트는 기기와 사용 조건에 따라 더 낮을 수 있다고 적습니다.

### A1, A2는 속도 클래스인가요?

앱 성능 클래스입니다. 카드에 설치한 앱을 실행할 때의 성능을 나타냅니다. Samsung 데이터시트는 A1과 A2의 지속 연속 쓰기를 초당 10MB로 적습니다.
