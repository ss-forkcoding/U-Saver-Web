## 要点まとめ

SDカードのV30とは、動画撮影で毎秒30MBの書き込みを保つビデオスピードクラスです。スピードクラスは、カードが保証する最低の書き込み速度を示します。

スピードクラスは4つの系統があります。Class 2〜10、U1・U3、V6〜V90、E150〜E600です。Class 10、U1、V10はどれも毎秒10MBの書き込みを示します。

パッケージの「最大○○MB/s」は別の数字です。メーカーが示す最大速度で、最低の保証値ではありません。

機器の取扱説明書が求める表示と同じ系統で、同じか上の数字のカードを選びます。説明書がV30を求めるなら、V30以上のカードを使います。

「V30とはどういう意味?」「Class 10で4Kは撮れる?」カードを選ぶときによく出る疑問です。この記事ではスピードクラスの表示を1つずつ読み解き、機器に合うカードの選び方をまとめます。サイズ、容量、速度の表示全体は[SDカードとは?](/blog/ja/what-is-sd-card)にあります。

## SDカードの速度表示は何を意味しますか?

カードには性質の違う速度表示がいくつか付いています。

| 表示 | 意味 | 例 |
| --- | --- | --- |
| スピードクラス | 動画撮影で保証する最低の書き込み速度 | Class 10、U3、V30 |
| バス方式 | カードと機器の間の通り道の最大速度 | UHS-I、UHS-II、SD Express |
| アプリパフォーマンスクラス | カードに入れたアプリを動かすときの性能 | A1、A2 |
| メーカー表記の速度 | メーカーが示す最大の読み込み・書き込み速度 | 最大○○MB/s |

[SD Associationのスピードクラスの案内](https://www.sdcard.org/developers/sd-standard-overview/speed-class/)は、スピードクラスが規格で決めた条件のもとで最低の連続書き込み性能を保証すると説明しています。動画はコマ落ちを防ぐため、一定の速度で書き続ける必要があります。そのためスピードクラスは動画撮影でもっとも重要です。

メーカー表記の速度は最低の保証値ではありません。SanDiskのデータシートは、表記の速度は社内テストによるもので、機器や使用条件によって低くなる場合があると書いています。

## V30、Class 10、U3はそれぞれ何ですか?

SD Associationはスピードクラスを4つの系統に分けています。記号に付いた数字は最低の書き込み速度を示します。

| 系統 | 表示 | 使うバス方式 |
| --- | --- | --- |
| スピードクラス | Class 2、4、6、10 | Class 10はHigh Speed以上 |
| UHSスピードクラス | U1、U3 | UHS-I、UHS-II、UHS-III |
| ビデオスピードクラス | V6、V10、V30、V60、V90 | V30はUHS、V60・V90はUHS-II以上 |
| SD Expressスピードクラス | E150、E300、E450、E600 | SD Express |

数字は次の資料で確かめました。

- **Class 10、U1、V10:** SD Associationは、3つとも同じ毎秒10MBの書き込み速度だと書いています。
- **V30:** [Samsungのデータシート](https://download.semiconductor.samsung.com/resources/data-sheet/2023_samsung_data_sheet_microsd_card_pro_plus_v1.1.pdf)は、V10を毎秒10MB、V30を毎秒30MBの持続的な動画記録速度と説明しています。
- **U3:** [SanDiskのデータシート](https://documents.sandisk.com/content/dam/asset-library/en_us/assets/public/sandisk/product/memory-cards/high-endurance-uhs-i-microsd/data-sheet-high-endurance-uhs-i-microsd.pdf)は、U3とV30を毎秒30MBの持続的な動画記録のための性能表示としてまとめて説明しています。

SD Associationは、4K・8Kの高画質撮影と3D NANDのような新しいフラッシュメモリに合わせてビデオスピードクラスを定めました。

## どの動画にどのSDカードの速度が必要ですか?

[SD AssociationのFAQ](https://www.sdcard.org/consumers/faq/)は、クラスごとの代表的な用途を次のように挙げています。

| 表示 | 代表的な用途 |
| --- | --- |
| Class 2 | H.264、MPEG-4、MPEG-2の動画撮影 |
| Class 4 | MPEG-2(HDTV)の動画撮影 |
| Class 6、V6 | SD〜HDの動画撮影 |
| Class 10、U1、V10 | HD〜フルHDの動画撮影 |
| U3、V30 | フルHD〜4Kの動画撮影 |
| V60 | 4K〜8Kの動画撮影 |
| V90 | 8Kの動画撮影 |

この表は代表的な用途です。同じ4Kでも、機器の画質設定で必要な速度が変わります。最終的な基準は取扱説明書です。

## Class 10のSDカードで4K撮影はできますか?

説明書がClass 10を求めていれば足ります。説明書がU3やV30を求めていれば、Class 10のカードでは足りません。

SD Associationは、機器とカードの表示の系統が違うと、期待した書き込み速度が出ないと説明しています。挙げている例は次のとおりです。

| 機器が求める表示 | カードの表示 | 結果 |
| --- | --- | --- |
| Class 4 | Class 4、6、10 | 使える |
| U1 | U1、U3 | 使える |
| V10 | V10、V30 | 使える |
| Class 10 | U1 | 数字が同じでも期待した速度が出ない |
| U1 | V10 | 数字が同じでも期待した速度が出ない |

同じ系統のなかで、同じか上の数字を選びます。上のSamsungやSanDiskのデータシートのカードのように、Class 10、U3、V30をまとめて表示するカードもあります。カードの表面とパッケージの表示を両方確かめてください。

## 自分の機器に合うSDカードの速度はどう選びますか?

1. 取扱説明書のメモリーカードの項目で、推奨のスピードクラスを探します。SD Associationは、機器の本体、パッケージ、説明書にスピードクラスの記号を表示できると案内しています。
2. 同じ項目で、対応する容量規格(SDHC、SDXC)を確かめます。規格の違いは[SDXCとは?](/blog/ja/sdhc-vs-sdxc)にあります。
3. 機器がSDかmicroSDかを確かめます。違いは[micro SDとは?](/blog/ja/microsd-vs-sd)にあります。
4. 説明書が求める表示と同じ系統で、同じか上の数字のカードを選びます。
5. V60やV90が必要なら、機器がUHS-IIに対応しているかも確かめます。SD Associationの表では、UHS-IのモードはV30までです。

## 表示より遅く記録されるのはなぜですか?

SD Associationは2つの原因を挙げています。

| 原因 | 内容 | すること |
| --- | --- | --- |
| バスのモードが遅い | Class 10はHigh Speed以上、U1・U3はSDR50・DDR50以上、V60・V90はUHS-II以上のモードで使います | 機器が対応するバス方式を確かめます |
| 断片化 | ファイルの削除と書き込みを繰り返すと空き領域がばらばらになり、書き込みが遅くなります | データを移してからカードをフォーマットします |

スピードクラスの書き込みは、断片化していない空き領域に連続して書くことを前提にしています。空き容量が十分でも、断片化が進むと機器がスピードクラスでの記録をできない場合があります。SD Associationは、その場合はデータをほかのストレージに移し、カードをフォーマットし直すよう案内しています。

フォーマットするとカードのデータはすべて消えます。写真や動画を先にほかの場所へコピーしてください。手順は[SDカードフォーマット方法](/blog/ja/format-sd-card)にあります。

## iPhoneではSDカードの速度で差が出ますか?

iPhoneはカードリーダーでSDカードを読みます。このとき転送速度は、リーダーとiPhoneのUSBの速度にも左右されます。

[Appleのカメラアダプタの案内](https://support.apple.com/en-us/118280)は、iPhone 15 Pro、iPhone 15 Pro Max、iPhone 16 Pro、iPhone 16 Pro MaxがUSB 3の転送速度に対応すると書いています。そのほかのアダプタと機器はUSB 2の速度です。この記事では実際の転送速度を測っていません。

リーダーの使い方は[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)にあります。

## SDカードのV30・スピードクラスのよくある質問

### SDカードのV30とは何の略ですか?

V30はビデオスピードクラス30です。Samsungのデータシートは、毎秒30MBの持続的な動画記録速度と説明しています。

### Class 10とU1は同じ速度ですか?

どちらも毎秒10MBを示しますが、系統が違います。SD Associationは、Class 10を求める機器でU1のカードを使うと、期待した速度が出ないと説明しています。

### U3とV30は何が違いますか?

U3はUHSスピードクラス、V30はビデオスピードクラスです。SD AssociationのFAQは、どちらもフルHD〜4Kの撮影向けに分類しています。機器の説明書の表示に従ってください。

### スピードクラスが高いと写真のコピーも速くなりますか?

そうとは限りません。スピードクラスは最低の連続書き込み速度です。コピーの速度は、バス方式、カードリーダー、つないだ機器のUSBの速度にも左右されます。

### A1、A2はスピードクラスですか?

アプリパフォーマンスクラスです。カードに入れたアプリを動かすときの性能を示します。Samsungのデータシートは、A1とA2の持続的な連続書き込みを毎秒10MBと書いています。
