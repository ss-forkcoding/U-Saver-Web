## 핵심 요약

에스디 카드(SD 카드)는 카메라, 스마트폰, 게임기 같은 기기에 꽂아 쓰는 작은 메모리 카드입니다. 규격은 SD Association이 정합니다.

SD 카드 종류는 세 가지 기준으로 나뉩니다. 크기(SD, microSD), 용량(SD, SDHC, SDXC, SDUC), 속도(버스 방식과 스피드 클래스)입니다.

카드를 고를 때는 기기가 어떤 규격을 지원하는지 먼저 봅니다. 큰 용량 카드는 그보다 낮은 규격만 아는 기기에서 쓸 수 없습니다.

"카드에 SDXC, U3, V30이 적혀 있는데 무슨 뜻이에요?" "마이크로 SD와 그냥 SD는 뭐가 달라요?" 에스디 카드를 처음 살 때 자주 나오는 질문입니다. 이 글은 카드에 적힌 표시를 하나씩 풀고, 기기별 쓰임을 정리합니다.

## 에스디 카드란 무엇인가요?

SD 카드는 전원이 꺼져도 내용이 남는 플래시 메모리 카드입니다. [SD Association](https://www.sdcard.org/developers/sd-standard-overview/sd-family/)은 SD 메모리 카드를 탈착식 비휘발성 메모리로 분류합니다. 이 단체는 2000년 1월 Panasonic, SanDisk, Toshiba(현 KIOXIA)가 세웠습니다.

카드를 꽂는 기기를 호스트라고 부릅니다. 카메라, 스마트폰, 노트북의 카드 슬롯, 카드 리더가 모두 호스트입니다. 카드와 호스트가 같은 규격을 지원해야 제 속도와 용량으로 쓸 수 있습니다.

## SD 카드 종류는 크기에 따라 어떻게 나뉘나요?

지금 흔히 쓰는 크기는 일반 SD와 microSD 두 가지입니다. 크기는 [SD Association의 스피드 클래스 안내](https://www.sdcard.org/consumers/speed-class-standards-for-video-recording/) 표 기준입니다.

| 크기 | 가로 x 세로 x 두께 | 주로 쓰는 기기 |
| --- | --- | --- |
| SD | 32 x 24 x 2.1mm | 디지털카메라, 노트북 카드 슬롯 |
| microSD | 11 x 15 x 1.0mm | 스마트폰, 액션캠, 휴대용 게임기 |

microSD 카드를 SD 슬롯에 쓰려면 어댑터에 끼웁니다. 아이폰에서 microSD를 쓰는 순서는 [아이폰 마이크로 SD 쓰는 법](/blog/ko/iphone-microsd)에 정리했습니다.

## SD 카드 종류는 용량에 따라 어떻게 나뉘나요?

용량 규격은 네 가지입니다. 카드 앞면의 로고가 규격을 알려 줍니다. [SD Association의 용량 규격 안내](https://www.sdcard.org/developers/sd-standard-overview/capacity-sd-sdhc-sdxc-sduc/) 기준입니다.

| 규격 | 용량 | 기본 파일 시스템 |
| --- | --- | --- |
| SD | 2GB까지 | FAT12, FAT16 |
| SDHC | 2GB 초과 32GB까지 | FAT32 |
| SDXC | 32GB 초과 2TB까지 | exFAT |
| SDUC | 2TB 초과 128TB까지 | exFAT |

용량 규격은 호환 범위를 정합니다. [SD Association의 호환 안내](https://www.sdcard.org/consumers/sd-sdhc-sdxc-and-sduc-card-capacity-choices/)에 따르면 상위 규격 기기는 하위 규격 카드를 읽습니다. 반대는 안 됩니다.

1. SDXC 기기는 SD, SDHC, SDXC 카드를 씁니다.
2. SDHC 기기는 SD와 SDHC 카드만 씁니다. SDXC 카드는 쓸 수 없습니다.
3. SDUC 카드는 SDUC 기기에서만 씁니다.

오래된 카메라에 64GB 카드가 들어가지 않는다면 기기가 SDXC를 지원하는지 설명서에서 확인하세요.

## SD 카드에 적힌 속도 표시는 무엇인가요?

속도 표시는 두 종류입니다. 버스 방식은 카드와 기기가 주고받는 통로의 최대 속도입니다. 스피드 클래스는 영상을 찍을 때 보장하는 최소 쓰기 속도입니다.

### 버스 방식: UHS-I, UHS-II, SD Express

[SD Association의 버스 속도 안내](https://www.sdcard.org/developers/sd-standard-overview/bus-speed-default-speed-high-speed-uhs-sd-express/) 기준입니다.

| 버스 방식 | 버스 최대 속도 |
| --- | --- |
| Default Speed | 12.5MB/s |
| High Speed | 25MB/s |
| UHS-I | 50MB/s, 104MB/s |
| UHS-II | 156MB/s(전이중), 312MB/s(반이중) |
| UHS-III | 624MB/s |
| SD Express | 985MB/s~3,940MB/s |

같은 안내는 실제 최대 속도가 버스 속도와 다르고 카드 성능에 따라 달라진다고 설명합니다. UHS-II 카드를 UHS-I 기기에 꽂으면 UHS-II 속도가 나오지 않습니다. 버스 속도는 기기와 카드가 함께 지원해야 나옵니다.

### 스피드 클래스: Class 10, U3, V30

[SD Association의 스피드 클래스 규격](https://www.sdcard.org/developers/sd-standard-overview/speed-class/)은 네 종류의 표시를 정합니다. 숫자는 최소 쓰기 속도를 나타냅니다.

| 표시 종류 | 등급 |
| --- | --- |
| Speed Class | C2, C4, C6, C10 |
| UHS Speed Class | U1, U3 |
| Video Speed Class | V6, V10, V30, V60, V90 |
| SD Express Speed Class | E150, E300, E450, E600 |

스피드 클래스는 영상 녹화처럼 일정한 속도로 계속 써야 하는 일에 중요합니다. 카메라 설명서가 V30을 요구한다면 V30 이상 카드를 고르세요.

### 앱 성능 등급: A1, A2

[SD Association의 앱 성능 등급 안내](https://www.sdcard.org/developers/sd-standard-overview/application-performance-class/)에 따르면 A1과 A2는 카드에 앱을 설치해 쓸 때의 성능을 보장하는 등급입니다. A2 성능은 기기와 카드가 모두 A2를 지원해야 나옵니다.

## 에스디 카드는 어디에 쓰나요?

기기마다 카드에 맡기는 일이 다릅니다.

| 기기 | 주된 쓰임 | 확인할 표시 |
| --- | --- | --- |
| 디지털카메라, 캠코더 | 사진과 영상 저장 | 용량 규격, 스피드 클래스 |
| 안드로이드 스마트폰 | 사진 저장, 앱 설치 | microSD, A1·A2 |
| 액션캠, 드론 | 고화질 영상 녹화 | microSD, 설명서가 요구하는 스피드 클래스 |
| 휴대용 게임기 | 게임 데이터 저장 | 제조사가 지정한 카드 종류 |
| 아이폰 | 카드 사진 가져오기, 파일 복사 | 카드 리더와 파일 형식 |

아이폰에는 SD 카드 슬롯이 없습니다. [Apple 카메라 어댑터 안내](https://support.apple.com/en-us/118280)의 지원 목록에는 SDSC, SDHC, SDXC, miniSD, microSD, MMC 카드가 있습니다. 카드 리더로 연결하는 순서는 [아이폰 SD 카드 총정리](/blog/ko/iphone-sd-card-guide)에서 확인하세요.

## 처음 산 에스디 카드는 어떻게 쓰나요?

1. 기기 설명서에서 지원하는 크기, 용량 규격, 스피드 클래스를 확인합니다.
2. 카드를 기기에 넣고 기기 메뉴에서 포맷합니다. 포맷하면 카드 자료가 모두 지워집니다.
3. 사진을 몇 장 찍거나 파일을 복사해 카드가 제대로 읽히는지 봅니다.
4. 카드의 중요한 사진은 다른 저장장치에도 복사해 둡니다.

PC나 Mac에서 포맷하는 순서는 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에 있습니다. 카드가 인식되지 않으면 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)를 보세요.

## 아이폰 사진을 USB 메모리에 저장하려면?

아래 앱은 USB 메모리를 기준으로 안내합니다. USB 메모리 연결 조건은 [아이폰 USB 메모리 사용법](/blog/ko/iphone-flash-drive-guide)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비하고 있으며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## 에스디 카드 자주 묻는 질문

### SD 카드와 microSD 카드는 같은 규격인가요?

크기만 다르고 같은 SD 규격 안에 있습니다. SD Association 표에서 SD는 32 x 24 x 2.1mm, microSD는 11 x 15 x 1.0mm입니다.

### SDXC 카드를 SDHC만 지원하는 기기에 쓸 수 있나요?

쓸 수 없습니다. SD Association 안내에 따르면 SDHC 기기는 SD와 SDHC 카드만 씁니다.

### 숫자가 큰 스피드 클래스 카드는 항상 빠른가요?

스피드 클래스는 최소 쓰기 속도를 보장하는 표시입니다. 실제 속도는 기기와 카드가 지원하는 버스 방식, 카드 성능, 작업 종류에 따라 달라집니다.

### SD 카드의 기본 파일 시스템은 무엇인가요?

SDHC는 FAT32, SDXC와 SDUC는 exFAT입니다. FAT32는 4GB가 넘는 파일을 저장하지 못합니다. 형식 차이는 [USB FAT32 포맷 방법](/blog/ko/format-usb-fat32)에 정리했습니다.

### 아이폰에서 SD 카드를 바로 꽂을 수 있나요?

아이폰에는 SD 카드 슬롯이 없습니다. 아이폰 단자에 맞는 카드 리더를 연결해 씁니다. 자세한 조건은 [아이폰 SD 카드 슬롯 글](/blog/ko/iphone-sd-card-slot)에 있습니다.
