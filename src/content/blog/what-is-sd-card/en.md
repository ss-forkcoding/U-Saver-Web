## Key takeaways

An SD card is a small memory card you insert into cameras, phones, game consoles, and other devices. The SD Association sets the standards.

The types of SD cards differ in three ways: physical size (SD, microSD), capacity (SD, SDHC, SDXC, SDUC), and speed (bus interface and speed class).

Before buying a card, check which standards your device supports. A higher-capacity card won't work in a device that only knows an older standard.

"My card says SDXC, U3, and V30. What does that mean?" "What's the difference between micro SD and regular SD?" These are common questions the first time you shop for a card. This guide explains each marking and what each type of card is used for.

## What is an SD card?

An SD card is flash memory that keeps its data when the power is off. The [SD Association](https://www.sdcard.org/developers/sd-standard-overview/sd-family/) classifies SD memory cards as removable nonvolatile memory. Panasonic, SanDisk, and Toshiba (now KIOXIA) founded the association in January 2000.

The device you insert the card into is called the host. Cameras, phones, laptop card slots, and card readers are all hosts. The card and the host must support the same standard to reach the card's full speed and capacity.

## What types of SD cards are there by size?

Two sizes are common today: full-size SD and microSD. The dimensions come from the [SD Association's speed class page](https://www.sdcard.org/consumers/speed-class-standards-for-video-recording/).

| Size | Width x height x thickness | Typical devices |
| --- | --- | --- |
| SD | 32 x 24 x 2.1 mm | Digital cameras, laptop card slots |
| microSD | 11 x 15 x 1.0 mm | Phones, action cameras, handheld consoles |

To use a microSD card in an SD slot, put it in an adapter. For using microSD with an iPhone, see [micro SD for iPhone](/blog/en/iphone-microsd).

## What types of SD cards are there by capacity?

There are four capacity standards. The logo on the front of the card tells you which one it is. This table follows the [SD Association's capacity standards](https://www.sdcard.org/developers/sd-standard-overview/capacity-sd-sdhc-sdxc-sduc/).

| Standard | Capacity | Default file system |
| --- | --- | --- |
| SD | Up to 2 GB | FAT12, FAT16 |
| SDHC | Over 2 GB up to 32 GB | FAT32 |
| SDXC | Over 32 GB up to 2 TB | exFAT |
| SDUC | Over 2 TB up to 128 TB | exFAT |

The capacity standard also sets compatibility. According to the [SD Association's compatibility guide](https://www.sdcard.org/consumers/sd-sdhc-sdxc-and-sduc-card-capacity-choices/), a host that supports a newer standard reads cards of older standards. The reverse doesn't work.

1. SDXC devices use SD, SDHC, and SDXC cards.
2. SDHC devices use only SD and SDHC cards. They can't use SDXC cards.
3. SDUC cards work only in SDUC devices.

If an older camera won't accept a 64 GB card, check its manual to see whether it supports SDXC.

## What do the speed markings on an SD card mean?

There are two kinds of speed markings. The bus interface is the maximum speed of the link between the card and the device. The speed class is the minimum write speed the card guarantees for recording video.

### Bus interface: UHS-I, UHS-II, SD Express

From the [SD Association's bus speed page](https://www.sdcard.org/developers/sd-standard-overview/bus-speed-default-speed-high-speed-uhs-sd-express/):

| Bus interface | Maximum bus speed |
| --- | --- |
| Default Speed | 12.5 MB/s |
| High Speed | 25 MB/s |
| UHS-I | 50 MB/s, 104 MB/s |
| UHS-II | 156 MB/s (full duplex), 312 MB/s (half duplex) |
| UHS-III | 624 MB/s |
| SD Express | 985 MB/s to 3,940 MB/s |

The same page notes that real maximum speed differs from the bus speed and depends on the card's performance. A UHS-II card in a UHS-I device won't reach UHS-II speeds. The device and the card both need to support the bus.

### Speed class: Class 10, U3, V30

The [SD Association's speed class standard](https://www.sdcard.org/developers/sd-standard-overview/speed-class/) defines four kinds of markings. The number indicates the minimum write speed.

| Marking type | Classes |
| --- | --- |
| Speed Class | C2, C4, C6, C10 |
| UHS Speed Class | U1, U3 |
| Video Speed Class | V6, V10, V30, V60, V90 |
| SD Express Speed Class | E150, E300, E450, E600 |

Speed class matters most for tasks that write at a steady rate, such as video recording. If your camera's manual asks for V30, choose a card rated V30 or higher.

### App performance class: A1, A2

According to the [SD Association's application performance class page](https://www.sdcard.org/developers/sd-standard-overview/application-performance-class/), A1 and A2 guarantee performance for running apps installed on the card. A2 performance requires both a device and a card that support A2.

## What are SD cards used for?

Each device uses the card for something different.

| Device | Main use | Markings to check |
| --- | --- | --- |
| Digital camera, camcorder | Storing photos and videos | Capacity standard, speed class |
| Android phone | Storing photos, installing apps | microSD, A1 or A2 |
| Action camera, drone | Recording high-resolution video | microSD, the speed class in the manual |
| Handheld game console | Storing game data | The card type the manufacturer specifies |
| iPhone | Importing photos from a card, copying files | Card reader and file format |

An iPhone has no SD card slot. [Apple's camera adapter guide](https://support.apple.com/en-us/118280) lists SDSC, SDHC, SDXC, miniSD, microSD, and MMC cards as supported. To connect a card through a reader, see [SD card reader for iPhone: the complete guide](/blog/en/iphone-sd-card-guide).

## How do you start using a new SD card?

1. Check your device's manual for the supported size, capacity standard, and speed class.
2. Insert the card and format it from the device's menu. Formatting erases everything on the card.
3. Take a few photos or copy a file to confirm the card reads correctly.
4. Copy important photos on the card to another storage device as well.

To format a card on a PC or Mac, see [how to format an SD card](/blog/en/format-sd-card). If the card isn't recognized, see [SD card corrupted or not recognized?](/blog/en/sd-card-not-working)

## FAQ: types of SD cards

### Are SD and microSD cards the same standard?

They differ only in size and belong to the same SD standards. In the SD Association's table, SD measures 32 x 24 x 2.1 mm and microSD measures 11 x 15 x 1.0 mm.

### Can I use an SDXC card in a device that only supports SDHC?

No. According to the SD Association, SDHC devices use only SD and SDHC cards.

### Is a card with a higher speed class always faster?

Speed class guarantees a minimum write speed. Actual speed depends on the bus interface both the device and card support, the card's performance, and the task.

### What file system do SD cards use by default?

SDHC uses FAT32. SDXC and SDUC use exFAT. FAT32 can't store a file larger than 4 GB. The differences are explained in [how to format a USB drive to FAT32](/blog/en/format-usb-fat32).

### Can I plug an SD card straight into an iPhone?

An iPhone has no SD card slot. You connect a card reader that fits your iPhone's port. Details are in [can you plug an SD card into an iPhone?](/blog/en/iphone-sd-card-slot)
