## この記事の要点

MacでSDカードを使うときは、まずMacにSDカードスロットがあるかを確かめます。Appleはスロットがあるモデルの一覧を公開しています。一覧にないMacでは、USB SDカードリーダーを使います。

カードを入れたら、Finderでファイルを開きます。写真や動画は、写真アプリの読み込みでも移せます。使い終わったら、カードのアイコンをゴミ箱にドラッグして取り出してから抜きます。

カードが表示されないときは、挿し直し、Finderの設定、ロックスイッチを確かめます。それでも直らなければ、ディスクユーティリティのFirst Aidを使います。フォーマットは、ファイルを移した後の最後の手段です。

「MacBookにSDスロットはある?」「カードを挿したのにFinderに出ない」。この記事では、MacでSDカードを使う手順だけを扱います。Windowsパソコンもあわせて知りたい方は、[SDカードをパソコンにつなぐ方法](/blog/ja/sd-card-to-pc)を読んでください。

## MacにSDカードスロットはありますか?

[AppleのMacのSDカードスロットの案内](https://support.apple.com/en-us/102352)によると、SDXCカードスロットがあるモデルは次のとおりです。

| Macの種類 | SDXCスロットがあるモデル |
| --- | --- |
| Mac Studio | 2022年以降 |
| 14インチ・16インチMacBook Pro | 2021年以降 |
| MacBook Pro | 2011年〜2015年 |
| Mac mini | 2011年〜2014年 |
| 13インチMacBook Air | 2013年〜2017年 |
| 27インチ・21.5インチiMac | 2010年以降 |

同じ一覧は[AppleのMacのポートの案内](https://support.apple.com/en-us/109523)にもあります。この案内は、SDカードスロットでSD、SDHC、SDXC、MMC、UHS-IIのカードを使えると説明しています。

一覧にないMacにはスロットがありません。その場合はUSBカードリーダーを使います。

## スロットがないMacにはどのカードリーダーを使いますか?

MacのUSB端子に合うリーダーを選びます。USB-C端子しかないMacなら、USB-Cのリーダーを使うか、アダプターを経由します。この記事では特定の製品をすすめず、確かめる項目だけをまとめます。

| 確認すること | 理由 |
| --- | --- |
| リーダーの端子 | Macの端子(USB-C、USB-A)と合わないと挿せません |
| カードのサイズ | SDだけに対応するリーダーでmicroSDを使うには、変換アダプターが必要です |
| 容量規格 | SDXCカードは、SDXC以降に対応したリーダーで読みます |
| バス方式 | UHS-IIカードもUHS-Iのリーダーで使えますが、UHS-IIの速度は出ません |

容量規格の互換性は[SD Associationの容量規格の案内](https://www.sdcard.org/consumers/about-sd-memory-card-choices/sd-sdhc-sdxc-and-sduc-card-capacity-choices/)、バス方式の互換性は[SD Associationのバス方式の案内](https://www.sdcard.org/consumers/about-sd-memory-card-choices/bus-interface-speed-standards-for-large-size-data-transfer/)に沿っています。選び方は[SDカードリーダーの選び方](/blog/ja/choose-sd-card-reader)にくわしくまとめました。USB-Cリーダーの挿し方と外し方は[USB-C SDカードリーダーの使い方](/blog/ja/usb-c-sd-card-reader)を読んでください。

## MacのスロットはどのSDカードに対応していますか?

[Appleの案内](https://support.apple.com/en-us/102352)に書かれたスロットの条件です。

| 項目 | Appleの案内 |
| --- | --- |
| 対応カード | MMC、Default Speed、High Speed、UHS-I |
| UHS-II対応 | 2022年以降のMac Studio、2021年以降のMacBook Pro、2020年のiMac、iMac Pro |
| miniSD、microSD | アダプターを付けて使用 |
| 非対応のカード | SDIOカード |
| 注意 | 厚さ2.1mmを超えるカードはスロットを傷めるおそれがあります |

UHS-IIに対応していないMacにUHS-IIカードを入れても、カードは使えます。ただし速度はUHS-Iの水準です。方式ごとの違いは[UHSスピードクラスとは?](/blog/ja/uhs-sd-card)にあります。microSDとアダプターの関係は[micro SDとは?](/blog/ja/microsd-vs-sd)を読んでください。

## MacでSDカードを開いて取り出す手順

[AppleのMacのSDカードスロットの案内](https://support.apple.com/en-us/102352)に沿った手順です。

1. カードの金属端子を下に向け、Mac側に向けてスロットに入れます。リーダーを使うなら、カードをリーダーに入れてからリーダーをMacに挿します。
2. 無理に押し込みません。Appleは、無理に入れるとスロットを傷めるおそれがあると説明しています。
3. カードのアイコンが表示されたら、Finderで開き、ファイルをMacのフォルダーにコピーします。
4. 使い終わったら、カードのアイコンをゴミ箱にドラッグして取り出します。
5. アイコンが消えたら、カードを抜きます。

Appleは、Macがスリープ中にカードを抜くとデータを失うおそれがあると説明しています。Macをスリープから戻し、取り出してから抜きます。

## Macの写真アプリでSDカードの写真を読み込むには?

[Appleの写真アプリの読み込みの案内](https://support.apple.com/guide/photos/import-from-storage-devices-phtae4e05c67/mac)に沿った手順です。

1. カードをMacのSDカードスロットに入れるか、リーダーに入れてMacにつなぎます。
2. 写真アプリを開きます。
3. ファイル > 読み込むを選び、読み込む写真や動画を選んでから、読み込み内容を確認をクリックします。
4. 新しい写真をすべて読み込むなら、すべての新しい写真を読み込むをクリックします。一部だけなら、写真を選んでから選択項目を読み込むをクリックします。
5. 読み込んだ後にカードの写真を削除するか残すかを聞かれたら、項目を削除か項目を残すを選びます。
6. 読み込みが終わったら、カードを取り出します。

読み込んだ写真は、サイドバーの読み込みアルバムと写真アルバムに表示されます。カードに元の写真を残すなら、手順5で項目を残すを選びます。ファイル名やフォルダー構成をそのまま移すなら、Finderでコピーするほうが簡単です。

## SDカードがFinderに表示されないときは?

| 症状 | 確認すること |
| --- | --- |
| カードを入れても何も出ない | カードを抜いて挿し直します。Appleは、入れる速さが遅すぎたり速すぎたりするとマウントされないことがあると説明しています |
| つながっているようなのにアイコンがない | Finder > 設定の一般とサイドバーのタブで、外部ディスクの表示をオンにします |
| 「変更できません」と出る | カードを取り出し、ロックスイッチを解除して挿し直します |
| リーダーでは表示され、スロットでは表示されない | カードがスロットの対応一覧にあるか確かめます |
| ファイルが開かない、エラーが出る | ディスクユーティリティのFirst Aidで検査します |

Finderに外部ディスクを表示する方法は、[Appleの接続中のデバイスを確認する案内](https://support.apple.com/guide/mac-help/see-the-devices-connected-to-your-mac-mchlp1039/mac)にあります。ロックスイッチの位置は[SDカードのロックとは?](/blog/ja/sd-card-lock-switch)で確かめてください。

## ディスクユーティリティのFirst Aidはどう使いますか?

[Appleのストレージデバイスの修復の案内](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac)によると、First Aidはストレージデバイスのフォーマットとディレクトリ構造のエラーを確認して修復します。すべての問題を見つけたり直したりできるわけではありません。

1. ディスクユーティリティを開きます。
2. 表示 > すべてのデバイスを表示を選びます。
3. サイドバーでカードのボリュームを選び、First Aidをクリックしてから実行をクリックします。
4. コンテナがあれば、コンテナにも同じ手順で実行します。
5. 最後に、カード本体(いちばん上の項目)を選んで実行します。

Appleは、失敗したらもう一度試すよう説明しています。それでも直らなければ、できるだけデータをバックアップしてからフォーマットし直すよう案内しています。フォーマットを求める画面がすぐに出ても、まだクリックしないでください。先に[SDカードが認識しないときの確認手順](/blog/ja/sd-card-not-working)を進めます。

## MacでSDカードをフォーマットするには?

フォーマットすると、カードのファイルはすべて消えます。残したいファイルは先に別の場所へコピーします。形式は、カードをどこで使うかで選びます。[Appleのファイルシステムフォーマットの案内](https://support.apple.com/guide/disk-utility/file-system-formats-dsku19ed921c/mac)に沿っています。

| 形式 | Appleの案内 |
| --- | --- |
| APFS | macOS 10.13以降のMacの標準のファイルシステムです |
| MS-DOS(FAT) | 32GB以下のWindowsボリュームに使います |
| ExFAT | 32GBを超えるWindowsボリュームに使います |

[AppleのWindows用にディスクをフォーマットする案内](https://support.apple.com/guide/disk-utility/format-a-disk-for-windows-computers-dskutl1010/mac)に沿った手順です。

1. ディスクユーティリティを開き、表示 > すべてのデバイスを表示を選びます。
2. サイドバーでカードを選び、消去をクリックします。
3. 方式を選び、フォーマットでMS-DOS(FAT)かExFATを選びます。
4. 名前を入力します。名前は11文字までです。
5. 消去をクリックしてから、完了をクリックします。

カメラに入れるカードは、まず機器の取扱説明書の方法に従ってください。SD規格の団体のツールでフォーマットする方法は[SDカードフォーマッターの使い方](/blog/ja/sd-card-formatter)にあります。容量ごとの形式の選び方は[SDカードフォーマット方法](/blog/ja/format-sd-card)を読んでください。

## MacとSDカードのよくある質問

### MacBook AirにSDカードスロットはありますか?

Appleの一覧でSDXCスロットがあるMacBook Airは、2013年〜2017年の13インチモデルです。それ以外のMacBook Airでは、USBカードリーダーを使います。

### MacのスロットにmicroSDをそのまま入れられますか?

入れません。Appleは、microSDとminiSDはアダプターを付けて使うよう案内しています。

### UHS-IIカードなのに、思ったより速くありません。

Appleの一覧でUHS-IIに対応するMacは、2022年以降のMac Studio、2021年以降のMacBook Pro、2020年のiMac、iMac Proです。ほかのモデルのスロットはUHS-Iまでの対応です。リーダーを使っているなら、リーダーが対応するバス方式も確かめてください。

### 取り出し操作をせずに抜いてもいいですか?

おすすめしません。Appleは、アイコンをゴミ箱にドラッグして取り出してからカードを抜くよう案内しています。スリープ中に抜くとデータを失うおそれがあるとも説明しています。

### MacでAPFSにフォーマットしたカードをWindowsパソコンで使えますか?

Appleは、Windowsと一緒に使うディスクにはMS-DOS(FAT)かExFATを選ぶよう案内しています。MacとWindowsパソコンの両方で使うカードは、このどちらかでフォーマットしてください。
