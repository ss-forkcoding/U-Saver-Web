## この記事の要点

micro SDとは、SDカードを小さくしたメモリーカードです。形、サイズ、ピン数、書き込み禁止スイッチの有無が違い、内部の論理と電子構造は同じです。

microSDカードはアダプターに入れるとSDスロットで使えます。アダプターが変えるのはサイズだけです。容量規格の互換性はそのまま確認します。

カードを買うときは、まず機器のスロットのサイズを見ます。スマートフォンやアクションカメラはmicroSD、カメラやノートパソコンのスロットはSDサイズが中心です。

「micro SDをカメラで使えますか?」「カードに付いてきたアダプターは何に使いますか?」micro SDとは何かを調べると、こうした疑問が出てきます。この記事では2つのカードの違いとアダプターの使い方を規格文書にもとづいて整理します。カードの種類全体は[SDカードとは?](/blog/ja/what-is-sd-card)にあります。

## micro SDとSDカードは何が違いますか?

[SD AssociationのFAQ](https://www.sdcard.org/consumers/faq/)は違いを4つ挙げています。形、サイズ、ピン数、書き込み禁止スイッチの有無です。内部の論理と電子構造は同じです。

| 項目 | SDカード | microSDカード |
| --- | --- | --- |
| サイズ(横 x 縦 x 厚さ) | 32 x 24 x 2.1mm | 11 x 15 x 1.0mm |
| 書き込み禁止スイッチ | カードの側面にあります | カードにはありません |
| 主な機器 | デジタルカメラ、ノートパソコンのカードスロット | スマートフォン、アクションカメラ、携帯ゲーム機 |
| 規格名 | SD、SDHC、SDXC | microSD、microSDHC、microSDXC |

サイズは[SD Associationのスピードクラス案内](https://www.sdcard.org/consumers/speed-class-standards-for-video-recording/)の表によります。同じFAQは、miniSDもSDと同じ関係だと説明しています。

## micro SDはSDカードより性能が低いですか?

サイズだけで性能は決まりません。2つのカードは同じ容量規格とスピードクラスの表示を使います。[SD Associationのスピードクラス案内](https://www.sdcard.org/consumers/speed-class-standards-for-video-recording/)もSDとmicroSDを1つの表で説明しています。

性能はカードに書かれた表示で比べます。

| 表示 | 意味 | 例 |
| --- | --- | --- |
| 容量規格 | 保存できる容量の範囲 | SDHC、SDXC |
| バス方式 | カードと機器の間の最大速度 | UHS-I、UHS-II |
| スピードクラス | 動画録画で保証する最低書き込み速度 | U3、V30 |
| アプリ性能クラス | カードにアプリを入れたときの性能 | A1、A2 |

表示の読み方は[SDカードとは?](/blog/ja/what-is-sd-card)で詳しく説明しています。

## microSDの変換アダプターはどう使いますか?

microSD to SDアダプターは、SDカードの形をした枠です。中にmicroSDを入れると、SDスロットに挿せます。[Western Digitalのアダプター製品資料](https://documents.sandisk.com/content/dam/asset-library/en_us/assets/public/western-digital/product/accessories/microsd-to-sd-card-adapter/product-brief-microsd-to-sd-card-adapter.pdf)がこの手順を説明しています。この記事は規格の説明のためにこの資料を引用しており、特定の製品をすすめるものではありません。

1. 機器の電源を切るか、先にカードの取り出し操作をします。
2. microSDカードの端子側をアダプターの差し込み口に向け、奥まで差し込みます。向きは1つだけなので、無理に押さないでください。
3. アダプター側面の書き込み禁止スイッチがロック側にないか確認します。
4. アダプターをカメラ、ノートパソコン、カードリーダーのSDスロットに挿します。
5. 使い終わったら機器で取り出し操作をしてからアダプターを抜きます。

上の資料のアダプターは、SD規格に準拠しUHS-Iホストインターフェースに対応すると書かれています。対応範囲はアダプターごとに違います。UHS-IIなど速いバスを使う予定なら、アダプターの製品説明を確認してください。

## アダプターを付ければどのSD機器でも使えますか?

使えるとは限りません。アダプターが変えるのはサイズだけで、カードの容量規格はそのままです。

[SD Associationの互換性案内](https://www.sdcard.org/consumers/sd-sdhc-sdxc-and-sduc-card-capacity-choices/)は、機器とカードの互換性を次のように定めています。

| 機器の規格 | 使えるカード |
| --- | --- |
| SD機器 | SD |
| SDHC機器 | SD、SDHC |
| SDXC機器 | SD、SDHC、SDXC |
| SDUC機器 | SD、SDHC、SDXC、SDUC |

たとえばSDHCまでしか対応しない古いカメラでは、アダプターに入れた128GBのmicroSDXCカードは使えません。先に機器の説明書でSDロゴや対応規格を確認してください。

逆に、SDカードはmicroSDスロットに入りません。SDカードは32 x 24mmで、ずっと大きいためです。

## 機器ごとにどのカードを選びますか?

スロットのサイズと説明書が求める規格をあわせて見ます。

| 機器 | スロットのサイズ | 選ぶ基準 |
| --- | --- | --- |
| デジタルカメラ | 主にSD | 説明書が求めるスピードクラス |
| ノートパソコンのカードスロット | 主にSD | microSDはアダプターに入れて使用 |
| Androidスマートフォン | microSD | 容量規格、アプリを入れるならA1・A2 |
| アクションカメラ、ドローン | microSD | 説明書が求めるスピードクラス |
| iPhone | スロットなし | カードリーダーのカード差し込み口のサイズ |

microSDを買うなら、カメラでも使えるようにアダプターを手元に置いておく方法があります。ただし機器の説明書がSDカードだけを推奨している場合は、その案内に従ってください。

## iPhoneでmicro SDを使うには?

iPhoneにはカードスロットがありません。カードリーダーを充電ポートにつなぎます。[Appleのカメラアダプター案内](https://support.apple.com/en-us/118280)の対応カード一覧には、SDSC、SDHC、SDXC、miniSD、microSD、MMCがあります。[AppleのUSB-C案内](https://support.apple.com/en-us/105099)も、接続できる機器として「SDカードアダプターを使ったSDカード」を挙げています。

リーダーにSDの差し込み口しかない場合は、microSDをアダプターに入れるか、microSDの差し込み口があるリーダーを使います。接続の手順は[micro SDをiPhoneで使う方法](/blog/ja/iphone-microsd)と[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)にまとめました。

ほかの機器で使ったカードがiPhoneで表示されない場合は、形式が合っていない可能性があります。手順は[マイクロSDカードフォーマット方法](/blog/ja/format-microsd)にあります。フォーマットするとカードのデータはすべて消えます。

## micro SDとはのよくある質問

### micro SDとSDカードでデータの保存方法は違いますか?

違いません。SD AssociationのFAQによると、2つのカードの内部の論理と電子構造は同じです。違うのは形、サイズ、ピン数、書き込み禁止スイッチの有無だけです。

### アダプターに入れたmicroSDはSDカードとまったく同じように動きますか?

アダプターはサイズを合わせてSDスロットに挿せるようにします。容量規格の互換性はカードを基準に考えます。バス速度はアダプターの対応範囲も確認してください。

### microSDカードにはロックスイッチがないのですか?

SD AssociationのFAQは、書き込み禁止スイッチの有無を2つのカードの違いとして挙げています。ロックスイッチはSDカードと一部のアダプターにあります。カードに保存できないときは、まずアダプターのスイッチの位置を見てください。

### SDカードをmicroSDスロットに入れられますか?

入れられません。SDカードは32 x 24mm、microSDは11 x 15mmです。スロットに合うカードを買ってください。

### micro SDが認識されないときはどうしますか?

アダプターの接触とカードの形式を先に確認します。手順は[microSDが認識しないときの確認手順](/blog/ja/sd-card-not-working)にまとめました。
