## 핵심 요약

micro SD 카드는 일반 SD 카드를 작게 만든 메모리 카드입니다. 크기, 핀 수, 쓰기 방지 스위치 유무가 다르고 내부 논리와 전자 구조는 같습니다.

microSD 카드는 어댑터에 끼우면 SD 슬롯에 넣을 수 있습니다. 어댑터는 크기만 맞춥니다. 용량 규격 호환은 그대로 따져야 합니다.

카드를 살 때는 기기 슬롯 크기를 먼저 봅니다. 스마트폰과 액션캠은 대부분 microSD, 카메라와 노트북 슬롯은 SD 크기입니다.

"마이크로 SD 카드를 카메라에 써도 되나요?" "카드에 딸려 온 어댑터는 어디에 쓰나요?" micro sd 카드를 처음 다루면 이런 질문이 나옵니다. 이 글은 두 카드의 차이와 어댑터 쓰는 법을 규격 문서 기준으로 정리합니다. 카드 종류 전체는 [에스디 카드란?](/blog/ko/what-is-sd-card)에 있습니다.

## micro SD 카드와 SD 카드는 무엇이 다른가요?

[SD Association FAQ](https://www.sdcard.org/consumers/faq/)는 두 카드의 차이를 네 가지로 적었습니다. 모양, 크기, 핀 수, 쓰기 방지 스위치 유무입니다. 내부 논리와 전자 구조는 같습니다.

| 구분 | SD 카드 | microSD 카드 |
| --- | --- | --- |
| 크기(가로 x 세로 x 두께) | 32 x 24 x 2.1mm | 11 x 15 x 1.0mm |
| 쓰기 방지 스위치 | 카드 옆면에 있습니다 | 카드에 없습니다 |
| 주로 쓰는 기기 | 디지털카메라, 노트북 카드 슬롯 | 스마트폰, 액션캠, 휴대용 게임기 |
| 규격 이름 | SD, SDHC, SDXC | microSD, microSDHC, microSDXC |

크기는 [SD Association의 스피드 클래스 안내](https://www.sdcard.org/consumers/speed-class-standards-for-video-recording/) 표 기준입니다. 같은 FAQ는 miniSD도 SD와 같은 관계라고 설명합니다.

## micro SD 카드는 SD 카드보다 성능이 낮은가요?

크기만으로 성능이 정해지지 않습니다. 두 카드는 같은 용량 규격과 스피드 클래스 표시를 씁니다. [SD Association 스피드 클래스 안내](https://www.sdcard.org/consumers/speed-class-standards-for-video-recording/)도 SD와 microSD를 한 표에 묶어 설명합니다.

성능은 카드에 적힌 표시로 비교합니다.

| 카드 표시 | 뜻 | 예 |
| --- | --- | --- |
| 용량 규격 | 담을 수 있는 용량 범위 | SDHC, SDXC |
| 버스 방식 | 카드와 기기 사이 통로의 최대 속도 | UHS-I, UHS-II |
| 스피드 클래스 | 영상 녹화 때 보장하는 최소 쓰기 속도 | U3, V30 |
| 앱 성능 등급 | 카드에 앱을 설치할 때의 성능 | A1, A2 |

표시 읽는 법은 [에스디 카드란?](/blog/ko/what-is-sd-card)에 자세히 있습니다.

## microSD 어댑터는 어떻게 쓰나요?

microSD to SD 어댑터는 SD 카드 모양의 틀입니다. 안에 microSD를 넣으면 SD 슬롯에 꽂을 수 있습니다. [Western Digital의 어댑터 제품 설명서](https://documents.sandisk.com/content/dam/asset-library/en_us/assets/public/western-digital/product/accessories/microsd-to-sd-card-adapter/product-brief-microsd-to-sd-card-adapter.pdf)가 이 순서를 설명합니다. 이 글은 규격 설명을 위해 이 문서를 인용했고 특정 제품을 추천하지 않습니다.

1. 기기의 전원을 끄거나 카드 꺼내기를 먼저 합니다.
2. microSD 카드의 단자 쪽을 어댑터 입구로 향하게 해 끝까지 밀어 넣습니다. 한 방향으로만 들어가니 억지로 밀지 마세요.
3. 어댑터 옆면의 쓰기 방지 스위치가 잠금 쪽에 있지 않은지 봅니다.
4. 어댑터를 카메라, 노트북, 카드 리더의 SD 슬롯에 넣습니다.
5. 다 쓴 뒤에는 기기에서 꺼내기를 하고 어댑터를 뺍니다.

위 설명서의 어댑터는 SD 규격을 따르고 UHS-I 호스트 인터페이스를 지원한다고 적었습니다. 어댑터마다 지원 범위가 다릅니다. UHS-II 같은 빠른 버스를 쓸 계획이면 어댑터 제품 설명을 확인하세요.

## 어댑터를 끼우면 어떤 SD 기기에서든 쓸 수 있나요?

아닙니다. 어댑터는 크기만 바꿉니다. 카드의 용량 규격은 그대로입니다.

[SD Association의 호환 안내](https://www.sdcard.org/consumers/sd-sdhc-sdxc-and-sduc-card-capacity-choices/)는 기기와 카드의 호환을 이렇게 정합니다.

| 기기 규격 | 쓸 수 있는 카드 |
| --- | --- |
| SD 기기 | SD |
| SDHC 기기 | SD, SDHC |
| SDXC 기기 | SD, SDHC, SDXC |
| SDUC 기기 | SD, SDHC, SDXC, SDUC |

예를 들어 SDHC까지만 지원하는 오래된 카메라라면 어댑터에 끼운 128GB microSDXC 카드는 쓸 수 없습니다. 기기 설명서의 SD 로고나 지원 규격을 먼저 확인하세요.

반대로 SD 카드는 microSD 슬롯에 넣을 수 없습니다. SD 카드가 32 x 24mm로 훨씬 큽니다.

## 기기별로 어떤 카드를 고르나요?

슬롯 크기와 설명서의 요구 규격을 함께 봅니다.

| 기기 | 슬롯 크기 | 고르는 기준 |
| --- | --- | --- |
| 디지털카메라 | 대부분 SD | 설명서가 요구하는 스피드 클래스 |
| 노트북 카드 슬롯 | 대부분 SD | microSD는 어댑터에 끼워 사용 |
| 안드로이드 스마트폰 | microSD | 용량 규격, 앱 설치 시 A1·A2 |
| 액션캠, 드론 | microSD | 설명서가 요구하는 스피드 클래스 |
| 아이폰 | 슬롯 없음 | 카드 리더의 카드 자리 크기 |

microSD를 사면 카메라에도 쓸 수 있도록 어댑터를 함께 두는 방법이 있습니다. 다만 기기 설명서가 SD 카드만 권장한다면 그 안내를 따르세요.

## 아이폰에서 micro SD 카드를 쓰려면?

아이폰에는 카드 슬롯이 없습니다. 카드 리더를 충전 단자에 연결합니다. [Apple 카메라 어댑터 안내](https://support.apple.com/en-us/118280)의 지원 카드 목록에는 SDSC, SDHC, SDXC, miniSD, microSD, MMC가 있습니다. [Apple의 USB-C 안내](https://support.apple.com/en-us/105099)도 연결할 수 있는 장치에 "SD 카드 어댑터를 쓴 SD 카드"를 적었습니다.

리더에 SD 자리만 있다면 microSD를 어댑터에 끼워 넣거나 microSD 자리가 있는 리더를 씁니다. 연결 순서는 [아이폰 마이크로 SD 쓰는 법](/blog/ko/iphone-microsd)과 [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader)에 정리했습니다.

다른 기기에서 쓰던 카드가 아이폰에서 안 보이면 형식이 맞지 않을 수 있습니다. 포맷 순서는 [마이크로 SD 카드 포맷 방법](/blog/ko/format-microsd)에 있습니다. 포맷하면 카드의 자료가 모두 지워집니다.

## 아이폰 사진을 USB 메모리에 저장하려면?

아래 앱은 USB 메모리를 기준으로 안내합니다. USB 메모리 연결 조건은 [아이폰 USB 메모리 사용법](/blog/ko/iphone-flash-drive-guide)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비하고 있으며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## micro SD 카드 자주 묻는 질문

### micro SD 카드와 SD 카드는 데이터 저장 방식이 다른가요?

다르지 않습니다. SD Association FAQ에 따르면 두 카드의 내부 논리와 전자 구조는 같습니다. 모양, 크기, 핀 수, 쓰기 방지 스위치 유무만 다릅니다.

### 어댑터에 끼운 microSD는 SD 카드와 똑같이 동작하나요?

어댑터는 크기를 맞춰 SD 슬롯에 넣게 해 줍니다. 용량 규격 호환은 카드 기준으로 따집니다. 버스 속도는 어댑터 지원 범위도 확인하세요.

### microSD 카드에는 잠금 스위치가 없나요?

SD Association FAQ는 쓰기 방지 스위치 유무를 두 카드의 차이로 적었습니다. 잠금 스위치는 SD 카드와 일부 어댑터에 있습니다. 카드에 저장이 안 되면 어댑터 스위치 위치부터 보세요.

### SD 카드를 microSD 슬롯에 넣을 수 있나요?

넣을 수 없습니다. SD 카드는 32 x 24mm, microSD는 11 x 15mm입니다. 슬롯 크기에 맞는 카드를 사세요.

### micro SD 카드가 인식되지 않으면 어떻게 하나요?

어댑터 접촉과 카드 형식을 먼저 확인합니다. 확인 순서는 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)에 정리했습니다.
