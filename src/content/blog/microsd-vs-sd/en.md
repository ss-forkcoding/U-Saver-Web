## Key takeaways

A micro SD card is a smaller version of the SD card. The two differ in shape, size, number of pins, and whether there is a write-protect switch. Their internal logic and electronics are the same.

You can put a microSD card into an adapter and use it in an SD slot. The adapter only changes the size. Capacity compatibility still applies.

When you buy a card, check the slot size first. Phones and action cameras mostly use microSD. Cameras and laptop card slots mostly use full-size SD.

"Can I use a micro SD card in my camera?" "What is the adapter in the package for?" These questions come up often when people compare a micro SD card and an SD card. This guide explains the differences and how to use an adapter, based on standards documents. For every card type, see [types of SD cards](/blog/en/what-is-sd-card).

## What is the difference between a micro SD card and an SD card?

The [SD Association FAQ](https://www.sdcard.org/consumers/faq/) lists four differences: form factor, size, number of pins, and whether there is a write-protect switch. The logic and electronics of both cards are identical.

| Item | SD card | microSD card |
| --- | --- | --- |
| Size (W x H x D) | 32 x 24 x 2.1 mm | 11 x 15 x 1.0 mm |
| Write-protect switch | On the side of the card | None on the card |
| Common devices | Digital cameras, laptop card slots | Phones, action cameras, handheld game consoles |
| Standard names | SD, SDHC, SDXC | microSD, microSDHC, microSDXC |

Sizes come from the table in the [SD Association's speed class guide](https://www.sdcard.org/consumers/speed-class-standards-for-video-recording/). The same FAQ says miniSD has the same relationship to SD.

## Is a micro SD card slower than an SD card?

Size alone doesn't decide performance. Both cards use the same capacity standards and speed class markings. The [SD Association's speed class guide](https://www.sdcard.org/consumers/speed-class-standards-for-video-recording/) covers SD and microSD in one table.

Compare cards by the markings printed on them.

| Marking | Meaning | Examples |
| --- | --- | --- |
| Capacity standard | Range of capacity | SDHC, SDXC |
| Bus interface | Maximum speed of the path between card and device | UHS-I, UHS-II |
| Speed class | Minimum write speed for video recording | U3, V30 |
| Application performance class | Performance when apps run from the card | A1, A2 |

How to read each marking is explained in [types of SD cards](/blog/en/what-is-sd-card).

## How do you use a microSD adapter?

A microSD to SD adapter is a shell shaped like an SD card. You insert a microSD card into it and then put it in an SD slot. [Western Digital's adapter product brief](https://documents.sandisk.com/content/dam/asset-library/en_us/assets/public/western-digital/product/accessories/microsd-to-sd-card-adapter/product-brief-microsd-to-sd-card-adapter.pdf) describes this process. This guide cites that document to explain the standard and doesn't recommend any product.

1. Turn off the device or eject the card first.
2. Face the contacts of the microSD card toward the adapter opening and slide it all the way in. It fits only one way, so don't force it.
3. Check that the write-protect switch on the side of the adapter isn't in the lock position.
4. Insert the adapter into the SD slot of your camera, laptop, or card reader.
5. When you're done, eject it on the device and remove the adapter.

The brief says that adapter follows SD standards and supports UHS-I host interfaces. Adapters differ. If you plan to use a faster bus such as UHS-II, check the adapter's product description.

## Does an adapter make a microSD card work in any SD device?

No. The adapter changes only the size. The card's capacity standard stays the same.

The [SD Association's compatibility guide](https://www.sdcard.org/consumers/sd-sdhc-sdxc-and-sduc-card-capacity-choices/) sets these rules.

| Device standard | Cards it can use |
| --- | --- |
| SD device | SD |
| SDHC device | SD, SDHC |
| SDXC device | SD, SDHC, SDXC |
| SDUC device | SD, SDHC, SDXC, SDUC |

For example, an older camera that supports only SDHC can't use a 128 GB microSDXC card, even in an adapter. Check the SD logo or supported standards in the device manual first.

An SD card can't go into a microSD slot. At 32 x 24 mm, it is much larger.

## Which card should you choose for each device?

Check the slot size and the standard the manual asks for.

| Device | Slot size | What to check |
| --- | --- | --- |
| Digital camera | Mostly SD | Speed class in the manual |
| Laptop card slot | Mostly SD | Use microSD in an adapter |
| Android phone | microSD | Capacity standard, A1 or A2 for apps |
| Action camera, drone | microSD | Speed class in the manual |
| iPhone | No slot | Card slot size on the card reader |

If you buy microSD, keep an adapter so you can also use it in a camera. If the device manual recommends only SD cards, follow it.

## How do you use a micro SD card with an iPhone?

An iPhone has no card slot. You connect a card reader to the charging port. The supported card list in [Apple's camera adapter guide](https://support.apple.com/en-us/118280) includes SDSC, SDHC, SDXC, miniSD, microSD, and MMC. [Apple's USB-C guide](https://support.apple.com/en-us/105099) also lists "SD cards using SD card adapters" among devices you can connect.

If the reader has only an SD slot, put the microSD card in an adapter or use a reader with a microSD slot. The steps are in [micro SD for iPhone](/blog/en/iphone-microsd) and [how to use an iPhone SD card reader](/blog/en/iphone-sd-card-reader).

If a card from another device doesn't appear on iPhone, its format may not match. The steps are in [how to reformat a micro SD card](/blog/en/format-microsd). Formatting erases everything on the card.

## FAQ: micro SD card and SD card

### Do micro SD cards and SD cards store data differently?

No. According to the SD Association FAQ, their internal logic and electronics are identical. Only the form factor, size, number of pins, and write-protect switch differ.

### Does a microSD card in an adapter work exactly like an SD card?

The adapter lets it fit an SD slot. Capacity compatibility depends on the card. For bus speed, also check what the adapter supports.

### Does a microSD card have a lock switch?

The SD Association FAQ lists the write-protect switch as one of the differences. The lock switch is on SD cards and some adapters. If you can't save to the card, check the adapter's switch first.

### Can I put an SD card in a microSD slot?

No. An SD card is 32 x 24 mm and a microSD card is 11 x 15 mm. Buy the card that fits the slot.

### What if my micro SD card isn't recognized?

Check the adapter contact and the card format first. The steps are in [SD card corrupted or not recognized?](/blog/en/sd-card-not-working)
