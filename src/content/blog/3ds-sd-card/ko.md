## 핵심 요약

3DS SD 카드 추천의 기준은 두 가지입니다. 모델에 맞는 카드 크기를 고르고, 32GB 이하 SDHC 카드를 고릅니다. 닌텐도는 3DS 계열이 최대 32GB까지 쓰고, 64GB 이상인 SDXC 카드는 쓸 수 없다고 안내합니다.

닌텐도 3DS, 3DS XL, 2DS는 크기가 큰 SD 카드를 씁니다. New 닌텐도 3DS, New 3DS XL, New 2DS XL은 microSD 카드를 씁니다.

카드를 바꿀 때는 컴퓨터로 "Nintendo 3DS" 폴더를 통째로 옮깁니다. 폴더 안의 파일을 골라 옮기거나 고치지 않습니다.

"3DS에 64GB 카드를 넣었더니 안 읽혀요." "New 3DS는 카드를 어디에 넣나요?" 오래된 3DS를 다시 꺼낼 때 자주 나오는 질문입니다. 이 글은 3DS SD 카드의 규격, 넣는 법, 포맷, 큰 카드로 옮기는 순서를 닌텐도 공식 안내로 확인합니다. 이 글은 특정 카드를 시험하거나 추천하지 않습니다. 스위치용 카드는 [닌텐도 스위치 SD 카드 사용법](/blog/ko/switch-microsd)에 따로 정리했습니다.

## 3DS SD 카드 추천 기준은 무엇인가요?

모델에 맞는 크기와 32GB 이하 용량입니다. 아래 표는 [닌텐도의 3DS 호환 카드 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/274/~/what-sd-cards-and-microsd-cards-are-compatible)와 [닌텐도 일본의 최대 용량 Q&A](https://support-jp.nintendo.com/app/answers/detail/a_id/31955/)를 합친 것입니다.

| 모델 | 카드 크기 | 쓸 수 있는 카드 |
| --- | --- | --- |
| 닌텐도 3DS, 3DS XL, 2DS | SD | SD 2GB까지, SDHC 4GB~32GB |
| New 닌텐도 3DS, New 3DS XL, New 2DS XL | microSD | microSD 2GB까지, microSDHC 4GB~32GB |
| 모든 3DS 계열 | - | SDXC, microSDXC는 호환되지 않음 |

닌텐도는 본체에 들어 있던 카드 외의 제품은 동작을 보장할 수 없다고 적습니다. 닌텐도 일본은 일부 타사 카드로 동작을 확인한 목록을 공개하지만, 이 목록도 동작 보장은 아니라고 밝힙니다. 그 목록은 2014년 12월에 마지막으로 고쳤습니다.

카드에 적힌 SDHC, SDXC 표시는 용량 규격입니다. 표시 읽는 법은 [SDHC·SDXC·SDUC 차이](/blog/ko/sdhc-vs-sdxc)에 있습니다. 새로 산 카드의 실제 용량이 의심되면 [가짜 SD 카드 구별법](/blog/ko/fake-sd-card)으로 먼저 확인하세요.

## 3DS에 64GB SD 카드는 쓸 수 있나요?

공식으로는 쓸 수 없습니다. 64GB 카드는 SDXC 규격이고, 닌텐도는 SDXC와 microSDXC를 3DS 계열과 호환되지 않는 카드로 분류합니다. 닌텐도 일본 Q&A도 3DS 계열의 최대 용량을 32GB로 적습니다.

용량이 부족하면 32GB 카드로 바꾸고 안 쓰는 소프트웨어를 지웁니다. [닌텐도의 SD 카드 용도 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/399/~/what-are-sd-cards-and-microsd-cards-used-for%3F)에 따르면 SD 카드 한 장에는 소프트웨어 최대 300개, 사진 최대 3,000장, 음악 파일 최대 3,000개를 저장합니다.

## 3DS SD 카드에는 무엇이 저장되나요?

다운로드한 소프트웨어와 사진, 음악이 저장됩니다. 닌텐도의 SD 카드 용도 안내 기준입니다.

| 데이터 | 저장 위치 |
| --- | --- |
| 다운로드 소프트웨어(DSiWare 제외) | SD 카드 |
| 3DS 카메라로 찍은 사진 | SD 카드에 저장 가능 |
| 음악 파일 | SD 카드에서 재생 |
| 게임 카드 소프트웨어의 진행 기록 | 게임 카드 |

게임 카드의 진행 기록은 [닌텐도의 저장 위치 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/337/)에 따라 게임 카드에 저장됩니다. 같은 안내는 일부 게임 카드가 엇갈림 통신(StreetPass)과 SpotPass 정보를 SD 카드나 본체 메모리에 저장한다고 적습니다. 닌텐도 안내는 폴더 깊이가 8단계를 넘으면 파일이 보이지 않는다고 적습니다.

## 3DS에 SD 카드는 어떻게 넣나요?

전원을 끄고 넣습니다. [닌텐도의 카드 넣는 법 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/271/)는 카드를 넣거나 뺄 때 본체 전원이 꺼져 있어야 한다고 적습니다.

| 모델 | 슬롯 위치 | 넣는 방향 |
| --- | --- | --- |
| 닌텐도 3DS | 본체 왼쪽 옆면, 커버 안 | 라벨이 아래로 |
| 닌텐도 3DS XL, 2DS | 본체 오른쪽 옆면, 커버 안 | 라벨이 아래로 |
| New 닌텐도 2DS XL | 본체 앞면, 커버 안 | 라벨이 아래로 |
| New 닌텐도 3DS, New 3DS XL | 배터리 커버 안 | 카드가 본체 바깥쪽을 향하게 |

1. 본체 전원을 끕니다.
2. 표의 위치에서 슬롯 커버나 배터리 커버를 엽니다.
3. 딸깍 소리가 날 때까지 카드를 밀어 넣습니다.
4. 커버를 닫고 본체를 켭니다.

[닌텐도의 카드 간 이동 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/309/~/how-to-transfer-data-between-sd-cards-or-microsd-cards)에 따르면 New 3DS와 New 3DS XL의 카드를 빼려면 0번 십자드라이버가 필요합니다.

SD 카드의 쓰기 방지 스위치를 아래로 내리면 저장과 삭제가 막힙니다. 위로 올려 둡니다. 스위치 보는 법은 [SD 카드 잠금 해제 방법](/blog/ko/sd-card-lock-switch)에 있습니다.

## 3DS SD 카드는 어떻게 포맷하나요?

컴퓨터에서 SD 협회의 SD Memory Card Formatter로 포맷합니다. [닌텐도의 3DS 카드 포맷 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/220/~/how-to-format-an-sd-card-or-microsd-card)는 닌텐도 제품에 쓸 카드에 이 도구를 권하고, 덮어쓰기 포맷(Overwrite format)을 고르라고 적습니다.

1. 카드의 사진과 음악을 먼저 컴퓨터에 복사합니다. 포맷하면 카드의 자료가 모두 지워집니다.
2. 카드를 컴퓨터의 슬롯이나 카드 리더기에 넣습니다.
3. SD Memory Card Formatter를 열고 카드를 고릅니다.
4. 덮어쓰기 포맷을 고르고 포맷을 실행합니다.

도구의 화면과 빠른 포맷과의 차이는 [SD 카드 포맷터 사용법](/blog/ko/sd-card-formatter)에 정리했습니다. 컴퓨터에 카드를 연결하는 방법은 [SD 카드 컴퓨터 연결 방법](/blog/ko/sd-card-to-pc)에 있습니다.

## 더 큰 3DS SD 카드로 바꾸려면 어떻게 하나요?

컴퓨터로 카드 내용을 통째로 옮깁니다. [닌텐도의 카드 간 이동 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/309/~/how-to-transfer-data-between-sd-cards-or-microsd-cards) 순서입니다. Windows 탐색기와 Mac의 Finder 모두 이 안내에 나옵니다.

1. 본체 전원을 끄고 기존 카드를 뺍니다.
2. 기존 카드를 컴퓨터의 슬롯이나 카드 리더기에 넣습니다. microSD 카드는 슬롯에 맞는 어댑터가 필요할 수 있습니다.
3. 탐색기나 Finder에서 카드를 열고 폴더 전체를 바탕화면으로 끌어 옵니다.
4. 새 카드를 닌텐도 권장 방식으로 포맷합니다.
5. 바탕화면의 폴더를 새 카드로 끌어 옮깁니다.
6. 새 카드를 본체에 넣고 동작을 확인합니다.

| 주의할 점 | 닌텐도 안내 |
| --- | --- |
| Nintendo 3DS 폴더 | 폴더 안을 열어 파일을 고르지 않습니다. 폴더 전체를 복사하고, 안의 파일을 고치거나 지우지 않습니다 |
| 기존 카드 | 새 카드가 정상 동작하는지 확인하기 전에는 지우거나 포맷하지 않습니다 |
| 옮긴 뒤 | 기존 카드의 저장 데이터를 다시 쓰지 않습니다 |
| 카드 여러 장 | 카드를 번갈아 쓰지 않고, 본체 하나에 카드 한 장을 씁니다 |
| 다른 본체 | 다른 본체의 카드에 복사해도 그 본체에서는 쓸 수 없습니다. 본체를 바꿀 때는 본체 이사 기능을 씁니다 |

같은 안내에 따르면 New 3DS 계열은 카드를 빼지 않고 집의 네트워크로 카드 데이터에 접근하는 기능도 있습니다.

## 지운 3DS 소프트웨어를 다시 받을 수 있나요?

구매한 소프트웨어는 다시 받을 수 있습니다. [닌텐도의 3DS e숍 종료 Q&A](https://en-americas-support.nintendo.com/app/answers/detail/a_id/57847/~/wii-u-&-nintendo-3ds-eshop-discontinuation-q&a)에 따르면 3DS용 닌텐도 e숍 구매는 미국 태평양 시간 2023년 3월 27일 오후 5시에 끝났습니다. 같은 Q&A는 그 뒤에도 당분간 게임과 추가 콘텐츠를 다시 받고 업데이트를 받을 수 있다고 적습니다.

새로 살 수는 없습니다. 같은 날부터 체험판 같은 무료 콘텐츠도 받을 수 없습니다. 카드를 포맷하거나 교체하기 전에는 이 조건을 기억해 두세요.

## 3DS 사진을 아이폰으로 옮기려면?

3DS 카메라 앱에서 사진을 SD 카드로 보낸 뒤, 카드 리더기로 아이폰에 연결합니다. [닌텐도의 사진 이동 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/113/)의 순서입니다.

1. 닌텐도 3DS 카메라에서 사진 보기를 고릅니다.
2. 설정 > 데이터 관리를 고릅니다.
3. 본체에서 SD 카드로를 눌러 사진을 카드로 보냅니다. 사진은 한 장씩 고를 수 없고 한 번에 모두 옮겨집니다.
4. 본체 전원을 끄고 카드를 뺀 뒤 카드 리더기에 넣습니다.

[Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)에 따르면 아이폰은 exFAT, FAT32, FAT 등의 형식을 읽습니다. 이 글은 3DS가 쓰던 카드를 아이폰에서 시험하지 않았습니다. Nintendo 3DS 폴더의 파일은 고치거나 지우지 말고 사진만 복사합니다. 연결 순서는 [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader)에 있고, 아이폰 사진을 카드로 옮기는 방법은 [아이폰 사진 SD 카드로 옮기기](/blog/ko/iphone-photos-to-sd-card)에 있습니다.

## 3DS가 SD 카드를 인식하지 못하면?

[닌텐도의 SD 카드 문제 해결 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/452/~/general-sd-card-and-microsd-card-troubleshooting)의 순서입니다.

1. 본체 전원을 끄고 카드를 뺍니다.
2. 카드가 3DS 호환 규격인지 확인합니다. 64GB 이상 SDXC 카드는 호환되지 않습니다.
3. SD 카드의 잠금 스위치가 풀려 있는지 봅니다. microSD 카드에는 잠금 스위치가 없습니다.
4. 카드를 넣고 본체를 켭니다.
5. 카드가 가득 찼다는 메시지가 나오면 안 쓰는 콘텐츠를 지웁니다.
6. 그래도 안 되면 다른 카드나 다른 본체로 시험합니다. 다른 카드는 되면 카드를 바꿉니다.

같은 안내는 어댑터에 microSD를 끼워 쓸 때 어댑터가 본체에 꽂힌 채로 microSD만 빼지 말라고 적습니다. 미국 닌텐도는 New 2DS XL을 뺀 3DS 계열 본체의 수리를 더 받지 않습니다. 카드 자체 점검은 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)에 있습니다.

## 3DS SD 카드 자주 묻는 질문

### 3DS SD 카드는 몇 GB까지 되나요?

32GB까지입니다. 닌텐도는 SD 2GB까지, SDHC 4GB~32GB를 호환 카드로 안내합니다. 64GB 이상 SDXC 카드는 호환되지 않습니다.

### New 3DS에 일반 SD 카드를 넣을 수 있나요?

안 됩니다. New 3DS, New 3DS XL, New 2DS XL은 microSD 카드를 씁니다. 닌텐도 일본 표도 New 3DS 계열은 SD 카드 크기를 지원하지 않는다고 적습니다. 크기 차이는 [micro SD와 SD 카드 차이](/blog/ko/microsd-vs-sd)에 있습니다.

### 구형 3DS에 microSD 카드를 쓸 수 있나요?

SD 카드 어댑터에 끼우면 씁니다. 닌텐도는 3DS, 3DS XL, 2DS에서 microSD와 miniSD를 어댑터와 함께 쓸 수 있다고 안내합니다.

### SD 카드를 포맷하면 게임 카드 진행 기록도 지워지나요?

게임 카드 소프트웨어의 진행 기록은 게임 카드에 저장됩니다. 카드에 있던 다운로드 소프트웨어, 사진, 음악은 지워집니다. 포맷 전에 컴퓨터에 카드 내용을 복사하세요.

### SD 카드 여러 장을 번갈아 써도 되나요?

닌텐도는 본체 하나에 카드 한 장을 쓰라고 안내합니다. 용량이 부족하면 위 순서대로 더 큰 카드로 통째로 옮깁니다.
