## この記事の要点

3DS SDカードを選ぶときに確かめることは2つです。機種に合うカードの大きさを選び、32GB以下のSDHCカードを選びます。任天堂は、3DSシリーズで使えるSDカードは最大32GBで、64GB以上のSDXCカードは使えないと案内しています。

ニンテンドー3DS、3DS LL、2DSは大きいSDカードを使います。Newニンテンドー3DS、New 3DS LL、New 2DS LLはmicroSDカードを使います。

カードを替えるときは、パソコンで「Nintendo 3DS」フォルダーをまるごと移します。フォルダーの中のファイルを選んで移したり、書き換えたりしません。

「3DSに64GBのカードを入れたら読み込まない」「New 3DSのカードはどこに入れるの?」。しまっていた3DSをまた使うときによく出る疑問です。この記事では、3DS SDカードの規格、入れかた、フォーマット、大きいカードへの移しかたを任天堂の公式案内で確かめます。この記事は特定のカードを試しておらず、推奨もしません。Switch用のカードは[Switch SDカードの使い方](/blog/ja/switch-microsd)にまとめました。

## 3DS SDカードはどう選べばいいですか?

機種に合う大きさで、32GB以下のカードを選びます。下の表は[任天堂の3DSシリーズ最大容量Q&A](https://support-jp.nintendo.com/app/answers/detail/a_id/31955/)と[米国任天堂の対応カード案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/274/~/what-sd-cards-and-microsd-cards-are-compatible)をまとめたものです。

| 機種 | カードの大きさ | 使えるカード |
| --- | --- | --- |
| ニンテンドー3DS、3DS LL、2DS | SDカード | SDカード(最大2GB)、SDHCカード(最大32GB) |
| Newニンテンドー3DS、New 3DS LL、New 2DS LL | microSDカード | microSDカード(最大2GB)、microSDHCカード(最大32GB) |
| 3DSシリーズ全機種 | - | 64GB以上のSDXC、microSDXCは使えない |

任天堂は、本体付属のSDカードや任天堂が販売するSDカードのほか、一部の他社製品で動作確認をしていると案内しています。ただし、動作を保証するものではないと書いています。他社製カードの確認リストは2014年12月が最終更新です。

カードに書かれたSDHC、SDXCは容量の規格です。読みかたは[SDXCとは?](/blog/ja/sdhc-vs-sdxc)にあります。新しいカードの実際の容量があやしいときは、[SDカードの偽物の見分け方](/blog/ja/fake-sd-card)で先に確かめてください。

## 3DSで64GBのSDカードは使えますか?

使えません。64GBのカードはSDXC規格で、任天堂のQ&Aは64GB以上のSDXCカードは使用できないと書いています。米国任天堂の案内も、SDXCとmicroSDXCを対応外としています。

容量が足りないときは、32GBのカードに替えて、使わないソフトを消します。[任天堂のSDカードの用途の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/399/~/what-are-sd-cards-and-microsd-cards-used-for%3F)によると、SDカード1枚にソフトは最大300本、写真は最大3,000枚、音楽ファイルは最大3,000曲保存できます。

## 3DS SDカードには何が保存されますか?

ダウンロードしたソフト、写真、音楽が保存されます。任天堂のSDカードの用途の案内にもとづく表です。

| データ | 保存先 |
| --- | --- |
| ダウンロードソフト(DSiウェアを除く) | SDカード |
| ニンテンドー3DSカメラで撮った写真 | SDカードに保存できる |
| 音楽ファイル | SDカードから再生 |
| ゲームカードのソフトの進行データ | ゲームカード |

[任天堂の保存先の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/337/)によると、ゲームカードのソフトの進行データはゲームカードに保存されます。同じ案内は、一部のゲームカードがすれちがい通信やいつの間に通信の情報をSDカードや本体保存メモリーに保存すると書いています。任天堂は、8階層より深いフォルダーのファイルは表示されないとも案内しています。

## 3DSにSDカードを入れるには?

電源を切ってから入れます。[任天堂のカードの入れかたの案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/271/)は、カードを抜き差しするときは本体の電源を切るよう書いています。

| 機種 | スロットの場所 | 入れる向き |
| --- | --- | --- |
| ニンテンドー3DS | 本体の左側面、カバーの中 | ラベル面を下に |
| ニンテンドー3DS LL、2DS | 本体の右側面、カバーの中 | ラベル面を下に |
| Newニンテンドー2DS LL | 本体の前面、カバーの中 | ラベル面を下に |
| Newニンテンドー3DS、New 3DS LL | 電池カバーの中 | カードが本体の外側を向くように |

1. 本体の電源を切ります。
2. 表の場所にあるスロットカバーか電池カバーを開けます。
3. カチッと音がするまでカードを差し込みます。
4. カバーを閉じて本体の電源を入れます。

[任天堂のカード間のデータ移動の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/309/~/how-to-transfer-data-between-sd-cards-or-microsd-cards)によると、New 3DSとNew 3DS LLからmicroSDカードを取り出すには0番のプラスドライバーが必要です。

SDカードの書き込み禁止スイッチを下げると、保存も削除もできません。上げておきます。スイッチの見かたは[SDカードのロックとは?](/blog/ja/sd-card-lock-switch)にあります。

## 3DS SDカードはどうフォーマットしますか?

パソコンでSDアソシエーションのSDメモリカードフォーマッターを使います。[任天堂の3DS用カードのフォーマットの案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/220/~/how-to-format-an-sd-card-or-microsd-card)は、任天堂の製品で使うカードにこのツールをすすめ、上書きフォーマットを選ぶよう書いています。

1. カードの写真と音楽を先にパソコンにコピーします。フォーマットするとカードのデータはすべて消えます。
2. カードをパソコンのスロットかカードリーダーに入れます。
3. SDメモリカードフォーマッターを開き、カードを選びます。
4. 上書きフォーマットを選んでフォーマットを始めます。

ツールの画面とクイックフォーマットとの違いは[SDカードフォーマッターの使い方](/blog/ja/sd-card-formatter)にまとめました。パソコンにカードをつなぐ方法は[SDカードをパソコンにつなぐ方法](/blog/ja/sd-card-to-pc)にあります。

## 大きい3DS SDカードに替えるには?

パソコンでカードの中身をまるごと移します。[任天堂のカード間のデータ移動の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/309/~/how-to-transfer-data-between-sd-cards-or-microsd-cards)の手順です。WindowsのエクスプローラーとMacのFinderのどちらも案内に出てきます。

1. 本体の電源を切り、今のカードを抜きます。
2. 今のカードをパソコンのスロットかカードリーダーに入れます。microSDカードはアダプターが要ることがあります。
3. エクスプローラーかFinderでカードを開き、フォルダーをすべてデスクトップにドラッグします。
4. 新しいカードを任天堂のすすめる方法でフォーマットします。
5. デスクトップのフォルダーを新しいカードにドラッグします。
6. 新しいカードを本体に入れ、動くか確かめます。

| 気をつけること | 任天堂の案内 |
| --- | --- |
| Nintendo 3DSフォルダー | 中を開いてファイルを選びません。フォルダーごとコピーし、中のファイルを書き換えたり消したりしません |
| 今のカード | 新しいカードが正しく動くと確かめるまで、消したりフォーマットしたりしません |
| 移したあと | 前のカードのセーブデータを使いません |
| 複数のカード | カードを差し替えて使いません。本体1台にカード1枚で使います |
| ほかの本体 | ほかの本体のカードにコピーしても、その本体では使えません。本体を替えるときは引っ越し機能を使います |

同じ案内によると、New 3DSシリーズにはカードを取り出さずに家のネットワークでカードのデータを扱う機能もあります。

## 消した3DSのソフトはまたダウンロードできますか?

購入したソフトは再ダウンロードできます。[任天堂の3DSニンテンドーeショップ終了Q&A](https://en-americas-support.nintendo.com/app/answers/detail/a_id/57847/~/wii-u-&-nintendo-3ds-eshop-discontinuation-q&a)によると、3DSシリーズのニンテンドーeショップでの購入は、米国太平洋時間の2023年3月27日午後5時に終わりました。同じQ&Aは、その後も当面はゲームと追加コンテンツの再ダウンロードと更新データの受信ができると書いています。

新しく買うことはできません。同じ日から、体験版などの無料コンテンツもダウンロードできなくなりました。カードをフォーマットしたり替えたりする前に、この条件を覚えておいてください。

## 3DSの写真をiPhoneに移すには?

ニンテンドー3DSカメラで写真をSDカードに送り、カードリーダーでiPhoneにつなぎます。[任天堂の写真の移動の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/113/)の手順です。

1. ニンテンドー3DSカメラで「写真を見る」を選びます。
2. 設定から「データ管理」を選びます。
3. 本体からSDカードへの移動を選び、写真をカードに送ります。写真は1枚ずつ選べず、まとめて移ります。
4. 本体の電源を切ってカードを抜き、カードリーダーに入れます。

[AppleのiPhoneユーザガイドの外部ストレージの案内](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)によると、iPhoneはexFAT、FAT32、FATなどの形式を読み込みます。この記事は3DSで使っていたカードをiPhoneで試していません。Nintendo 3DSフォルダーのファイルは書き換えたり消したりせず、写真だけをコピーします。つなぐ手順は[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)に、iPhoneの写真をカードに移す方法は[iPhoneからSDカードに写真を移す方法](/blog/ja/iphone-photos-to-sd-card)にあります。

## 3DSがSDカードを認識しないときは?

[任天堂のSDカードのトラブル対処の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/452/~/general-sd-card-and-microsd-card-troubleshooting)の手順です。

1. 本体の電源を切り、カードを抜きます。
2. カードが3DSシリーズに対応する規格か確かめます。64GB以上のSDXCカードは使えません。
3. SDカードのロックスイッチが外れているか見ます。microSDカードにはロックスイッチがありません。
4. カードを入れて本体の電源を入れます。
5. カードがいっぱいというメッセージが出たら、使わないコンテンツを消します。
6. それでもだめなら、別のカードか別の本体で試します。別のカードが使えるなら、カードを替えます。

同じ案内は、アダプターにmicroSDを入れて使うとき、アダプターを本体に差したままmicroSDだけを抜かないよう書いています。米国任天堂は、New 2DS XLを除く3DSシリーズ本体の修理を受け付けていません。カードそのものの確かめかたは[microSDが認識しない・フォーマットできないときの確認手順](/blog/ja/sd-card-not-working)にあります。

## 3DS SDカードのよくある質問

### 3DS SDカードは何GBまで使えますか?

32GBまでです。任天堂はSDカード(最大2GB)とSDHCカード(最大32GB)を対応カードとしています。64GB以上のSDXCカードは使えません。

### New 3DSに普通のSDカードは入りますか?

入りません。New 3DS、New 3DS LL、New 2DS LLはmicroSDカードを使います。任天堂のQ&Aの表も、New 3DSシリーズではSDカードを「非対応」としています。大きさの違いは[micro SDとは?](/blog/ja/microsd-vs-sd)にあります。

### 古い3DSでmicroSDカードは使えますか?

SDカードアダプターに入れれば使えます。任天堂のQ&Aは、3DS、3DS LL、2DSでmicroSDカードを使うにはSDカードサイズに変換するアダプターが必要だと書いています。

### SDカードをフォーマットすると、ゲームカードの進行データも消えますか?

ゲームカードのソフトの進行データはゲームカードに保存されます。SDカードにあったダウンロードソフト、写真、音楽は消えます。フォーマットする前に、カードの中身をパソコンにコピーしてください。

### 複数のSDカードを差し替えて使ってもいいですか?

任天堂は本体1台にカード1枚で使うよう案内しています。容量が足りなければ、上の手順で大きいカードにまるごと移します。
