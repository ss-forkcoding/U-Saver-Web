## 핵심 요약

SD 카드 포맷 안될 때는 포맷을 반복하기 전에 원인을 좁힙니다. 잠금 스위치, 연결, 파일 시스템 오류, 카드 자체의 고장 순서로 확인합니다.

"cannot be modified" 같은 메시지가 뜨면 잠금 스위치부터 봅니다. Apple은 SD 카드가 잠겨 있을 수 있다고 안내합니다. 카드가 아예 보이지 않으면 다시 꽂고, 그래도 안 되면 포맷이 필요할 수 있다고 설명합니다.

카드에 남길 파일이 있다면 포맷 전에 Mac 디스크 유틸리티의 응급 처치나 윈도우의 `chkdsk`로 먼저 검사합니다. 여러 방법으로도 안 되면 카드 제조사에 문의합니다.

"카메라에서 쓰던 SD 카드가 PC에서 안 열려요." "포맷하려는데 끝까지 진행되지 않아요." SD 카드 포맷이 안 되거나 카드가 인식되지 않는 분들이 자주 묻는 질문입니다. 정상 카드의 포맷 순서는 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에 정리했습니다. 이 글은 포맷과 인식이 막혔을 때 확인할 순서를 다룹니다.

## SD 카드 포맷 안될 때 먼저 무엇을 확인하나요?

증상에 따라 확인할 곳이 다릅니다. 아래 표에서 내 증상을 찾으세요.

| 증상 | 먼저 확인할 것 | 이 글의 해당 부분 |
| --- | --- | --- |
| "cannot be modified"나 읽기 전용이라는 메시지 | 카드의 잠금 스위치 | 잠금 스위치 |
| 카드를 꽂아도 아무것도 나타나지 않음 | 카드 방향, 리더, 다시 꽂기 | 인식 안 될 때 |
| 아이폰 파일 앱의 위치 목록에 카드가 없음 | 카드 형식과 데이터 파티션 수 | 아이폰에서 안 보일 때 |
| 윈도우 디스크 관리에는 있는데 탐색기에 없음 | 드라이브 문자, 할당되지 않은 공간 | 드라이브 문자 |
| 열리기는 하지만 파일이 깨지거나 오류가 남 | 파일 시스템 검사 | 손상된 카드 검사 |
| 위 방법을 모두 해도 같은 증상 | 카드 제조사 문의 | 그래도 안 될 때 |

이 글은 특정 카드나 리더를 시험하지 않았고 특정 제품을 추천하지 않습니다.

## 잠금 스위치 때문에 SD 카드 포맷이 안 될 수 있나요?

그럴 수 있습니다. [Apple의 Mac SD 카드 슬롯 안내](https://support.apple.com/en-us/102352)는 카드를 쓸 때 "cannot be modified" 메시지가 나오면 SD 카드가 잠겨 있을 수 있다고 설명합니다.

1. 카드를 꺼내기 한 뒤 기기에서 뺍니다.
2. 카드 옆면의 잠금 스위치를 잠금 해제 쪽으로 밉니다.
3. 카드를 다시 넣습니다.

[SD Association FAQ](https://www.sdcard.org/consumers/faq/)에 따르면 SD 카드와 microSD 카드는 쓰기 방지 스위치 유무 등 모양과 크기만 다릅니다. microSD를 SD 크기 어댑터에 넣어 쓴다면 어댑터에 스위치가 있는지 확인하세요.

## SD 카드가 인식되지 않을 때는 어떻게 하나요?

카드가 어디에도 나타나지 않으면 포맷 메뉴에 들어갈 수 없습니다. 연결부터 확인합니다.

1. 카드를 빼고 기기 설명서대로 다시 넣습니다. Apple은 카드가 한 방향으로만 들어가니 억지로 밀지 말라고 안내합니다.
2. Mac이라면 Apple 안내대로 카드를 뺐다가 다시 넣습니다. 그래도 마운트되지 않으면 포맷이 필요할 수 있습니다.
3. 오류 메시지가 나오면 기록하고 기기 설명서를 확인합니다. SD Association FAQ가 권하는 순서입니다.
4. 다른 리더나 다른 컴퓨터에 연결해 봅니다. 한쪽에서만 안 보이면 카드보다 리더나 기기 쪽을 의심합니다.

카드 규격도 확인하세요. SD Association FAQ에 따르면 SDXC 이전의 SD, SDHC 기기는 SDXC 카드와 호환되지 않습니다. 32GB를 넘는 카드를 오래된 카메라나 리더에 꽂았다면 이 경우일 수 있습니다.

Apple 안내는 SDIO 카드를 지원하지 않는다고 적어 둡니다. microSD는 어댑터를 써서 연결합니다.

## 아이폰에서 SD 카드가 보이지 않을 때는?

[Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)에 따르면 아이폰은 데이터 파티션이 하나인 저장장치만 씁니다. 형식은 APFS, macOS 확장(HFS+), exFAT, FAT32, FAT 중 하나여야 합니다.

| 확인할 것 | 해야 할 일 |
| --- | --- |
| 파일 앱에서 위치가 보이지 않음 | 둘러보기를 한 번 더 누릅니다 |
| 카드 형식이 NTFS | Apple 목록에 없으므로 exFAT이나 FAT32로 다시 포맷합니다 |
| 데이터 파티션이 여러 개 | Mac 디스크 유틸리티에서 맨 위 항목을 지웁니다 |
| 리더와 아이폰 단자가 맞지 않음 | 아이폰 단자에 맞는 리더나 어댑터를 씁니다 |

리더 연결 조건은 [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader)에, microSD 연결은 [아이폰 마이크로 SD 쓰는 법](/blog/ko/iphone-microsd)에 정리했습니다.

## 손상된 SD 카드는 포맷 전에 검사할 수 있나요?

카드에 남길 파일이 있다면 포맷 전에 파일 시스템을 검사합니다. 검사로 고쳐지면 파일을 다른 곳에 옮긴 뒤 포맷할 수 있습니다.

### Mac에서 응급 처치로 검사하기

[Apple의 디스크 유틸리티 응급 처치 안내](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac)를 따른 순서입니다.

1. 디스크 유틸리티를 열고 보기, 모든 기기 보기를 선택합니다.
2. 사이드바에서 카드의 볼륨을 선택하고 응급 처치를 실행합니다.
3. 컨테이너가 있으면 컨테이너에도 실행합니다.
4. 마지막으로 카드 맨 위 항목을 선택하고 응급 처치를 실행합니다.

Apple은 응급 처치가 실패하면 한 번 더 시도하고, 그래도 안 되면 가능한 만큼 자료를 백업한 뒤 다시 포맷하라고 안내합니다.

### 윈도우에서 chkdsk로 검사하기

[Microsoft의 chkdsk 문서](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/chkdsk)에 따르면 매개변수 없이 실행하면 상태만 보여 주고, `/f`를 붙여야 오류를 고칩니다. 관리자 권한이 필요합니다.

1. 시작 메뉴에서 명령 프롬프트를 마우스 오른쪽 버튼으로 누르고 관리자 권한으로 실행을 고릅니다.
2. `chkdsk E: /f`처럼 입력합니다. E는 예시이므로 카드의 드라이브 문자로 바꾸세요.
3. 끝날 때까지 기다립니다. Microsoft는 실행 중에 중단하지 말라고 권합니다.

같은 문서는 FAT 파일 시스템을 고치면 데이터가 사라질 수 있다고 설명합니다. 잃어버린 조각을 파일로 바꿀지 물으면 Y를 누르세요. 루트 폴더에 `File<nnnn>.chk` 형식의 파일로 남습니다.

지운 사진을 되살리는 방법은 SD Association FAQ도 카드 제조사 안내를 보라고 답합니다. 이 글은 사진 복구 도구를 다루지 않습니다.

## 윈도우에서 드라이브 문자가 없어 포맷이 안 될 때는?

카드가 디스크 관리에는 보이는데 파일 탐색기에 없다면 드라이브 문자가 없을 수 있습니다. [Microsoft의 드라이브 문자 변경 안내](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/change-a-drive-letter)를 따른 순서입니다.

1. 시작 메뉴에서 디스크 관리를 찾아 관리자 권한으로 엽니다.
2. 카드의 볼륨을 마우스 오른쪽 버튼으로 누르고 드라이브 문자 및 경로 변경을 고릅니다.
3. 추가를 누르고 드라이브 문자를 고른 뒤 확인을 누릅니다.

이 메뉴가 회색이면 Microsoft는 드라이브가 할당되지 않아 초기화가 필요한 상태일 수 있다고 설명합니다. 이때 카드에는 쓸 수 있는 볼륨이 없으니 아래 순서로 카드 전체를 다시 포맷합니다.

## 인식은 되는데 포맷이 안 되면 어떻게 다시 포맷하나요?

운영체제 도구로 실패했다면 [SD Association의 포맷 프로그램](https://www.sdcard.org/downloads/formatter/)을 씁니다. SD Association은 운영체제 도구가 SD 카드에 최적화되지 않았을 수 있다며 이 프로그램을 강하게 권합니다.

1. 윈도우용이나 Mac용 SD Memory Card Formatter를 내려받아 설치합니다.
2. 카드를 리더에 넣고 PC나 Mac에 연결합니다.
3. 프로그램에서 카드를 고르고 이름과 용량을 다시 확인합니다.
4. 포맷을 실행합니다.

| 막히는 상황 | 공식 안내 |
| --- | --- |
| BitLocker To Go로 암호화한 카드 | SD Association 프로그램이 지원하지 않습니다. 잠금을 푼 뒤 포맷합니다 |
| 파티션이 여러 개인 카드 | Mac 디스크 유틸리티에서 카드 맨 위 항목을 지웁니다 |
| 오류를 자주 내던 카드 | 윈도우에서는 빠른 포맷을 끕니다 |

빠른 포맷에 대해 [Microsoft의 format 명령 문서](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/format)는 상태가 좋다고 아는 드라이브에만 쓰라고 설명합니다. 용량별 형식과 기기별 순서는 [마이크로 SD 카드 포맷 방법](/blog/ko/format-microsd)에도 있습니다.

## 그래도 SD 카드가 안 되면?

여러 기기와 리더에서 같은 증상이 나오면 카드 자체를 의심합니다. SD Association은 표준 단체이고 카드를 만들지 않으므로, FAQ에서 카드 제조사에 문의하라고 안내합니다.

| 할 일 | 근거 |
| --- | --- |
| 카드 제조사 지원에 문의 | SD Association FAQ |
| 교환이나 반품이 필요하면 구입처에 문의 | SD Association FAQ |
| 보증 조건은 제조사에서 확인 | SD Association FAQ |

Apple도 응급 처치와 다시 포맷으로 해결되지 않으면 장치가 물리적으로 손상되었을 수 있다고 설명합니다.

## USB 메모리에 정기적으로 백업하려면?

아래 앱은 USB 메모리를 기준으로 안내합니다. 카드 리더에서의 동작은 확인하지 않았습니다. USB 메모리 형식을 바꾸는 순서는 [exFAT 포맷 방법](/blog/ko/format-usb-exfat)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비 중이며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## SD 카드 포맷 안될 때 자주 묻는 질문

### SD 카드가 읽기 전용이라 포맷이 안 돼요.

카드 옆면의 잠금 스위치를 확인하세요. Apple은 "cannot be modified" 메시지가 나오면 카드를 빼고 스위치를 잠금 해제 쪽으로 옮긴 뒤 다시 넣으라고 안내합니다.

### SD 카드가 인식되지 않으면 바로 포맷해야 하나요?

먼저 다시 꽂고 다른 리더나 컴퓨터에서 확인하세요. Apple은 다시 넣어도 마운트되지 않을 때 포맷이 필요할 수 있다고 설명합니다. 포맷하면 카드의 자료가 모두 지워집니다.

### chkdsk를 실행하면 파일이 지워지나요?

`/f` 없이 실행하면 상태만 보여 줍니다. Microsoft는 FAT 파일 시스템을 고칠 때 데이터가 사라질 수 있다고 설명하므로, 남길 파일이 있다면 열리는 동안 먼저 복사하세요.

### 64GB SD 카드가 오래된 카메라에서 인식되지 않아요.

SD Association FAQ에 따르면 SD, SDHC 기기는 SDXC 카드와 호환되지 않습니다. 기기 설명서에서 SDXC 지원 여부를 확인하세요.

### SD Association 포맷 프로그램으로도 포맷이 안 되면요?

카드 제조사에 문의하세요. SD Association은 카드를 만들지 않으므로 기술 문제는 제조사에 문의하라고 안내합니다.
