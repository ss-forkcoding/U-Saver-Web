## この記事の要点

microSDが認識しないときや、SDカードがフォーマットできないときは、フォーマットを繰り返す前に原因を絞ります。ロックスイッチ、接続、ファイルシステムのエラー、カード自体の故障の順に確認します。

「cannot be modified」のようなメッセージが出たら、まずロックスイッチを見ます。Appleは、SDカードがロックされている可能性があると案内しています。カードがまったく表示されないなら挿し直し、それでもマウントされなければフォーマットが必要な場合があると説明しています。

残したいファイルがあるなら、フォーマットの前にMacのディスクユーティリティの「First Aid」かWindowsの`chkdsk`で検査します。どの方法でも直らなければ、カードのメーカーに問い合わせます。

「スマホから抜いたmicroSDがパソコンで認識しない」「フォーマットしようとしても最後まで進まない」。カードが認識しない、フォーマットできないという方からよく聞く質問です。正常なカードのフォーマット手順は[マイクロSDカードフォーマット方法](/blog/ja/format-microsd)にまとめました。この記事では、認識やフォーマットで止まったときに確認する順番を扱います。

## microSDが認識しない・フォーマットできないとき、まず何を確認しますか?

症状によって確認する場所が違います。下の表で自分の症状を探してください。

| 症状 | 先に確認すること | この記事の該当箇所 |
| --- | --- | --- |
| 「cannot be modified」や読み取り専用というメッセージ | カードのロックスイッチ | ロックスイッチ |
| カードを挿しても何も表示されない | カードの向き、リーダー、挿し直し | 認識しないとき |
| iPhoneのファイルアプリの「場所」にカードがない | カードの形式とデータパーティションの数 | iPhoneに表示されないとき |
| Windowsの「ディスクの管理」にはあるのにエクスプローラーにない | ドライブ文字、未割り当て領域 | ドライブ文字 |
| 開けるがファイルが壊れている、エラーが出る | ファイルシステムの検査 | 破損したカードの検査 |
| ここまでの方法で直らない | カードのメーカーに問い合わせ | それでも直らないとき |

この記事では特定のカードやリーダーを試しておらず、特定の製品をおすすめしていません。

## ロックスイッチのせいでSDカードをフォーマットできないことはありますか?

あります。[AppleのMac SDカードスロットの案内](https://support.apple.com/en-us/102352)は、カードを使うときに「cannot be modified」と表示されたら、SDカードがロックされている可能性があると説明しています。

1. カードを取り出す操作をしてから、機器から抜きます。
2. カード側面のロックスイッチをロック解除の位置にずらします。
3. カードをもう一度挿します。

[SD AssociationのFAQ](https://www.sdcard.org/consumers/faq/)によると、SDカードとmicroSDカードの違いは、書き込み禁止スイッチの有無など形状とサイズだけです。microSDをSDサイズのアダプタに入れて使うなら、アダプタにスイッチがあるか確認してください。

## microSDが認識しないときはどうしますか?

カードがどこにも表示されなければ、フォーマットのメニューにも進めません。まず接続を確認します。

1. カードを抜き、機器の説明書どおりに挿し直します。Appleは、カードは一方向にしか入らないので無理に押し込まないよう案内しています。
2. Macなら、Appleの案内どおりカードを抜いてもう一度挿します。それでもマウントされなければ、フォーマットが必要な場合があります。
3. エラーメッセージが出たら控えて、機器の説明書を確認します。SD AssociationのFAQが勧める順番です。
4. 別のリーダーや別のパソコンにつないでみます。片方でだけ表示されないなら、カードよりリーダーや機器を疑います。

カードの規格も確認してください。SD AssociationのFAQによると、SDXCより前のSD、SDHC機器はSDXCカードに対応していません。32GBを超えるカードを古いカメラやリーダーに挿した場合は、これに当たる可能性があります。

Appleの案内では、SDIOカードには対応していません。microSDはアダプタを使って接続します。

## iPhoneでmicroSDやSDカードが表示されないときは?

[Appleの外部ストレージの案内](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)によると、iPhoneが使えるのはデータパーティションが1つのストレージだけです。形式は、APFS、Mac OS拡張(HFS+)、exFAT、FAT32、FATのいずれかである必要があります。

| 確認すること | やること |
| --- | --- |
| ファイルアプリに「場所」が表示されない | もう一度「ブラウズ」をタップします |
| カードの形式がNTFS | Appleの一覧にないので、exFATかFAT32でフォーマットし直します |
| データパーティションが複数ある | Macのディスクユーティリティで最上位の項目を消去します |
| リーダーとiPhoneの端子が合わない | iPhoneの端子に合うリーダーかアダプタを使います |

リーダーの条件は[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)に、microSDの接続は[micro SDをiPhoneで使う方法](/blog/ja/iphone-microsd)にまとめました。

## 破損したSDカードはフォーマットの前に検査できますか?

残したいファイルがあるなら、フォーマットの前にファイルシステムを検査します。検査でエラーが直れば、ファイルを別の場所に移してからフォーマットできます。

### MacのFirst Aidで検査する

[Appleのディスクユーティリティの修復の案内](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac)に沿った手順です。

1. ディスクユーティリティを開き、「表示」>「すべてのデバイスを表示」を選びます。
2. サイドバーでカードのボリュームを選び、First Aidを実行します。
3. コンテナがあれば、コンテナにも実行します。
4. 最後にカードの最上位の項目を選び、First Aidを実行します。

Appleは、First Aidが失敗したらもう一度試し、それでも直らなければできるだけデータをバックアップしてからフォーマットし直すよう案内しています。

### Windowsのchkdskで検査する

[Microsoftのchkdskコマンドの案内](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/chkdsk)によると、パラメーターなしで実行すると状態を表示するだけで、エラーを修正するには`/f`が必要です。管理者の権限も必要です。

1. スタートメニューで「コマンドプロンプト」を右クリックし、「管理者として実行」を選びます。
2. `chkdsk E: /f`のように入力します。Eは例なので、カードのドライブ文字に置き換えてください。
3. 終わるまで待ちます。Microsoftは実行中の中断を勧めていません。

同じ案内は、FATファイルシステムの修復でデータが失われる場合があると説明しています。失われたチェーンをファイルに変換するか聞かれたらYを押します。ルートフォルダに`File<nnnn>.chk`という名前のファイルとして残ります。

削除した写真を取り戻す方法について、SD AssociationのFAQはカードのメーカーの案内を見るよう答えています。この記事では写真の救出ツールは扱いません。

## Windowsでドライブ文字がなくてフォーマットできないときは?

カードが「ディスクの管理」には表示されるのにエクスプローラーにない場合、ドライブ文字が割り当てられていない可能性があります。[Microsoftのドライブ文字の変更の案内](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/change-a-drive-letter)に沿った手順です。

1. スタートメニューで「ディスクの管理」を探し、管理者の権限で開きます。
2. カードのボリュームを右クリックし、「ドライブ文字とパスの変更」を選びます。
3. 「追加」を選び、ドライブ文字を選んで「OK」を選びます。

このメニューがグレーで選べないとき、Microsoftはドライブが未割り当てで、初期化が必要な状態の可能性があると説明しています。この場合カードには使えるボリュームがないので、下の手順でカード全体をフォーマットし直します。

## 認識はするのにフォーマットできないときは、どうフォーマットし直しますか?

OSのツールで失敗したら、[SD Associationのフォーマットソフト](https://www.sdcard.org/downloads/formatter/)を使います。SD Associationは、OSのツールはSDカード向けに最適化されていない場合があるとして、このソフトを強く勧めています。

1. Windows用かMac用のSD Memory Card Formatterをダウンロードしてインストールします。
2. カードをリーダーに入れ、パソコンかMacに接続します。
3. ソフトでカードを選び、名前と容量をもう一度確かめます。
4. フォーマットを実行します。

| 止まる場面 | 公式の案内 |
| --- | --- |
| BitLocker To Goで暗号化したカード | SD Associationのソフトは対応していません。ロックを解除してからフォーマットします |
| パーティションが複数あるカード | Macのディスクユーティリティでカードの最上位の項目を消去します |
| エラーがよく出ていたカード | Windowsではクイックフォーマットをオフにします |

クイックフォーマットについて、[Microsoftのformatコマンドの案内](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/format)は、状態が良いとわかっているドライブにだけ使うよう説明しています。容量別の形式と機器別の手順は[SDカードフォーマット方法](/blog/ja/format-sd-card)にもあります。

## それでもmicroSDやSDカードが直らないときは?

複数の機器やリーダーで同じ症状が出るなら、カード自体を疑います。SD Associationは規格団体でカードを製造していないため、FAQでカードのメーカーに問い合わせるよう案内しています。

| やること | 根拠 |
| --- | --- |
| カードのメーカーのサポートに問い合わせる | SD AssociationのFAQ |
| 返品や交換が必要なら購入店に問い合わせる | SD AssociationのFAQ |
| 保証の条件はメーカーで確認する | SD AssociationのFAQ |

Appleも、First Aidとフォーマットのし直しで解決しなければ、ストレージが物理的に損傷している可能性があると説明しています。

## microSDが認識しない・フォーマットできないときのよくある質問

### SDカードが読み取り専用でフォーマットできません。

カード側面のロックスイッチを確認してください。Appleは、「cannot be modified」と表示されたらカードを抜き、スイッチをロック解除の位置にずらしてから挿し直すよう案内しています。

### microSDが認識しないなら、すぐフォーマットすべきですか?

まず挿し直し、別のリーダーやパソコンで確認してください。Appleは、挿し直してもマウントされないときにフォーマットが必要な場合があると説明しています。フォーマットするとカードのデータはすべて消えます。

### chkdskを実行するとファイルは消えますか?

`/f`を付けなければ状態を表示するだけです。MicrosoftはFATファイルシステムの修復でデータが失われる場合があると説明しているので、残したいファイルはカードが開けるうちにコピーしてください。

### 64GBのmicroSDが古いカメラで認識しません。

SD AssociationのFAQによると、SD、SDHC機器はSDXCカードに対応していません。機器の説明書でSDXCに対応しているか確認してください。

### SD Associationのフォーマットソフトでもフォーマットできないときは?

カードのメーカーに問い合わせてください。SD Associationはカードを製造していないため、技術的な問題はメーカーに問い合わせるよう案内しています。
