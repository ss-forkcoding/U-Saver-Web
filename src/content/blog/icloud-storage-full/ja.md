## この記事の要点

iCloudの容量が足りないと、iCloudバックアップ、iCloud写真のアップロード、iCloud Driveの同期が止まります。まず「設定」>自分の名前>「iCloud」で、何が容量を使っているかを確かめます。

空きを作る方法は2つです。不要なものを削除するか、iCloud+のプランにアップグレードします。削除する前に、残したい写真やファイルのコピーを別の場所に作ります。

iCloud写真がオンの状態で写真を削除すると、同じApple Accountのすべてのデバイスから消えます。iCloudの容量を超えた状態で削除した写真は、「最近削除した項目」にも残りません。

「iCloudのストレージがほぼいっぱいという通知が消えない」「バックアップできないと出る」「無料の5GBを使い切ったけど、プランを上げるしかない?」。iCloudの容量が足りないときによく聞く声です。iPhone本体の空きが足りない場合は、[iPhoneストレージ不足のとき](/blog/ja/iphone-storage-full)にまとめました。この記事はiCloudのストレージだけを扱います。

## iCloudの容量が足りないと何が止まりますか?

[AppleのiCloudストレージ管理の案内](https://support.apple.com/en-us/108922)によると、iCloudを設定すると5GBのストレージを無料で使えます。この容量を、バックアップ、iCloud写真、iCloud Driveなどが共有します。容量がいっぱいになると、次の機能が止まります。

| 機能 | いっぱいになったとき |
| --- | --- |
| iCloudバックアップ | デバイスがiCloudにバックアップされません |
| iCloud写真 | 新しい写真とビデオがiCloudにアップロードされません |
| iCloud DriveとiCloudのアプリ | デバイス間で最新の状態に保たれません |
| iCloudメール | iCloudのメールアドレスでメールを送受信できません |

iPhoneにある写真やファイルがすぐに消えるわけではありません。ただ、新しいデータがiCloudに上がらないので、iPhoneをなくすとそのデータは残りません。バックアップが止まったときのメッセージ別の対処は、[iPhoneのバックアップができない・容量不足のとき](/blog/ja/iphone-backup-fails)にあります。

## iCloudの容量はどこで確認しますか?

[Appleの案内](https://support.apple.com/en-us/102670)では、iCloudストレージとデバイスのストレージを分けています。確認する場所が違います。

| 種類 | 何か | 確認する場所 |
| --- | --- | --- |
| iCloudストレージ | Apple Accountに付くオンラインの容量 | 「設定」>自分の名前>「iCloud」 |
| デバイスのストレージ | iPhoneの中の容量 | 「設定」>「一般」>「iPhoneストレージ」 |

iCloudの容量は次の手順で確認します。

1. 「設定」アプリを開き、自分の名前をタップします。
2. 「iCloud」をタップします。上のほうに、使っているiCloudストレージの量が表示されます。
3. 「ストレージ」または「ストレージを管理」をタップします。写真、バックアップ、iCloud Drive、メッセージなど項目ごとの使用量が表示されます。

いちばん大きい項目から減らすと効果があります。次の表は、項目ごとにこの記事のどこを読めばよいかをまとめたものです。

| 大きい項目 | 読む部分 |
| --- | --- |
| バックアップ | iCloudバックアップを小さくする方法 |
| 写真 | iCloud写真を削除する前に確認すること |
| iCloud Drive、メッセージ、メール | iCloud Drive、メッセージ、メールの整理 |

## iCloudの容量がいちばん早く空く方法は?

[Appleの案内](https://support.apple.com/en-us/108922)によると、iOS 17以降ではiCloudの設定に「あなたへのおすすめ」があります。不要かもしれない写真、大きなファイル、古いバックアップをまとめて表示します。

1. 「設定」アプリを開き、自分の名前をタップして「iCloud」をタップします。
2. 「あなたへのおすすめ」をタップします。
3. 項目を1つタップし、画面の案内に沿って空きを作ります。

探しているものがおすすめにない場合は、次の方法で自分で削除します。

## iCloudバックアップを小さくするには?

[Appleの案内](https://support.apple.com/en-us/108922)では、使っていないアプリのバックアップをオフにするか、古いバックアップを削除する方法を説明しています。

**アプリのバックアップをオフにする**

1. 「設定」アプリを開き、自分の名前をタップして「iCloud」をタップします。
2. 「ストレージ」または「アカウントのストレージを管理」をタップします。
3. 「バックアップ」をタップし、使っているデバイスの名前をタップします。
4. バックアップしないアプリをオフにし、「オフにする」をタップして確定します。

オフにすると、そのアプリの情報はiCloudからすべて削除されます。常にバックアップされ、オフにできないアプリもあります。

**古いバックアップを削除する**

1. 同じ「バックアップ」の画面で、削除するバックアップのデバイス名をタップします。
2. 「オフにしてiCloudから削除」をタップし、もう一度確定します。

バックアップを削除すると、そのデバイスのiCloudバックアップもオフになります。Appleによると、iCloudバックアップをオフにするか使わなくなってから180日間、バックアップは残ります。いまデバイスの復元に使っているバックアップは削除できません。

iCloud写真を使っていない場合、写真ライブラリはiCloudバックアップに含まれます。「バックアップ」の画面のデバイス名の下で、写真ライブラリの大きさを確かめてください。大きいなら、写真を別のストレージに移してからバックアップすると効果があります。

## iCloud写真を削除する前に確認することは?

[Appleの案内](https://support.apple.com/en-us/108922)には、写真を削除する前に知っておきたい点が3つあります。

| 内容 | 意味 |
| --- | --- |
| すべてのデバイスから消えます | iCloud写真を使っていると、1台で削除した写真は同じApple Accountのほかのデバイスからも消えます |
| 「最近削除した項目」に30日間残ります | このアルバムの項目はiCloudストレージに含まれません |
| 容量を超えるとすぐに消えます | iCloudストレージの上限を超えた状態で削除した写真とビデオは、「最近削除した項目」に残らず、取り戻せません |

そのため、削除する前に残したい写真のコピーを作ります。[Appleの写真のダウンロードの案内](https://support.apple.com/en-us/111762)に沿って、USBメモリにオリジナルを保存する手順です。

1. USBメモリをiPhoneに接続します。
2. 写真アプリでライブラリに移動します。
3. 「選択」をタップし、コピーする写真とビデオを選びます。
4. 共有ボタンをタップし、「未編集のオリジナルを書き出す」をタップします。
5. ファイルアプリがiCloud Driveで開いたら、戻るボタンをタップし、「場所」の下のUSBメモリを選びます。
6. 「保存」をタップします。

「iPhoneのストレージを最適化」をオンにしていると、オリジナルがiPhoneにない場合があります。そのときはオリジナルのダウンロードに時間がかかるので、Wi-Fiに接続してから書き出してください。保存が終わったら、ファイルアプリでUSBメモリを開き、写真を数枚とビデオを1本開いてみます。画面ごとの手順は[iPhoneの写真をUSBに移す方法](/blog/ja/iphone-photos-to-usb)に、パソコンに移す方法は[iPhone写真バックアップをiCloud以外でする方法](/blog/ja/iphone-photo-backup)にあります。

USBメモリがFAT32なら、4GBを超えるビデオは保存できません。[Microsoftのファイルシステム比較表](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison)では、FAT32の1ファイルの最大サイズは4GiBです。長いビデオがあるなら、[exFATフォーマット方法](/blog/ja/format-usb-exfat)でUSBメモリを準備してください。

コピーを確かめたら、写真アプリのライブラリで「選択」をタップし、削除する写真を選んで削除ボタンをタップします。iCloud共有写真ライブラリを使っている場合、共有ライブラリの写真は、ライブラリを作成した人のストレージに含まれます。自分の容量を空けるなら、個人用ライブラリを表示しているか確かめてください。

## iCloud Drive、メッセージ、メールはどう整理しますか?

[Appleの案内](https://support.apple.com/en-us/108922)に沿った手順です。

| 項目 | 削除の手順 | 注意すること |
| --- | --- | --- |
| iCloud Drive | ファイルアプリ>「ブラウズ」>「場所」の下の「iCloud Drive」>その他ボタン>「選択」>ファイルを選ぶ>削除 | すべてのデバイスのiCloud Driveから削除されます。ほかの人の共有フォルダは自分の容量に含まれません |
| メッセージの添付ファイル | 会話の上の相手の名前>「写真」>「編集」>「写真を選択」>削除する画像を選ぶ>「削除」>「添付ファイルを削除」 | iOS 26以降の手順です。メッセージをiCloudに保存している場合にあてはまります |
| メッセージの会話 | 会話を左にスワイプし、削除ボタンをタップしてもう一度「削除」をタップ | 削除した会話は取り戻すのが難しくなります |
| iCloudメール | メールアプリのiCloudの受信ボックス>その他ボタン>整理のおすすめ>iCloudメールのクリーンアップ | オフにするまで、同じ種類のメールを自動で整理し続けます |

iCloud Driveのファイルを削除する前にコピーを残すなら、[AppleのiCloudのデータのコピーを作る案内](https://support.apple.com/en-us/108306)に沿います。ファイルアプリでiCloud Driveを開き、その他ボタン>「選択」でファイルを選んでから、「その他」>「項目をコピー」をタップします。「場所」の下で別の場所を開き、フォルダを長押しして「ペースト」をタップします。

## iCloudの容量を増やすと料金はいくらですか?

削除できるものが少ないなら、iCloud+にアップグレードします。[AppleのiCloud+のプランと料金の案内](https://support.apple.com/en-us/108047)に載っている日本の月額料金です。2026年11月16日に確認した値で、Appleによると税込みです。

| プラン | 月額料金(日本) |
| --- | --- |
| 無料 | 5GB、0円 |
| iCloud+ 50GB | 180円 |
| iCloud+ 200GB | 540円 |
| iCloud+ 2TB | 1,800円 |
| iCloud+ 6TB | 5,500円 |
| iCloud+ 12TB | 11,000円 |

アップグレードすると、毎月請求されます。どのiCloud+プランも、ほかの家族最大5人と共有できます。[AppleのiCloud+購入の案内](https://support.apple.com/en-us/108349)によると、手順はiOSのバージョンによって違います。

| iOSのバージョン | 手順 |
| --- | --- |
| iOS 27以降 | 「設定」>自分の名前>「iCloud」>「ストレージ」(または「ほぼいっぱい」)>「ストレージを追加購入」 |
| iOS 18.4〜iOS 26 | 「設定」>自分の名前>「iCloud」>下にスクロール>「iCloud+にアップグレード」 |

すでにiCloud+を使っているなら、iOS 27以降は「設定」>自分の名前>「iCloud」>「iCloud+の機能」の下の「プランを管理」で変更します。iOS 18.4〜iOS 26は「設定」>自分の名前>「サブスクリプション」>「iCloud+」>「すべてのプランを表示」で変更します。

## 写真をUSBメモリに移しておくなら

写真をUSBメモリに移せば、iCloud写真から削除する写真を選べます。ただ、写真アプリから書き出す方法では、毎回写真と保存先を選ぶ必要があります。連絡先もコピーしておくなら、[iPhone連絡先バックアップの方法](/blog/ja/iphone-contacts-backup)をご覧ください。

NextGenAIが作ったU-Saverは、一般的なUSBメモリに写真、ビデオ、連絡先を保存するアプリで、exFATかFAT32のUSBメモリを使い、iOS 26以降で動作します。U-SaverはApp Storeでの公開を準備中で、韓国での価格は4,900ウォンの買い切りです。U-Saverはメッセージ、アプリのデータ、iPhoneの設定を保存せず、U-Saverで保存したUSBメモリの内容は暗号化されません。購入前に[U-Saverを使う前に確認したい6つのこと](/blog/ja/before-you-buy)をご確認ください。

## iCloudの容量が足りないときのよくある質問

### iCloudの容量がいっぱいになると、iPhoneの写真は消えますか?

Appleの案内によると、いっぱいになると止まるのはバックアップ、新しい写真のアップロード、iCloud Driveの同期、iCloudメールです。iPhoneの写真が消えるという説明はありません。ただし、新しい写真はiCloudにアップロードされません。

### iPhoneストレージとiCloudの容量は同じですか?

違います。iPhoneストレージはiPhoneの中の容量で、iCloudストレージはApple Accountに付くオンラインの容量です。iPhoneの空きが足りないなら、[iPhoneストレージ不足のとき](/blog/ja/iphone-storage-full)をご覧ください。

### 「最近削除した項目」もiCloudの容量を使いますか?

Appleの案内によると、「最近削除した項目」の写真とビデオはiCloudストレージに含まれません。ただし、容量を超えた状態で削除したものはこのアルバムに残らず、すぐに消えます。

### 古いiPhoneのiCloudバックアップは削除してもいいですか?

そのデバイスをもう使わず、バックアップのデータが別の場所にあるなら削除できます。バックアップを削除すると、そのデバイスのiCloudバックアップもオフになります。いまデバイスの復元に使っているバックアップは削除できません。

### プランを上げずに無料の5GBでやりくりできますか?

使っていないアプリのバックアップをオフにし、写真をUSBメモリやパソコンに移してから削除すれば減らせます。写真とビデオが多いと、5GBに収めるのは難しい場合があります。どの項目が大きいかを先に確かめてから判断してください。
