## 핵심 요약

SD 카드 데이터 복구를 찾기 전에 카드에 쓰는 작업부터 멈춥니다. 지운 뒤 새로 찍거나 파일을 넣으면 남은 자료를 덮어쓸 수 있습니다.

그다음 지운 파일이 어디로 갔는지 봅니다. 컴퓨터에서 지웠다면 휴지통을, 아이폰으로 가져온 사진을 지웠다면 사진 앱의 최근 삭제된 항목을 먼저 확인합니다.

그래도 없으면 윈도우에서는 Microsoft의 Windows 파일 복구를 쓸 수 있습니다. 이 글은 이 도구나 다른 복구 프로그램을 시험하지 않았고, 파일을 되찾는다고 약속하지 않습니다.

"필요 없는 사진만 지운다는 게 폴더를 통째로 지웠어요." "카메라에서 전체 삭제를 눌렀어요." 실수로 파일을 지운 뒤 SD 카드 데이터 복구를 검색하는 분들이 자주 하는 말입니다. 지운 기억이 없는데 사진이 안 보이는 경우는 [SD 카드 복구 전에 먼저 할 일](/blog/ko/sd-card-photos-missing)에, 카드가 열리지 않는 경우는 [손상된 SD 카드 복구 전에](/blog/ko/sd-card-corrupted)에 따로 정리했습니다. 이 글은 직접 지운 파일을 찾는 순서를 다룹니다.

## 실수로 지웠다면 왜 카드부터 멈춰야 하나요?

지운 파일이 차지하던 자리는 빈 공간으로 표시되기 때문입니다. [Microsoft의 Windows 파일 복구 안내](https://support.microsoft.com/en-us/windows/recover-lost-files-on-windows-10-61f5b28a-f5b8-3cc2-0f8e-a63cb4e1d4c4)는 지운 파일의 자리가 빈 공간으로 표시되어 자료가 남아 있을 수 있지만, 새 파일이 언제든 그 자리를 덮어쓸 수 있다고 설명합니다. 같은 안내는 되찾을 가능성을 높이려면 사용을 줄이거나 멈추라고 합니다.

1. 카메라나 휴대폰에서 카드를 빼고 그 카드로 더 촬영하지 않습니다.
2. 카드에 새 파일을 복사하지 않습니다.
3. 포맷하지 않습니다. 포맷은 카드의 자료를 모두 지웁니다.
4. 카드를 뺄 때는 꺼내기를 먼저 합니다. [Apple의 Mac SD 카드 슬롯 안내](https://support.apple.com/en-us/102352)는 Mac이 잠자기 상태일 때 카드를 빼면 데이터를 잃을 수 있다고 설명합니다.

## 어디에서 지웠는지에 따라 무엇을 확인하나요?

지운 곳에 따라 먼저 볼 곳이 다릅니다. 아래 표는 상황별로 확인할 곳을 정리한 것입니다.

| 지운 곳 | 먼저 확인할 곳 | 참고 |
| --- | --- | --- |
| Mac의 Finder | Dock의 휴지통 | 휴지통을 비우면 영구 삭제됩니다 |
| 윈도우 파일 탐색기 | 휴지통 | 없으면 Windows 파일 복구를 검토합니다 |
| 아이폰 사진 앱(가져온 사진) | 최근 삭제된 항목 | 30일이 지나면 영구 삭제됩니다 |
| 카메라·휴대폰의 삭제 메뉴 | 기기 설명서 | 기기마다 동작이 다릅니다 |
| 포맷으로 지움 | 카드 제조사 안내 | 이 글의 범위 밖입니다 |

이 글은 특정 카드, 리더, 복구 프로그램을 시험하지 않았고 특정 제품을 추천하지 않습니다.

## Mac에서 지운 파일은 휴지통에 있나요?

Mac에서는 휴지통을 비우기 전까지 항목이 지워지지 않습니다. [Apple의 Mac 파일 삭제 안내](https://support.apple.com/guide/mac-help/delete-files-and-folders-on-mac-mchlp1093/mac)는 휴지통으로 옮긴 항목은 휴지통을 비울 때까지 지워지지 않는다고 설명합니다.

1. Dock에서 휴지통 아이콘을 클릭합니다.
2. 되돌릴 항목을 휴지통 밖으로 끌어내거나, 항목을 고른 뒤 파일 메뉴에서 되돌려 놓기를 고릅니다.
3. 되찾은 파일은 Mac이나 다른 저장장치에도 사본을 만듭니다.

같은 안내는 휴지통에서 비운 항목은 영구 삭제되어 더는 쓸 수 없다고 경고합니다. Finder 설정의 고급에서 30일 후 자동 제거 옵션을 켰다면 30일 뒤 자동으로 영구 삭제됩니다. Mac에 카드를 연결하는 순서는 [Mac SD 카드 사용법](/blog/ko/sd-card-on-mac)에 있습니다.

## 아이폰으로 가져온 사진을 지웠다면?

카드에서 아이폰 사진 앱으로 가져온 뒤 아이폰에서 지웠다면 최근 삭제된 항목을 봅니다. 가져오기 순서는 [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader)에 있습니다.

1. 아이폰 사진 앱을 열고 최근 삭제된 항목을 찾습니다.
2. 되찾을 사진을 고르고 복구합니다.
3. 찾은 사진은 아이폰 밖의 다른 저장장치에도 사본을 만듭니다.

[Apple의 iCloud 사진 안내](https://support.apple.com/en-us/108782)는 실수로 지운 항목을 최근 삭제된 항목에서 30일 동안 되찾을 수 있고, 그 뒤에는 영구 삭제된다고 설명합니다. 같은 안내는 iCloud 사진을 켠 상태에서 한 기기에서 지우면 iCloud 사진을 쓰는 모든 기기에서 지워진다고 설명합니다.

## 윈도우에서 휴지통에도 없다면 무엇을 쓸 수 있나요?

Microsoft는 Windows 파일 복구라는 명령줄 앱을 Microsoft Store에서 제공합니다. [Microsoft의 Windows 파일 복구 안내](https://support.microsoft.com/en-us/windows/recover-lost-files-on-windows-10-61f5b28a-f5b8-3cc2-0f8e-a63cb4e1d4c4)는 백업에서도 찾지 못하고 휴지통에서도 되돌릴 수 없는 파일에 쓰라고 설명합니다. 대상은 내장 드라이브, 외장 드라이브, USB 장치 같은 로컬 저장장치입니다. 클라우드와 네트워크 공유는 지원하지 않습니다.

SD 카드에서 쓸 때 알아 둘 조건은 아래와 같습니다.

| 항목 | Microsoft 안내 |
| --- | --- |
| 지원 윈도우 | 윈도우 11, 윈도우 10 |
| SD 카드의 파일 시스템 | 보통 FAT 또는 exFAT입니다 |
| FAT·exFAT에서 쓸 모드 | 확장(Extensive) 모드만 지원합니다 |
| 저장 위치 | 원본과 다른 드라이브여야 합니다 |
| 결과 폴더 | 저장할 드라이브에 Recovery_날짜와 시간 폴더가 생깁니다 |

카드의 파일 시스템은 파일 탐색기에서 드라이브를 마우스 오른쪽 버튼으로 클릭하고 속성을 고르면 볼 수 있습니다. 안내에 따른 기본 순서는 아래와 같습니다.

1. Microsoft Store에서 Windows 파일 복구를 설치합니다.
2. Windows 키를 누르고 검색창에 Windows File Recovery를 입력한 뒤 앱을 고릅니다.
3. 앱이 장치를 변경하도록 허용할지 물으면 예를 고릅니다.
4. 명령 프롬프트 창에 `winfr 원본드라이브: 저장드라이브: /extensive` 형식으로 입력합니다. 예를 들어 카드가 E:이고 사진만 C:로 찾으려면 `winfr E: C: /extensive /n *.JPG`처럼 입력합니다.
5. 계속할지 물으면 Y를 입력합니다. 멈추려면 Ctrl + C를 누릅니다.

같은 안내는 찾지 못했다면 빈 공간이 이미 덮어쓰였을 수 있다고 설명합니다. 이 글은 Windows 파일 복구를 직접 시험하지 않았습니다. 윈도우에 카드를 연결하는 순서는 [SD 카드 컴퓨터 연결 방법](/blog/ko/sd-card-to-pc)에 있습니다.

## 다른 복구 프로그램이나 업체는 어떻게 고르나요?

이 글은 특정 복구 프로그램이나 업체를 추천하지 않습니다. [SD Association FAQ](https://www.sdcard.org/consumers/faq/)는 지운 사진을 되찾는 방법은 카드 제조사의 안내를 보라고 답합니다. SD Association은 사진을 되찾는 도구를 제공하지 않는다고도 밝힙니다.

어떤 방법을 쓰든 아래 두 가지는 지킵니다.

1. 되찾은 파일을 같은 카드에 저장하지 않습니다. 카드에 다시 쓰는 작업이 됩니다.
2. 되찾은 파일이 열리는지 다른 저장장치에서 확인합니다.

## 다음에는 실수로 지운 파일을 어떻게 막나요?

카드 하나에만 파일을 두지 않는 것이 기본입니다. 촬영을 마치면 컴퓨터나 다른 저장장치로 복사하고, 복사한 파일이 열리는지 확인한 뒤에 카드를 비웁니다.

| 습관 | 이유 |
| --- | --- |
| 지우기 전에 다른 곳에 사본 만들기 | Apple은 나중에 필요할 경우를 대비해 저장장치에 백업 사본을 두라고 안내합니다 |
| 휴지통은 확인한 뒤에 비우기 | 비운 항목은 영구 삭제됩니다 |
| 카드를 비우는 순서 미리 알아 두기 | 순서는 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에 있습니다 |

## 아이폰 사진을 USB 메모리에도 저장해 두려면?

아이폰으로 가져온 사진도 한 곳에만 두면 같은 실수로 잃을 수 있습니다. 다른 저장장치에 사본을 하나 더 만들어 두세요. 아래 앱은 USB 메모리를 기준으로 안내합니다. USB 형식을 바꾸는 순서는 [exFAT 포맷 방법](/blog/ko/format-usb-exfat)에, 옮기는 순서는 [아이폰 사진 USB로 옮기기](/blog/ko/iphone-photos-to-usb)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비 중이며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## SD 카드 데이터 복구 자주 묻는 질문

### SD 카드에서 파일을 실수로 지우면 가장 먼저 무엇을 하나요?

카드를 기기에서 빼고 더 촬영하거나 복사하지 않습니다. 새 파일이 지운 파일의 자리를 덮어쓸 수 있습니다.

### Mac에서 지운 카드 파일은 어디서 찾나요?

Dock의 휴지통을 봅니다. 휴지통을 비우지 않았다면 항목을 끌어내거나 되돌려 놓기를 고릅니다.

### 윈도우 휴지통에도 없으면요?

Microsoft Store의 Windows 파일 복구를 쓸 수 있습니다. SD 카드처럼 FAT·exFAT인 드라이브는 확장 모드만 지원하고, 결과는 다른 드라이브에 저장해야 합니다.

### 아이폰에서 지운 사진은 언제까지 되찾을 수 있나요?

Apple은 최근 삭제된 항목에서 30일 동안 되찾을 수 있다고 설명합니다. 그 뒤에는 영구 삭제됩니다.

### 되찾은 파일을 원래 카드에 다시 넣어도 되나요?

작업이 끝나기 전에는 넣지 마세요. 카드에 쓰는 작업이 남은 자료를 덮어쓸 수 있습니다. 다른 저장장치에 먼저 저장합니다.
