## この記事の要点

SDカードの消えたデータを復元する前に、まずカードへの書き込みを止めます。削除したあとに撮影したりファイルを入れたりすると、残っているデータを上書きするおそれがあります。

次に、削除したファイルがどこへ行ったかを確かめます。パソコンで削除したならゴミ箱を、iPhoneに読み込んだ写真を削除したなら写真アプリの「最近削除した項目」を先に見ます。

それでも見つからなければ、WindowsではMicrosoftのWindows File Recoveryを使えます。この記事ではこのツールもほかの復元ソフトも試しておらず、ファイルが戻ると約束しません。

「いらない写真だけ消すつもりが、フォルダーごと削除した」「カメラで全削除を押してしまった」。SDカードの消えたデータを復元したいと検索する人からよく聞く声です。削除した覚えがないのに写真が見えない場合は[SDカードのデータが消えたときに最初にすること](/blog/ja/sd-card-photos-missing)に、カードが開けない場合は[壊れたSDカードの復元を試す前に](/blog/ja/sd-card-corrupted)に別にまとめました。この記事では、自分で削除したファイルを探す手順を扱います。

## 誤って削除したら、なぜまずカードを止めるのですか?

削除したファイルが使っていた場所は、空き領域として扱われるからです。[MicrosoftのWindows File Recoveryの案内](https://support.microsoft.com/en-us/windows/recover-lost-files-on-windows-10-61f5b28a-f5b8-3cc2-0f8e-a63cb4e1d4c4)は、削除したファイルの場所は空き領域として扱われ、データが残っている可能性はあるものの、新しいファイルがいつでも上書きしうると説明しています。同じ案内は、取り戻せる可能性を高めるには使用を減らすか止めるよう書いています。

1. カメラやスマホからカードを抜き、そのカードでこれ以上撮影しません。
2. カードに新しいファイルをコピーしません。
3. フォーマットしません。フォーマットはカードのデータをすべて消します。
4. カードを抜く前に取り出しをします。[AppleのMac SDカードスロットの案内](https://support.apple.com/en-us/102352)は、Macがスリープ中にカードを抜くとデータを失うおそれがあると説明しています。

## どこで削除したかによって、何を確認しますか?

削除した場所によって、先に見る場所が変わります。下の表は、状況ごとの確認先をまとめたものです。

| 削除した場所 | 先に確認する場所 | 補足 |
| --- | --- | --- |
| MacのFinder | Dockのゴミ箱 | ゴミ箱を空にすると完全に削除されます |
| Windowsのエクスプローラー | ごみ箱 | なければWindows File Recoveryを検討します |
| iPhoneの写真アプリ(読み込んだ写真) | 最近削除した項目 | 30日を過ぎると完全に削除されます |
| カメラやスマホの削除メニュー | 機器の説明書 | 機器によって動作が違います |
| フォーマットで消した | カードメーカーの案内 | この記事の範囲外です |

この記事では特定のカード、カードリーダー、復元ソフトを試しておらず、特定の製品をすすめません。

## Macで削除したファイルはゴミ箱にありますか?

Macでは、ゴミ箱を空にするまで項目は削除されません。[AppleのMacでファイルを削除する案内](https://support.apple.com/guide/mac-help/delete-files-and-folders-on-mac-mchlp1093/mac)は、ゴミ箱に入れた項目はゴミ箱を空にするまで削除されないと説明しています。

1. Dockのゴミ箱アイコンをクリックします。
2. 戻したい項目をゴミ箱の外にドラッグするか、項目を選んでファイルメニューの「戻す」を選びます。
3. 戻したファイルは、Macや別の記憶装置にもコピーを作ります。

同じ案内は、ゴミ箱から消去した項目は完全に削除され、使えなくなると注意しています。Finderの設定の詳細で30日後に自動で削除する設定をオンにしていれば、30日後に完全に削除されます。Macにカードをつなぐ手順は[MacでSDカードを使う方法](/blog/ja/sd-card-on-mac)にあります。

## iPhoneに読み込んだ写真を削除したときは?

カードからiPhoneの写真アプリに読み込んだあと、iPhoneで削除したなら「最近削除した項目」を見ます。読み込みの手順は[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)にあります。

1. iPhoneで写真アプリを開き、「最近削除した項目」を探します。
2. 取り戻したい写真を選んで戻します。
3. 見つかった写真は、iPhoneの外の別の記憶装置にもコピーを作ります。

[AppleのiCloud写真の案内](https://support.apple.com/en-us/108782)は、うっかり削除した項目は「最近削除した項目」から30日間取り戻せ、そのあとは完全に削除されると説明しています。同じ案内は、iCloud写真をオンにしていると、1台で削除した写真はiCloud写真を使うすべての機器から削除されると説明しています。

## Windowsでごみ箱にもないときは、何を使えますか?

Microsoftは、Windows File RecoveryというコマンドラインのアプリをMicrosoft Storeで提供しています。[MicrosoftのWindows File Recoveryの案内](https://support.microsoft.com/en-us/windows/recover-lost-files-on-windows-10-61f5b28a-f5b8-3cc2-0f8e-a63cb4e1d4c4)は、バックアップにもなく、ごみ箱からも戻せないファイルに使うよう説明しています。対象は内蔵ドライブ、外付けドライブ、USBデバイスなどのローカルの記憶装置です。クラウドとネットワーク共有には対応していません。

SDカードで使うときに知っておく条件は次のとおりです。

| 項目 | Microsoftの案内 |
| --- | --- |
| 対応するWindows | Windows 11、Windows 10 |
| SDカードのファイルシステム | 多くはFATかexFATです |
| FAT・exFATで使うモード | 拡張(Extensive)モードのみ対応します |
| 保存先 | 元とは別のドライブにします |
| 結果のフォルダー | 保存先のドライブに `Recovery_<日付と時刻>` フォルダーができます |

カードのファイルシステムは、エクスプローラーでドライブを右クリックし、「プロパティ」を選ぶと確認できます。案内に沿った基本の手順は次のとおりです。

1. Microsoft StoreからWindows File Recoveryをインストールします。
2. Windowsキーを押し、検索ボックスにWindows File Recoveryと入力してアプリを選びます。
3. アプリがデバイスに変更を加えることを許可するか聞かれたら、「はい」を選びます。
4. コマンドプロンプトの画面で、`winfr 元のドライブ: 保存先のドライブ: /extensive` の形式で入力します。たとえばカードがE:で、JPGの写真だけをC:に保存するなら `winfr E: C: /extensive /n *.JPG` と入力します。
5. 続けるか聞かれたらYを入力します。止めるときはCtrl + Cを押します。

同じ案内は、取り戻せなかった場合は空き領域がすでに上書きされている可能性があると説明しています。この記事ではWindows File Recoveryを自分たちで試していません。Windowsパソコンにカードをつなぐ手順は[SDカードをパソコンにつなぐ方法](/blog/ja/sd-card-to-pc)にあります。

## ほかの復元ソフトや業者はどう選べばいいですか?

この記事では特定の復元ソフトや業者をすすめません。[SD Associationのよくある質問](https://www.sdcard.org/consumers/faq/)は、消した写真を取り戻す方法はカードメーカーの案内を見るよう答えています。SD Associationは写真を取り戻すツールを提供していないとも書いています。

どの方法を使う場合も、次の2つは守ります。

1. 取り戻したファイルを同じカードに保存しません。カードにまた書き込むことになります。
2. 取り戻したファイルが開けるか、別の記憶装置で確かめます。

## 次に誤って削除しないためには?

ファイルを1枚のカードだけに置かないことが基本です。撮影が終わったらパソコンや別の記憶装置にコピーし、コピーしたファイルが開けるか確かめてから、カードを空にします。

| 習慣 | 理由 |
| --- | --- |
| 削除する前に別の場所へコピーを作る | Appleは、あとで必要になる場合に備えて記憶装置にバックアップのコピーを置くよう案内しています |
| ゴミ箱は中身を確かめてから空にする | 空にした項目は完全に削除されます |
| カードを空にする手順を先に知っておく | 手順は[SDカードフォーマット方法](/blog/ja/format-sd-card)にあります |

## iPhoneの写真をUSBメモリにも保存しておくには?

iPhoneに読み込んだ写真も、1か所だけに置いていると同じ失敗で失うおそれがあります。別の記憶装置にもう1つコピーを作っておきましょう。以下のアプリはUSBメモリを前提に説明します。形式を変える手順は[exFATフォーマット方法](/blog/ja/format-usb-exfat)に、移す手順は[iPhoneの写真をUSBに移す方法](/blog/ja/iphone-photos-to-usb)にあります。

NextGenAIが作ったU-Saverは、一般的なUSBメモリに写真、ビデオ、連絡先を保存するアプリで、exFATかFAT32のUSBメモリを使い、iOS 26以降で動作します。U-SaverはApp Storeでの公開を準備しており、韓国での価格は4,900ウォンの買い切りです。U-Saverはメッセージ、アプリのデータ、iPhoneの設定は保存せず、U-Saverで保存したUSBメモリの内容は暗号化されません。購入前に[U-Saverを使う前に確認したい6つのこと](/blog/ja/before-you-buy)をご確認ください。

## SDカードの消えたデータの復元でよくある質問

### SDカードのファイルを誤って削除したら、最初に何をしますか?

機器からカードを抜き、これ以上撮影やコピーをしません。新しいファイルが、削除したファイルの場所を上書きするおそれがあります。

### Macで削除したカードのファイルはどこで探しますか?

Dockのゴミ箱を見ます。ゴミ箱を空にしていなければ、項目をドラッグして出すか「戻す」を選びます。

### Windowsのごみ箱にもないときは?

Microsoft StoreのWindows File Recoveryを使えます。SDカードに多いFAT・exFATのドライブは拡張モードのみ対応し、結果は別のドライブに保存します。

### iPhoneで削除した写真はいつまで取り戻せますか?

Appleは「最近削除した項目」から30日間取り戻せると説明しています。そのあとは完全に削除されます。

### 取り戻したファイルを元のカードに戻してもいいですか?

作業が終わるまでは戻さないでください。カードへの書き込みが、残っているデータを上書きするおそれがあります。先に別の記憶装置へ保存します。
