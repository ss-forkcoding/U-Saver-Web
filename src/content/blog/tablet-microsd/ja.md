## この記事の要点

タブレットのSDカードは、ほとんどがmicroSDです。Fireタブレットは第5世代以降の対応機種でmicroSDを使え、最大容量は世代ごとに200GBから1TBまで違います。

FireタブレットやAndroidタブレットでは、カードを初めて挿すときに外部(ポータブル)ストレージか内部ストレージかを選びます。内部ストレージにしたカードは、再フォーマットしないかぎり別の端末で使えません。

Galaxy Tabは扱いが違います。SamsungはAndroid端末でカードを内部ストレージに組み込む機能に対応していないと説明しています。

「このタブレットには何GBのカードまで入るの?」「カードを挿したら使い方を聞かれたけれど、どちらを選べばいい?」。タブレットに初めてmicroSDを入れる方からよく出る質問です。この記事ではタブレットに絞って説明します。スマートフォンについては[スマホのSDカードの使い方](/blog/ja/android-microsd)と[Galaxy SDカードのスロットと設定](/blog/ja/galaxy-sd-card)にまとめました。

## タブレットのSDカードは何GBまで使えますか?

機種と世代で違います。Fireタブレットは[Amazonのトラブルシューティングの案内](https://www.amazon.co.jp/gp/help/customer/display.html?nodeId=GN5X9QEFQHZHZXLU)に世代ごとの上限があります。

| Fireタブレットの世代 | 最大容量 |
| --- | --- |
| 第5世代、第6世代 | 200GBまで |
| 第7世代 | 256GBまで |
| 第8世代、第9世代 | 512GBまで |
| 第10世代以降 | 1TBまで |

同じ案内は、カードがUHSであること、UHSでなければClass 4以上であることを確かめるよう書いています。Fire Max 11は、イジェクトピンホールを使ってカードを出し入れします。速度表示の見方は[SDカードのスピードクラスの見方](/blog/ja/sd-card-speed-class)にまとめました。

Galaxy Tabは[Samsungアイルランドのタブレット用メモリーカードの表](https://www.samsung.com/ie/support/mobile-devices/what-size-memory-card-does-my-galaxy-tablet-accept/)で確かめます。

| 機種 | 外部メモリーの最大容量 | カードの種類 |
| --- | --- | --- |
| Galaxy Tab S7+ | 1TBまで | microSD |
| Galaxy Tab S7 | 1TBまで | microSD |
| Galaxy Tab S7 FE | 1TBまで | microSD |
| Galaxy Tab S6 | 1TBまで | microSD |
| Galaxy Tab S5e | 512GBまで | microSD |
| Galaxy Tab S4 10.5 | 400GBまで | microSD |
| Galaxy Tab S3 | 256GBまで | microSD |
| Galaxy Tab A7 | 1TBまで | microSD |

この表はイギリス・アイルランドの機種が基準です。同じ案内は地域によって仕様が違う場合があるとして、機種ごとの仕様ページを確かめるよう書いています。容量の規格は[SDHCとSDXCの違い](/blog/ja/sdhc-vs-sdxc)にあります。この記事は特定のカードを試しておらず、おすすめもしていません。

## Fireタブレットでは外部と内部ストレージのどちらを選びますか?

ほかの端末とファイルをやり取りするなら外部(ポータブル)ストレージです。[AmazonのFireタブレットのmicroSDカードの案内](https://www.amazon.co.jp/gp/help/customer/display.html?nodeId=GMRDCX9BUV3L7TKA)によると、カードを初めて挿すときにどちらかを指定します。同じ案内は、FireタブレットがFAT32ファイルシステムにのみ対応していると書いています。

| 方式 | 向いている使い方 | 注意すること |
| --- | --- | --- |
| ポータブルストレージ | ファイル、写真、ビデオを端末間で移すとき | 著作権で保護された映画や音楽は、ほかの端末に移せない場合があります |
| 内部ストレージ | タブレットのストレージを増やすとき | カードがフォーマットされ、再フォーマットしてデータを消さないかぎり別の端末で使えません |

同じ案内によると、KindleとPrime Videoのアプリはポータブルストレージにのみ対応しています。内部ストレージを選ぶと、ファイルをすぐカードに移すかを聞かれます。この手順を飛ばすと、コンテンツはタブレットに保存されたままです。設定は後からFireタブレットの設定で変えられます。

アプリについては案内ごとに書き方が違います。上の案内は内部ストレージがアプリやゲームのストレージに対応すると書き、[トラブルシューティングの案内](https://www.amazon.co.jp/gp/help/customer/display.html?nodeId=GN5X9QEFQHZHZXLU)はFire OS 6以降のタブレットではmicroSDカードにアプリやゲームをインストールできないと書いています。アプリをカードに置きたい場合は、自分の機種の設定画面を先に確かめてください。

## Galaxy TabではSDカードをどう使いますか?

独立したストレージとして使います。[Samsungアメリカのサポート](https://www.samsung.com/us/support/answer/ANS10001928/)はスマートフォンとタブレットをまとめて説明しています。

| 項目 | Samsungの案内 |
| --- | --- |
| 対応 | すべてのSamsung端末がmicroSDに対応するわけではありません |
| 内部ストレージへの組み込み | Samsung製Android端末はAdoptable storageに対応していません |
| 使える形式 | FAT32かexFAT、exFATを推奨 |
| FAT32 | 32GB未満のカードのみ、4GBを超えるファイルは保存できません |

フォーマット、マウント解除、暗号化は、Galaxyのスマートフォンと同じストレージ設定にあります。手順は[Galaxy SDカードのスロットと設定](/blog/ja/galaxy-sd-card)にまとめました。メニュー名はOne UIのバージョンで違います。

## Androidタブレットの外部ストレージと内部ストレージの違いは?

カードを別の端末に移せるかどうかが違います。[GoogleのAndroidヘルプ](https://support.google.com/android/answer/12153449?hl=ja)の説明です。

| 項目 | 外部ストレージ | 内部ストレージ |
| --- | --- | --- |
| 写真や動画の保存 | できます | できます |
| アプリのインストール | できません | できます |
| 端末間でカードを移す | できます | できません |

新しいカードを設定する手順です。フォーマットするとカード内のデータは完全に削除されるので、先にバックアップします。

1. 画面を上から下にスワイプします。
2. 「SDカードが検出されました」という通知をタップします。
3. 外部ストレージにするなら[フォーマット]、内部ストレージにするなら[別の方法でフォーマット]を選びます。
4. フォーマットが終わったら、[コンテンツを移動]か[後で移動]を選びます。

使っているカードの方式を変えるときは、設定アプリのストレージからSDカードを開き、右上のメニューから操作します。変えるときもカードはフォーマットされます。メニュー名はメーカーごとに違います。

## タブレットからmicroSDを取り出すには?

先に取り外しの操作をしてから抜きます。

| 端末 | 取り出し方 | 出典 |
| --- | --- | --- |
| Fireタブレット(ポータブルストレージ) | 設定 > ストレージで安全に取り出します。強制的に抜くとデータが失われる場合があります | [Amazonの案内](https://www.amazon.co.jp/gp/help/customer/display.html?nodeId=GMRDCX9BUV3L7TKA) |
| Fireタブレット(内部ストレージ) | 取り出すことは想定されていません。「microSDカードを削除」を選ぶと、映画、本、アプリなどカードのデータはすべて失われます | 同じ案内 |
| Galaxy Tab | ストレージ設定かマイファイルアプリでマウントを解除します | [Galaxy SDカードのマウント解除](/blog/ja/galaxy-sd-card) |

Fireタブレットで内部ストレージのカードを強制的に抜くと、ポップアップメッセージが繰り返し表示されます。Amazonの案内によると、カードを挿し直すか、カードを削除すると表示が消えます。

## タブレットがmicroSDを認識しないときは?

順番に確かめます。[Amazonのトラブルシューティングの案内](https://www.amazon.co.jp/gp/help/customer/display.html?nodeId=GN5X9QEFQHZHZXLU)はFireタブレット向けですが、ほかのタブレットでも同じ順番で確かめられます。

1. カードの容量がタブレットの上限内か確かめます。
2. カードをアンマウントして挿し直します。
3. スマートフォンや別のタブレットでカードが動くか確かめます。
4. 別のmicroSDカードで試します。

フォーマットで直す場合は、先にデータを別の場所へ移します。パソコンでのフォーマット方法は[microSDカードのフォーマット方法](/blog/ja/format-microsd)に、カードの確認手順は[SDカードが認識しないとき](/blog/ja/sd-card-not-working)にあります。

## iPadにもmicroSDのスロットはありますか?

ありません。iPadは充電端子にカードリーダーを挿し、写真アプリかファイルアプリでカードを開きます。[Appleのカメラアダプタの案内](https://support.apple.com/en-us/118280)の対応カードにmicroSDがあります。手順は[iPadでSDカードを使う方法](/blog/ja/ipad-sd-card)にまとめました。

タブレットで使ったカードをiPhoneで読むなら、形式を確かめます。[Appleの外部ストレージの案内](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)によると、iPhoneはAPFS、Mac OS拡張、exFAT、FAT32、FATを読めます。iPhoneでの使い方は[iPhoneでmicroSDを使う方法](/blog/ja/iphone-microsd)にあります。

## タブレットのSDカードのよくある質問

### FireタブレットでexFATのカードは使えますか?

Amazonの案内は、FireタブレットがFAT32ファイルシステムにのみ対応していると書いています。exFATのカードについての説明はないので、FAT32を前提に準備してください。[Microsoftのファイルシステム比較表](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison)によると、FAT32は4GiBを超えるファイルを保存できません。

### Galaxy Tab S7は何TBのカードまで使えますか?

Samsungの表では、Galaxy Tab S7のmicroSDは1TBまでです。地域で仕様が違う場合があるので、仕様ページで確かめてください。

### 内部ストレージにしたカードを別の端末で開けますか?

開けません。GoogleとAmazonの案内はどちらも、内部ストレージのカードは端末間で移せないと書いています。別の端末で使うには再フォーマットが必要で、データは消えます。

### Prime Videoの動画をカードに保存できますか?

Amazonの案内によると、KindleとPrime Videoのアプリはポータブルストレージにのみ対応しています。これらのアプリで使うならポータブルストレージに設定します。

### タブレットのmicroSDカードの中身は暗号化されますか?

Microsoftの比較表では、FAT32とexFATはファイルシステム単位の暗号化に対応していません。Galaxy TabにはSDカードを暗号化する設定が別にあります。カードをなくすとほかの人が中身を見られるので、保管に気をつけてください。
