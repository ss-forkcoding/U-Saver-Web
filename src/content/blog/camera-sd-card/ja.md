## この記事の要点

カメラのSDカードは、おすすめの製品名ではなくカメラの説明書で選びます。説明書のメモリーカードの項目に、カードの大きさ、容量規格、動画形式ごとのスピードクラスが書かれています。

写真だけなら、カメラが対応するSD、SDHC、SDXCカードで足ります。動画は画質とビットレートに応じて、U3、V30、V60、V90などの表示が必要です。

V60とV90はUHS-II以上の方式で使います。カメラがUHS-Iにしか対応していなければ、UHS-IIカードもUHS-Iの速度で動きます。

「4K動画にはどのカードが要りますか?」「容量はどれくらいがいいですか?」カメラを買うと、まずこうした疑問が出てきます。この記事では、カメラ用SDカードを選ぶときに確かめる表示と順番をまとめます。特定の製品はおすすめせず、カードを実際に試してもいません。SDカード全体の基礎は[SDカードの基礎総まとめ](/blog/ja/sd-card-basics-guide)にあります。

## カメラ用SDカードは何から確かめますか?

次の5つを確かめます。

| 確かめること | 例 | どこで見るか |
| --- | --- | --- |
| カードの大きさ | SD、microSD | カメラの説明書、カードスロット |
| 容量規格 | SDHC、SDXC、SDUC | 説明書の対応カード一覧 |
| バスインターフェース | UHS-I、UHS-II、SD Express | 説明書の対応カード一覧 |
| スピードクラス | Class 10、U3、V30、V60、V90 | 動画形式ごとの対応カード表 |
| スロットとファイルシステム | スロット2つ、exFAT、FAT32 | 説明書のメモリーカードの注意 |

[SD Associationの容量の案内](https://www.sdcard.org/consumers/sd-sdhc-sdxc-and-sduc-card-capacity-choices/)は、カードを入れる前に機器のSDロゴや記号を探すか、説明書やメーカーの情報で対応を確かめるよう案内しています。

## カメラの説明書のカード条件はどう読みますか?

説明書は撮影方法ごとに必要なカードを分けて書いています。たとえば[Sony α7 IVのヘルプガイド](https://helpguide.sony.net/ilc/2110/v1/en/contents/TP1000640149.html)には次のように書かれています。

| 撮影 | 最大ビットレート | 必要なSDカード |
| --- | --- | --- |
| 静止画 | — | SD、SDHC、SDXC |
| XAVC S 4K動画 | 200Mbps | SDHC・SDXC(U3/V30以上) |
| XAVC S HD動画 | 100Mbps | SDHC・SDXC(U3/V30以上) |
| XAVC S-I 4K動画 | 600Mbps | SDXC V90以上 |
| XAVC S 4Kスロー&クイックモーション | 200Mbps | SDXC V60以上 |

同じヘルプガイドには、ビットレートが60Mbps以下ならClass 10のSDHC・SDXCカードでも記録できると書かれています。この機種はUHS-IとUHS-IIのSDカードに対応し、microSDはアダプターを付けて使います。

この表は1機種の例です。同じメーカーでも機種によって条件は違います。お使いのカメラの説明書の表に従ってください。

## 動画の画質ごとにカメラ用SDカードの速度はどれが必要ですか?

[SD AssociationのFAQ](https://www.sdcard.org/consumers/faq/)は、スピードクラスごとの主な用途を次のように示しています。

| 表示 | 主な用途 |
| --- | --- |
| Class 6、V6 | SD〜HD動画の記録 |
| Class 10、U1、V10 | HD〜フルHD動画の記録 |
| U3、V30 | フルHD〜4K動画の記録 |
| V60 | 4K〜8K動画の記録 |
| V90 | 8K動画の記録 |

[SD Associationのスピードクラスの案内](https://www.sdcard.org/consumers/speed-class-standards-for-video-recording/)によると、動画には一定の書き込み速度が必要です。スピードクラスは決められた条件で最低限の連続書き込み性能を保証します。パッケージの「最大○○MB/s」は最低保証の値ではありません。

Sonyの例のように、同じ4Kでもビットレートが高いほど高い表示が必要です。表示の読み方は[SDカードのV30とは?](/blog/ja/sd-card-speed-class)にまとめました。

## カメラ用SDカードの容量はSDHCとSDXCのどちらにしますか?

SD Associationは容量規格を次のように分けています。

| 規格 | 容量 | ファイルシステム |
| --- | --- | --- |
| SD | 2GB以下 | FAT12、FAT16 |
| SDHC | 2GB超〜32GB | FAT32 |
| SDXC | 32GB超〜2TB | exFAT |
| SDUC | 2TB超〜128TB | exFAT |

カメラが対応する規格の中から選びます。SD Associationによると、SDXC機器ではSD、SDHC、SDXCカードを使えます。SDXCカードはSDXCかSDUCの機器でしか使えません。SDHCまでしか対応しないカメラにはSDXCカードを使わないでください。

規格は動画ファイルにも関わります。Sony α7 IVのヘルプガイドには、SDHCカードでXAVC S動画を長時間撮ると4GBごとにファイルが分かれると書かれています。2つのスロットに同時記録するときは、ファイルシステムが同じカードを2枚入れます。exFATとFAT32のカードを組み合わせると同時記録はできません。規格の違いは[SDXCとは?SDHC・SDUCとの違い](/blog/ja/sdhc-vs-sdxc)をご覧ください。

## カメラにUHS-IIのSDカードは必要ですか?

カメラがV60やV90を求めるなら、UHS-II以上のカードが必要です。SD Associationの表では、UHS-IモードはV30まで、UHS-II・UHS-IIIモードはV90まで使います。

| カメラの方式 | 使える動画向け表示 |
| --- | --- |
| UHS-I | U1、U3、V6、V10、V30 |
| UHS-II、UHS-III | U1、U3、V6、V10、V30、V60、V90 |
| SD Express | E150、E300、E450、E600 |

カメラがUHS-Iにしか対応していなければ、UHS-IIカードを入れてもUHS-Iの速度で動きます。パソコンへ移すときも、リーダーがUHS-IIに対応していないとUHS-IIの速度は出ません。組み合わせは[UHSスピードクラスとは?](/blog/ja/uhs-sd-card)にあります。

## カメラ用SDカードはどんな順番で選びますか?

1. カメラの説明書でメモリーカードの項目を探します。
2. カードの大きさを確かめます。SDスロットでmicroSDを使うにはアダプターが必要です。違いは[micro SDとは?](/blog/ja/microsd-vs-sd)にあります。
3. 対応する容量規格(SDHC、SDXC)を確かめます。
4. よく撮る動画形式とビットレートを決め、表で合うスピードクラスを探します。
5. その表示がV60かV90なら、カメラとカードがUHS-IIに対応しているか確かめます。
6. 同じ系統で、同じか高い表示のカードを選びます。
7. 2つのスロットを一緒に使うなら、ファイルシステムが同じカードを用意します。

正規品を買うことも大切です。容量を偽ったカードでは写真が保存されないことがあります。確かめ方は[SDカードの偽物の見分け方](/blog/ja/fake-sd-card)にまとめました。

## 新しいカメラ用SDカードはどう準備しますか?

SD Associationは、SD、SDHC、SDXCカードにはOSの一般的なフォーマットツールではなくSD Memory Card Formatterを使うよう強く勧めています。一般的なツールでは性能が十分に出ないことがあると説明しています。カメラ本体でフォーマットする方法は、カメラの説明書に従ってください。

フォーマットするとカードのデータはすべて消えます。使っていたカードなら、写真と動画を先に別の場所へコピーしてください。形式の選び方と手順は[SDカードフォーマット方法](/blog/ja/format-sd-card)にあります。

## カメラの写真をiPhoneに移すには?

iPhoneにはカードスロットがないので、カードリーダーを使います。[Appleのカメラアダプタの案内](https://support.apple.com/en-us/118280)によると、Apple USB-C - SDカードリーダーやLightning - SDカードカメラリーダーでSDカードの写真とビデオを読み込めます。対応カードにはSDSC、SDHC、SDXC、microSDがあります。

接続と読み込みの手順は[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)をご覧ください。

## カメラ用SDカードのよくある質問

### 写真だけでもV90カードが必要ですか?

説明書によります。Sony α7 IVのヘルプガイドは、静止画にSD、SDHC、SDXCカードを使えるとし、スピードクラスは動画の項目にだけ書いています。連写が多いなら説明書の推奨を確かめてください。

### 4K動画ならV30で足りますか?

カメラとビットレートによります。Sony α7 IVは200MbpsのXAVC S 4KにU3/V30以上を挙げていますが、同じ4Kでも600MbpsのXAVC S-IにはV90以上を求めています。

### UHS-IのカメラでUHS-IIカードを使えますか?

使えます。ただしUHS-Iの速度で動きます。SD Associationの表では、UHS-IモードはV30までです。

### カメラでmicroSDを使えますか?

カメラが対応していれば、アダプターを付けて使います。Sony α7 IVのヘルプガイドは、microSDを使うときは適切なアダプターを使うよう書いています。

### ドラレコ向けの高耐久カードをカメラで使えますか?

カメラの説明書の規格とスピードクラスに合えば使えます。高耐久の意味は[高耐久SDカードとは?](/blog/ja/high-endurance-sd-card)にあります。
