## 핵심 요약

컴퓨터 없이 아이폰을 백업하는 방법은 iCloud 백업과 USB 저장 두 가지입니다. 두 방법은 저장 범위와 필요한 준비물이 다릅니다.

iCloud 백업은 아이폰의 설정과 데이터를 인터넷에 저장합니다. iCloud 저장 공간이 모자라면 공간을 추가로 구입해야 합니다.

USB 저장은 사진, 영상, 연락처, 파일의 사본을 내 손에 둡니다. 메시지와 아이폰 설정은 USB로 옮기는 기본 방법이 없습니다.

아이폰을 그대로 되살리려면 iCloud 백업을, 사진 사본을 따로 두려면 USB를 고르세요. 둘을 함께 쓰면 한쪽이 잘못되어도 다른 쪽이 남습니다.

"집에 컴퓨터가 없는데 아이폰 백업은 어떻게 하나요?" "iCloud 저장 공간이 부족하다는 알림이 계속 떠요." "돈을 계속 내지 않고 사진을 보관할 수는 없나요?" 컴퓨터 없이 아이폰을 백업하려는 분들의 고민입니다.

컴퓨터 없이 아이폰 백업은 iCloud나 USB로 할 수 있습니다. 어떤 방법이 내 상황에 맞는지 표로 비교하고 고르는 기준을 설명합니다.

## 컴퓨터 없이 아이폰 백업하는 두 가지 방법은 무엇이 다른가요?

컴퓨터 없이 아이폰을 백업할 때 iCloud는 아이폰 상태를 저장하고 USB는 파일 사본을 저장합니다. 비용 구조도 다릅니다.

| 비교 기준 | iCloud 백업 | USB 저장 |
| --- | --- | --- |
| 저장 범위 | 기기에 있는 정보와 설정 | 사진, 영상, 연락처, 파일 |
| 메시지, 아이폰 설정 | 백업 대상입니다 | 기본 방법이 없습니다 |
| 필요한 것 | Wi-Fi, iCloud 저장 공간 | USB, 필요하면 어댑터 |
| 비용 | 공간이 모자라면 추가 구입 | USB를 살 때 한 번 |
| 자료 위치 | Apple 서버 | 내가 가진 USB |

아이폰 전체를 되살리는 데는 iCloud가 유리하고 사진 사본을 인터넷 밖에 두는 데는 USB가 유리합니다.

## iCloud로 컴퓨터 없이 아이폰 백업하는 방법

설정 앱에서 내 이름을 누르고 iCloud, iCloud 백업 순서로 들어갑니다. "이 iPhone 백업"을 켜고 지금 백업을 누르면 바로 시작됩니다.

[Apple 안내](https://support.apple.com/guide/iphone/back-up-iphone-iph3ecf67d29/ios)에 따르면 아이폰이 전원과 Wi-Fi에 연결되어 있고 잠겨 있을 때 iCloud가 매일 자동으로 백업합니다. 잠들기 전에 충전기를 꽂아 두면 따로 신경 쓸 일이 줄어듭니다.

[iCloud 백업](https://support.apple.com/en-us/108366)에는 iCloud에 이미 동기화된 항목이 들어가지 않습니다. iCloud 사진을 켰다면 사진은 백업이 아니라 iCloud 사진에 따로 저장됩니다.

저장 공간이 부족하다는 알림이 나오면 화면 안내에 따라 공간을 추가로 구입하거나 백업 항목을 줄여야 합니다. 사진과 영상이 공간의 대부분을 차지한다면 USB로 사본을 옮기는 방법을 함께 살펴보세요.

## USB로 컴퓨터 없이 아이폰 백업하는 방법

USB로 백업할 때는 사진 앱, 연락처 앱, 파일 앱에서 항목별로 저장합니다. 사진은 "수정되지 않은 원본 내보내기"를 선택해 위치 목록에서 USB를 고릅니다.

자세한 순서는 [아이폰 사진 USB로 옮기기](/blog/ko/iphone-photos-to-usb)와 [아이폰 USB 백업 방법](/blog/ko/backup-iphone-to-usb)에 항목별로 나눠 두었습니다.

USB 형식은 exFAT을 권합니다. FAT32 형식은 4GB가 넘는 파일을 저장하지 못하고 NTFS 형식은 [Apple의 지원 목록](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)에 없습니다.

## 컴퓨터 없이 아이폰 백업, 어떤 방법을 골라야 하나요?

컴퓨터 없이 아이폰을 백업할 때는 되살리려는 범위를 먼저 정하세요. 아래 네 가지 중 두 개 이상 해당하면 USB 저장을 함께 쓰는 편이 낫습니다.

- iCloud 저장 공간이 부족하다는 알림이 자주 나옵니다.
- 사진과 영상이 아이폰 저장 공간의 절반 이상을 차지합니다.
- 인터넷 없이도 볼 수 있는 사본을 갖고 싶습니다.
- 매달 내는 비용을 늘리고 싶지 않습니다.

아이폰을 잃어버렸을 때 메시지와 설정까지 되살리고 싶다면 iCloud 백업을 켜 두세요. USB는 iCloud 백업을 대신하지 못하고 사진과 연락처의 사본을 하나 더 만듭니다.

## 컴퓨터 없이 USB 백업을 간단히 하고 싶다면

기본 앱으로 USB에 저장하는 방법은 항목마다 앱을 옮겨 가며 진행해야 합니다. 부모님의 아이폰처럼 대신 챙겨 드려야 하는 경우에는 이 과정이 더 번거롭습니다.

NextGenAI가 만든 U-Saver는 컴퓨터 없이 USB에 사진, 영상, 연락처를 백업하고 복원하는 앱입니다. USB를 꽂고 "모두 백업"이나 "사진만"을 고른 뒤 원을 꾹 누르면 시작되고 결과는 앱의 기록에 남습니다. U-Saver는 App Store 출시를 준비하고 있으며 iOS 26 이상에서 씁니다.

메시지, 앱 데이터, 아이폰 설정은 저장하지 않고 USB의 내용은 암호화되지 않습니다. 구매 전 조건은 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)에서 확인하세요.

## 컴퓨터 없이 아이폰 백업 자주 묻는 질문

### 컴퓨터 없이 아이폰 전체를 백업할 수 있나요?

iCloud 백업을 쓰면 컴퓨터 없이 기기의 정보와 설정을 백업할 수 있습니다. USB에는 항목별 사본만 저장합니다.

### 컴퓨터 없이 아이폰 백업을 하려면 Wi-Fi가 필요한가요?

iCloud 자동 백업에는 Wi-Fi가 필요합니다. USB 저장은 인터넷 연결 없이 아이폰에 있는 파일을 옮길 수 있습니다. 다만 iCloud에만 있는 사진은 먼저 내려받아야 합니다.

### 컴퓨터 없이 아이폰 백업을 무료로 할 수 있나요?

USB가 이미 있다면 아이폰의 기본 앱으로 추가 비용 없이 사진을 옮길 수 있습니다. iCloud는 저장 공간이 모자라면 공간을 추가로 구입해야 합니다.

### 컴퓨터 없이 아이폰 백업을 USB로 하면 메시지도 저장되나요?

메시지는 저장되지 않습니다. 메시지를 백업하려면 iCloud 백업이나 컴퓨터 백업을 쓰세요.

### 컴퓨터 없이 아이폰 백업을 하면 나중에 복원할 수 있나요?

iCloud 백업은 아이폰을 처음 설정할 때 복원합니다. USB에 저장한 사진은 파일 앱에서 다시 사진 앱으로 저장합니다.
