## この記事の要点

SDカードのデータが消えたときは、まずカードを使うのをやめます。新しく撮影したりファイルを入れたりすると、カードにまた書き込みます。フォーマットを求める画面が出ても押しません。

次に、写真が本当に消えたのか、表示されていないだけなのかを見分けます。別のパソコンやカードリーダーで開き、隠しファイルを表示し、iPhoneに読み込んだことがあれば写真アプリを確認します。

それでも見つからなければ、カードメーカーの案内を確認します。SD Associationは消した写真を取り戻すツールを提供していません。この記事では特定の復元ソフトを扱わず、写真が戻ると約束しません。

「昨日撮った旅行の写真が、カードからまるごと見えなくなった」「iPhoneに移したあとカードを開いたら空だった」。SDカードのデータが消えたと検索する人からよく聞く声です。カードが開けない、写真が崩れて見えるといった場合は[壊れたSDカードの復元を試す前に](/blog/ja/sd-card-corrupted)に別にまとめました。この記事では、写真が消えたときに何を先に確かめるかを扱います。

## データが消えたら、なぜまずカードを止めるのですか?

カードへの書き込みが増えるほど、残っているデータを探しにくくなるおそれがあるからです。新しい撮影、ファイルのコピー、フォーマットは、どれもカードに書き込む作業です。フォーマットはカードのデータをすべて消します。

1. カメラやスマホからカードを抜き、そのカードでこれ以上撮影しません。
2. 機器にエラーメッセージが出ていたら控えておきます。[SD Associationのよくある質問](https://www.sdcard.org/consumers/faq/)は、エラーメッセージを控えて機器の説明書を確認するよう案内しています。
3. カードをパソコンにつなぎます。フォーマットを求める画面が出たら閉じます。
4. いま見えている写真とビデオを、先に別の記憶装置へコピーします。

カードを抜くときにも順番があります。[AppleのMac SDカードスロットの案内](https://support.apple.com/en-us/102352)は、Macがスリープ中にカードを抜くとデータを失うおそれがあると説明しています。コンピュータを起こし、取り出してから抜いてください。

## 写真は消えたのですか、それとも見えないだけですか?

まず状況を分けます。下の表は、症状ごとに疑うことと先にすることをまとめたものです。

| 症状 | 疑うこと | 先にすること |
| --- | --- | --- |
| カメラでは見えるのにパソコンで見えない | 接続、カードリーダー、隠しファイル | 別のカードリーダーやパソコンで確認 |
| フォルダーはあるのに写真がない | 隠しファイル、別のフォルダー | 隠しファイルを表示してフォルダーを確認 |
| iPhoneに読み込んだあとカードが空になった | 読み込み後にカードの元データを削除 | iPhoneの写真アプリを確認 |
| カードを挿すとフォーマットを求められる | ファイルシステムの破損 | フォーマットせず[壊れたSDカードの復元を試す前に](/blog/ja/sd-card-corrupted)を確認 |
| どの機器でもカードが表示されない | 接続、カードリーダー、カードの故障 | [microSDが認識しない・フォーマットできないとき](/blog/ja/sd-card-not-working)を確認 |
| 写真は見えるが削除や保存ができない | ロックのつまみ | [SDカードの書き込み禁止を解除する方法](/blog/ja/sd-card-write-protected)を確認 |

この記事では特定のカードやカードリーダーを試しておらず、特定の製品をすすめません。

## 別の機器では写真が見えますか?

撮影した機器にカードを戻し、再生画面を見ます。その機器で見えるなら、写真はカードに残っています。その場合は、パソコン側の接続やカードリーダーを疑います。

1. 撮影したカメラやスマホにカードを入れ、写真が見えるか確かめます。
2. 別のカードリーダーや別のパソコンにつないでみます。
3. 見える写真は、すぐにパソコンや別の記憶装置へコピーします。

パソコンにカードをつなぐ手順は、[SDカードをパソコンにつなぐ方法](/blog/ja/sd-card-to-pc)と[MacでSDカードを使う方法](/blog/ja/sd-card-on-mac)にあります。

## Windowsで隠しファイルを確認するには?

フォルダーはあるのに中が空に見えるなら、隠しファイルを表示します。[Microsoftの隠しファイルを表示する案内](https://support.microsoft.com/en-us/windows/view-hidden-files-and-folders-in-windows-97fbc472-c603-9d90-91d0-1166d1d9f4b5)に沿った手順です。

| Windowsのバージョン | 手順 |
| --- | --- |
| Windows 11 | タスクバーからエクスプローラーを開き、「表示」、「表示」、「隠しファイル」の順に選びます |
| Windows 10 | エクスプローラーで「表示」、「オプション」、「フォルダーと検索のオプションの変更」を選び、「表示」タブの詳細設定で「隠しファイル、隠しフォルダー、および隠しドライブを表示する」を選んで「OK」を押します |

隠しファイルが見えたら、写真を別のフォルダーにコピーしておきます。元の場所のファイルはそのままにします。

## iPhoneに読み込んだあと、カードから写真が消えたときは?

iPhoneの写真アプリに読み込んだあとでカードの元データを削除していれば、カードには写真がありません。この場合はiPhoneの写真アプリで探します。読み込みの手順は[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)にあります。

1. iPhoneで写真アプリを開き、最近の項目を見ます。
2. iPhoneでも削除していたら、「最近削除した項目」を確認します。
3. 見つかった写真は、iPhoneの外の別の記憶装置にもコピーを作ります。

[AppleのiCloud写真の案内](https://support.apple.com/en-us/108782)は、うっかり削除した項目は「最近削除した項目」から30日間取り戻せ、そのあとは完全に削除されると説明しています。同じ案内は、iCloud写真をオンにしていると、1台で削除した写真はiCloud写真を使うすべての機器から削除されると説明しています。

## カードが開けない、フォーマットを求められるときは?

フォーマットしません。フォーマットするとカードのデータはすべて消えます。開けるファイルを先にコピーし、MacのFirst AidかWindowsの`chkdsk`で検査します。

[Microsoftのchkdskの説明](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/chkdsk)は、パラメーターなしで実行すると状態を表示するだけでエラーは直さないと書いています。同じ説明は、FATファイルシステムの修復ではデータが失われることがあるとも書いています。そのため、`/f`で直す前に開けるファイルを移してください。検査の手順は[壊れたSDカードの復元を試す前に](/blog/ja/sd-card-corrupted)に順を追ってまとめました。

## SDカードの復元ソフトを使ってもいいですか?

この記事では特定の復元ソフトをすすめません。[SD Associationのよくある質問](https://www.sdcard.org/consumers/faq/)は、消した写真を取り戻す方法はカードメーカーの案内を見るよう答えています。SD Associationは写真を取り戻すツールを提供していないとも書いています。

| 確認先 | 理由 |
| --- | --- |
| カードメーカーのサポート | SD Associationが、消した写真の相談をメーカーに案内しています |
| カードを買った店 | SD Associationは、返品や交換が必要なら購入店に問い合わせるよう案内しています |
| カメラや機器の説明書 | 機器のエラーメッセージの意味が書かれています |

どの方法を使う場合も、取り戻したファイルを同じカードに保存しないでください。カードにまた書き込むことになります。

## 次に写真を失わないためには?

写真を1枚のカードだけに置かないことが基本です。撮影が終わったらパソコンや別の記憶装置にコピーし、コピーしたファイルが開けるか確かめてから、カードを空にします。

| 習慣 | 公式の案内 |
| --- | --- |
| Macでカードを抜く前に取り出す | Apple:コンピュータを起こし、取り出してから抜く |
| Windowsでカードを抜く前に安全に取り外す | Microsoft:[ハードウェアの安全な取り外し](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)のアイコンを使う |
| エラーが出たらメッセージを控える | SD Association:メッセージを控えて説明書を確認する |

## iPhoneの写真をUSBメモリにも保存しておくには?

iPhoneに読み込んだ写真も、iPhoneだけに置いていると同じリスクがあります。別の記憶装置にもう1つコピーを作っておきましょう。以下のアプリはUSBメモリを前提に説明します。形式を変える手順は[exFATフォーマット方法](/blog/ja/format-usb-exfat)に、移す手順は[iPhoneの写真をUSBに移す方法](/blog/ja/iphone-photos-to-usb)にあります。

## SDカードのデータが消えたときのよくある質問

### SDカードの写真が消えたら、最初に何をしますか?

機器からカードを抜き、これ以上撮影しません。フォーマットを求める画面が出ても押しません。そのあと、別の機器と隠しファイルを確認します。

### カメラでは見えるのにパソコンで見えないときは?

写真はカードに残っています。別のカードリーダーや別のパソコンにつなぎ、見える写真をすぐにコピーしてください。

### iPhoneに読み込んだ写真はどこで探しますか?

iPhoneの写真アプリで探します。iPhoneでも削除していたら、「最近削除した項目」を見てください。Appleは30日間取り戻せると説明しています。

### フォーマットを求められたら押してもいいですか?

押さないでください。フォーマットするとカードのデータはすべて消えます。開けるファイルを先にコピーしてから検査します。

### 消した写真をSD Associationが取り戻してくれますか?

いいえ。SD Associationは写真を取り戻すツールを提供していません。カードメーカーの案内を確認してください。
