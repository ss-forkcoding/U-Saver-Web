## この記事の要点

フォーマットしたSDカードのデータを取り戻そうとする前に、まずカードの使用を止めます。フォーマットのあとに撮影したりファイルを入れたりすると、残っているかもしれないデータを上書きします。

元に戻せるかは、フォーマットの方式によります。Microsoftは、クイックフォーマットはファイルテーブルとルートディレクトリを削除すると説明しています。一方、すべてのセクターを0で埋めるフォーマットや上書きのオプションを使った場合は、データそのものが上書きされています。

WindowsではMicrosoftのWindows File Recoveryを使えます。この記事ではこのツールもほかの復元ソフトも試しておらず、ファイルが戻ると約束しません。

「カメラにカードをフォーマットするよう言われて、押してしまった」「別のカードだと思ってパソコンでフォーマットした」。フォーマットしたSDカードを元に戻したい人からよく聞く声です。自分でいくつかのファイルを削除した場合は[SDカードの消えたデータを復元する前に](/blog/ja/deleted-files-sd-card)に、削除した覚えがないのに写真が見えない場合は[SDカードのデータが消えたときに最初にすること](/blog/ja/sd-card-photos-missing)にまとめました。この記事では、カードをフォーマットしたあとにすることを扱います。

## フォーマットしたSDカードは、なぜすぐに使うのを止めるのですか?

フォーマットのあと、カードは空のカードのように見え、機器はその場所に新しいファイルを書き込みます。[MicrosoftのWindows File Recoveryの案内](https://support.microsoft.com/en-us/windows/recover-lost-files-on-windows-10-61f5b28a-f5b8-3cc2-0f8e-a63cb4e1d4c4)は、削除したファイルの場所は空き領域として扱われ、データが残っている可能性はあるものの、新しいファイルがいつでも上書きしうると説明しています。

1. カメラやスマホからカードを抜き、そのカードでこれ以上撮影しません。
2. カードに新しいファイルをコピーしません。
3. もう一度フォーマットしません。エラーメッセージがフォーマットをすすめても、今は押しません。
4. カードを抜く前に取り出しをします。[AppleのMac SDカードスロットの案内](https://support.apple.com/en-us/102352)は、Macがスリープ中にカードを抜くとデータを失うおそれがあると説明しています。

カードが開けずにフォーマットのメッセージが出た場合は、先に[壊れたSDカードの復元を試す前に](/blog/ja/sd-card-corrupted)をご覧ください。

## どの方式でフォーマットしたかが、なぜ大事なのですか?

フォーマットは方式によって消す範囲が違います。下の表は公式の文書に書かれている動作です。

| フォーマットの方式 | 公式の文書の説明 | データが残る余地 |
| --- | --- | --- |
| Windowsのクイックフォーマット(`/Q`) | ファイルテーブルとルートディレクトリを削除し、不良領域の検査を省きます | データそのものを上書きするという説明はありません |
| Windowsの `/P` オプション | すべてのセクターを0で埋め、指定した回数だけ乱数で上書きします | データは上書きされています |
| Macのディスクユーティリティのセキュリティオプション | 消去したデータを何回上書きするかを選びます | データは上書きされています |
| カメラやスマホのフォーマットメニュー | 機器によって違います | 機器の説明書を確認します |

Windowsの動作は[Microsoftのformatコマンドの案内](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/format)にあります。Macの動作は[Appleのディスクユーティリティの案内](https://support.apple.com/guide/disk-utility/erase-and-reformat-a-storage-device-dskutl14079/mac)にあり、同じ案内はセキュリティオプションが一部の記憶装置でしか表示されないと説明しています。SD Associationのフォーマッターのクイックフォーマットと上書きフォーマットの違いは[SDカードフォーマッターの使い方](/blog/ja/sd-card-formatter)にまとめました。

上書きで消去したカードは、この記事の方法では元に戻せません。その場合は、カードの外に残っているコピーを探すほうが早道です。

## カードの外にコピーが残っていませんか?

フォーマットしたカードより先に、ほかの場所のコピーを探します。カードに何も書き込まないので、いちばん安全な順番です。

| 確認する場所 | 見ること |
| --- | --- |
| パソコン | 写真アプリや取り込みフォルダーに、前に移したファイルがあるか |
| iPhoneの写真アプリ | カードから読み込んだ写真がライブラリや「最近削除した項目」にあるか |
| ほかの記憶装置 | バックアップ用のUSBメモリや外付けドライブにコピーしたファイルがあるか |

[AppleのiCloud写真の案内](https://support.apple.com/en-us/108782)は、うっかり削除した項目は「最近削除した項目」から30日間取り戻せると説明しています。iPhoneへの読み込みの手順は[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)にあります。

## WindowsでフォーマットしたSDカードからファイルを取り戻すには?

Microsoftは、Windows File RecoveryというコマンドラインのアプリをMicrosoft Storeで提供しています。[MicrosoftのWindows File Recoveryの案内](https://support.microsoft.com/en-us/windows/recover-lost-files-on-windows-10-61f5b28a-f5b8-3cc2-0f8e-a63cb4e1d4c4)は、SDカードをFAT・exFATのファイルシステムの例に挙げています。同じ案内のモードの表は、NTFSのディスクをフォーマットしたあとは拡張モードを、FAT・exFATはどの状況でも拡張モードを使うようまとめています。

| 項目 | Microsoftの案内 |
| --- | --- |
| 対応するWindows | Windows 11、Windows 10 |
| FAT・exFATで使うモード | 拡張(Extensive)モードのみ対応します |
| 保存先 | 元とは別のドライブにします |
| 結果のフォルダー | 保存先のドライブに `Recovery_<日付と時刻>` フォルダーができます |

案内に沿った基本の手順は次のとおりです。

1. Microsoft StoreからWindows File Recoveryをインストールします。
2. Windowsキーを押し、検索ボックスにWindows File Recoveryと入力してアプリを選びます。
3. アプリがデバイスに変更を加えることを許可するか聞かれたら、「はい」を選びます。
4. コマンドプロンプトの画面で、`winfr 元のドライブ: 保存先のドライブ: /extensive` の形式で入力します。たとえばカードがE:で、JPGの写真だけをC:に保存するなら `winfr E: C: /extensive /n *.JPG` と入力します。
5. 続けるか聞かれたらYを入力します。止めるときはCtrl + Cを押します。

同じ案内は、取り戻せなかった場合は空き領域がすでに上書きされている可能性があると説明しています。この記事ではWindows File Recoveryを自分たちで試していません。パソコンにカードをつなぐ手順は[SDカードをパソコンにつなぐ方法](/blog/ja/sd-card-to-pc)にあります。

## Macやほかの復元ソフトはどうしますか?

Appleのディスクユーティリティの案内は、記憶装置を消去するとすべての内容が削除されると説明し、残したいファイルは消去の前に別の記憶装置へコピーするよう案内しています。この記事で確認したAppleの文書には、フォーマットしたカードを元に戻す手順はありません。

[SD Associationのよくある質問](https://www.sdcard.org/consumers/faq/)は、消した写真を取り戻す方法はカードメーカーの案内を見るよう答えています。SD Associationは写真を取り戻すツールを提供していないとも書いています。この記事では特定の復元ソフトや業者をすすめません。

どの方法を使う場合も、次の2つは守ります。

1. 取り戻したファイルを同じカードに保存しません。
2. 取り戻したファイルが開けるか、別の記憶装置で確かめます。

## 次にフォーマットの失敗を防ぐには?

フォーマットの前に確かめる順番を決めておくと、同じ失敗を減らせます。

| 習慣 | 理由 |
| --- | --- |
| フォーマットの前に別の場所へコピーを作る | Appleは、消去の前に残したいファイルを別の記憶装置へコピーするよう案内しています |
| フォーマットする機器の名前と容量を確かめる | 別のカードやドライブを消す失敗を防ぎます |
| コピーが開けるか確かめてからフォーマットする | コピーが終わっていないファイルを消さずにすみます |

機器ごとのフォーマットの手順は[SDカードフォーマット方法](/blog/ja/format-sd-card)にあります。

## フォーマットしたSDカードでよくある質問

### フォーマットしたSDカードは元に戻せますか?

フォーマットの方式と、そのあとの使い方によります。クイックフォーマットのあとカードを使っていなければ、データが残っている可能性があります。上書きのオプションでフォーマットした場合は、データそのものが上書きされています。

### フォーマットしたあと、最初に何をしますか?

機器からカードを抜き、これ以上撮影やコピーをしません。もう一度フォーマットもしません。

### Windowsで使える公式のツールはありますか?

Microsoft StoreのWindows File Recoveryがあります。FAT・exFATのカードは拡張モードのみ対応し、結果は別のドライブに保存します。

### カメラでフォーマットしたカードも同じ方法ですか?

カメラのフォーマットの動作は機器によって違います。先に機器の説明書とカードメーカーの案内を確認してください。

### 取り戻したファイルを元のカードに戻してもいいですか?

作業が終わるまでは戻さないでください。カードへの書き込みが、残っているデータを上書きするおそれがあります。
