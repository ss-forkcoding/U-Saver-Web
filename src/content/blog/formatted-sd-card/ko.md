## 핵심 요약

포맷한 SD 카드 복구를 시도하기 전에 카드 사용부터 멈춥니다. 포맷 뒤에 새로 찍거나 파일을 넣으면 남아 있을 수 있는 자료를 덮어씁니다.

되돌릴 수 있는지는 포맷 방식에 달려 있습니다. Microsoft는 빠른 포맷이 파일 목록과 루트 디렉터리를 지운다고 설명합니다. 반면 모든 섹터를 0으로 채우는 포맷이나 덮어쓰기 옵션을 썼다면 자료 자체가 덮어쓰였습니다.

윈도우에서는 Microsoft의 Windows 파일 복구를 쓸 수 있습니다. 이 글은 이 도구나 다른 복구 프로그램을 시험하지 않았고, 파일을 되찾는다고 약속하지 않습니다.

"카메라가 카드를 새로 쓰라고 해서 포맷을 눌렀어요." "다른 카드인 줄 알고 컴퓨터에서 포맷했어요." 포맷한 SD 카드 복구를 검색하는 분들이 자주 하는 말입니다. 파일 몇 개를 직접 지운 경우는 [SD 카드 데이터 복구](/blog/ko/deleted-files-sd-card)에, 지운 기억 없이 사진이 안 보이는 경우는 [SD 카드 복구 전에 먼저 할 일](/blog/ko/sd-card-photos-missing)에 정리했습니다. 이 글은 카드를 포맷한 뒤에 할 일을 다룹니다.

## 포맷한 SD 카드는 왜 바로 사용을 멈춰야 하나요?

포맷 뒤 카드는 빈 카드처럼 보이고, 기기는 그 공간에 새 파일을 씁니다. [Microsoft의 Windows 파일 복구 안내](https://support.microsoft.com/en-us/windows/recover-lost-files-on-windows-10-61f5b28a-f5b8-3cc2-0f8e-a63cb4e1d4c4)는 지운 파일의 자리가 빈 공간으로 표시되어 자료가 남아 있을 수 있지만, 새 파일이 언제든 그 자리를 덮어쓸 수 있다고 설명합니다.

1. 카메라나 휴대폰에서 카드를 빼고 그 카드로 더 촬영하지 않습니다.
2. 카드에 새 파일을 복사하지 않습니다.
3. 다시 포맷하지 않습니다. 오류 메시지가 포맷을 권해도 지금은 누르지 않습니다.
4. 카드를 뺄 때는 꺼내기를 먼저 합니다. [Apple의 Mac SD 카드 슬롯 안내](https://support.apple.com/en-us/102352)는 Mac이 잠자기 상태일 때 카드를 빼면 데이터를 잃을 수 있다고 설명합니다.

카드가 열리지 않아서 포맷 메시지가 뜬 상황이라면 [손상된 SD 카드 복구 전에](/blog/ko/sd-card-corrupted)를 먼저 보세요.

## 어떤 방식으로 포맷했는지가 왜 중요한가요?

포맷은 방식마다 지우는 범위가 다릅니다. 아래 표는 공식 문서에 적힌 동작입니다.

| 포맷 방식 | 공식 문서의 설명 | 자료가 남을 여지 |
| --- | --- | --- |
| 윈도우 빠른 포맷(`/Q`) | 파일 목록과 루트 디렉터리를 지우고 불량 영역 검사를 건너뜁니다 | 자료 자체를 덮어쓴다는 설명은 없습니다 |
| 윈도우 `/P` 옵션 | 모든 섹터를 0으로 채우고, 지정한 횟수만큼 무작위 값으로 덮어씁니다 | 자료가 덮어쓰였습니다 |
| Mac 디스크 유틸리티 보안 옵션 | 지운 데이터를 몇 번 덮어쓸지 고릅니다 | 자료가 덮어쓰였습니다 |
| 카메라·휴대폰의 포맷 메뉴 | 기기마다 다릅니다 | 기기 설명서를 확인합니다 |

윈도우 동작은 [Microsoft의 format 명령 안내](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/format)에 있습니다. Mac 동작은 [Apple의 디스크 유틸리티 안내](https://support.apple.com/guide/disk-utility/erase-and-reformat-a-storage-device-dskutl14079/mac)에 있고, 같은 안내는 보안 옵션이 일부 저장장치에서만 보인다고 설명합니다. SD Association 포맷 프로그램의 빠른 포맷과 덮어쓰기 포맷 차이는 [SD 카드 포맷 프로그램 사용법](/blog/ko/sd-card-formatter)에 정리했습니다.

덮어쓰기로 지운 카드는 이 글의 방법으로 되돌릴 수 없습니다. 이 경우 카드 밖에 남은 사본을 찾는 편이 빠릅니다.

## 카드 밖에 사본이 남아 있지는 않나요?

포맷한 카드보다 다른 곳의 사본을 먼저 찾습니다. 카드에 아무것도 쓰지 않으므로 가장 안전한 순서입니다.

| 확인할 곳 | 볼 것 |
| --- | --- |
| 컴퓨터 | 사진 앱이나 가져오기 폴더에 예전에 옮긴 파일이 있는지 봅니다 |
| 아이폰 사진 앱 | 카드에서 가져온 사진이 보관함이나 최근 삭제된 항목에 있는지 봅니다 |
| 다른 저장장치 | 백업용 USB나 외장 드라이브에 복사해 둔 파일이 있는지 봅니다 |

[Apple의 iCloud 사진 안내](https://support.apple.com/en-us/108782)는 실수로 지운 항목을 최근 삭제된 항목에서 30일 동안 되찾을 수 있다고 설명합니다. 아이폰으로 가져오는 순서는 [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader)에 있습니다.

## 윈도우에서 포맷한 SD 카드를 복구하려면?

Microsoft는 Windows 파일 복구라는 명령줄 앱을 Microsoft Store에서 제공합니다. [Microsoft의 Windows 파일 복구 안내](https://support.microsoft.com/en-us/windows/recover-lost-files-on-windows-10-61f5b28a-f5b8-3cc2-0f8e-a63cb4e1d4c4)는 SD 카드를 FAT·exFAT 파일 시스템의 예로 듭니다. 같은 안내의 모드 표는 NTFS 디스크를 포맷한 뒤에는 확장 모드를, FAT·exFAT은 어떤 상황이든 확장 모드를 쓰라고 정리합니다.

| 항목 | Microsoft 안내 |
| --- | --- |
| 지원 윈도우 | 윈도우 11, 윈도우 10 |
| FAT·exFAT에서 쓸 모드 | 확장(Extensive) 모드만 지원합니다 |
| 저장 위치 | 원본과 다른 드라이브여야 합니다 |
| 결과 폴더 | 저장할 드라이브에 Recovery_날짜와 시간 폴더가 생깁니다 |

안내에 따른 기본 순서는 아래와 같습니다.

1. Microsoft Store에서 Windows 파일 복구를 설치합니다.
2. Windows 키를 누르고 검색창에 Windows File Recovery를 입력한 뒤 앱을 고릅니다.
3. 앱이 장치를 변경하도록 허용할지 물으면 예를 고릅니다.
4. 명령 프롬프트 창에 `winfr 원본드라이브: 저장드라이브: /extensive` 형식으로 입력합니다. 예를 들어 카드가 E:이고 사진만 C:로 찾으려면 `winfr E: C: /extensive /n *.JPG`처럼 입력합니다.
5. 계속할지 물으면 Y를 입력합니다. 멈추려면 Ctrl + C를 누릅니다.

같은 안내는 찾지 못했다면 빈 공간이 이미 덮어쓰였을 수 있다고 설명합니다. 이 글은 Windows 파일 복구를 직접 시험하지 않았습니다. 카드를 PC에 연결하는 순서는 [SD 카드 컴퓨터 연결 방법](/blog/ko/sd-card-to-pc)에 있습니다.

## Mac이나 다른 복구 프로그램은 어떻게 하나요?

Apple 디스크 유틸리티 안내는 저장장치를 지우면 모든 내용이 삭제된다고 설명하고, 남길 파일은 지우기 전에 다른 곳에 복사하라고 안내합니다. 이 글이 확인한 Apple 문서에는 포맷한 카드를 되돌리는 절차가 없습니다.

[SD Association FAQ](https://www.sdcard.org/consumers/faq/)는 지운 사진을 되찾는 방법은 카드 제조사의 안내를 보라고 답합니다. SD Association은 사진을 되찾는 도구를 제공하지 않는다고 밝힙니다. 이 글은 특정 복구 프로그램이나 업체를 추천하지 않습니다.

어떤 방법을 쓰든 아래 두 가지는 지킵니다.

1. 되찾은 파일을 같은 카드에 저장하지 않습니다.
2. 되찾은 파일이 열리는지 다른 저장장치에서 확인합니다.

## 다음에 포맷 실수를 막으려면?

포맷 전에 확인하는 순서를 정해 두면 같은 실수를 줄입니다.

| 습관 | 이유 |
| --- | --- |
| 포맷 전에 다른 곳에 사본 만들기 | Apple은 지우기 전에 남길 파일을 다른 저장장치에 복사하라고 안내합니다 |
| 포맷할 장치의 이름과 용량 확인 | 다른 카드나 드라이브를 지우는 실수를 막습니다 |
| 사본이 열리는지 확인한 뒤 포맷 | 복사가 끝나지 않은 파일을 지우지 않습니다 |

기기별 포맷 순서는 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에 있습니다.

## 아이폰 사진을 USB 메모리에도 저장해 두려면?

아이폰으로 가져온 사진도 한 곳에만 두면 같은 실수로 잃을 수 있습니다. 다른 저장장치에 사본을 하나 더 만들어 두세요. 아래 앱은 USB 메모리를 기준으로 안내합니다. USB 형식을 바꾸는 순서는 [exFAT 포맷 방법](/blog/ko/format-usb-exfat)에, 옮기는 순서는 [아이폰 사진 USB로 옮기기](/blog/ko/iphone-photos-to-usb)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비 중이며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## 포맷한 SD 카드 복구 자주 묻는 질문

### 포맷한 SD 카드는 되돌릴 수 있나요?

포맷 방식과 그 뒤의 사용에 달려 있습니다. 빠른 포맷 뒤 카드를 쓰지 않았다면 자료가 남아 있을 수 있습니다. 덮어쓰기 옵션으로 포맷했다면 자료 자체가 덮어쓰였습니다.

### 포맷한 뒤 가장 먼저 무엇을 하나요?

카드를 기기에서 빼고 더 촬영하거나 복사하지 않습니다. 다시 포맷하지도 않습니다.

### 윈도우에서 쓸 수 있는 공식 도구가 있나요?

Microsoft Store의 Windows 파일 복구가 있습니다. FAT·exFAT 카드는 확장 모드만 지원하고, 결과는 다른 드라이브에 저장해야 합니다.

### 카메라에서 포맷한 카드도 같은 방법을 쓰나요?

카메라의 포맷 동작은 기기마다 다릅니다. 기기 설명서와 카드 제조사의 안내를 먼저 확인하세요.

### 되찾은 파일을 원래 카드에 다시 넣어도 되나요?

작업이 끝나기 전에는 넣지 마세요. 카드에 쓰는 작업이 남은 자료를 덮어쓸 수 있습니다.
