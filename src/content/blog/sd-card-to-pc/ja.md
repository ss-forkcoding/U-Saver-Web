## この記事の要点

SDカードをパソコンにつなぐ方法は2つです。パソコンにSDスロットがあれば、カードを直接挿します。スロットがなければ、USBカードリーダーにカードを入れてUSBポートに挿します。

スロットがあっても、カードより古い規格のスロットではカードを読めないことがあります。その場合は、カードの規格に対応したUSBカードリーダーを使います。

つないだ後は、WindowsのエクスプローラーかMacのFinderでファイルをコピーします。Windowsでは、フォトアプリのインポートでも写真を移せます。使い終わったら、取り出し操作をしてからカードを抜きます。

「カメラのSDカードをパソコンにどうつなぐ?」「ノートパソコンにSDスロットがない」。この記事では、SDカードをパソコンにつないでファイルを移す基本の手順を扱います。カードリーダーの選び方は[SDカードリーダーの選び方](/blog/ja/choose-sd-card-reader)にまとめました。

## SDカードをパソコンにつなぐ方法は?

[SD AssociationのFAQ](https://www.sdcard.org/consumers/faq/)は、パソコンにSDスロットがあればカードを挿してデータを移せると説明しています。スロットがない場合や、カードより前の規格のスロットの場合は、USBリーダー・ライターかカードアダプターを使うよう案内しています。

| 方法 | 使う場面 | 確認すること |
| --- | --- | --- |
| パソコンのSDスロット | ノートパソコンやデスクトップにSDスロットがあるとき | スロットがカードの容量規格に対応しているか |
| USB SDカードリーダー | スロットがない、またはスロットの規格が古いとき | リーダーの端子(USB-A、USB-C)と対応規格 |
| microSD変換アダプター | microSDをSDスロットに挿すとき | アダプターを使ってもカードの規格は変わりません |

microSDとアダプターの関係は[micro SDとは?](/blog/ja/microsd-vs-sd)にあります。USB-C端子しかないノートパソコンなら、[USB-C SDカードリーダーの使い方](/blog/ja/usb-c-sd-card-reader)もあわせて読んでください。

## このSDカードはパソコンで読めますか?

カードの容量規格と、スロットやリーダーの規格を照らし合わせます。[SD Associationの容量規格の案内](https://www.sdcard.org/consumers/about-sd-memory-card-choices/sd-sdhc-sdxc-and-sduc-card-capacity-choices/)は、互換性を次のようにまとめています。

| カード | 使えるスロット・リーダー |
| --- | --- |
| SD | SD、SDHC、SDXC、SDUC |
| SDHC | SDHC、SDXC、SDUC |
| SDXC | SDXC、SDUC |
| SDUC | SDUC |

同じ案内は、カードを入れる前に機器の取扱説明書やメーカー情報で対応規格を確かめるよう求めています。ノートパソコンのSDスロットの対応規格は、パソコンメーカーの仕様表で探します。規格ごとの容量の範囲は[SDXCとは?](/blog/ja/sdhc-vs-sdxc)にあります。

Macは、Appleが対応モデルを公開しています。[AppleのMacのSDカードスロットの案内](https://support.apple.com/en-us/102352)によると、SDXCスロットがあるモデルは次のとおりです。

| Macの種類 | SDXCスロットがあるモデル |
| --- | --- |
| Mac Studio | 2022年以降 |
| 14インチ・16インチMacBook Pro | 2021年以降 |
| MacBook Pro | 2011年〜2015年 |
| Mac mini | 2011年〜2014年 |
| 13インチMacBook Air | 2013年〜2017年 |
| 27インチ・21.5インチiMac | 2010年以降 |

この一覧にないMacでは、USBカードリーダーを使います。

## WindowsパソコンでSDカードを開く手順

1. カードのロックスイッチの位置を確かめます。ファイルを削除したり保存したりするなら、解除の位置にします。
2. カードをパソコンのSDスロットに入れるか、カードリーダーに入れてからリーダーをUSBポートに挿します。スロットに入れる向きは、パソコンの取扱説明書に従います。
3. エクスプローラーを開き、カードのドライブを探します。
4. カードのファイルをパソコンのフォルダーにコピーします。

スイッチの位置は[SDカードのロックとは?](/blog/ja/sd-card-lock-switch)で確かめてください。

カードを挿したときに出る画面は、自動再生の設定で変わります。[Microsoftの案内](https://support.microsoft.com/en-us/windows/apps/how-to-install-programs-from-a-disc)によると、スタート > 設定 > Bluetoothとデバイス > 自動再生で、自動再生をオンまたはオフにします。リムーバブルドライブとメモリカードの既定の動作も、同じ画面で選べます。

## WindowsのフォトアプリでSDカードの写真を取り込むには?

[Microsoftのフォトアプリの案内](https://support.microsoft.com/en-us/windows/apps/photos/manage-photos-and-videos-with-microsoft-photos-app)は、カメラのSDカード、USBドライブ、スマートフォンから写真や動画をインポートできると説明しています。手順は[Microsoftのインポートの案内](https://support.microsoft.com/en-us/windows/import-photos-and-videos-aed09800-f826-4d40-a243-7640de229d9d)に沿います。

1. スタートボタンを選び、フォトアプリを開きます。
2. インポートを選び、接続されたデバイスからカードを選びます。
3. 取り込む項目と保存先を選びます。
4. 画面の指示に従ってインポートを終えます。

ファイル名やフォルダー構成をそのまま移すなら、エクスプローラーでコピーするほうが簡単です。フォトアプリは、取り込む項目を選んで移したいときに使います。

## MacにSDカードをつなぐ手順

[AppleのMacのSDカードスロットの案内](https://support.apple.com/en-us/102352)に沿った手順です。

1. カードの金属端子を下に向け、パソコン側に向けてスロットに入れます。無理に押し込みません。
2. カードのアイコンが表示されたら、Finderでファイルを開きます。
3. 使い終わったら、カードのアイコンをゴミ箱にドラッグして取り出します。
4. アイコンが消えたら、カードを抜きます。

同じ案内に書かれたスロットの条件です。

| 項目 | Appleの案内 |
| --- | --- |
| 対応カード | MMC、Default Speed、High Speed、UHS-I |
| UHS-II対応 | 2022年以降のMac Studio、2021年以降のMacBook Pro、2020年のiMac、iMac Pro |
| miniSD、microSD | アダプターを付けて使用 |
| 非対応のカード | SDIOカード |
| 注意 | 厚さ2.1mmを超えるカードはスロットを傷めるおそれがあります |

## SDカードを安全に取り外すには?

Windowsでは[Microsoftの安全な取り外しの案内](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)に従います。Microsoftは、データを失わないよう、外す前に必ず安全な取り外しを行うよう説明しています。

1. タスクバーの通知領域にある「ハードウェアを安全に取り外してメディアを取り出す」アイコンを右クリックします。アイコンがなければ、先に隠れているインジケーターを表示します。
2. メニューでカードのドライブの取り出しを選びます。
3. ハードウェアを安全に取り外せるという通知が出たら、カードやリーダーを抜きます。

Macでは、カードのアイコンをゴミ箱にドラッグします。Appleは、Macがスリープ中にカードを抜くとデータを失うおそれがあると説明しています。パソコンをスリープから戻し、取り出してから抜きます。

## パソコンにSDカードが表示されないときは?

| 症状 | 確認すること |
| --- | --- |
| Macにカードのアイコンが出ない | カードを抜いて挿し直します。Appleは、入れる速さが遅すぎたり速すぎたりするとマウントされないことがあると説明しています |
| Macで「変更できません」と出る | カードを取り出し、ロックスイッチを解除して挿し直します |
| スロットでは表示されず、リーダーでは表示される | スロットがカードの規格に対応しているか確かめます |
| Windowsで安全な取り外しのアイコンが出ない | Microsoftは、機器がつながっていないか、Windowsが機器を認識していないとアイコンが出ないことがあると説明しています |

フォーマットを求める画面が出たり、エラーが続いたりしても、すぐにフォーマットしないでください。先に[SDカードが認識しないときの確認手順](/blog/ja/sd-card-not-working)を進めます。フォーマットが必要なら、[SDカードフォーマッターの使い方](/blog/ja/sd-card-formatter)を参考にしてください。

## SDカードとパソコンのよくある質問

### ノートパソコンにSDスロットがない場合は?

USBカードリーダーを使います。SD Associationは、スロットのないパソコンではUSBリーダー・ライターかカードアダプターでデータを移すよう案内しています。ノートパソコンの端子(USB-A、USB-C)に合うリーダーを選んでください。

### パソコンのスロットにmicroSDをそのまま挿せますか?

SDスロットには、microSDをSDサイズにする変換アダプターを付けて挿します。Appleも、MacのスロットでmicroSDを使うにはアダプターを使うよう案内しています。

### 取り出し操作をせずに抜いてもいいですか?

おすすめしません。Microsoftは、データを失わないよう外す前に安全な取り外しを行うよう説明しています。Appleも、取り出してからカードを抜くよう案内しています。

### スロットがUHS-Iだけに対応している場合、UHS-IIカードは使えませんか?

使えます。[SD Associationのバス方式の案内](https://www.sdcard.org/consumers/about-sd-memory-card-choices/bus-interface-speed-standards-for-large-size-data-transfer/)は、高速なカードもUHS-Iの機器で使えると説明しています。ただしUHS-IIの速度は出ません。方式ごとの違いは[UHSスピードクラスとは?](/blog/ja/uhs-sd-card)にあります。

### 古いパソコンが64GBのカードを読めません。

64GBのカードはSDXCです。SD Associationの案内では、SDXCカードはSDXCかSDUCの機器でだけ使えます。スロットがSDHCまでの対応なら、SDXCに対応したUSBカードリーダーを使ってください。
