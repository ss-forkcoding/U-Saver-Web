## 핵심 요약

SD 카드 컴퓨터 연결 방법은 두 가지입니다. 컴퓨터에 SD 슬롯이 있으면 카드를 바로 꽂습니다. 슬롯이 없으면 USB 리더기에 카드를 넣어 USB 포트에 꽂습니다.

슬롯이 있어도 카드보다 이전 규격으로 만든 슬롯이면 카드를 못 읽을 수 있습니다. 이때는 카드 규격을 지원하는 USB 리더기를 씁니다.

연결한 뒤에는 윈도우 파일 탐색기나 Mac Finder에서 파일을 복사합니다. 사진은 윈도우 사진 앱의 가져오기로도 옮길 수 있습니다. 다 쓴 카드는 꺼내기를 먼저 하고 뺍니다.

"카메라 SD 카드를 컴퓨터에 어떻게 연결하나요?" "노트북에 SD 슬롯이 없는데요." 이 글은 컴퓨터에 카드를 연결하고 파일을 옮기는 기본 순서를 다룹니다. 리더기를 고르는 기준은 [SD 카드 리더기 고르는 법](/blog/ko/choose-sd-card-reader)에 정리했습니다.

## SD 카드 컴퓨터 연결은 어떤 방법이 있나요?

[SD Association FAQ](https://www.sdcard.org/consumers/faq/)는 컴퓨터에 SD 슬롯이 있으면 카드를 꽂아 옮기면 된다고 적습니다. 슬롯이 없거나 카드보다 이전 규격의 슬롯이면 USB 리더기나 카드 어댑터를 쓰라고 안내합니다.

| 방법 | 이럴 때 씁니다 | 확인할 것 |
| --- | --- | --- |
| 컴퓨터의 SD 슬롯 | 노트북이나 데스크톱에 SD 슬롯이 있을 때 | 슬롯이 카드의 용량 규격을 지원하는지 |
| USB SD 카드 리더기 | 슬롯이 없거나 슬롯 규격이 낮을 때 | 리더기 단자(USB-A, USB-C)와 지원 규격 |
| microSD 어댑터 | microSD를 SD 슬롯에 꽂을 때 | 어댑터를 쓴 뒤에도 카드 규격은 그대로입니다 |

microSD와 어댑터의 관계는 [micro SD 카드와 SD 카드 차이](/blog/ko/microsd-vs-sd)에 있습니다. USB-C 단자만 있는 노트북이라면 [C 타입 SD 카드 리더기 사용법](/blog/ko/usb-c-sd-card-reader)을 함께 보세요.

## 내 컴퓨터가 이 카드를 읽을 수 있나요?

카드의 용량 규격과 슬롯·리더기의 규격을 맞춰 봅니다. [SD Association의 용량 규격 안내](https://www.sdcard.org/consumers/about-sd-memory-card-choices/sd-sdhc-sdxc-and-sduc-card-capacity-choices/)는 호환을 이렇게 정리합니다.

| 카드 | 쓸 수 있는 슬롯·리더기 |
| --- | --- |
| SD | SD, SDHC, SDXC, SDUC |
| SDHC | SDHC, SDXC, SDUC |
| SDXC | SDXC, SDUC |
| SDUC | SDUC |

같은 안내는 카드를 넣기 전에 기기 설명서나 제조사 정보로 지원 규격을 확인하라고 적습니다. 노트북 SD 슬롯의 지원 규격은 컴퓨터 제조사 사양표에서 찾습니다. 규격별 용량 범위는 [SDHC·SDXC·SDUC 차이](/blog/ko/sdhc-vs-sdxc)에 있습니다.

Mac은 Apple이 모델 목록을 공개합니다. [Apple의 Mac SD 카드 슬롯 안내](https://support.apple.com/en-us/102352)에 따르면 SDXC 슬롯이 있는 모델은 아래와 같습니다.

| Mac 종류 | SDXC 슬롯이 있는 모델 |
| --- | --- |
| Mac Studio | 2022년 이후 |
| 14형·16형 MacBook Pro | 2021년 이후 |
| MacBook Pro | 2011년~2015년 |
| Mac mini | 2011년~2014년 |
| 13형 MacBook Air | 2013년~2017년 |
| 27형·21.5형 iMac | 2010년 이후 |

목록에 없는 Mac은 USB 리더기를 씁니다.

## 윈도우 PC에서 SD 카드를 여는 순서

1. 카드의 쓰기 방지 스위치 위치를 확인합니다. 파일을 지우거나 저장하려면 잠금 해제 위치에 둡니다.
2. 카드를 PC의 SD 슬롯에 넣거나, 리더기에 넣은 뒤 리더기를 USB 포트에 꽂습니다. 슬롯에 넣는 방향은 PC 설명서를 따릅니다.
3. 파일 탐색기를 열고 카드 드라이브를 찾습니다.
4. 카드의 파일을 PC 폴더로 복사합니다.

스위치 위치는 [SD 카드 잠금 스위치 글](/blog/ko/sd-card-lock-switch)에서 확인하세요.

카드를 꽂을 때 뜨는 창은 자동 실행 설정에 따라 다릅니다. [Microsoft 안내](https://support.microsoft.com/en-us/windows/apps/how-to-install-programs-from-a-disc)에 따르면 시작 > 설정 > Bluetooth 및 장치 > 자동 실행에서 자동 실행을 켜고 끕니다. 이동식 드라이브와 메모리 카드의 기본 동작도 같은 화면에서 고릅니다.

## 윈도우 사진 앱으로 SD 카드 사진을 가져오려면?

[Microsoft 사진 앱 안내](https://support.microsoft.com/en-us/windows/apps/photos/manage-photos-and-videos-with-microsoft-photos-app)는 카메라 SD 카드, USB 드라이브, 휴대폰에서 사진과 영상을 가져올 수 있다고 적습니다. 가져오기 순서는 [Microsoft의 사진 가져오기 안내](https://support.microsoft.com/en-us/windows/import-photos-and-videos-aed09800-f826-4d40-a243-7640de229d9d)를 따릅니다.

1. 시작 단추를 누르고 사진 앱을 엽니다.
2. 가져오기를 누르고 연결된 장치에서 카드를 고릅니다.
3. 가져올 항목과 저장할 위치를 고릅니다.
4. 화면 안내를 따라 가져오기를 끝냅니다.

파일 이름과 폴더 구조를 그대로 옮기려면 파일 탐색기로 복사하는 편이 단순합니다. 사진 앱은 가져올 항목을 골라 옮길 때 씁니다.

## Mac에서 SD 카드를 연결하는 순서

[Apple의 Mac SD 카드 슬롯 안내](https://support.apple.com/en-us/102352)를 따른 순서입니다.

1. 카드의 금속 접점이 아래를 보고 컴퓨터 쪽을 향하게 해서 슬롯에 넣습니다. 힘을 주어 밀어 넣지 않습니다.
2. 카드 아이콘이 나타나면 Finder에서 파일을 엽니다.
3. 다 쓴 뒤 카드 아이콘을 휴지통으로 드래그해 꺼냅니다.
4. 아이콘이 사라지면 카드를 뺍니다.

같은 안내가 적은 슬롯 조건입니다.

| 항목 | Apple 안내 |
| --- | --- |
| 지원 카드 | MMC, Default Speed, High Speed, UHS-I |
| UHS-II 지원 | 2022년 이후 Mac Studio, 2021년 이후 MacBook Pro, 2020년 iMac, iMac Pro |
| miniSD, microSD | 어댑터를 끼워 사용 |
| 지원하지 않는 카드 | SDIO 카드 |
| 주의 | 두께 2.1mm를 넘는 카드는 슬롯을 망가뜨릴 수 있습니다 |

## SD 카드는 어떻게 안전하게 빼나요?

윈도우는 [Microsoft 하드웨어 안전 제거 안내](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)를 따릅니다. Microsoft는 데이터 손실을 막으려면 빼기 전에 항상 안전 제거를 하라고 적습니다.

1. 작업 표시줄 알림 영역의 하드웨어 안전 제거 및 미디어 꺼내기 아이콘을 마우스 오른쪽 버튼으로 누릅니다. 아이콘이 없으면 숨겨진 아이콘 표시를 먼저 누릅니다.
2. 메뉴에서 카드 드라이브의 꺼내기를 고릅니다.
3. 하드웨어를 안전하게 제거할 수 있다는 알림이 뜨면 카드나 리더기를 뺍니다.

Mac은 카드 아이콘을 휴지통으로 드래그합니다. Apple은 Mac이 잠자기 상태일 때 카드를 빼면 데이터를 잃을 수 있다고 적습니다. 컴퓨터를 깨우고 꺼낸 뒤에 뺍니다.

## 컴퓨터에서 SD 카드가 안 보이면 무엇을 확인하나요?

| 증상 | 확인할 것 |
| --- | --- |
| Mac에서 카드 아이콘이 나타나지 않습니다 | 카드를 뺐다가 다시 넣습니다. Apple은 너무 느리거나 빠르게 넣으면 인식되지 않을 수 있다고 적습니다 |
| Mac에서 '수정할 수 없음'이 뜹니다 | 카드를 꺼내고 잠금 스위치를 풀어 다시 넣습니다 |
| 카드가 슬롯에서 안 보이고 리더기에서는 보입니다 | 슬롯이 카드 규격을 지원하는지 확인합니다 |
| 윈도우 안전 제거 아이콘이 안 보입니다 | Microsoft는 장치가 연결되지 않았거나 윈도우가 장치를 인식하지 못하면 아이콘이 없을 수 있다고 적습니다 |

포맷을 묻는 창이 뜨거나 오류가 반복되면 바로 포맷하지 마세요. [SD 카드 인식 안 될 때 확인 순서](/blog/ko/sd-card-not-working)를 먼저 따르세요. 포맷이 필요하면 [SD 카드 포맷 프로그램 사용법](/blog/ko/sd-card-formatter)을 참고하세요.

## SD 카드 컴퓨터 연결 자주 묻는 질문

### 노트북에 SD 슬롯이 없으면 어떻게 하나요?

USB 리더기를 씁니다. SD Association은 슬롯이 없는 컴퓨터에서 USB 리더기나 카드 어댑터로 데이터를 옮기라고 안내합니다. 노트북의 USB 단자 모양(USB-A, USB-C)에 맞는 리더기를 고르세요.

### 컴퓨터 슬롯에 microSD를 그대로 꽂을 수 있나요?

SD 슬롯에는 microSD를 SD 크기로 바꾸는 어댑터를 끼워 넣습니다. Apple도 Mac 슬롯에서 microSD를 쓰려면 어댑터를 쓰라고 안내합니다.

### 꺼내기 없이 그냥 빼도 되나요?

권하지 않습니다. Microsoft는 데이터 손실을 막으려면 빼기 전에 안전 제거를 하라고 적습니다. Apple도 꺼내기를 한 뒤에 카드를 빼라고 안내합니다.

### 슬롯이 UHS-I만 지원하면 UHS-II 카드를 못 쓰나요?

쓸 수 있습니다. [SD Association의 버스 방식 안내](https://www.sdcard.org/consumers/about-sd-memory-card-choices/bus-interface-speed-standards-for-large-size-data-transfer/)는 빠른 카드를 UHS-I 기기에서도 쓸 수 있다고 적습니다. 다만 UHS-II 속도는 나지 않습니다. 방식별 차이는 [UHS-I·UHS-II·SD Express 차이](/blog/ko/uhs-sd-card)에 있습니다.

### 64GB 카드를 넣었는데 오래된 컴퓨터가 읽지 못해요.

64GB 카드는 SDXC입니다. SD Association 안내에 따르면 SDXC 카드는 SDXC나 SDUC 기기에서만 씁니다. 슬롯이 SDHC까지만 지원하면 SDXC를 지원하는 USB 리더기를 쓰세요.
