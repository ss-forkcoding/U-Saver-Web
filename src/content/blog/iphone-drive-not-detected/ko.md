## 핵심 요약

아이폰 외장하드 인식이 안 될 때는 아이폰 쪽에서 외장하드 쪽으로 차례로 원인을 좁힙니다. 잠금 해제, 전원, 케이블, 형식과 파티션 순서입니다.

Apple 안내에 따르면 저장장치를 쓰려면 아이폰 잠금을 먼저 풀어야 합니다. 잠금을 푼 뒤에도 인식되지 않으면 외장하드를 뺐다가 다시 연결합니다.

외장하드는 외부 전원이 필요한 경우가 많습니다. 형식이 NTFS거나 데이터 파티션이 여러 개면 아이폰 파일 앱에 나타나지 않습니다.

"외장하드를 꽂았는데 파일 앱에 아무것도 안 떠요." "USB 메모리는 되는데 외장하드만 안 돼요." 외장하드와 외장 SSD를 아이폰에 연결할 때 자주 나오는 질문입니다. 처음 연결하는 순서는 [아이폰 외장하드 연결 방법](/blog/ko/iphone-hard-drive-connect)에 정리했습니다. 이 글은 연결했는데 인식되지 않을 때 확인할 순서를 다룹니다.

## 아이폰 외장하드 인식이 안 될 때 무엇부터 확인하나요?

증상에 맞는 줄을 찾아 해당 부분부터 보세요.

| 증상 | 먼저 확인할 것 | 이 글의 해당 부분 |
| --- | --- | --- |
| 잠긴 아이폰에 연결했는데 반응이 없음 | 아이폰 잠금 해제, 유선 액세서리 설정 | 잠금 해제 |
| 외장하드가 돌지 않거나 불이 켜지지 않음 | 외장하드 전원 | 전원 |
| 다른 케이블이나 어댑터에서는 될 때가 있음 | 케이블 규격, 어댑터 종류 | 케이블과 어댑터 |
| 외장하드는 켜지는데 위치 목록에 없음 | 형식과 데이터 파티션 수 | 형식과 파티션 |
| Mac이나 PC에서도 열리지 않음 | 디스크 검사 | 컴퓨터에서도 안 열릴 때 |

이 글은 특정 외장하드, 외장 SSD, 허브, 케이블을 시험하지 않았고 특정 제품을 추천하지 않습니다.

## 아이폰 잠금을 풀어야 외장하드가 인식되나요?

그렇습니다. [Apple의 액세서리 연결 허용 안내](https://support.apple.com/en-us/111806)에 따르면 아이폰은 기본적으로 잠금을 먼저 풀어야 USB 기기와 통신합니다. 저장장치를 연결할 때는 설정과 관계없이 항상 잠금을 풀어야 합니다.

1. 아이폰 잠금을 풉니다.
2. 외장하드를 연결합니다.
3. 연결을 허용할지 묻는 창이 나오면 허용합니다.
4. 그래도 인식되지 않으면 외장하드를 빼고, 잠금을 푼 상태에서 다시 연결합니다.

연결을 허용하는 방식은 설정 앱의 개인정보 보호 및 보안에서 보안 아래 유선 액세서리(Wired Accessories)에서 바꿉니다. Apple 안내의 선택지는 아래와 같습니다.

| 아이폰 단자 | 선택지 | 뜻 |
| --- | --- | --- |
| USB-C | Always Ask | 연결할 때마다 직접 승인합니다 |
| USB-C | Ask for New Accessories | 새 액세서리만 처음 연결할 때 승인합니다 |
| USB-C, Lightning | Automatically Allow When Unlocked | 잠금이 풀린 아이폰에 연결하면 자동으로 승인합니다(기본값) |
| USB-C, Lightning | Always Allow | 모든 액세서리를 자동으로 승인합니다 |

Always Ask로 바꿔 두었다면 연결할 때마다 승인 창이 뜹니다. 회사나 학교에서 관리하는 아이폰은 관리자가 이 설정을 정할 수 있다고 Apple은 설명합니다.

## 외장하드 전원이 부족하면 인식되지 않나요?

그럴 수 있습니다. [Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)는 외장 하드디스크가 아이폰과 함께 쓸 때 외부 전원이 필요한 경우가 많다고 설명합니다.

| 아이폰 단자 | 외장하드가 스스로 전원을 받지 못할 때 Apple 안내의 구성 |
| --- | --- |
| USB-C | 전원이 공급되는 USB 허브를 거쳐 연결합니다 |
| Lightning | Lightning to USB 3 Camera Adapter에 USB 전원 어댑터를 연결하고 외장하드를 꽂습니다 |

외장하드에 전원 어댑터 단자가 있으면 어댑터를 먼저 연결하세요. 제조사 사양에 전원 조건이 있다면 그것을 따릅니다. 이 글은 외장하드의 소비 전력을 측정하지 않았습니다. 어댑터 종류는 [아이폰 OTG 연결 조건](/blog/ko/iphone-otg-usb)에 정리했습니다.

## 케이블과 어댑터 때문에 인식되지 않을 수 있나요?

그럴 수 있습니다. [Apple의 USB-C 안내](https://support.apple.com/en-us/105099)는 USB-C 표준을 따르지 않는 기기와 케이블은 예상대로 동작하지 않을 수 있다고 설명합니다.

1. USB-C 표준을 따르는 케이블인지 확인합니다.
2. 다른 케이블로 바꿔 연결합니다.
3. 허브나 어댑터를 거친다면 빼고 직접 연결해 봅니다. 전원이 필요한 외장하드라면 전원 구성은 유지합니다.
4. USB 메모리를 같은 케이블로 연결해 봅니다. USB 메모리는 보이고 외장하드만 안 보이면 외장하드 쪽을 의심합니다.

같은 안내는 아이폰에 들어 있는 USB-C 케이블이 USB 2 속도를 지원한다고 적어 둡니다. 인식은 되는데 느리다면 10Gbit/s를 지원하는 USB 3 케이블이 필요한지 확인하세요. USB 3 속도를 지원하는 아이폰 모델은 [아이폰 SSD 연결 방법](/blog/ko/iphone-external-ssd-connect)에 정리했습니다.

## 형식과 파티션 때문에 외장하드가 안 보일 때는?

외장하드가 켜지는데도 파일 앱에 없다면 형식과 파티션을 확인합니다. [Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)에 따르면 외부 저장장치는 데이터 파티션이 하나여야 합니다. 형식은 APFS, APFS(암호화), macOS 확장(HFS+), exFAT, FAT32, FAT 중 하나여야 합니다.

| 확인할 것 | 확인하는 곳 | 해야 할 일 |
| --- | --- | --- |
| 파일 앱의 위치 목록 | 아이폰 파일 앱 | 둘러보기를 한 번 더 누릅니다 |
| 형식이 NTFS | Mac 디스크 유틸리티, 윈도우 파일 탐색기 | Apple 목록에 없으므로 자료를 옮긴 뒤 exFAT으로 포맷합니다 |
| 데이터 파티션이 여러 개 | Mac 디스크 유틸리티, 윈도우 디스크 관리 | 자료를 옮긴 뒤 저장장치 전체를 한 형식으로 지웁니다 |

윈도우의 디스크 관리는 [Microsoft 안내](https://learn.microsoft.com/en-us/windows-server/storage/disk-management/overview-of-disk-management)대로 드라이브마다 파티션을 나눠 보여 줍니다. Mac에서는 디스크 유틸리티에서 보기, 모든 기기 보기를 고르면 저장장치 아래의 볼륨이 보입니다.

저장장치 전체를 지울 때는 [Apple의 디스크 유틸리티 지우기 안내](https://support.apple.com/guide/disk-utility/erase-and-reformat-a-storage-device-dskutl14079/mac)대로 사이드바 맨 위의 저장장치를 고르고, 스킴은 GUID 파티션 맵을 고릅니다. 포맷하면 자료가 모두 지워집니다. Mac과 윈도우에서 exFAT으로 포맷하는 자세한 순서는 [exFAT 포맷 방법](/blog/ko/format-usb-exfat)에 있습니다. USB 메모리를 예로 들었지만 순서는 외장하드에도 같습니다.

USB-C 아이폰은 파일 앱에서도 포맷할 수 있습니다. [Apple의 파일 전송 안내](https://support.apple.com/guide/iphone/transfer-files-iphone-a-storage-device-iphe9aff429a/ios)에 따르면 위치 아래의 저장장치 이름을 길게 누르고 지우기를 고릅니다. 이 방법은 위치 목록에 저장장치가 보일 때만 쓸 수 있습니다.

## 외장하드가 컴퓨터에서도 안 열리면 어떻게 하나요?

Mac이나 PC에서도 열리지 않으면 아이폰보다 외장하드 자체를 의심합니다. 남길 자료가 있다면 포맷 전에 디스크를 검사합니다.

[Apple의 디스크 유틸리티 응급 처치 안내](https://support.apple.com/guide/disk-utility/repair-a-storage-device-dskutl1040/mac)를 따른 순서입니다.

1. 디스크 유틸리티를 열고 보기, 모든 기기 보기를 고릅니다.
2. 사이드바에서 외장하드의 볼륨을 하나씩 골라 응급 처치를 실행합니다.
3. 컨테이너가 있으면 컨테이너에도 실행합니다.
4. 마지막으로 맨 위의 저장장치를 골라 응급 처치를 실행합니다.

Apple은 응급 처치가 모든 문제를 찾거나 고치지는 못한다고 설명합니다. 응급 처치가 실패하면 한 번 더 시도합니다. 디스크 유틸리티가 디스크가 곧 고장 날 것이라고 알리면 수리할 수 없으니 자료를 백업하고 디스크를 교체하라고 안내합니다. 이때는 외장하드 제조사 지원에 문의하세요.

윈도우에서 검사하는 `chkdsk` 순서와 드라이브 문자가 없을 때의 대처는 [SD 카드 포맷 안될 때](/blog/ko/sd-card-not-working)에 정리했습니다. SD 카드를 예로 들었지만 윈도우의 순서는 외장하드에도 같습니다.

## 인식된 뒤에는 무엇을 하나요?

파일 앱의 위치 아래에 외장하드 이름이 보이면 연결된 것입니다. 사진, 영상, 연락처를 항목별로 옮기는 순서는 [아이폰 외장하드 백업 방법](/blog/ko/backup-iphone-external-drive)에 있습니다. 복사가 끝나기 전에 빼면 파일이 다 옮겨지지 않을 수 있으니 진행 표시가 사라진 뒤 분리하세요.

## USB 메모리에 정기적으로 저장하려면?

아래 앱은 USB 메모리를 기준으로 안내합니다. 외장하드와 외장 SSD에서의 동작은 확인하지 않았습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비 중이며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## 아이폰 외장하드 인식 자주 묻는 질문

### 잠긴 아이폰에 외장하드를 연결해 두면 인식되나요?

Apple 안내에 따르면 저장장치를 쓰려면 항상 아이폰 잠금을 먼저 풀어야 합니다. 잠금을 푼 뒤에도 인식되지 않으면 외장하드를 뺐다가 다시 연결하세요.

### USB 메모리는 인식되는데 외장하드만 안 돼요.

전원부터 확인하세요. Apple은 외장 하드디스크에 외부 전원이 필요한 경우가 많다고 설명합니다. USB-C 아이폰은 전원이 공급되는 USB 허브를, Lightning 아이폰은 USB 3 카메라 어댑터와 USB 전원 어댑터를 씁니다.

### 윈도우에서 쓰던 외장하드가 아이폰에서 안 보여요.

형식이 NTFS인지 확인하세요. NTFS는 Apple의 외부 저장장치 형식 목록에 없습니다. 자료를 다른 곳에 옮긴 뒤 exFAT으로 포맷하면 아이폰과 윈도우에서 함께 쓸 수 있습니다.

### 파티션을 나눈 외장하드도 쓸 수 있나요?

Apple 안내는 데이터 파티션이 하나인 저장장치만 쓸 수 있다고 설명합니다. 파티션을 하나로 합치려면 자료를 옮긴 뒤 저장장치 전체를 지워야 합니다.

### 외장하드를 연결하면 와이파이가 느려져요.

Apple USB-C 안내는 일부 USB-C 액세서리와 케이블이 무선 연결을 방해할 수 있다고 설명합니다. 액세서리를 분리하면 성능이 돌아옵니다. 다 쓴 뒤 분리하거나 다른 케이블로 바꿔 보세요.
