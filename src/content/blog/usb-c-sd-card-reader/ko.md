## 핵심 요약

C 타입 SD 카드 리더기는 USB-C 단자에 꽂아 SD 카드를 읽는 기기입니다. 리더기를 꽂고 카드를 넣은 뒤, 기기마다 정해진 앱에서 카드를 엽니다. 아이폰은 파일 앱, Mac은 Finder, 윈도우는 파일 탐색기, 안드로이드는 Files by Google입니다.

빼기 전에는 꺼내기를 먼저 합니다. Microsoft는 데이터 손실을 막으려면 USB 저장장치를 빼기 전에 하드웨어 안전 제거를 하라고 안내합니다.

전송 속도는 리더기, 카드, 꽂은 기기의 USB 속도 중 가장 느린 쪽에 묶입니다. 아이폰은 모델마다 USB 속도가 다릅니다.

"C 타입 리더기를 꽂았는데 아무 창도 안 떠요." "다 옮긴 뒤 그냥 뽑아도 되나요?" USB-C 리더기를 처음 쓰는 분들이 자주 묻는 질문입니다. 리더기를 고르는 기준은 [SD 카드 리더기 고르는 법](/blog/ko/choose-sd-card-reader)에 따로 정리했습니다. 이 글은 이미 가진 리더기를 기기별로 쓰는 순서를 다룹니다.

## C 타입 SD 카드 리더기는 어떤 기기에 꽂을 수 있나요?

USB-C 단자가 있는 기기에 꽂습니다. Apple의 [USB-C to SD Card Reader 제품 페이지](https://www.apple.com/shop/product/MW653AM/A/usb-c-to-sd-card-reader)는 이 리더가 USB-C 단자가 있는 Mac, iPad, iPhone에서 UHS-II 속도로 사진과 영상을 옮긴다고 적습니다. UHS-II 카드와 함께 쓰고, 다른 SD 카드와 어댑터에도 하위 호환된다고 안내합니다.

| 기기 | 카드를 여는 곳 | 근거 |
| --- | --- | --- |
| USB-C 아이폰 | 파일 앱, 사진 앱 | [Apple 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios) |
| Mac | Finder 사이드바의 위치 | [Apple Mac 저장장치 안내](https://support.apple.com/guide/mac-help/connect-storage-devices-mac-mchl027f1d66/mac) |
| 윈도우 PC | 파일 탐색기 | [Microsoft 하드웨어 안전 제거 안내](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369) |
| 안드로이드 | Files by Google의 저장장치 | [Google USB 저장장치 안내](https://support.google.com/files/answer/9301516?hl=en) |

Lightning 아이폰에는 C 타입 리더기를 바로 꽂을 수 없습니다. Lightning 단자에 맞는 리더나 어댑터는 [아이폰 OTG 연결 조건](/blog/ko/iphone-otg-usb)에 정리했습니다.

## C 타입 SD 카드 리더기를 아이폰에서 쓰는 순서

[Apple 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)를 따른 순서입니다.

1. 리더기를 아이폰의 USB-C 충전 단자에 꽂습니다.
2. SD 카드를 리더기에 넣습니다. 카드는 한 방향으로만 들어가니 억지로 밀어 넣지 않습니다.
3. 파일 앱을 열고 둘러보기를 누릅니다.
4. 위치 아래의 카드 이름을 누릅니다. 위치가 보이지 않으면 둘러보기를 한 번 더 누릅니다.
5. 다 쓴 뒤 리더기를 충전 단자에서 뺍니다.

카메라로 찍은 사진과 영상은 사진 앱에서 바로 가져올 수 있습니다. 가져오기 순서와 안 될 때 확인할 것은 [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader)에 있습니다.

카드는 데이터 파티션이 하나여야 하고 APFS, macOS 확장(HFS+), exFAT, FAT32, FAT 중 하나로 포맷되어 있어야 합니다. NTFS는 목록에 없습니다. 형식을 바꾸는 순서는 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에 있습니다.

## C 타입 SD 카드 리더기를 Mac에서 쓰는 순서

[Apple Mac 저장장치 안내](https://support.apple.com/guide/mac-help/connect-storage-devices-mac-mchl027f1d66/mac)를 따른 순서입니다.

1. 리더기를 Mac의 USB-C 단자에 꽂고 카드를 넣습니다.
2. Dock에서 Finder를 엽니다.
3. 사이드바의 위치 아래에서 카드 이름을 고릅니다.
4. 파일을 Mac의 폴더로 끌어 옮깁니다. Mac 파일을 카드로 옮길 때는 반대로 카드 이름 위로 끌어 놓습니다.
5. 카드 이름 옆의 꺼내기 버튼을 누르거나, 카드를 고른 뒤 파일 메뉴에서 꺼내기를 고릅니다.
6. 사이드바에서 카드가 사라지면 리더기를 뺍니다.

꺼내기가 되지 않으면 다른 앱이나 사용자가 카드의 파일을 쓰고 있을 수 있습니다. 같은 안내가 이 경우를 따로 설명합니다. Mac에 SD 슬롯이 있다면 리더기 없이 쓸 수 있는지 [SD 카드 리더기 고르는 법](/blog/ko/choose-sd-card-reader)에서 확인하세요.

## C 타입 SD 카드 리더기를 윈도우 PC에서 쓰는 순서

1. 리더기를 PC의 USB-C 단자에 꽂고 카드를 넣습니다.
2. 파일 탐색기를 열어 카드 드라이브를 찾고 파일을 복사합니다.
3. 작업 표시줄 알림 영역의 하드웨어 안전 제거 및 미디어 꺼내기 아이콘을 마우스 오른쪽 버튼으로 누릅니다. 아이콘이 없으면 숨겨진 아이콘 표시를 먼저 누릅니다.
4. 메뉴에서 카드 드라이브의 꺼내기를 고릅니다.
5. 하드웨어를 안전하게 제거할 수 있다는 알림이 뜨면 리더기를 뺍니다.

3~5번은 [Microsoft 하드웨어 안전 제거 안내](https://support.microsoft.com/en-us/windows/safely-remove-hardware-in-windows-1ee6677d-4e6c-4359-efca-fd44b9cec369)의 순서입니다. Windows 11과 Windows 10에 같은 아이콘이 있습니다. 아이콘이 계속 보이지 않으면 같은 안내의 작업 표시줄 설정 방법을 따릅니다.

## C 타입 SD 카드 리더기를 안드로이드에서 쓰는 순서

[Google의 Files by Google 안내](https://support.google.com/files/answer/9301516?hl=en)는 USB 저장장치를 Android 7.0 이상에서만 열 수 있다고 적습니다.

1. 리더기를 휴대폰의 USB-C 단자에 꽂고 카드를 넣습니다.
2. Files by Google을 엽니다.
3. USB를 쓸 수 있다는 알림이 뜨면 열 저장장치를 누르고 허용을 누릅니다. 알림이 열리지 않으면 리더기를 뺐다가 다시 꽂습니다.
4. 저장장치 목록에서 카드를 눌러 파일을 찾습니다.
5. 파일 옆의 아래 화살표에서 복사나 이동 메뉴를 고르고, 옮길 위치를 정합니다.

휴대폰 제조사마다 메뉴 이름이 다를 수 있습니다. 이 글은 제조사별 화면을 확인하지 않았습니다.

## C 타입 SD 카드 리더기 속도는 무엇에 묶이나요?

전송 속도는 세 가지 중 가장 느린 쪽에 묶입니다.

| 요소 | 확인할 것 |
| --- | --- |
| 카드 | UHS-I, UHS-II 같은 버스 방식과 속도 표기 |
| 리더기 | 리더기가 지원하는 버스 방식 |
| 꽂은 기기 | USB-C 단자의 USB 속도 |

[Apple의 USB-C 아이폰 안내](https://support.apple.com/en-us/105099)는 iPhone 15 Pro, 16 Pro, 17 Pro, 18 Pro 모델과 iPhone Duo가 USB 3.2 Gen 2(최대 10Gbit/s)를 지원한다고 적습니다. [Apple 카메라 어댑터 안내](https://support.apple.com/en-us/118280)는 USB 3 목록에 없는 기기와 어댑터는 USB 2 속도를 쓴다고 적습니다.

UHS-II 리더기에 UHS-I 카드를 넣으면 UHS-I 성능으로 읽습니다. 버스 방식별 차이는 [UHS-I·UHS-II·SD Express 차이](/blog/ko/uhs-sd-card)에 있습니다. 이 글은 리더기별 실제 속도를 측정하지 않았습니다.

## 카드가 보이지 않을 때 무엇을 확인하나요?

| 순서 | 확인할 것 | 해야 할 일 |
| --- | --- | --- |
| 1 | 카드 방향 | 카드를 빼고 방향을 확인해 다시 넣습니다 |
| 2 | 리더기 연결 | 리더기를 뺐다가 다시 꽂습니다 |
| 3 | 카드 크기 | microSD는 microSD 슬롯이나 SD 어댑터를 씁니다 |
| 4 | 용량 규격 | SDXC 카드는 SDXC 이상을 지원하는 리더기에 넣습니다 |
| 5 | 파일 형식 | 아이폰은 NTFS 카드를 읽지 못합니다 |

microSD와 어댑터는 [micro SD 카드와 SD 카드 차이](/blog/ko/microsd-vs-sd)에, 용량 규격은 [SDHC·SDXC·SDUC 차이](/blog/ko/sdhc-vs-sdxc)에 있습니다. 그래도 안 되면 [SD 카드 인식 안 될 때](/blog/ko/sd-card-not-working)의 순서를 따르세요.

## 아이폰 사진을 USB 메모리에 저장하려면?

아래 앱은 USB 메모리를 기준으로 안내합니다. USB 메모리 연결 조건은 [아이폰 USB 메모리 사용법](/blog/ko/iphone-flash-drive-guide)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비하고 있으며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## C 타입 SD 카드 리더기 자주 묻는 질문

### 리더기를 꽂았는데 아이폰에 아무 창도 안 떠요.

정상입니다. Apple 안내는 파일 앱의 둘러보기에서 위치 아래의 카드 이름을 누르라고 적습니다. 사진은 사진 앱에서 가져옵니다.

### 다 옮긴 뒤 그냥 뽑아도 되나요?

Mac과 윈도우에서는 꺼내기를 먼저 합니다. Microsoft는 데이터 손실을 막으려면 빼기 전에 하드웨어 안전 제거를 하라고 안내합니다. 아이폰은 Apple 안내에 충전 단자에서 빼는 방법만 나옵니다. 복사 진행 표시가 사라진 것을 확인하고 빼세요.

### Lightning 아이폰에도 C 타입 리더기를 쓸 수 있나요?

바로 꽂을 수 없습니다. Apple은 Lightning 아이폰용으로 Lightning to SD Card Camera Reader를 안내합니다.

### UHS-II 리더기면 아이폰에서도 UHS-II 속도가 나나요?

보장되지 않습니다. 아이폰의 USB 속도가 전송 속도를 묶습니다. Apple 안내에서 USB 3 목록에 없는 아이폰은 USB 2 속도를 씁니다.

### SD 카드 내용은 암호화되나요?

[Microsoft 비교표](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison)에서 exFAT의 파일 시스템 수준 암호화는 지원하지 않음으로 나옵니다. 카드를 잃어버리면 다른 사람이 내용을 볼 수 있으니 보관에 유의하세요.
