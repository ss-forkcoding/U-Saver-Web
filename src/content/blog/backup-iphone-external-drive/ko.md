## 핵심 요약

아이폰 외장하드 백업은 사진, 영상, 연락처, 파일을 항목별로 외장하드에 복사하는 방식입니다. 방법은 두 가지입니다. 외장하드를 아이폰에 직접 연결해 파일 앱으로 저장하거나, Mac이나 윈도우 PC로 사진을 가져오면서 저장 위치로 외장하드를 고릅니다.

Apple 안내는 외장 하드디스크를 아이폰에 연결할 때 외부 전원이 필요한 경우가 많다고 설명합니다. 직접 연결이 안 되면 전원부터 확인하세요.

메시지, 앱 데이터, 아이폰 설정은 외장하드로 옮기는 기본 방법이 없습니다. 세 항목은 iCloud 백업이나 컴퓨터 백업으로 보관하세요.

"집에 쓰던 외장하드가 있는데 아이폰 사진을 옮길 수 있나요?" "외장하드를 꽂았는데 아이폰에서 안 보여요." 외장하드는 용량이 커서 사진과 영상을 모아 두기 좋습니다. 이 글은 외장하드를 백업용으로 준비하는 방법, 두 가지 저장 순서, 지우기 전에 확인할 항목을 차례로 정리합니다.

## 아이폰 외장하드 백업은 어떤 방법이 있나요?

컴퓨터가 있는지와 외장하드의 전원 방식이 방법을 정합니다.

| 구분 | 아이폰에 직접 연결 | 컴퓨터를 거쳐 저장 |
| --- | --- | --- |
| 필요한 것 | 외장하드, 단자에 맞는 케이블이나 어댑터 | Mac 또는 윈도우 PC, 아이폰 케이블 |
| 쓰는 앱 | 사진 앱, 연락처 앱, 파일 앱 | Mac의 이미지 캡처, 윈도우의 사진 앱 |
| 담기는 항목 | 사진, 영상, 연락처, 파일 | 사진, 영상 |
| 전원 | 외장하드에 따라 외부 전원이 필요할 수 있습니다 | 외장하드를 컴퓨터에 연결합니다 |
| 외장하드 형식 | Apple 목록의 형식이어야 합니다 | 컴퓨터가 읽는 형식이면 됩니다 |

컴퓨터가 없다면 직접 연결을 쓰세요. 외장하드가 아이폰에서 보이지 않거나 NTFS 형식이라 다시 포맷하기 어렵다면 컴퓨터를 거치는 방법이 맞습니다. 컴퓨터 없이 할 수 있는 백업은 [컴퓨터 없이 아이폰 백업하는 방법](/blog/ko/backup-iphone-without-computer)에 모았습니다.

## 아이폰 외장하드를 백업용으로 준비하는 방법

직접 연결하려면 외장하드가 아래 조건을 맞춰야 합니다. [Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)에 따르면 외부 저장장치는 데이터 파티션이 하나여야 합니다. 형식은 APFS, APFS(암호화), macOS 확장(HFS+), exFAT, FAT32, FAT 중 하나여야 합니다.

| 확인할 것 | 기준 | 해야 할 일 |
| --- | --- | --- |
| 형식 | Apple 목록의 형식 | NTFS라면 자료를 옮긴 뒤 다시 포맷하거나 컴퓨터를 거칩니다 |
| 파티션 | 데이터 파티션 하나 | 여럿이면 Mac이나 PC에서 하나로 만듭니다 |
| 파일 크기 | FAT32는 파일 하나가 4GiB까지 | 긴 영상은 exFAT이나 APFS에 저장합니다 |
| 전원 | 외장하드가 스스로 전원을 받는지 | 받지 못하면 아래 전원 방법을 씁니다 |

FAT32의 4GiB 제한은 [Microsoft의 파일 시스템 비교표](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison) 기준입니다. 같은 표에서 exFAT의 파일 하나 최대 크기는 2^64-1바이트입니다. 윈도우 PC에서도 외장하드를 열어 볼 계획이면 exFAT이 맞습니다. 포맷하면 외장하드의 자료가 모두 지워지므로 먼저 다른 곳에 복사하세요. 순서는 [exFAT 포맷 방법](/blog/ko/format-usb-exfat)에 있습니다. USB 메모리를 예로 들었지만 Mac 디스크 유틸리티와 윈도우의 순서는 외장하드에도 같습니다.

## 아이폰에 외장하드를 연결할 때 전원이 필요한가요?

필요한 경우가 많습니다. [Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)는 외장 하드디스크가 아이폰과 함께 쓸 때 외부 전원이 필요한 경우가 많다고 설명합니다. 외장하드가 스스로 전원을 받지 못하면 아래 방법을 씁니다.

| 아이폰 단자 | Apple 안내의 전원 공급 방법 |
| --- | --- |
| USB-C | 전원이 공급되는 USB 허브를 거쳐 연결합니다 |
| Lightning | Lightning to USB 3 Camera Adapter에 USB 전원 어댑터를 연결합니다 |

이 글은 특정 외장하드를 시험하지 않았고 추천하지 않습니다. 소비 전력도 측정하지 않았습니다. 제조사 사양에 전원 조건이 있다면 그것을 따르세요. 케이블과 어댑터 종류는 [아이폰 SSD 연결 방법](/blog/ko/iphone-external-ssd-connect)과 [아이폰 OTG 연결 조건](/blog/ko/iphone-otg-usb)에 정리했습니다.

## 아이폰에 외장하드를 직접 연결해 백업하는 순서

외장하드를 연결하고 파일 앱에서 둘러보기를 누릅니다. 위치 아래에 외장하드 이름이 보이면 시작합니다.

### 사진과 영상을 외장하드에 저장합니다

[Apple의 iCloud 사진 다운로드 안내](https://support.apple.com/en-us/111762)를 따른 순서입니다.

1. 사진 앱에서 보관함을 엽니다.
2. 선택을 누르고 저장할 사진과 영상을 고릅니다.
3. 공유 버튼을 누른 뒤 수정되지 않은 원본 내보내기를 누릅니다.
4. 파일 앱 화면에서 뒤로 화살표를 눌러 위치 아래의 외장하드를 고릅니다.
5. 저장을 누릅니다.

iCloud 사진을 쓰면 원본을 내려받는 데 Wi-Fi가 필요합니다. 큰 영상을 옮기는 요령은 [아이폰 동영상 옮기기](/blog/ko/iphone-videos-to-usb)에 있습니다.

### 연락처와 파일을 외장하드에 저장합니다

연락처는 [Apple의 연락처 내보내기 안내](https://support.apple.com/guide/iphone/export-contacts-iph075ddebf2/ios)대로 연락처 앱의 목록을 길게 눌러 내보내기를 고릅니다. 공유 방법에서 파일에 저장을 누르고 외장하드를 고릅니다.

문서와 파일은 파일 앱에서 길게 눌러 복사를 고릅니다. 외장하드 폴더를 열고 빈 곳을 길게 눌러 붙여넣기를 고릅니다. 출처는 [Apple의 파일 전송 안내](https://support.apple.com/guide/iphone/transfer-files-iphone-a-storage-device-iphe9aff429a/ios)입니다. 항목별 순서는 [아이폰 외장 SSD 백업 방법](/blog/ko/backup-iphone-to-ssd)과 같습니다.

## 컴퓨터를 거쳐 아이폰 사진을 외장하드에 백업하는 순서

외장하드를 컴퓨터에 연결한 뒤 아이폰을 케이블로 연결합니다. 아이폰에 이 컴퓨터를 신뢰하겠냐는 질문이 나오면 신뢰를 누릅니다.

### Mac에서는 이미지 캡처를 씁니다

[Apple의 이미지 캡처 안내](https://support.apple.com/guide/image-capture/transfer-images-to-your-mac-imgcp1003/mac)를 따른 순서입니다.

1. Mac에서 이미지 캡처 앱을 엽니다.
2. 사이드바의 기기 아래에서 아이폰을 고릅니다.
3. 가져올 사진과 영상을 고릅니다.
4. 창 아래의 가져올 위치 메뉴에서 기타를 고른 뒤 외장하드의 폴더를 고릅니다.
5. 다운로드나 모두 다운로드를 누릅니다.

Apple 안내에 따르면 라이브 포토는 사진 파일과 영상 파일 두 개로 저장됩니다.

### 윈도우 PC에서는 사진 앱을 씁니다

[Apple의 사진 전송 안내](https://support.apple.com/en-us/120267)는 Microsoft Store에서 Apple Devices 앱을 설치하라고 설명합니다. 그다음은 [Microsoft의 사진 가져오기 안내](https://support.microsoft.com/en-us/windows/apps/photos/import-photos-and-videos-from-phone-to-pc)를 따른 순서입니다.

1. 아이폰을 켜고 잠금을 풉니다. Microsoft 안내에 따르면 잠긴 기기는 PC가 찾지 못합니다.
2. 시작 버튼을 누르고 사진 앱을 엽니다.
3. 가져오기를 누르고 연결된 아이폰을 고릅니다.
4. 가져올 항목을 고르고 저장 위치로 외장하드의 폴더를 고릅니다.

iCloud 사진을 쓰면 PC로 가져오기 전에 원본을 아이폰에 내려받아야 합니다. Apple 안내는 윈도우 호환성을 높이려면 설정 앱의 카메라, 포맷에서 높은 호환성을 고르라고 설명합니다. 이 설정은 앞으로 찍는 사진과 영상에만 적용됩니다.

## 외장하드 백업과 Apple 백업은 무엇이 다른가요?

외장하드 백업은 파일 사본을 따로 두는 일입니다. Apple 백업은 아이폰의 정보와 설정을 함께 저장합니다.

| 구분 | 외장하드에 복사 | iCloud 백업 | 컴퓨터 백업 |
| --- | --- | --- | --- |
| 저장 위치 | 외장하드 | iCloud | Mac 또는 Windows 기기 |
| 담기는 항목 | 사진, 영상, 연락처, 파일 | 기기 설정, 홈 화면 배치 등 iCloud에 동기화되지 않는 정보 | 아이폰의 데이터 |
| 메시지, 앱 데이터 | 담기지 않습니다 | Apple 백업 범위를 따릅니다 | Apple 백업 범위를 따릅니다 |
| 새 아이폰으로 옮기기 | 파일을 하나씩 다시 넣습니다 | 백업으로 옮길 수 있습니다 | 백업으로 옮길 수 있습니다 |

출처는 [Apple의 아이폰 백업 안내](https://support.apple.com/guide/iphone/back-up-iphone-iph3ecf67d29/ios)입니다. Apple 안내는 컴퓨터 백업을 Mac에 저장한다고 설명합니다. 백업 저장 위치를 외장하드로 바꾸는 방법은 Apple 안내에 없습니다. 아이폰을 새 기기로 그대로 옮기려면 Apple 백업을 쓰고, 사진과 영상의 사본은 외장하드에 따로 두세요.

## 아이폰 외장하드 백업 뒤 확인할 다섯 가지

아래 다섯 가지 중 하나라도 "아니요"라면 아이폰의 사진을 지우지 마세요.

1. 외장하드의 사진이 파일 앱이나 컴퓨터에서 열립니다.
2. 가장 긴 영상이 끝까지 재생됩니다.
3. 외장하드에 저장한 사진과 영상의 개수가 고른 개수와 같습니다.
4. 연락처 카드 파일이 외장하드에 들어 있습니다.
5. 외장하드가 고장 나거나 없어져도 괜찮도록 다른 곳에 사본이 하나 더 있습니다.

[Microsoft 비교표](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison)에서 exFAT과 FAT32는 파일 시스템 수준 암호화를 지원하지 않음으로 나옵니다. exFAT 외장하드를 가진 사람은 누구나 내용을 열 수 있으니 보관 장소에 신경 쓰세요.

## USB 메모리에 정기적으로 저장하려면?

아래 앱은 USB 메모리를 기준으로 안내합니다. 외장하드에서의 동작은 확인하지 않았습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비 중이며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

USB 메모리로 백업하는 순서는 [아이폰 USB 백업](/blog/ko/backup-iphone-to-usb)에 있습니다.

## 아이폰 외장하드 백업 자주 묻는 질문

### 아이폰 전체를 외장하드에 백업할 수 있나요?

Apple 안내에서 아이폰 백업의 저장 위치는 iCloud와 컴퓨터입니다. 외장하드에는 사진, 영상, 연락처, 파일을 항목별로 저장합니다.

### 외장하드를 꽂았는데 아이폰에서 안 보여요.

먼저 전원을 확인하세요. USB-C 아이폰은 전원이 공급되는 USB 허브를, Lightning 아이폰은 Lightning to USB 3 Camera Adapter에 USB 전원 어댑터를 연결해 시험합니다. 그래도 안 보이면 Mac이나 PC에서 형식과 파티션 수를 확인하세요.

### NTFS 외장하드에 아이폰 사진을 백업할 수 있나요?

NTFS는 Apple의 외부 저장장치 형식 목록에 없어 직접 연결로는 쓸 수 없습니다. 윈도우 PC를 거치면 형식을 바꾸지 않고 사진 앱으로 가져올 수 있습니다. 직접 연결로 쓰려면 자료를 옮긴 뒤 exFAT으로 포맷하세요.

### 4GB가 넘는 영상이 외장하드에 저장되지 않아요.

외장하드가 FAT32일 가능성이 큽니다. FAT32는 파일 하나가 4GiB를 넘을 수 없습니다. exFAT이나 APFS로 포맷한 뒤 다시 저장하세요.

### 외장하드 백업에 메시지도 들어가나요?

들어가지 않습니다. 메시지를 보관하려면 iCloud나 컴퓨터로 아이폰을 백업하세요.
