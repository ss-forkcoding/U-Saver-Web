## この記事の要点

Galaxy SDカードは、すべてのGalaxyで使えるわけではありません。Samsung日本のサポートでは、S21シリーズ以降、Z Flipシリーズ、Z Foldシリーズは外部SDカードを挿入できません。対応する機種でも、使える最大容量は機種ごとに違います。

カードを使える機種なら、設定のストレージ画面でカードのフォーマット、マウント解除、暗号化をします。メニューの名前と場所はOne UIのバージョンや機種で異なります。

カードを抜く前に、マウント解除をします。Samsung日本のサポートは、解除せずに抜くと保存データが壊れる場合があると説明しています。

「新しいGalaxyを買ったらSDカードの場所が見当たらない」「カードを挿したけれど、設定のどこで管理するの?」。Galaxy SDカードを初めて扱う方からよく出る声です。この記事では、自分のGalaxyにスロットがあるかを確かめる方法と、設定メニューでカードを管理する方法を扱います。写真をカードに移す手順は[Androidで内部ストレージからSDカードに写真を移動する方法](/blog/ja/android-photos-to-sd)に、Androidスマートフォン全般でのカードの使い方は[スマホのSDカードの使い方](/blog/ja/android-microsd)にまとめました。

## 自分のGalaxyにSDカードのスロットはありますか?

機種によって違います。[Samsung日本サポートの対応microSDカードの案内](https://www.samsung.com/jp/support/mobile-devices/tell-me-a-micro-sd-card-or-sim-card-that-can-be-used-in-the-device/)の一部は次のとおりです。

| 区分 | 主な機種 |
| --- | --- |
| 外部SDカードの挿入不可 | S6 / S6 edge、S21シリーズ以降、A36 5G、A57 5G、Z Flipシリーズ、Z Foldシリーズ |
| 最大256GB | S7 edge、S8 / S8+、A8、Note8 |
| 最大512GB | S9 / S9+、S10 / S10+、A7、A20、A30、A41、Note9 |
| 最大1TB | S20 5G / S20+ 5G / S20 Ultra 5G、A21、A32 5G、A51 5G〜A55 5G、Note20 Ultra 5G など |
| 最大1.5TB | A25 5G |

表は各通信会社のモデル名ではなく製品名で書かれています。同じ案内は、海外で販売されているモデルとは異なる場合があると説明しています。[Samsung米国サポート](https://www.samsung.com/us/support/answer/ANS10001928/)も、すべてのSamsung機器がmicroSDに対応するわけではなく、非対応の機種のトレイにはSIMの場所しかないとしています。

確かめる順番は次のとおりです。

1. 「設定」アプリ>「端末情報」で製品名を確かめます。
2. 上の表か、Samsungサイトのその機種の仕様ページでメモリーカードの項目を探します。
3. 最大容量を控えておきます。カードはこの容量の範囲で選びます。

容量規格の違いは[SDXCとは?](/blog/ja/sdhc-vs-sdxc)にあります。この記事は特定のカードを試したり勧めたりしていません。

## Galaxy SDカードのトレイはどうなっていますか?

多くの機種では、SIMトレイと一緒に使います。[Samsung英国サポート](https://www.samsung.com/uk/support/mobile-devices/using-an-sd-card/)が挙げるトレイの種類です。

| トレイの種類 | 入れられるもの |
| --- | --- |
| 兼用(ハイブリッド)トレイ | SIM 2枚、またはSIM 1枚とSDカード1枚 |
| デュアルSIMトレイ | SIM 2枚 |
| シングルSIMトレイ | SIM 1枚 |

トレイには、SDカードを置く場所の表示があります。カードは金色の端子を下に向けて置きます。[Samsung米国サポート](https://www.samsung.com/us/support/answer/ANS10001928/)は、取り出しピンをマイクやスピーカーの穴に入れないよう、トレイの輪郭を確かめるよう案内しています。トレイが抜けない、または壊れた場合は修理が必要になることがあるとしています。

バッテリーを外せる機種は手順が違います。同じ米国サポートによると、XCover6 Proは電源を切り、背面カバーとバッテリーを外してから、SIMスロットのすぐ上にあるカードの場所に挿します。

## Galaxyの設定でSDカードはどこにありますか?

「設定」>「デバイスケア」(「バッテリーとデバイスケア」)>「ストレージ」です。[Samsung日本サポートのマウント解除の案内](https://www.samsung.com/jp/support/mobile-devices/how-do-i-dismount-an-external-sd-card-of-galaxy/)では、ストレージで内部ストレージの欄をタップし、「外部ストレージ」を選びます。[Samsung米国サポート](https://www.samsung.com/us/support/answer/ANS10001928/)は、画面上部の内部ストレージを左にスワイプするとSDカードの画面が出ると説明しています。

この画面でできることは次のとおりです。

| したいこと | 設定の場所 | 出典 |
| --- | --- | --- |
| カードのフォーマット | ストレージ>SDカード>その他のオプション>フォーマット | [Samsung米国](https://www.samsung.com/us/support/answer/ANS10001928/) |
| マウント解除 | ストレージ>外部ストレージ>他のオプション>マウント解除 | [Samsung日本](https://www.samsung.com/jp/support/mobile-devices/how-do-i-dismount-an-external-sd-card-of-galaxy/) |
| 暗号化・暗号化の解除 | 設定の検索でSDカードの暗号化・復号化を探す | [Samsung米国](https://www.samsung.com/us/support/answer/ANS10001928/) |
| アプリの保存先の変更 | 設定>アプリ>アプリを選択>ストレージ>変更 | [Samsung米国](https://www.samsung.com/us/support/answer/ANS10001928/) |

同じ米国サポートは、SamsungのAndroid機器はカードを内部ストレージとして組み込む方式(Adoptable storage)に対応していないと説明しています。カードは別のストレージとして表示されます。

## GalaxyでSDカードをフォーマットするには?

設定からフォーマットします。フォーマットするとカードのデータはすべて消えるので、必要なデータは先にパソコンなどにコピーします。[Samsung米国サポート](https://www.samsung.com/us/support/answer/ANS10001928/)の手順です。

1. 「設定」を開き、「バッテリーとデバイスケア」をタップします。
2. 「ストレージ」をタップします。
3. 画面上部の内部ストレージを左にスワイプし、SDカードの画面を出します。
4. 縦3点の「その他のオプション」をタップし、「フォーマット」をタップします。
5. 確認画面でもう一度「フォーマット」をタップします。

[Samsung韓国サービスセンターの案内](https://www.samsungsvc.co.kr/solution/618136)には、ストレージ>その他>詳細設定>SDカード>フォーマットという経路も載っています。機種によってどちらかが表示されます。

カードの形式は次のとおりです。

| 項目 | Samsungの案内 | 出典 |
| --- | --- | --- |
| 使える形式 | FAT32かexFAT、exFATを推奨 | [Samsung米国](https://www.samsung.com/us/support/answer/ANS10001928/) |
| FAT32 | 32GB未満のカードのみ、4GBを超えるファイルは不可 | 同じ案内 |
| NTFS・APFS | 非対応 | 同じ案内 |
| 容量ごとの形式 | 32GBまではFAT32、64GBからはexFAT | [Samsung韓国サービスセンター](https://www.samsungsvc.co.kr/solution/39935) |

パソコンでフォーマットする方法は[マイクロSDカードフォーマット方法](/blog/ja/format-microsd)にあります。

## Galaxy SDカードのマウントを解除するには?

カードを抜く前に、設定で解除します。[Samsung日本サポート](https://www.samsung.com/jp/support/mobile-devices/how-do-i-dismount-an-external-sd-card-of-galaxy/)の手順で、Galaxy A55(Android 16 / One UI 8.5)を基にしています。

1. 設定アプリを開きます。
2. 「デバイスケア」をタップします。
3. 「ストレージ」をタップします。
4. 内部ストレージの欄をタップします。
5. 「外部ストレージ」をタップします。
6. 右上の縦3点「他のオプション」をタップします。
7. 「マウント解除」をタップします。解除されるとSDカードの情報が見えなくなります。

デバイスケアから解除できない場合は、同じ案内のとおり「マイファイル」アプリで「外部SDカード」を開き、縦3点>「マウント解除」をタップします。外付けのカードリーダーを使っている場合も、マイファイルから操作します。

## Galaxy SDカードを暗号化すると何が変わりますか?

暗号化した機器でしか、カードを読めなくなります。[Samsung米国サポート](https://www.samsung.com/us/support/answer/ANS10001928/)の手順です。

1. 本体を充電器につなぎます。暗号化と解除はバッテリーを早く消費します。
2. 設定を開き、SDカードの暗号化(または復号化)を検索して選びます。
3. 暗号化(または復号化)をタップします。
4. 画面ロックを設定している場合は、ロックの情報を入力します。
5. 終わるまで待ちます。カードの容量とデータ量によって数分かかります。

同じ案内は、カードを暗号化したまま本体を初期化すると、その本体でもカードを読めなくなると説明しています。初期化する前や、カードをパソコンやほかのスマートフォンで使う前に、暗号化を解除します。

## GalaxyがSDカードを認識しないときは?

順番に確かめます。[Samsung韓国サービスセンターの案内](https://www.samsungsvc.co.kr/solution/618136)の順序です。

| 順番 | すること | 内容 |
| --- | --- | --- |
| 1 | ソフトウェア更新 | 設定>ソフトウェア更新>ダウンロードおよびインストール |
| 2 | カードを挿し直す | 電源を切ってカードを取り出し、傷や汚れを確かめ、柔らかい布で拭いてから挿し直します |
| 3 | ほかの機器で確かめる | ほかの機器に挿して認識するか見ます |
| 4 | 強制再起動 | サイドボタンと音量下ボタンで電源を切り、入れ直します |
| 5 | セーフモード | セーフモードで認識するなら、最近入れたアプリの削除を試します |
| 6 | フォーマット | データをパソコンにコピーしてから、設定でフォーマットします |
| 7 | 端末診断 | Samsung Membersアプリの端末診断でSDカードの項目を点検します |

ほかのスマートフォンやパソコンでも認識しない場合、[Samsung韓国サービスセンター](https://www.samsungsvc.co.kr/solution/39935)はカードの損傷の可能性があるとして、サービスセンターでの点検を勧めています。カードの点検手順は[microSDが認識しない・フォーマットできないときの確認手順](/blog/ja/sd-card-not-working)にもまとめました。

## スロットのないGalaxyでSDカードを使うには?

USB-Cのカードリーダーをつなぐ方法があります。[Samsung日本サポート](https://www.samsung.com/jp/support/mobile-devices/how-do-i-dismount-an-external-sd-card-of-galaxy/)は、外付けのカードリーダーを使う場合はマイファイルからマウント解除するよう案内しています。リーダーの動作は製品ごとに違うので、リーダーのメーカーの案内を確かめてください。パソコンでカードを開く方法は[SDカードをパソコンにつなぐ方法](/blog/ja/sd-card-to-pc)にあります。

## iPhoneにもSDカードのスロットはありますか?

ありません。iPhoneでは、カードリーダーを充電端子につなぎ、ファイルアプリでカードを開きます。GalaxyでexFATとして使っていたカードは、[Appleの外部ストレージデバイスの案内](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)にある形式(APFS、Mac OS拡張(HFS+)、exFAT、FAT32、FAT)に入ります。つなぎ方は[iPhoneにSDカードは挿せる?](/blog/ja/iphone-sd-card-slot)と[micro SDをiPhoneで使う方法](/blog/ja/iphone-microsd)にまとめました。

## Galaxy SDカードのよくある質問

### Galaxy S24やS25にSDカードは挿せますか?

Samsung日本サポートの表では、S21シリーズ以降は外部SDカードを挿入できません。正確な仕様は、その機種のSamsung仕様ページで確かめてください。

### GalaxyでSDカードを内部ストレージとして組み込めますか?

Samsung米国サポートによると、SamsungのAndroid機器はこの方式(Adoptable storage)に対応していません。カードは別のストレージとして使います。

### SDカードを入れるとSIMが1枚使えなくなりますか?

兼用トレイならそうなります。Samsung英国サポートによると、兼用トレイはSIM 2枚か、SIM 1枚とSDカード1枚を入れます。

### パソコンでフォーマットしたカードをGalaxyで使えますか?

FAT32とexFATは使える形式です。Samsung米国サポートは、NTFSとAPFSは非対応としています。認識に問題があれば、データを移してからGalaxyの設定でフォーマットし直します。

### マウント解除せずにカードを抜くとどうなりますか?

Samsung日本サポートは、保存データが壊れる場合があると説明しています。カードを抜く前に、設定かマイファイルでマウント解除をします。
