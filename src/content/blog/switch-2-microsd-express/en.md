## Key takeaways

A Switch 2 SD card is a microSD Express card. The Nintendo Switch 2 stores game data only on microSD Express cards, up to 2 TB. The first time you use one, the console needs a system update over the internet.

A regular microSD card from a Nintendo Switch can't store games on a Switch 2. You can only use it to import Switch screenshots and videos into the Switch 2 system memory.

The Switch 2 has 256 GB of system memory, and part of it is reserved for the system. Game save data stays in the system memory and can't be copied to the card.

"Can I just move my old Switch SD card over?" "Will any microSD card work in a Switch 2?" These are common questions right after buying a Switch 2. This guide covers which Switch 2 SD card works, what happens to your old card, and how to format and move data, using Nintendo's own support pages. For the Switch, Switch Lite, and Switch OLED Model, see the [Nintendo Switch micro SD card guide](/blog/en/switch-microsd).

## Which Switch 2 SD card should I use?

Use a card that meets the microSD Express standard. The [Nintendo microSD Express Card FAQ](https://www.nintendo.com/au/support/articles/microsd-express-card-faq/) says any card up to 2 TB that meets the microSD Express standard works on Switch 2. The same FAQ says microSD Express cards are sold separately and aren't included with the console.

| Item | Nintendo Switch 2 |
| --- | --- |
| Card slot | microSD Express cards only |
| Maximum capacity | 2 TB |
| First use | System update over the internet required |
| Regular microSD (microSDHC, microSDXC) | Only for copying screenshots and videos from a Switch |
| Card in the box | No, sold separately |

The table follows the [Nintendo Switch 2 tech specs](https://www.nintendo.com/us/gaming-systems/switch-2/tech-specs/) and Nintendo's FAQ. The FAQ says Nintendo picked microSD Express for faster access speeds so games run smoothly.

A microSD Express card is the same size as a regular microSD card and has a second row of pins. How the format works and how to spot one are covered in [what is microSD Express?](/blog/en/microsd-express) This guide hasn't tested any card and doesn't recommend one.

## What happens to my old Switch SD card on a Switch 2?

It can't store games. [Nintendo's compatibility page](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68425/) says a microSD card used on a Nintendo Switch won't let you save or load digital games or save data on a Switch 2.

| Card | Nintendo Switch 2 | Nintendo Switch |
| --- | --- | --- |
| Regular microSD | No games. Can load Switch screenshots and videos only | Supported |
| microSD Express | Supported up to 2 TB. Internet update needed on first use | Supported. Read and write speed is the same as regular microSD |

To bring over Switch screenshots and videos, follow the [Nintendo microSD Express Card FAQ](https://www.nintendo.com/au/support/articles/microsd-express-card-faq/).

1. Find the microSD card that holds your Switch screenshots and videos.
2. Insert it into the Switch 2.
3. Select Import From a Nintendo Switch Console's microSD Card.
4. The screenshots and videos go into the Switch 2 system memory.

The same FAQ says regular microSD cards can't be used with Switch 2 for any other purpose.

## How much storage does the Switch 2 have?

256 GB. The [Nintendo Switch 2 tech specs](https://www.nintendo.com/us/gaming-systems/switch-2/tech-specs/) list 256 GB (UFS) and note that a portion is reserved for the system.

| Model | System memory | Card |
| --- | --- | --- |
| Nintendo Switch 2 | 256 GB | microSD Express |
| Nintendo Switch OLED Model | 64 GB | microSD, microSDHC, microSDXC |
| Nintendo Switch, Switch Lite | 32 GB | microSD, microSDHC, microSDXC |

The Switch figures come from [Nintendo Japan's system memory Q&A](https://support-jp.nintendo.com/app/answers/detail/a_id/34000/). To work out how much card space you need, see [Nintendo Switch SD capacity](/blog/en/switch-sd-card-capacity). The same math applies to a Switch 2, but the card type must be microSD Express.

## What does a Switch 2 SD card store?

Software data and captures, but not game saves. This list follows the [Nintendo microSD Express Card FAQ](https://www.nintendo.com/au/support/articles/microsd-express-card-faq/).

| Data | Stored on the microSD Express card? |
| --- | --- |
| Downloadable software | Yes |
| Software update data | Yes |
| Downloadable content (DLC) | Yes |
| Screenshots and captured videos | Yes |
| Game save data | No. System memory only |

The same FAQ says that once a card is inserted, it becomes the default save location for downloadable software. Nintendo recommends one card per console. Software saved across several cards can't be combined onto one card later.

## Can I move games from system memory to the SD card?

Yes. These steps follow [Nintendo's Switch 2 data move guide](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68340/).

1. Select System Settings from the HOME Menu.
2. Scroll down and select Data Management.
3. Select Move System / microSD Express Card Data.
4. Choose the data to move, then select OK.

Save data and some update data can't be moved. The same guide says this isn't a feature to choose where data is installed. If you keep playing after moving, update data may be saved to the location you didn't select. Nintendo's FAQ adds that screenshots and videos can also move between system memory and the card.

## How do I format a Switch 2 SD card?

Format it in System Settings. These steps follow [Nintendo Japan's Switch 2 format guide](https://support.nintendo.com/jp/switch2/mastery/sdcard/format/index.html). Menu names are translated from the Japanese page.

1. Select System Settings from the HOME Menu.
2. Select System, then Formatting Options. If parental controls are set, enter the PIN.
3. Select Format microSD Card.
4. Select Continue.
5. Select Format. Everything on the microSD Express card is erased.

Formatting erases software data, screenshots and videos, and data saved by other devices. Copy anything you want to keep to a computer first. The same page says save data isn't on the card, and you can redownload software and DLC afterward.

For general ways to format a card on a computer, see [how to format a micro SD card](/blog/en/format-microsd). For a Switch 2 card, formatting on the console matches Nintendo's guidance.

## How do I move to a bigger Switch 2 SD card?

Copy the card's data to the new card with a Windows PC. These steps follow [Nintendo UK's card-to-card transfer guide](https://www.nintendo.com/en-gb/Support/Troubleshooting/How-to-Transfer-Data-Between-microSD-Express-Cards-for-Use-on-Nintendo-Switch-2-2926036.html).

1. Format the new microSD Express card the way Nintendo recommends.
2. Remove the original card from the Switch 2.
3. Put the original card in your computer's card slot or a microSD card reader.
4. Open Windows Explorer, select the data, and drag it to the desktop. Copy the entire folder and never change or delete the files inside.
5. Eject the original card and insert the new one.
6. Drag the data from the desktop to the new card, then eject it.
7. Insert the new card into the Switch 2. Redownload software from Nintendo eShop if needed.

| Watch out for | Nintendo's guidance |
| --- | --- |
| Operating system | Copying may not work correctly outside Windows, such as on a Mac |
| Original card | Don't delete, format, or change it until the new card works |
| Other consoles | Software downloaded on one console won't play on another |
| Several cards | Don't swap cards. Use one card per console |

[Nintendo Japan's guide](https://support.nintendo.com/jp/switch2/mastery/sdcard/use-other/index.html) says to copy the whole Nintendo folder and keep the original data until the copy finishes. To connect a card to a computer, see [SD card reader for PC](/blog/en/sd-card-to-pc). If you doubt a new card's real capacity, check it first with [fake SD card checks](/blog/en/fake-sd-card).

## FAQ: Switch 2 SD card

### Can I use a regular microSDXC card in a Switch 2?

Not for games. Nintendo says the Switch 2 is only compatible with microSD Express cards. A regular microSD card can only import screenshots and videos taken on a Switch.

### What's the largest Switch 2 SD card?

2 TB. The first time you use a microSD Express card, the console needs a system update over the internet.

### Does a microSD Express card work in the original Switch?

Yes. Nintendo's compatibility page says its read and write speed on a Switch is the same as a regular microSD card.

### Does formatting a Switch 2 SD card erase my game progress?

No. Game save data is stored in the system memory, not on the card. You redownload the software that was on the card.

### Can I copy a Switch 2 card to a new card on a Mac?

Nintendo says copying may not work correctly outside Windows, such as on a Mac. Use a Windows PC to move cards.
