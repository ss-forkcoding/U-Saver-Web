## 핵심 요약

스위치 2 SD 카드는 microSD Express 카드입니다. 닌텐도 스위치 2는 microSD Express 카드만 게임 데이터 저장에 쓰고, 2TB까지 지원합니다. 처음 쓸 때는 인터넷으로 본체를 업데이트해야 합니다.

스위치에서 쓰던 일반 microSD 카드는 스위치 2에서 게임 저장에 쓸 수 없습니다. 그 카드에 담긴 스위치 화면 사진과 동영상을 스위치 2 본체로 불러오는 일만 됩니다.

스위치 2의 본체 저장 메모리는 256GB이고, 이 중 일부는 시스템이 씁니다. 게임 저장 데이터는 본체 저장 메모리에만 저장되며 카드로 옮길 수 없습니다.

"스위치 때 쓰던 SD 카드를 그대로 꽂으면 되나요?" "스위치 2 SD 카드는 아무 microSD나 사도 되나요?" 스위치 2를 처음 산 뒤 자주 나오는 질문입니다. 이 글은 스위치 2 SD 카드의 규격, 기존 카드 처리, 포맷과 데이터 옮기기를 닌텐도 공식 안내로 확인합니다. 스위치·스위치 Lite·스위치 OLED 모델의 카드 사용법은 [닌텐도 스위치 SD 카드 사용법](/blog/ko/switch-microsd)에 따로 정리했습니다.

## 스위치 2 SD 카드는 어떤 카드를 써야 하나요?

microSD Express 표준을 지키는 카드를 씁니다. [닌텐도 microSD Express 카드 FAQ](https://www.nintendo.com/au/support/articles/microsd-express-card-faq/)는 microSD Express 표준에 맞는 2TB 이하 카드라면 스위치 2에서 쓸 수 있다고 적습니다. 같은 FAQ는 microSD Express 카드가 본체에 들어 있지 않고 따로 판매된다고 답합니다.

| 항목 | 닌텐도 스위치 2 기준 |
| --- | --- |
| 카드 슬롯 | microSD Express 카드 전용 |
| 최대 용량 | 2TB |
| 처음 쓸 때 | 인터넷에 접속해 본체 업데이트 필요 |
| 일반 microSD(microSDHC·microSDXC) | 스위치 화면 사진·동영상 복사에만 사용 |
| 카드 동봉 여부 | 별매 |

표는 [한국닌텐도의 스위치 2 사양](https://www.nintendo.co.kr/hardware/switch2/specs/)과 닌텐도 FAQ 기준입니다. 닌텐도 FAQ는 스위치 2가 microSD Express를 고른 이유로 빠른 읽기·쓰기와 게임의 원활한 실행을 듭니다.

microSD Express 카드는 일반 microSD와 크기가 같고 핀이 한 열 더 있습니다. 카드 구조와 표기 확인법은 [microSD Express란?](/blog/ko/microsd-express)에 정리했습니다. 이 글은 특정 카드를 시험하거나 추천하지 않습니다.

## 스위치에서 쓰던 SD 카드는 스위치 2에서 어떻게 되나요?

게임 저장용으로는 쓸 수 없습니다. [닌텐도의 카드 호환 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68425/)는 스위치에서 쓰던 microSD 카드를 스위치 2에 넣으면 다운로드 게임과 저장 데이터를 저장하거나 불러올 수 없다고 적습니다.

| 카드 | Nintendo Switch 2 | Nintendo Switch |
| --- | --- | --- |
| 일반 microSD | 게임 저장 불가. 스위치에서 찍은 화면 사진·동영상 불러오기만 가능 | 쓸 수 있음 |
| microSD Express | 쓸 수 있음. 2TB까지, 처음 쓸 때 인터넷 업데이트 필요 | 쓸 수 있음. 읽기·쓰기 속도는 일반 microSD와 같음 |

스위치 카드의 화면 사진과 동영상은 이렇게 불러옵니다. [닌텐도 microSD Express 카드 FAQ](https://www.nintendo.com/au/support/articles/microsd-express-card-faq/)의 안내입니다.

1. 스위치에서 화면 사진과 동영상을 저장한 microSD 카드를 준비합니다.
2. 그 카드를 스위치 2에 넣습니다.
3. "Import From a Nintendo Switch Console's microSD Card"(스위치 microSD 카드에서 불러오기)를 고릅니다.
4. 사진과 동영상이 스위치 2의 본체 저장 메모리로 들어옵니다.

같은 FAQ는 일반 microSD 카드를 이 밖의 용도로 스위치 2에서 쓸 수 없다고 적습니다. 메뉴의 한국어 표기는 닌텐도 영어 안내만 확인했습니다.

## 스위치 2 본체 저장 공간은 얼마나 되나요?

256GB입니다. [한국닌텐도의 스위치 2 사양](https://www.nintendo.co.kr/hardware/switch2/specs/)은 본체 저장 메모리를 256GB(UFS)로 표시하고, 데이터를 저장할 수 있는 용량은 시스템 영역을 뺀 크기라고 적습니다.

| 모델 | 본체 저장 메모리 | 카드 |
| --- | --- | --- |
| Nintendo Switch 2 | 256GB | microSD Express |
| Nintendo Switch OLED 모델 | 64GB | microSD·microSDHC·microSDXC |
| Nintendo Switch, Switch Lite | 32GB | microSD·microSDHC·microSDXC |

스위치 모델의 수치는 [닌텐도 일본의 본체 저장 메모리 Q&A](https://support-jp.nintendo.com/app/answers/detail/a_id/34000/) 기준입니다. 필요한 카드 용량을 계산하는 순서는 [닌텐도 스위치 SD 카드 용량 고르기](/blog/ko/switch-sd-card-capacity)에 있습니다. 계산 순서는 스위치 2에도 같이 쓸 수 있지만, 카드 종류는 microSD Express로 고릅니다.

## 스위치 2 SD 카드에는 무엇이 저장되나요?

게임 저장 데이터를 뺀 소프트웨어 데이터와 화면 사진·동영상입니다. [닌텐도 microSD Express 카드 FAQ](https://www.nintendo.com/au/support/articles/microsd-express-card-faq/)의 목록입니다.

| 데이터 | microSD Express 카드에 저장 |
| --- | --- |
| 다운로드 소프트웨어 | 됩니다 |
| 소프트웨어 업데이트 데이터 | 됩니다 |
| 추가 콘텐츠(DLC) | 됩니다 |
| 화면 사진, 촬영한 동영상 | 됩니다 |
| 게임 저장 데이터 | 안 됩니다. 본체 저장 메모리에만 저장 |

같은 FAQ에 따르면 카드를 넣으면 다운로드 소프트웨어의 기본 저장 위치가 카드로 바뀝니다. 닌텐도는 본체 하나에 카드 한 장을 권합니다. 여러 카드에 나눠 받은 소프트웨어는 나중에 한 카드로 합칠 수 없습니다.

## 본체 저장 메모리의 게임을 SD 카드로 옮길 수 있나요?

옮길 수 있습니다. [닌텐도의 스위치 2 데이터 이동 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68340/)의 순서입니다.

1. HOME 메뉴에서 설정을 고릅니다.
2. 아래로 내려 데이터 관리를 고릅니다.
3. 본체와 microSD Express 카드 사이의 데이터 이동 메뉴를 고릅니다. 영문 메뉴 이름은 Move System / microSD Express Card Data입니다.
4. 옮길 데이터를 고르고 확인을 누릅니다.

저장 데이터와 일부 업데이트 데이터는 옮겨지지 않습니다. 같은 안내는 이 기능이 설치 위치를 정하는 기능이 아니라고 적습니다. 옮긴 뒤에 게임을 계속하면 업데이트 데이터가 고르지 않은 위치에 저장될 수 있습니다. 닌텐도 FAQ는 화면 사진과 동영상도 본체와 카드 사이에서 옮길 수 있다고 적습니다.

## 스위치 2 SD 카드는 어떻게 포맷하나요?

본체 설정에서 포맷합니다. [한국닌텐도의 다른 microSD Express 카드 사용 안내](https://www.nintendo.co.kr/support/switch2/mastery/sdcard/use-other/index.html)의 순서입니다.

1. HOME 메뉴에서 설정을 고릅니다.
2. 본체 > 초기화를 고릅니다. 보호자 설정을 했다면 비밀번호를 입력합니다.
3. SD 카드 포맷을 고릅니다.
4. 계속을 고릅니다.
5. 포맷하기를 고르면 카드 안의 모든 데이터가 지워집니다.

포맷하면 소프트웨어 데이터, 화면 사진·동영상, 다른 기기에서 저장한 데이터가 모두 지워집니다. 남길 데이터는 포맷 전에 컴퓨터 등에 복사합니다. [닌텐도 일본의 포맷 안내](https://support.nintendo.com/jp/switch2/mastery/sdcard/format/index.html)는 저장 데이터가 카드에 없으니 포맷해도 남는다고 적고, 포맷 뒤에는 필요한 다운로드 소프트웨어와 추가 콘텐츠를 다시 받으라고 안내합니다.

컴퓨터에서 카드를 포맷하는 일반 방법은 [마이크로 SD 카드 포맷 방법](/blog/ko/format-microsd)에 있습니다. 스위치 2용 카드는 본체에서 포맷하는 편이 닌텐도 안내와 맞습니다.

## 더 큰 스위치 2 SD 카드로 바꾸려면 어떻게 하나요?

Windows 컴퓨터로 카드 안의 Nintendo 폴더를 통째로 옮깁니다. [닌텐도 영국의 카드 간 데이터 이동 안내](https://www.nintendo.com/en-gb/Support/Troubleshooting/How-to-Transfer-Data-Between-microSD-Express-Cards-for-Use-on-Nintendo-Switch-2-2926036.html) 순서입니다.

1. 새 microSD Express 카드를 닌텐도 안내대로 포맷합니다.
2. 스위치 2에서 기존 카드를 뺍니다.
3. 기존 카드를 컴퓨터의 카드 슬롯이나 카드 리더기에 넣습니다.
4. Windows 탐색기에서 카드를 열고 데이터를 바탕화면으로 끌어 옵니다. 폴더 전체를 복사하고 안의 파일은 고치거나 지우지 않습니다.
5. 기존 카드를 빼고 새 카드를 넣습니다.
6. 바탕화면의 데이터를 새 카드로 끌어 옮기고 꺼냅니다.
7. 새 카드를 스위치 2에 넣습니다. 필요하면 닌텐도 e숍에서 소프트웨어를 다시 받습니다.

| 주의할 점 | 닌텐도 안내 |
| --- | --- |
| 운영체제 | Mac 등 Windows 이외 환경에서는 제대로 복사되지 않을 수 있습니다 |
| 기존 카드 | 새 카드가 정상 동작하는지 확인하기 전에는 지우거나 포맷하지 않습니다 |
| 여러 본체 | 한 본체에서 받은 소프트웨어는 다른 본체에서 실행되지 않습니다 |
| 카드 여러 장 | 카드를 번갈아 쓰지 말고 본체마다 한 장을 씁니다 |

[한국닌텐도 안내](https://www.nintendo.co.kr/support/switch2/mastery/sdcard/use-other/index.html)도 복사가 끝날 때까지 원본 카드의 데이터를 보관하라고 적습니다. 컴퓨터에 카드를 연결하는 방법은 [SD 카드 컴퓨터 연결 방법](/blog/ko/sd-card-to-pc)에 있습니다. 새 카드의 실제 용량이 의심되면 [가짜 SD 카드 구별법](/blog/ko/fake-sd-card)으로 먼저 확인하세요.

## 스위치 2 화면 사진을 아이폰에서 보려면?

이 글은 스위치 2 카드를 아이폰에 연결해 시험하지 않았습니다. 확인된 사실만 정리합니다.

| 확인한 내용 | 출처 |
| --- | --- |
| 아이폰은 APFS, macOS 확장, exFAT, FAT32, FAT 형식의 외부 저장장치를 읽습니다 | [Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios) |
| Apple 카메라 어댑터의 지원 카드 목록에는 SDSC, SDHC, SDXC, microSD가 있고 microSD Express는 없습니다 | [Apple 카메라 어댑터 안내](https://support.apple.com/en-us/118280) |
| 닌텐도는 Nintendo 폴더 안의 파일을 고치지 말라고 안내합니다 | 한국닌텐도 안내 |

카드를 리더기로 아이폰에 연결한다면 사진은 복사만 하고 카드 안의 파일은 지우거나 옮기지 않습니다. 리더기 연결 순서는 [아이폰 마이크로 SD 쓰는 법](/blog/ko/iphone-microsd)과 [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader)에 있습니다.

## 스위치 2 SD 카드 자주 묻는 질문

### 스위치 2에 일반 microSDXC 카드를 쓸 수 있나요?

게임 저장에는 쓸 수 없습니다. 닌텐도는 스위치 2가 microSD Express 카드만 지원한다고 안내합니다. 일반 microSD 카드는 스위치에서 찍은 화면 사진과 동영상을 불러오는 데만 씁니다.

### 스위치 2 SD 카드는 몇 TB까지 되나요?

2TB까지입니다. 처음 쓸 때는 인터넷에 접속해 본체를 업데이트해야 합니다.

### microSD Express 카드를 스위치에서도 쓸 수 있나요?

쓸 수 있습니다. 닌텐도 호환 안내에 따르면 스위치에서는 읽기·쓰기 속도가 일반 microSD 카드와 같습니다.

### 스위치 2 SD 카드를 포맷하면 게임 진행 기록도 지워지나요?

지워지지 않습니다. 게임 저장 데이터는 본체 저장 메모리에 저장되고 카드에는 저장되지 않습니다. 카드의 다운로드 소프트웨어는 다시 받습니다.

### Mac으로 스위치 2 카드를 새 카드에 복사해도 되나요?

닌텐도는 Mac 등 Windows 이외 환경에서 카드 내용이 제대로 복사되지 않을 수 있다고 안내합니다. 카드를 옮길 때는 Windows 컴퓨터를 쓰세요.
