## この記事の要点

スイッチ 2 microSDカードとして使えるのはmicroSD Expressカードです。Nintendo Switch 2はmicroSD Expressカードだけをゲームデータの保存に使い、2TBまで対応します。初めて使うときは、インターネットに接続して本体更新をします。

Switchで使っていた通常のmicroSDカードは、Switch 2ではゲームの保存に使えません。そのカードにあるSwitchの画面写真と動画を、Switch 2の本体保存メモリーに取り込むことだけができます。

Switch 2の本体保存メモリーは256GBで、その一部はシステムが使います。セーブデータは本体保存メモリーに保存され、カードには移せません。

「Switchのカードをそのまま挿せばいいの?」「スイッチ 2のmicroSDはどれを買えばいいの?」。Switch 2を買ったあとによく出る疑問です。この記事では、スイッチ 2のmicroSDの規格、今までのカードの扱い、フォーマットとデータの移しかたを任天堂の案内で確かめます。Switch、Switch Lite、Switch(有機ELモデル)のカードの使い方は[Switch SDカードの使い方](/blog/ja/switch-microsd)にまとめました。

## スイッチ 2 microSDはどのカードを使えばいいですか?

microSD Expressの規格に合うカードを使います。[任天堂のmicroSD ExpressカードFAQ](https://www.nintendo.com/au/support/articles/microsd-express-card-faq/)は、microSD Expressの規格に合う2TBまでのカードならSwitch 2で使えると書いています。同じFAQによると、microSD Expressカードは本体に付属せず、別売りです。

| 項目 | Nintendo Switch 2 |
| --- | --- |
| カードスロット | microSD Expressカードのみ対応 |
| 最大容量 | 2TB |
| 初めて使うとき | インターネットに接続して本体更新が必要 |
| 通常のmicroSD(microSDHC・microSDXC) | Switchからの画面写真/動画のコピーにのみ利用 |
| 本体への付属 | なし(別売り) |

表は[任天堂のNintendo Switch 2の仕様](https://www.nintendo.com/jp/hardware/switch2/specs/)と任天堂のFAQによるものです。FAQは、Switch 2がmicroSD Expressを選んだ理由として、速い読み書きとゲームの快適な動作を挙げています。

microSD Expressカードは通常のmicroSDと同じ大きさで、ピンがもう1列あります。カードのしくみと表示の見分け方は[microSD Expressとは?](/blog/ja/microsd-express)にまとめました。この記事では特定のカードを試したり、すすめたりしていません。

## Switchで使っていたmicroSDはスイッチ 2でどうなりますか?

ゲームの保存には使えません。[任天堂のカード互換の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68425/)は、Switchで使っていたmicroSDカードをSwitch 2に挿しても、ダウンロード版ソフトやセーブデータを保存したり読み込んだりできないと書いています。

| カード | Nintendo Switch 2 | Nintendo Switch |
| --- | --- | --- |
| 通常のmicroSD | ゲームの保存は不可。Switchで撮った画面写真・動画の読み込みのみ | 使えます |
| microSD Express | 2TBまで使えます。初回はインターネットで本体更新 | 使えます。読み書きの速度は通常のmicroSDと同じ |

Switchのカードにある画面写真と動画は、次の順で取り込みます。[任天堂のmicroSD ExpressカードFAQ](https://www.nintendo.com/au/support/articles/microsd-express-card-faq/)の案内です。

1. Switchで画面写真と動画を保存したmicroSDカードを用意します。
2. そのカードをSwitch 2に挿します。
3. 「Import From a Nintendo Switch Console's microSD Card」(Switchのカードから取り込む)を選びます。
4. 画面写真と動画がSwitch 2の本体保存メモリーに入ります。

同じFAQは、通常のmicroSDカードをこのほかの用途でSwitch 2に使うことはできないと書いています。メニューの日本語の表記は、この記事では確かめていません。

## スイッチ 2の本体保存メモリーはどれくらいですか?

256GBです。[任天堂のNintendo Switch 2の仕様](https://www.nintendo.com/jp/hardware/switch2/specs/)は本体保存メモリーを256GB(UFS)とし、データを保存できる容量はシステム領域を除いた容量になると書いています。

| モデル | 本体保存メモリー | カード |
| --- | --- | --- |
| Nintendo Switch 2 | 256GB | microSD Express |
| Nintendo Switch(有機ELモデル) | 64GB | microSD・microSDHC・microSDXC |
| Nintendo Switch、Switch Lite | 32GB | microSD・microSDHC・microSDXC |

Switchの数値は[任天堂サポートの本体保存メモリーのQ&A](https://support-jp.nintendo.com/app/answers/detail/a_id/34000/)によるものです。必要なカードの容量の計算は[スイッチのSDカード容量のおすすめの決め方](/blog/ja/switch-sd-card-capacity)にあります。計算の順番はSwitch 2でも同じですが、カードの種類はmicroSD Expressを選びます。

## スイッチ 2のmicroSDには何が保存されますか?

セーブデータを除くソフトのデータと、画面写真・動画です。[任天堂のmicroSD ExpressカードFAQ](https://www.nintendo.com/au/support/articles/microsd-express-card-faq/)の一覧です。

| データ | microSD Expressカードに保存 |
| --- | --- |
| ダウンロード版ソフト | されます |
| 更新データ | されます |
| 追加コンテンツ | されます |
| 画面写真、撮影した動画 | されます |
| セーブデータ | されません。本体保存メモリーのみ |

同じFAQによると、カードを挿すとダウンロード版ソフトの保存先はカードになります。任天堂は本体1台にカード1枚をすすめています。複数のカードに分けて保存したソフトは、あとで1枚にまとめられません。

## 本体保存メモリーのソフトをmicroSDに移せますか?

移せます。[任天堂のSwitch 2のデータ移動の案内](https://en-americas-support.nintendo.com/app/answers/detail/a_id/68340/)の手順です。

1. HOMEメニューで「設定」を選びます。
2. 下にスクロールして「データ管理」を選びます。
3. 本体とmicroSD Expressカードのあいだでデータを移すメニューを選びます。英語のメニュー名はMove System / microSD Express Card Dataです。
4. 移すデータを選び、OKを選びます。

セーブデータと一部の更新データは移せません。同じ案内によると、この機能はインストール先を決める機能ではありません。移したあとに遊び続けると、更新データが選ばなかった場所に保存されることがあります。任天堂のFAQは、画面写真と動画も本体とカードのあいだで移せると書いています。

## スイッチ 2のmicroSDはどうやってフォーマットしますか?

本体の設定でフォーマットします。[任天堂サポートのmicroSD Expressカードのフォーマットの案内](https://support.nintendo.com/jp/switch2/mastery/sdcard/format/index.html)の手順です。

1. HOMEメニューで「設定」を選びます。
2. 「本体」→「初期化」を選びます。みまもり設定をしている場合は、暗証番号を入力します。
3. 「SDカードのフォーマット」を選びます。
4. 「つづける」を選びます。
5. 「フォーマットする」を選ぶと、カード内のすべてのデータが消えます。

フォーマットすると、ソフトのデータ、画面写真/動画、ほかの機器で保存したデータが消えます。残したいデータは、先にパソコンなどにコピーします。同じ案内は、セーブデータはカードに保存されていないと書き、フォーマット後は必要に応じてダウンロード版ソフトや追加コンテンツをダウンロードし直すよう案内しています。

パソコンでカードをフォーマットする一般的な方法は[microSDカードのフォーマット方法](/blog/ja/format-microsd)にあります。Switch 2用のカードは、本体でフォーマットするほうが任天堂の案内に合います。

## 大きいスイッチ 2のmicroSDに替えるにはどうしますか?

Windowsのパソコンで、カードのNintendoフォルダを丸ごと新しいカードにコピーします。[任天堂(英国)のカード間のデータ移動の案内](https://www.nintendo.com/en-gb/Support/Troubleshooting/How-to-Transfer-Data-Between-microSD-Express-Cards-for-Use-on-Nintendo-Switch-2-2926036.html)の手順です。

1. 新しいmicroSD Expressカードを任天堂の案内どおりにフォーマットします。
2. Switch 2から今までのカードを抜きます。
3. 今までのカードをパソコンのカードスロットかカードリーダーに挿します。
4. Windowsのエクスプローラーでカードを開き、データをデスクトップにドラッグします。フォルダは丸ごとコピーし、中のファイルは変えたり消したりしません。
5. 今までのカードを取り出し、新しいカードを挿します。
6. デスクトップのデータを新しいカードにドラッグし、取り出します。
7. 新しいカードをSwitch 2に挿します。必要ならニンテンドーeショップからソフトをダウンロードし直します。

| 気をつけること | 任天堂の案内 |
| --- | --- |
| OS | MacなどWindows以外の環境では正しくコピーできないことがあります |
| 今までのカード | 新しいカードが正しく動くことを確かめるまで、消したりフォーマットしたりしません |
| ほかの本体 | ある本体でダウンロードしたソフトは、ほかの本体では遊べません |
| 複数のカード | カードを入れ替えて使わず、本体ごとに1枚を使います |

[任天堂サポートの別のカードを使う案内](https://support.nintendo.com/jp/switch2/mastery/sdcard/use-other/index.html)も、コピーが終わるまでコピー元のカードのデータを保管するよう書いています。カードをパソコンにつなぐ方法は[SDカードをパソコンにつなぐ方法](/blog/ja/sd-card-to-pc)にあります。新しいカードの本当の容量が気になるときは、[SDカードの偽物の見分け方](/blog/ja/fake-sd-card)で先に確かめてください。

## スイッチ 2の画面写真をiPhoneで見るには?

この記事では、Switch 2のカードをiPhoneにつないで試していません。公式の案内で確かめたことだけをまとめます。

| 確かめたこと | 出典 |
| --- | --- |
| iPhoneはAPFS、Mac OS拡張、exFAT、FAT32、FAT形式の外部ストレージを読み込みます | [Appleの外部ストレージの案内](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios) |
| Appleのカメラアダプタの対応カードはSDSC、SDHC、SDXC、microSDで、microSD Expressの記載はありません | [Appleのカメラアダプタの案内](https://support.apple.com/en-us/118280) |
| 任天堂はNintendoフォルダの中身に変更を加えないよう案内しています | 任天堂サポートの案内 |

カードリーダーでiPhoneにつなぐなら、写真はコピーだけにして、カードの中のファイルは消したり移したりしません。リーダーのつなぎ方は[micro SDをiPhoneで使う方法](/blog/ja/iphone-microsd)と[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)にあります。

## スイッチ 2のmicroSDのよくある質問

### Switch 2に通常のmicroSDXCカードは使えますか?

ゲームの保存には使えません。任天堂は、Switch 2はmicroSD Expressカードのみに対応すると案内しています。通常のmicroSDカードは、Switchで撮った画面写真と動画の取り込みにだけ使えます。

### スイッチ 2のmicroSDは何TBまで使えますか?

2TBまでです。初めて使うときは、インターネットに接続して本体更新をします。

### microSD ExpressカードはSwitchでも使えますか?

使えます。任天堂の互換の案内によると、Switchでの読み書きの速度は通常のmicroSDカードと同じです。

### スイッチ 2のmicroSDをフォーマットするとセーブデータも消えますか?

消えません。セーブデータは本体保存メモリーに保存され、カードには保存されません。カードにあったダウンロード版ソフトはダウンロードし直します。

### Macで新しいカードにコピーしてもいいですか?

任天堂は、MacなどWindows以外の環境では正しくコピーできないことがあると案内しています。カードを移すときはWindowsのパソコンを使ってください。
