## 핵심 요약

고내구성 SD 카드는 블랙박스, 가정용 보안 카메라처럼 영상을 계속 쓰고 덮어쓰는 기기를 위해 만든 microSD 카드입니다. 제조사는 이 카드의 내구성을 "Full HD 영상 몇 시간 기록"이나 "P/E 사이클"로 표시합니다.

기록 시간은 제조사마다 기준이 다릅니다. Samsung은 26Mbps 영상을 기준으로 적고, Kingston은 24시간 녹화 문구에 13Mbps 기준 각주를 답니다. 숫자만 놓고 바로 비교하지 않습니다.

고내구성이 빠르다는 뜻은 아닙니다. 4K 녹화나 빠른 복사가 필요하면 속도 등급(U3, V30)을 따로 확인합니다.

"블랙박스 카드가 몇 달 만에 고장 났어요." "고내구성 카드에 사진을 보관하면 더 안전한가요?" 고내구성 SD 카드를 찾을 때 자주 나오는 질문입니다. 이 글은 제조사 데이터시트에 적힌 내구성 수치를 읽는 법과 카드를 고를 때 확인할 순서를 정리합니다. 이 글은 특정 제품을 추천하지 않습니다. 아래 제품은 제조사 문서를 읽는 예로만 씁니다.

## 고내구성 SD 카드는 일반 카드와 무엇이 다른가요?

쓰고 지우기를 오래 반복하도록 만든 카드입니다. [SanDisk High Endurance microSD 데이터시트](https://documents.sandisk.com/content/dam/asset-library/en_us/assets/public/sandisk/product/memory-cards/high-endurance-uhs-i-microsd/data-sheet-high-endurance-uhs-i-microsd.pdf)는 쓰기와 다시 쓰기가 메모리 카드에 부담을 준다고 적고, 이 카드가 블랙박스와 가정용 보안 카메라의 녹화와 재녹화에 맞춰 만들어졌다고 설명합니다.

[Kingston High-Endurance microSD 데이터시트](https://www.kingston.com/datasheets/SDCE_us.pdf)도 보안 카메라, 블랙박스, 바디캠 같은 쓰기 집중 용도를 대상으로 적습니다.

| 구분 | 일반 SD 카드 | 고내구성 SD 카드 |
| --- | --- | --- |
| 제조사가 밝힌 주 용도 | 카메라, 휴대폰, 파일 보관 | 블랙박스, 보안 카메라처럼 계속 녹화하는 기기 |
| 내구성 표시 | 데이터시트에 없는 경우가 많음 | 기록 시간이나 P/E 사이클로 표시 |
| 카드 크기 | SD, microSD | 이 글에서 확인한 세 제품은 모두 microSD |

이 글에서 확인한 [SD Association FAQ](https://www.sdcard.org/consumers/faq/)와 [속도 등급 문서](https://www.sdcard.org/developers/sd-standard-overview/speed-class/)에는 내구성 등급이 나오지 않습니다. "고내구성"은 제조사가 붙이는 제품 이름이고, 내구성 기준도 제조사가 정합니다.

## 고내구성 SD 카드의 내구성 수치는 어떻게 읽나요?

제조사는 두 가지 방식으로 적습니다.

1. **기록 시간:** 카드가 견디도록 설계된 영상 녹화 시간입니다. SanDisk와 Samsung이 이 방식을 씁니다.
2. **P/E 사이클:** 플래시 메모리에 쓰고(program) 지우는(erase) 횟수입니다. Kingston은 3K P/E 사이클을 견디도록 정격을 정했다고 적습니다.

세 제조사의 데이터시트를 128GB 기준으로 옮기면 이렇습니다.

| 제조사 문서 | 128GB 내구성 표시 | 계산 기준 |
| --- | --- | --- |
| [SanDisk High Endurance](https://documents.sandisk.com/content/dam/asset-library/en_us/assets/public/sandisk/product/memory-cards/high-endurance-uhs-i-microsd/data-sheet-high-endurance-uhs-i-microsd.pdf) | 최대 10,000시간 | Full HD(1920x1080) 영상, 4K는 더 짧음 |
| [Samsung PRO Endurance](https://download.semiconductor.samsung.com/resources/data-sheet/2024_Samsung_Data_sheet_microSD_Card_PRO_Endurance_v.1.1.pdf) | 70,080시간 | Full HD 영상, 26Mbps(3.25MB/s) |
| [Kingston High-Endurance](https://www.kingston.com/datasheets/SDCE_us.pdf) | 3K P/E 사이클, 운영 시간 26.9K시간 | 3년 보증 기간 24시간 녹화(24시간 녹화 문구의 각주는 Full HD 13Mbps) |

SanDisk 문서는 용량이 커질수록 기록 시간도 길어진다고 적습니다. 32GB는 최대 2,500시간, 512GB는 최대 40,000시간입니다. Samsung 문서도 32GB 17,520시간부터 256GB 140,160시간까지 용량별로 다릅니다.

## 제조사끼리 기록 시간을 바로 비교해도 되나요?

바로 비교하지 않습니다. 기준 영상의 비트레이트가 다릅니다. Samsung은 26Mbps, Kingston은 13Mbps 영상을 각주의 기준으로 적습니다. 같은 카드라도 높은 비트레이트로 녹화하면 같은 시간에 더 많은 데이터를 씁니다.

SanDisk 문서는 실제 기록 시간이 표시보다 짧고, 4K 영상이면 더 짧다고 적습니다. Samsung 문서는 호스트 기기, 파일 속성, 사용 조건에 따라 영상 지원이 달라질 수 있다고 적습니다.

| 확인할 것 | 데이터시트에서 볼 곳 |
| --- | --- |
| 기준 해상도 | Full HD인지 4K인지 |
| 기준 비트레이트 | Mbps 값이 적혀 있는지 |
| 용량 | 같은 제품도 용량별로 시간이 다름 |
| 보증 기간 | SanDisk 2년, Kingston 3년, Samsung은 용량별 2~5년 |

내 기기의 녹화 비트레이트는 블랙박스나 카메라 제조사 설명서에서 확인합니다.

## 고내구성 SD 카드는 속도도 빠른가요?

내구성과 속도는 따로 봅니다. 같은 고내구성 제품이라도 속도 등급이 다릅니다.

| 제조사 문서 | 속도 등급 | 쓰기 속도 |
| --- | --- | --- |
| SanDisk High Endurance | Class 10, U3, V30 | 최대 40MB/s |
| Samsung PRO Endurance 32·64GB | Class 10, U1, V10 | 최대 30MB/s |
| Samsung PRO Endurance 128·256GB | Class 10, U3, V30 | 최대 40MB/s |
| Kingston High-Endurance | Class 10, U1, A1 | 최대 30~45MB/s(용량별) |

SD Association은 속도 등급 숫자가 최소 쓰기 속도를 뜻한다고 설명합니다. 기기 설명서에 V30이 필요하다고 적혀 있으면 V30 이상인 카드를 고릅니다. 표시 읽는 법은 [SD 카드 속도 표시 읽는 법](/blog/ko/sd-card-speed-class)에, A1 표시는 [SD 카드 A1·A2 뜻](/blog/ko/sd-card-a1-a2)에 정리했습니다.

## 고내구성 SD 카드는 어떤 순서로 고르나요?

1. **기기 설명서를 봅니다.** 지원하는 카드 크기(microSD인지), 최대 용량, 필요한 속도 등급을 확인합니다.
2. **용량 규격을 맞춥니다.** Kingston 문서는 카드 형식을 SDHC는 FAT32, SDXC는 exFAT으로 적습니다. 기기가 SDXC를 지원하는지 확인합니다. 차이는 [에스디 카드란?](/blog/ko/what-is-sd-card)에 있습니다.
3. **속도 등급을 맞춥니다.** 기기가 요구하는 등급 이상을 고릅니다.
4. **내구성 수치의 기준을 읽습니다.** 해상도, 비트레이트, 용량을 함께 봅니다.
5. **판매처를 확인합니다.** 고내구성 표시도 위조될 수 있습니다. 사고 나서 용량을 확인하는 법은 [가짜 SD 카드 구별법](/blog/ko/fake-sd-card)에 있습니다.

Kingston 문서는 자사 카드가 일반 소비자용 기기와의 호환성을 기준으로 설계·시험되었고, 그 밖의 특수 용도는 Kingston에 직접 문의하라고 적습니다.

## 고내구성 SD 카드를 아이폰에서도 쓸 수 있나요?

리더기를 거쳐 연결할 수 있습니다. 아이폰에는 카드 슬롯이 없으므로 SD 카드 리더기가 필요합니다. [Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)에 있는 형식(exFAT, FAT32 등)으로 포맷된 카드를 씁니다.

| 확인할 것 | 볼 곳 |
| --- | --- |
| microSD를 SD 리더기에 꽂기 | [micro SD 카드와 SD 카드 차이](/blog/ko/microsd-vs-sd) |
| 카드 형식 | [SD 카드 포맷 방법](/blog/ko/format-sd-card) |
| 사진 복사 순서 | [아이폰 사진 SD 카드로 옮기기](/blog/ko/iphone-photos-to-sd-card) |
| 어댑터에서 저장이 안 될 때 | [SD 카드 잠금 스위치](/blog/ko/sd-card-lock-switch) |

제조사 문서가 밝힌 고내구성 카드의 용도는 계속 덮어쓰는 녹화입니다. 사진을 가끔 옮겨 두는 용도라면 용량, 속도 등급, 진품 여부를 먼저 봅니다. 어떤 카드든 고장 날 수 있으므로 중요한 사진은 다른 저장장치에도 한 벌 더 둡니다.

## 아이폰 사진을 USB 메모리에 저장하려면?

아래 앱은 USB 메모리를 기준으로 안내합니다. USB 메모리 연결 조건은 [아이폰 USB 메모리 사용법](/blog/ko/iphone-flash-drive-guide)에 있습니다.

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비하고 있으며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## 고내구성 SD 카드 자주 묻는 질문

### 고내구성 SD 카드는 고장이 나지 않나요?

고장 날 수 있습니다. 제조사가 적은 기록 시간은 "최대"나 특정 조건 기준의 값입니다. SanDisk 문서는 실제 기록 시간이 표시보다 짧다고 적습니다.

### 고내구성 SD 카드와 일반 카드를 블랙박스에 똑같이 써도 되나요?

기기 설명서가 정한 카드 조건을 먼저 따릅니다. 제조사들은 블랙박스와 보안 카메라처럼 계속 녹화하는 기기를 고내구성 카드의 용도로 적습니다.

### P/E 사이클이 높으면 기록 시간도 긴가요?

비트레이트와 용량에 따라 달라집니다. Kingston 문서는 3K P/E 사이클과 운영 시간 26.9K시간을 따로 적습니다. 두 값을 함께 봅니다.

### 고내구성 SD 카드에 일반 SD 카드 크기 제품도 있나요?

이 글에서 확인한 SanDisk, Samsung, Kingston 문서의 제품은 모두 microSD입니다. SanDisk 문서는 일반 크기 SD 기기에 쓸 어댑터가 들어 있다고 적습니다.

### 고내구성 SD 카드의 수명은 어떻게 확인하나요?

제조사가 제공하는 도구가 있는지 봅니다. Kingston 문서는 카드 수명을 관리하는 상태 모니터링 도구를 선택 사항으로 제공한다고 적습니다.
