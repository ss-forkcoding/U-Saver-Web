## この記事の要点

高耐久SDカードは、ドライブレコーダーや家庭用の防犯カメラのように、映像を書き込んでは上書きし続ける機器向けのmicroSDカードです。メーカーは耐久性を「Full HD映像を何時間録画できるか」や「P/Eサイクル」で示します。

録画時間の基準はメーカーごとに違います。Samsungは26Mbpsの映像を基準にし、Kingstonは24時間録画の記載に13Mbps基準の注記を付けています。数字だけをそのまま比べないでください。

高耐久だから速いわけではありません。4K録画や速いコピーが必要なら、スピードクラス(U3、V30)を別に確認します。

「ドラレコのカードが数か月で壊れた」「高耐久SDカードに写真を保存すれば安心?」。高耐久SDカードを探すときによく出る疑問です。この記事では、メーカーのデータシートに書かれた耐久性の数値の読み方と、カードを選ぶときの確認の順番をまとめます。この記事は特定の製品をおすすめしません。以下の製品は、メーカー資料の読み方の例としてだけ使います。

## 高耐久SDカードは普通のカードと何が違いますか?

書き込みと消去を長く繰り返せるように作られたカードです。[SanDisk High Endurance microSDのデータシート](https://documents.sandisk.com/content/dam/asset-library/en_us/assets/public/sandisk/product/memory-cards/high-endurance-uhs-i-microsd/data-sheet-high-endurance-uhs-i-microsd.pdf)は、書き込みと書き直しがメモリーカードに負担をかけると書き、このカードがドライブレコーダーや家庭用防犯カメラの録画と再録画に向けて作られていると説明しています。

[Kingston High-Endurance microSDのデータシート](https://www.kingston.com/datasheets/SDCE_us.pdf)も、防犯カメラ、ドライブレコーダー、ボディカメラのような書き込みの多い用途を対象にしています。

| 区分 | 普通のSDカード | 高耐久SDカード |
| --- | --- | --- |
| メーカーが示す主な用途 | カメラ、スマートフォン、ファイルの保存 | ドラレコや防犯カメラのように録画を続ける機器 |
| 耐久性の表示 | データシートにないことが多い | 録画時間やP/Eサイクルで表示 |
| カードのサイズ | SD、microSD | この記事で確認した3製品はすべてmicroSD |

この記事で確認した[SD Associationのよくある質問](https://www.sdcard.org/consumers/faq/)と[スピードクラスの資料](https://www.sdcard.org/developers/sd-standard-overview/speed-class/)には、耐久性の等級は出てきません。「高耐久」はメーカーが付ける製品名で、耐久性の基準もメーカーが決めています。

## 高耐久SDカードの耐久性の数値はどう読みますか?

メーカーは2種類の数値で示します。

1. **録画時間:** カードが耐えるよう設計された映像の録画時間です。SanDiskとSamsungがこの方式です。
2. **P/Eサイクル:** フラッシュメモリーに書き込み(program)、消去(erase)できる回数です。Kingstonは3K P/Eサイクルに耐える定格だと書いています。

3社のデータシートを128GBで並べるとこうなります。

| メーカーの資料 | 128GBの耐久性の表示 | 計算の基準 |
| --- | --- | --- |
| [SanDisk High Endurance](https://documents.sandisk.com/content/dam/asset-library/en_us/assets/public/sandisk/product/memory-cards/high-endurance-uhs-i-microsd/data-sheet-high-endurance-uhs-i-microsd.pdf) | 最大10,000時間 | Full HD(1920x1080)映像。4Kでは短くなる |
| [Samsung PRO Endurance](https://download.semiconductor.samsung.com/resources/data-sheet/2024_Samsung_Data_sheet_microSD_Card_PRO_Endurance_v.1.1.pdf) | 70,080時間 | Full HD映像、26Mbps(3.25MB/s) |
| [Kingston High-Endurance](https://www.kingston.com/datasheets/SDCE_us.pdf) | 3K P/Eサイクル、稼働時間26.9K時間 | 3年保証期間の24時間録画(24時間録画の記載の注記はFull HD 13Mbps) |

SanDiskのデータシートは、容量が大きいほど録画時間も長いと書いています。32GBは最大2,500時間、512GBは最大40,000時間です。Samsungのデータシートも、32GBの17,520時間から256GBの140,160時間まで容量ごとに違います。

## メーカー同士で録画時間をそのまま比べてもいいですか?

そのままは比べません。基準にした映像のビットレートが違います。Samsungは26Mbps、Kingstonは13Mbpsの映像を注記の基準にしています。同じカードでも、高いビットレートで録画すると同じ時間でより多くのデータを書き込みます。

SanDiskのデータシートは、実際の録画時間は表示より短く、4K映像ではさらに短いと書いています。Samsungのデータシートは、ホスト機器、ファイルの属性、使い方によって映像の対応が変わることがあると書いています。

| 確認すること | データシートで見る場所 |
| --- | --- |
| 基準の解像度 | Full HDか4Kか |
| 基準のビットレート | Mbpsの値が書かれているか |
| 容量 | 同じ製品でも容量ごとに時間が違う |
| 保証期間 | SanDiskは2年、Kingstonは3年、Samsungは容量ごとに2〜5年 |

自分の機器の録画ビットレートは、ドラレコやカメラの取扱説明書で確認します。

## 高耐久SDカードは速度も速いですか?

耐久性と速度は別に見ます。同じ高耐久の製品でも、スピードクラスは違います。

| メーカーの資料 | スピードクラス | 書き込み速度 |
| --- | --- | --- |
| SanDisk High Endurance | Class 10、U3、V30 | 最大40MB/s |
| Samsung PRO Endurance 32GB・64GB | Class 10、U1、V10 | 最大30MB/s |
| Samsung PRO Endurance 128GB・256GB | Class 10、U3、V30 | 最大40MB/s |
| Kingston High-Endurance | Class 10、U1、A1 | 最大30〜45MB/s(容量ごと) |

SD Associationは、スピードクラスの数字が最低書き込み速度を表すと説明しています。機器の取扱説明書にV30が必要と書かれていれば、V30以上のカードを選びます。表示の読み方は[SDカードのV30とは?](/blog/ja/sd-card-speed-class)に、A1の表示は[SDカードのA1・A2とは?](/blog/ja/sd-card-a1-a2)にまとめました。

## 高耐久SDカードはどの順番で選びますか?

1. **機器の取扱説明書を見ます。** 対応するカードのサイズ(microSDか)、最大容量、必要なスピードクラスを確認します。
2. **容量の規格を合わせます。** Kingstonのデータシートは、カードの形式をSDHCはFAT32、SDXCはexFATと書いています。機器がSDXCに対応しているか確認します。違いは[SDカードとは?](/blog/ja/what-is-sd-card)にあります。
3. **スピードクラスを合わせます。** 機器が求める等級以上を選びます。
4. **耐久性の数値の基準を読みます。** 解像度、ビットレート、容量を合わせて見ます。
5. **販売元を確認します。** 高耐久の表示も偽装されることがあります。買った後に容量を確かめる方法は[SDカードの偽物の見分け方](/blog/ja/fake-sd-card)にあります。

Kingstonのデータシートは、同社のカードが一般消費者向けの製品との互換性を基準に設計・テストされており、それ以外の特殊な用途はKingstonに直接問い合わせるよう書いています。

カードリーダーを通せば接続できます。iPhoneにはカードスロットがないので、SDカードリーダーが必要です。[Appleの外部ストレージの案内](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)にある形式(exFAT、FAT32など)でフォーマットしたカードを使います。

## 高耐久SDカードのよくある質問

### 高耐久SDカードは壊れませんか?

壊れることがあります。メーカーが示す録画時間は「最大」や特定の条件での値です。SanDiskのデータシートは、実際の録画時間は表示より短いと書いています。

### ドラレコに普通のカードを使ってもいいですか?

まず機器の取扱説明書が決めているカードの条件に従います。メーカーは、ドラレコや防犯カメラのように録画を続ける機器を高耐久カードの用途として示しています。

### P/Eサイクルが多いほど録画時間も長いですか?

ビットレートと容量によって変わります。Kingstonのデータシートは、3K P/Eサイクルと稼働時間26.9K時間を別々に書いています。両方を合わせて見ます。

### 標準サイズのSDカードの高耐久製品はありますか?

この記事で確認したSanDisk、Samsung、Kingstonの製品はすべてmicroSDです。SanDiskのデータシートは、標準サイズのSD機器で使うためのアダプターが付属すると書いています。

### 高耐久SDカードの寿命はどう確認しますか?

メーカーがツールを用意しているかを見ます。Kingstonのデータシートは、カードの寿命を管理するヘルスモニタリングツールをオプションで用意していると書いています。
