## この記事の要点

SDカードフォーマッターは、SDアソシエーション(SDA)が配布する無料のソフトです。正式名はSDメモリカードフォーマッターで、SDカードの規格を定める団体が自ら提供しています。Windows、Mac、Linux版があります。

SDAは、OSに付属するフォーマットツールよりこのソフトを使うよう強く勧めています。OSのツールはSDカードに最適化されておらず、性能が落ちる場合があると説明しています。

オプションは2つです。クイックフォーマットはファイルの一覧を消します。上書きフォーマットはユーザ領域全体を上書きして消去します。カードを人に譲る前なら、上書きフォーマットを選んでください。

「SDカードフォーマッターはどこでダウンロードできる?」「クイックと上書き、どちらを選べばいい?」この記事はSDAの公式マニュアルとよくあるご質問をもとに、ソフトそのものの使い方を扱います。iPhoneのファイルアプリ、Macのディスクユーティリティ、Windowsのエクスプローラーでフォーマットする手順は[SDカードフォーマット方法](/blog/ja/format-sd-card)にまとめました。

## SDカードフォーマッターとは何ですか?

[SDAのフォーマッターの案内](https://www.sdcard.org/ja/downloads-2/formatter-2/)によると、このソフトはSD、SDHC、SDXC、SDUCカードをSDAのSDファイルシステム仕様どおりにフォーマットします。容量に合う形式はソフトが決めます。

| 項目 | 公式の案内 |
| --- | --- |
| 提供元 | SDAが配布、Tuxeraが開発 |
| 価格 | 無料 |
| 入手先 | SDAのWebサイト(sdcard.org)のみ |
| Windows・Mac版のバージョン | 5.0.4 |
| Linux版のバージョン | 1.0.3(x86_64、ARM64) |
| フォーマットできるカード | SD、SDHC、SDXC、SDUC |

バージョンは2026年11月20日にSDAのページで確認した値です。[SDAのよくあるご質問](https://www.sdcard.org/downloads/formatter/faq/)は、ほかのWebサイトにあるフォーマッターを使わないよう案内しています。SDAはほかのサイトにソフトのコピーを置くことを認めていません。

容量ごとにどの形式になるかは[SDXCとは?SDHC・SDUCとの違い](/blog/ja/sdhc-vs-sdxc)にまとめました。

## どのパソコンとカードリーダーで使えますか?

SDAの案内ページに記載された動作環境です。

| 項目 | 公式の案内 |
| --- | --- |
| Windows | Windows 10 22H2、Windows 11 22H2・23H2・24H2 |
| Mac | macOS 11 Big SurからmacOS 15 Sequoiaまで |
| Linux | x86_64版とARM64版を別に配布 |
| 権限 | Windows、macOSともに管理者権限が必要 |
| 接続機器 | パソコンのSDカードスロット、USB 2.0・3.0・3.1・USB-CのSDカードリーダー |

Appleシリコン搭載のMacでは、ソフトを開くときにRosettaのインストールを求められることがあります。上の一覧はSDAが案内しているOSです。一覧にないバージョンでの動作は、この記事では確かめていません。

iPhoneやAndroidスマートフォン向けの版はSDAのページにありません。iPhoneでカードをフォーマットするならファイルアプリを使います。手順は[SDカードフォーマット方法](/blog/ja/format-sd-card)にあります。

## フォーマットする前に何を確認しますか?

SDAのマニュアルは、フォーマットを始めると記録された情報は使えなくなると記載しています。次の5つを先に確認してください。

| 確認すること | やること |
| --- | --- |
| 残したいデータ | 別のストレージに先にコピーします |
| 書き込み禁止スイッチ | ロック解除の位置(上側)に動かします |
| BitLocker To Goの暗号化 | Windowsでロックを解除してからフォーマットします |
| 管理者権限 | 管理者のアカウントでサインインしているか確かめます |
| 電源とスリープ | 上書きフォーマットなら電源をつなぎ、スリープを無効にします |

スイッチの位置は[SDカードのロックスイッチの記事](/blog/ja/sd-card-lock-switch)で確かめてください。カードの写真を先にiPhoneへ移すなら[SDカードリーダーのiPhoneでの使い方](/blog/ja/iphone-sd-card-reader)に沿って進めてください。

## SDカードフォーマッターの使い方

[SDAのユーザーマニュアル](https://www.sdcard.org/pdf/SD_CardFormatterUserManualJP.pdf)に沿った手順です。

1. SDAのサイトから、使っているOS用のSDメモリカードフォーマッターをダウンロードします。
2. 開いているアプリをすべて閉じ、インストーラーを実行します。使用許諾契約(EULA)に同意するとインストールできます。
3. カードリーダーにSDカードを入れ、パソコンかMacにつなぎます。
4. ソフトを開き、ドライブの一覧からカードを選びます。あとからカードを入れたときはリフレッシュ(Refresh)を押します。
5. カードの種類と容量を見て、フォーマットするカードが合っているか確かめます。
6. クイックフォーマットと上書きフォーマットのどちらかを選びます。
7. ボリュームラベルにカードの名前を入力します。
8. フォーマットを押し、確認画面で続行を押します。
9. 終わったら、WindowsかMacの「取り出し」機能でカードを外します。

フォーマット中はカードやカードリーダーを抜かないでください。よくあるご質問によると、ボリュームラベルは半角英数字で11文字、全角の日本語で5文字まで入力できます。マニュアルは英字以外のラベルが正しく表示されないことがあるため、英字で入力するよう案内しています。

バージョン4.0以前が入っている場合は、先にアンインストールしてから最新版を入れます。よくあるご質問によると、以前のバージョンはもう配布されていません。

## クイックフォーマットと上書きフォーマットの違いは?

どちらもカードのファイルシステムパラメータを初期化します。違いはファイルの中のデータを消すかどうかです。

| 項目 | クイックフォーマット | 上書きフォーマット |
| --- | --- | --- |
| ファイル・フォルダの一覧 | 消します | 消します |
| ファイルの中のデータ | カードに残ります | ユーザ領域全体を上書きして消します |
| かかる時間 | 短いです | 容量に応じて大幅に長くなります |
| 選ぶ場面 | 同じカードを使い続けるとき | カードを人に譲る、処分する前 |

SDAのマニュアルは、クイックフォーマットのあともデータがカードに残り、データ復旧ツールで読み出される可能性があると記載しています。完全に消すなら上書きフォーマットを使うよう案内しています。

上書きフォーマットの途中でキャンセルすると、ユーザ領域は上書きされません。ファイルシステムパラメータだけが初期化され、入力したボリュームラベルが書き込まれます。データを確実に消すため、最後まで待ってください。

## CHSフォーマットサイズ調整はいつ使いますか?

CHSフォーマットサイズ調整はWindows版だけのオプションです。シリンダ数、ヘッド数、セクタ数から計算した容量に合わせてフォーマットします。

このオプションは、ユーザ容量が8,032.5MB(8,422,686,720バイト)以下のカードでだけ有効にできます。クイックフォーマットと上書きフォーマットの両方で使えます。マニュアルはどの機器にこのオプションが必要かを説明していません。カードを使う機器の説明書で求められていなければ、オフのままフォーマットしてください。

## カードが一覧に出ないときはどうしますか?

SDAのマニュアルとよくあるご質問が案内する手順です。

1. カードを抜いて入れ直し、リフレッシュを押します。
2. カードリーダーがカードの規格に対応しているか確かめます。SDとSDHCカードしか読めない機器もあります。
3. パソコンにSDカード用のドライバーを入れる必要があるか確かめます。
4. 規格が合っているのに表示されなければ、パソコンを再起動してソフトをもう一度実行します。

2TBを超えるSDUCカードには、SDUCに対応したドライバーが必要です。Windows版の一覧に内蔵ハードディスクが出る場合は、ソフトをアンインストールし、SDAのサイトからダウンロードし直して入れ直すよう、よくあるご質問は案内しています。

パソコン自体がカードを認識しない、エラーが繰り返し出る場合は[microSDが認識しない・フォーマットできないときの確認手順](/blog/ja/sd-card-not-working)を参照してください。

## フォーマット後に容量が違って見えるのはなぜですか?

SDAのよくあるご質問は2つの理由を挙げています。

| 見えること | 公式の説明 |
| --- | --- |
| WindowsとMacで表示容量が違う | Windowsは1KBを1,024バイト、Macは1,000バイトとして計算します |
| ソフトとOSで空き容量が違う | フォーマット後、OSがカードに隠しフォルダやファイルを作ります |

表示容量がカードの記載より大きく足りないなら、計算方法の違いではないかもしれません。実際の容量を確かめる方法は[SDカードの偽物の見分け方](/blog/ja/fake-sd-card)にまとめました。

## SDカードフォーマッターのよくある質問

### SDカードフォーマッターは無料ですか?

無料です。SDAのよくあるご質問は、SDAのサイトからのダウンロードは無料で、常に最新版を提供すると説明しています。

### USBメモリや外付けHDDもこのソフトでフォーマットできますか?

SDAのマニュアルは、SD、SDHC、SDXC、SDUCカード以外の記録媒体をこのソフトでフォーマットしないよう記載しています。誤ってフォーマットした場合は、その媒体に合うフォーマットソフトでフォーマットし直すよう案内しています。

### カードをNTFSなどほかの形式にできますか?

SDAのよくあるご質問は、SDA標準のFATファイルシステム以外での再フォーマットを勧めていません。ほかの機器とのデータのやり取りに支障が出る可能性があると説明しています。

### クイックフォーマットだけでデータは完全に消えますか?

完全には消えません。SDAのマニュアルは、クイックフォーマットのあともファイルのデータがカードに残ると記載しています。完全に消すなら上書きフォーマットを使ってください。

### 保護領域もフォーマットされますか?

フォーマットされません。SD、SDHC、SDXCカードの保護領域は著作権保護技術のCPRMが使います。SDAは、この領域をCPRMに対応したパソコンのアプリや機器でフォーマットするよう案内しています。SDUCカードには保護領域がありません。
