## 핵심 요약

SD 카드 포맷 프로그램을 찾는다면 SD Association(SDA)이 배포하는 SD Memory Card Formatter를 먼저 확인하세요. SD 카드 규격을 만드는 단체가 직접 내놓은 무료 프로그램입니다. 윈도우, Mac, 리눅스용이 있습니다.

SDA는 운영체제의 포맷 도구보다 이 프로그램을 쓰라고 강하게 권합니다. 운영체제 도구는 SD 카드에 최적화되지 않아 성능이 떨어질 수 있다고 설명합니다.

옵션은 두 가지입니다. 빠른 포맷은 파일 목록만 지웁니다. 덮어쓰기 포맷은 사용자 데이터 영역 전체를 덮어써서 지웁니다. 카드를 남에게 넘기기 전이라면 덮어쓰기 포맷을 고르세요.

"SD 카드 포맷 프로그램은 어디서 받나요?" "빠른 포맷과 덮어쓰기 포맷 중 무엇을 골라야 하나요?" 이 글은 SDA 공식 매뉴얼과 FAQ를 기준으로 프로그램 자체의 사용법을 다룹니다. 아이폰, Mac 디스크 유틸리티, 윈도우 탐색기로 포맷하는 순서는 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에 정리했습니다.

## SD 카드 포맷 프로그램 SD Card Formatter는 무엇인가요?

[SDA의 포맷 프로그램 안내](https://www.sdcard.org/downloads/formatter/)에 따르면 이 프로그램은 SD, SDHC, SDXC, SDUC 카드를 SDA의 SD 파일 시스템 규격대로 포맷합니다. 카드 용량에 맞는 형식은 프로그램이 정합니다.

| 항목 | 공식 안내 내용 |
| --- | --- |
| 만든 곳 | SDA 배포, Tuxera 개발 |
| 가격 | 무료 |
| 받는 곳 | SDA 웹사이트(sdcard.org)만 |
| 윈도우·Mac 버전 | 5.0.4 |
| 리눅스 버전 | 1.0.3(x86_64, ARM64) |
| 포맷하는 카드 | SD, SDHC, SDXC, SDUC |

버전은 2026년 11월 20일에 SDA 페이지에서 확인한 값입니다. [SDA FAQ](https://www.sdcard.org/downloads/formatter/faq/)는 다른 사이트에 올라온 포맷 프로그램을 쓰지 말라고 안내합니다. SDA는 다른 사이트에 프로그램 사본을 올리는 것을 허용하지 않습니다.

용량별로 어떤 형식이 되는지는 [SDHC와 SDXC 차이](/blog/ko/sdhc-vs-sdxc)에 정리했습니다.

## 어떤 컴퓨터와 리더기에서 쓸 수 있나요?

SDA 안내 페이지에 적힌 지원 환경입니다.

| 구분 | 공식 안내 내용 |
| --- | --- |
| 윈도우 | Windows 10 22H2, Windows 11 22H2·23H2·24H2 |
| Mac | macOS 11 Big Sur부터 macOS 15 Sequoia까지 |
| 리눅스 | x86_64용, ARM64용 별도 배포 |
| 권한 | 윈도우와 macOS 모두 관리자 권한 필요 |
| 연결 장치 | PC의 SD 카드 슬롯, USB 2.0·3.0·3.1·USB-C SD 카드 리더 |

Apple 실리콘 Mac에서는 프로그램을 열 때 Rosetta 설치를 요청받을 수 있습니다. 위 목록은 SDA가 안내한 운영체제입니다. 목록에 없는 버전에서의 동작은 이 글에서 확인하지 않았습니다.

아이폰과 안드로이드폰용은 SDA 페이지에 없습니다. 아이폰에서 카드를 포맷하려면 파일 앱을 씁니다. 순서는 [SD 카드 포맷 방법](/blog/ko/format-sd-card)에 있습니다.

## 포맷하기 전에 무엇을 확인하나요?

SDA 매뉴얼은 포맷을 시작하면 기록된 정보를 더 이상 쓸 수 없다고 적습니다. 아래 다섯 가지를 먼저 확인하세요.

| 확인할 것 | 해야 할 일 |
| --- | --- |
| 카드에 남길 자료 | 다른 저장장치에 먼저 복사합니다 |
| 쓰기 방지 스위치 | 잠금 해제 위치(위쪽)로 올립니다 |
| BitLocker To Go 암호화 | 윈도우에서 잠금을 푼 뒤 포맷합니다 |
| 관리자 권한 | 관리자 계정으로 로그인했는지 확인합니다 |
| 전원과 절전 모드 | 덮어쓰기 포맷이라면 전원을 연결하고 절전 모드를 끕니다 |

쓰기 방지 스위치 위치는 [SD 카드 잠금 스위치 글](/blog/ko/sd-card-lock-switch)에서 확인하세요. 카드 사진을 아이폰으로 먼저 옮기려면 [아이폰 SD 카드 리더기 사용법](/blog/ko/iphone-sd-card-reader)을 따르세요.

## SD Card Formatter 사용법

[SDA 사용자 매뉴얼](https://www.sdcard.org/pdf/SD_CardFormatterUserManualEN.pdf)을 따른 순서입니다.

1. SDA 사이트에서 운영체제에 맞는 SD Memory Card Formatter를 내려받습니다.
2. 열린 프로그램을 모두 닫고 설치 파일을 실행합니다. 사용권 계약(EULA)에 동의해야 설치됩니다.
3. 카드 리더에 SD 카드를 넣고 PC나 Mac에 연결합니다.
4. 프로그램을 열고 드라이브 목록에서 카드를 고릅니다. 카드를 나중에 넣었다면 새로 고침(Refresh)을 누릅니다.
5. 카드 종류와 용량을 보고 포맷할 카드가 맞는지 확인합니다.
6. 빠른 포맷(Quick format)과 덮어쓰기 포맷(Overwrite format) 중 하나를 고릅니다.
7. 볼륨 레이블에 카드 이름을 입력합니다.
8. 포맷(Format)을 누르고 확인 창에서 계속(Continue)을 누릅니다.
9. 포맷이 끝나면 윈도우나 Mac의 꺼내기 기능으로 카드를 뺍니다.

포맷 중에는 카드나 카드 리더를 빼지 마세요. 볼륨 레이블은 11자까지 입력합니다. 매뉴얼은 영문이 아닌 레이블이 바르게 보이지 않을 수 있으니 영문으로 입력하라고 안내합니다.

버전 4.0 이하가 설치되어 있다면 먼저 지우고 최신 버전을 설치해야 합니다. SDA FAQ에 따르면 예전 버전은 더 이상 배포하지 않습니다.

## 빠른 포맷과 덮어쓰기 포맷은 무엇이 다른가요?

두 옵션 모두 카드의 파일 시스템 정보를 초기화합니다. 차이는 파일 안의 데이터를 지우는지입니다.

| 구분 | 빠른 포맷 | 덮어쓰기 포맷 |
| --- | --- | --- |
| 파일·폴더 목록 | 지웁니다 | 지웁니다 |
| 파일 안의 데이터 | 카드에 남습니다 | 사용자 데이터 영역 전체를 덮어써서 지웁니다 |
| 걸리는 시간 | 짧습니다 | 카드 용량에 따라 훨씬 오래 걸립니다 |
| 이럴 때 고릅니다 | 같은 카드를 계속 쓸 때 | 카드를 남에게 넘기거나 버리기 전 |

SDA 매뉴얼은 빠른 포맷 뒤에도 파일 데이터가 남아 복구 도구로 읽힐 수 있다고 적습니다. 데이터를 완전히 지우려면 덮어쓰기 포맷을 쓰라고 안내합니다.

덮어쓰기 포맷 도중 취소하면 사용자 데이터 영역은 덮어쓰지 않습니다. 파일 시스템 정보만 초기화되고 입력한 볼륨 레이블이 기록됩니다. 지우려던 데이터가 남을 수 있으니 끝까지 기다리세요.

## CHS 포맷 크기 조정은 언제 쓰나요?

CHS 포맷 크기 조정(CHS Format Size Adjustment)은 윈도우판에만 있는 옵션입니다. 실린더, 헤드, 섹터 수로 계산한 값에 맞춰 포맷 용량을 조정합니다.

이 옵션은 사용자 용량이 8,032.5MB(8,422,686,720바이트) 이하인 카드에서만 켤 수 있습니다. 빠른 포맷과 덮어쓰기 포맷 모두에 쓸 수 있습니다. 매뉴얼은 어떤 기기에 이 옵션이 필요한지 설명하지 않습니다. 카드를 쓸 기기의 설명서가 요구하지 않는다면 꺼 둔 채 포맷하세요.

## 카드가 목록에 안 보이면 어떻게 하나요?

SDA 매뉴얼과 FAQ가 안내하는 순서입니다.

1. 카드를 뺐다가 다시 넣고 새로 고침을 누릅니다.
2. 카드 리더가 카드 규격을 지원하는지 확인합니다. 일부 장치는 SD와 SDHC 카드만 읽습니다.
3. 컴퓨터에 SD 카드용 드라이버를 설치해야 하는지 확인합니다.
4. 규격이 맞는데도 안 보이면 컴퓨터를 다시 시작하고 프로그램을 다시 실행합니다.

2TB를 넘는 SDUC 카드는 드라이버가 SDUC를 지원해야 합니다. 윈도우판 목록에 내장 하드디스크가 보이면 프로그램을 지우고 SDA 사이트에서 다시 받아 설치하라고 FAQ는 안내합니다.

카드가 컴퓨터 자체에서 보이지 않거나 오류가 반복되면 [SD 카드 인식 안 될 때 확인 순서](/blog/ko/sd-card-not-working)를 따르세요.

## 포맷 뒤 용량이 다르게 보이는 이유는?

SDA FAQ는 두 가지 이유를 듭니다.

| 보이는 현상 | 공식 설명 |
| --- | --- |
| 윈도우와 Mac에서 표시 용량이 다릅니다 | 윈도우는 1KB를 1,024바이트, Mac은 1,000바이트로 계산합니다 |
| 프로그램과 운영체제의 남은 공간이 다릅니다 | 포맷 뒤 운영체제가 카드에 숨김 폴더와 파일을 만듭니다 |

표시 용량이 카드에 적힌 용량보다 크게 모자라면 계산 방식 차이가 아닐 수 있습니다. 실제 용량을 확인하는 방법은 [가짜 SD 카드 구별법](/blog/ko/fake-sd-card)에 정리했습니다.

## SD 카드 포맷 프로그램 자주 묻는 질문

### SD Card Formatter는 무료인가요?

무료입니다. SDA FAQ는 SDA 사이트의 내려받기가 무료이고 항상 최신 버전을 제공한다고 설명합니다.

### USB 메모리나 외장하드도 이 프로그램으로 포맷할 수 있나요?

SDA 매뉴얼은 SD, SDHC, SDXC, SDUC 카드 외의 저장장치를 이 프로그램으로 포맷하지 말라고 적습니다. 실수로 포맷했다면 그 장치에 맞는 포맷 소프트웨어로 다시 포맷하라고 안내합니다.

### 카드를 NTFS나 다른 형식으로 바꿀 수 있나요?

SDA FAQ는 SDA 표준 FAT 파일 시스템 외의 형식으로 다시 포맷하는 것을 권하지 않습니다. 다른 기기와 카드를 주고받을 때 호환성이 떨어질 수 있다고 설명합니다.

### 빠른 포맷만 하면 자료가 완전히 지워지나요?

완전히 지워지지 않습니다. SDA 매뉴얼은 빠른 포맷 뒤에도 파일 데이터가 카드에 남는다고 적습니다. 완전히 지우려면 덮어쓰기 포맷을 쓰세요.

### 보호 영역(Protected Area)도 포맷되나요?

포맷되지 않습니다. SD, SDHC, SDXC 카드의 보호 영역은 CPRM 저작권 보호 기능이 씁니다. SDA는 이 영역을 CPRM을 지원하는 PC 프로그램이나 기기로 포맷하라고 안내합니다. SDUC 카드에는 보호 영역이 없습니다.
