## 핵심 요약

핸드폰 컴퓨터 USB 연결 안됨 증상은 대부분 케이블, 잠금, 허용 설정 중 하나에서 시작합니다. 충전은 되는데 사진이 안 보인다면 케이블부터 의심합니다. Apple은 케이블이 데이터 전송과 충전을 모두 지원해야 한다고 설명합니다.

아이폰은 잠금을 풀고 "이 컴퓨터를 신뢰하겠습니까?" 알림에서 신뢰를 눌러야 컴퓨터가 사진에 접근합니다. 윈도우 PC에서는 Apple 기기 앱을 씁니다.

안드로이드 폰은 연결 뒤 알림에서 USB 사용 용도를 파일 전송으로 바꿔야 PC에 파일 창이 열립니다.

"폰을 꽂으면 충전만 되고 컴퓨터에 아무것도 안 떠요." "예전엔 됐는데 오늘은 PC가 핸드폰을 못 알아봐요." 사진을 컴퓨터로 옮기려다 자주 막히는 순간입니다. 이 글은 Apple과 Google 공식 안내로 확인할 수 있는 절차만 다룹니다. 특정 케이블이나 프로그램을 시험하거나 추천하지 않습니다.

## 핸드폰 컴퓨터 USB 연결 안됨, 무엇부터 확인하나요?

증상에 맞는 줄을 찾아 해당 부분부터 보세요.

| 증상 | 먼저 확인할 것 | 이 글의 해당 부분 |
| --- | --- | --- |
| 충전만 되고 컴퓨터에 아무 반응이 없음 | 데이터 케이블, 충전 단자 이물질, 포트 | 케이블과 포트 |
| 아이폰이 윈도우 PC에서 안 보임 | Apple 기기 앱, 잠금 해제, 신뢰 | 윈도우 PC와 아이폰 |
| 아이폰이 Mac Finder에 안 보임 | 액세서리 허용, 신뢰, Finder 사이드바 | Mac과 아이폰 |
| 신뢰 알림이 뜨지 않거나 신뢰하지 않음을 눌렀음 | 위치 및 개인정보 보호 재설정 | 신뢰 알림 |
| 안드로이드 폰을 꽂아도 파일 창이 안 열림 | USB 사용 용도, 잠금 해제 | 안드로이드 |
| 인식은 되는데 사진이 일부만 보임 | iCloud 사진의 원본 다운로드 | 인식된 뒤 |

## 충전만 되고 파일이 안 보이면 케이블 문제인가요?

그럴 수 있습니다. [Apple의 컴퓨터 인식 문제 안내](https://support.apple.com/ko-kr/108643)는 케이블이 데이터 전송과 충전을 모두 지원해야 한다고 설명합니다. [Google의 파일 전송 안내](https://support.google.com/android/answer/9064445?hl=ko)도 모든 USB 케이블이 파일을 전송할 수 있는 것은 아니라고 적습니다. 충전용으로만 쓰던 케이블이라면 다른 케이블로 바꿔 봅니다.

두 안내를 합쳐 아래 순서로 확인합니다. 한 단계에서 인식되면 나머지는 건너뜁니다.

1. 케이블을 뺐다가 다시 꽂습니다.
2. 연결했을 때 핸드폰이 소리나 진동으로 반응하는지 봅니다. 반응이 없으면 케이블을 빼고 충전 단자에 이물질이 있는지 확인합니다.
3. 데이터 전송을 지원하는 다른 케이블로 바꿉니다.
4. 컴퓨터의 다른 USB 포트에 꽂습니다.
5. 다른 컴퓨터에 연결합니다.

Google은 핸드폰을 다른 컴퓨터에 연결하면 핸드폰 쪽 포트를, 다른 기기를 내 컴퓨터에 연결하면 컴퓨터 쪽 포트를 시험할 수 있다고 설명합니다. 다른 컴퓨터에서는 되고 내 컴퓨터에서만 안 되면 컴퓨터의 포트나 설정을 의심합니다.

## 아이폰을 윈도우 PC가 인식하지 못하면?

윈도우 PC에서는 Apple 기기 앱으로 아이폰을 확인합니다. [Apple 안내](https://support.apple.com/ko-kr/108643)를 따른 순서입니다.

1. Apple 기기 앱을 엽니다.
2. USB 케이블로 아이폰을 윈도우 PC에 연결합니다.
3. 아이폰 잠금을 풉니다.
4. 아이폰에 "이 컴퓨터를 신뢰하겠습니까?" 알림이 뜨면 신뢰를 누릅니다.
5. Apple 기기 앱의 사이드바에 아이폰이 나타나는지 봅니다.

그래도 나타나지 않으면 Apple은 아래 항목을 차례로 확인하라고 안내합니다.

| 확인할 것 | 내용 |
| --- | --- |
| 케이블과 연결 | 위의 케이블과 포트 순서를 따릅니다 |
| 소프트웨어 충돌 | 보안 프로그램 등 다른 소프트웨어가 연결을 막는지 봅니다 |
| 윈도우 버전 | 최신 버전의 윈도우인지 확인합니다 |
| iOS 버전 | 최신 버전의 iOS인지 확인합니다 |

[Apple의 액세서리 연결 허용 안내](https://support.apple.com/ko-kr/111806)에 따르면 아이폰은 기본적으로 잠금을 먼저 풀어야 컴퓨터와 통신합니다. 잠금을 풀지 않으면 컴퓨터와 통신하지 않고 충전되지 않을 수도 있습니다. 잠금을 푼 뒤에도 안 되면 케이블을 빼고, 잠금을 푼 상태에서 다시 연결합니다.

## 아이폰을 Mac이 인식하지 못하면?

Mac에서는 Finder 사이드바에 아이폰이 나타나야 합니다. [Apple 안내](https://support.apple.com/ko-kr/108643)를 따른 순서입니다.

1. USB 케이블로 아이폰을 Mac에 연결합니다.
2. Mac에 "액세서리를 연결하도록 허용하겠습니까?" 알림이 뜨면 허용을 누릅니다.
3. 아이폰에 "이 컴퓨터를 신뢰하겠습니까?" 알림이 뜨면 신뢰를 누릅니다.
4. Finder 사이드바에 아이폰이 나타나는지 봅니다.

Finder 윈도우에 사이드바가 없다면 메뉴 막대에서 보기, 사이드바 보기를 고릅니다. 그래도 안 보이면 케이블과 포트를 확인하고, VPN이나 다른 보안 소프트웨어가 연결을 막는지 봅니다. macOS와 iOS가 최신 버전인지도 확인합니다.

Mac의 액세서리 허용 창에서 허용 안 함을 눌렀다면 [Apple의 Mac 액세서리 허용 안내](https://support.apple.com/ko-kr/102282)대로 다시 연결해 허용합니다.

## '이 컴퓨터를 신뢰하겠습니까' 알림이 뜨지 않으면?

[Apple의 신뢰 알림 안내](https://support.apple.com/ko-kr/109054)에 따르면 신뢰하지 않음을 고른 컴퓨터는 아이폰의 콘텐츠에 접근할 수 없습니다. 이 경우 연결할 때마다 알림이 다시 뜹니다. 알림이 아예 뜨지 않거나 실수로 신뢰하지 않음을 눌렀다면 위치 및 개인정보 보호 설정을 재설정합니다.

1. 설정을 엽니다.
2. 일반을 탭합니다.
3. 전송 또는 [기기] 재설정을 탭합니다.
4. 재설정을 탭합니다.
5. 위치 및 개인정보 보호 재설정을 탭합니다.

재설정 뒤에는 전에 신뢰했던 컴퓨터에 연결해도 신뢰할지 다시 묻습니다. 신뢰를 눌렀는데 컴퓨터가 받아들이지 않을 때 Apple이 안내하는 순서는 아래와 같습니다. 한 단계마다 다시 연결해 봅니다.

| 순서 | 할 일 |
| --- | --- |
| 1 | 컴퓨터의 macOS나 Apple 기기 앱을 최신 버전으로 맞춥니다 |
| 2 | 아이폰을 뺐다가 다시 연결합니다 |
| 3 | 컴퓨터를 재시동합니다 |
| 4 | 아이폰을 재시동합니다 |
| 5 | 위치 및 개인정보 보호를 재설정합니다 |
| 6 | 네트워크 설정을 재설정합니다 |

네트워크 설정을 재설정하면 저장된 Wi-Fi 네트워크와 암호, 셀룰러 설정, VPN과 APN 설정도 초기화됩니다. Wi-Fi 암호를 미리 확인해 두세요.

## 안드로이드 폰을 PC가 인식하지 못하면?

안드로이드 폰은 연결만 해서는 충전만 될 수 있습니다. [Google의 파일 전송 안내](https://support.google.com/android/answer/9064445?hl=ko)를 따른 윈도우 컴퓨터 순서입니다.

1. 핸드폰 잠금을 풉니다.
2. USB 케이블로 핸드폰을 컴퓨터에 연결합니다.
3. 핸드폰에서 '이 기기를 USB로 충전' 알림을 탭합니다.
4. 'USB 사용'에서 파일 전송을 고릅니다.
5. 컴퓨터에 파일 전송 창이 열리면 파일을 끌어 옮깁니다.
6. 다 옮긴 뒤 윈도우에서 기기를 분리하고 케이블을 뽑습니다.

Google은 이 단계 중 일부가 Android 14 이상에서만 동작한다고 적습니다. 메뉴 이름은 제조사와 버전에 따라 다를 수 있습니다.

그래도 파일 창이 열리지 않을 때 Google이 안내하는 확인 항목입니다.

| 확인할 쪽 | 할 일 |
| --- | --- |
| 컴퓨터 | 윈도우가 새 하드웨어를 자동으로 감지하도록 설정되어 있는지 봅니다. 컴퓨터를 재시동합니다 |
| 핸드폰 | Android 버전을 업데이트합니다. 핸드폰을 재시동합니다 |
| USB 연결 | 다른 케이블로 바꿉니다. 다른 컴퓨터와 다른 기기로 포트를 시험합니다 |

Google의 이 안내는 윈도우와 Chromebook 순서만 다룹니다. Mac에서 안드로이드 폰을 쓰는 방법은 핸드폰 제조사 안내를 확인하세요.

## 인식된 뒤 아이폰 사진을 가져오려면?

아이폰이 보이면 사진을 가져옵니다. [Apple의 사진 전송 안내](https://support.apple.com/ko-kr/120267)에 따르면 Mac은 사진 앱의 가져오기 화면을 쓰고, 윈도우 PC는 Microsoft Store에서 Apple 기기 앱을 설치한 뒤 Microsoft 사진 앱으로 가져옵니다.

| 상황 | Apple 안내 |
| --- | --- |
| iCloud 사진을 켜 둠 | PC로 가져오기 전에 원본 해상도 사진을 아이폰에 내려받아야 합니다 |
| 윈도우에서 사진이 잘 열리지 않음 | 설정 > 카메라 > 포맷에서 높은 호환성을 고르면 이후 사진과 영상이 JPEG와 H.264로 찍힙니다 |
| Mac으로 가져오기 | 사진 앱 사이드바에서 기기 이름을 누르고, 가져오기가 끝난 뒤 분리합니다 |

높은 호환성은 이후에 찍는 사진에만 적용됩니다. 이미 찍은 사진의 형식은 바뀌지 않습니다. Mac과 윈도우로 옮기는 자세한 순서는 [아이폰 사진 백업 방법](/blog/ko/iphone-photo-backup)에 정리했습니다.

## 그래도 컴퓨터가 핸드폰을 인식하지 못하면?

케이블, 포트, 다른 컴퓨터까지 바꿨는데도 안 되면 핸드폰 쪽 단자나 하드웨어를 의심합니다. Apple은 이 경우 지원에 문의해 서비스를 받아야 할 수 있다고 안내합니다. 안드로이드 폰은 제조사 지원 범위를 먼저 확인하세요.

컴퓨터 연결이 당장 어렵다면 사진을 옮기는 다른 길도 있습니다. iCloud와 USB를 비교한 내용은 [컴퓨터 없이 아이폰 백업](/blog/ko/backup-iphone-without-computer)에 있습니다. USB 메모리를 아이폰에 바로 꽂았는데 안 보인다면 [갑자기 USB 인식 안됨](/blog/ko/usb-data-rescue)에서 확인할 순서를 보세요.

## 컴퓨터 없이 아이폰 사진을 USB에 저장하려면?

NextGenAI가 만든 U-Saver는 일반 USB에 사진, 영상, 연락처를 저장하는 앱으로, exFAT이나 FAT32 형식의 USB를 쓰고 iOS 26 이상에서 동작합니다. U-Saver는 App Store 출시를 준비 중이며 가격은 4,900원이고 한 번 결제합니다. U-Saver는 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고, U-Saver로 저장한 USB의 내용은 암호화되지 않습니다. 항목별로 USB에 옮기는 순서는 [아이폰 USB 백업 방법](/blog/ko/backup-iphone-to-usb)에, 구매 전 확인할 점은 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)에 정리했습니다.

## 핸드폰 컴퓨터 USB 연결 안됨 자주 묻는 질문

### 충전은 되는데 왜 컴퓨터에 핸드폰이 안 보이나요?

케이블이 충전만 지원하거나, 안드로이드라면 USB 사용 용도가 충전으로 되어 있을 수 있습니다. Apple은 데이터 전송과 충전을 모두 지원하는 케이블을 쓰라고 안내합니다. 안드로이드는 알림에서 파일 전송을 고르세요.

### 신뢰하지 않음을 실수로 눌렀어요.

설정 > 일반 > 전송 또는 [기기] 재설정 > 재설정 > 위치 및 개인정보 보호 재설정을 누릅니다. 그 뒤 다시 연결하면 신뢰 알림이 다시 뜹니다.

### 윈도우 PC에서 아이폰을 보려면 따로 앱이 필요한가요?

Apple 안내는 윈도우 PC에서 Apple 기기 앱을 열고 아이폰을 연결하라고 설명합니다. 사진을 가져올 때도 Microsoft Store에서 Apple 기기 앱을 먼저 설치하라고 적습니다.

### 잠긴 아이폰을 꽂아 두면 컴퓨터가 인식하나요?

Apple 안내에 따르면 아이폰은 기본적으로 잠금을 먼저 풀어야 컴퓨터와 통신합니다. 잠금을 푼 뒤 다시 연결하세요.

### 안드로이드에서 파일 전송 메뉴가 안 보여요.

Google은 일부 단계가 Android 14 이상에서만 동작한다고 설명합니다. Android 버전을 업데이트하고 핸드폰을 재시동해 보세요. 메뉴 이름이 다르면 제조사 안내를 확인하세요.
