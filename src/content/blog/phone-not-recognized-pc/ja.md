## 要点まとめ

PCがスマホを認識しないときは、ケーブル、ロック、許可の設定のどれかが原因であることが多いです。充電はできるのに写真が見えないなら、まずケーブルを疑います。Appleは、ケーブルがデータ転送と充電の両方に対応している必要があると説明しています。

iPhoneはロックを解除し、「このコンピュータを信頼しますか？」の警告で「信頼」を押すと、パソコンが写真にアクセスできるようになります。WindowsパソコンではAppleデバイスアプリを使います。

Androidスマホは、接続後の通知でUSBの使用方法を「ファイル転送」に変えると、パソコンにファイルのウインドウが開きます。

「スマホを挿しても充電されるだけで、パソコンに何も出ない」「前はできたのに、今日はPCがスマホを認識しない」。写真をパソコンに移そうとして、よくつまずく場面です。この記事はAppleとGoogleの公式資料で確認できる手順だけを扱い、特定のケーブルやソフトを試したり勧めたりはしません。

## PCがスマホを認識しないとき、まず何を確認しますか?

症状に合う行を探し、その部分から読んでください。

| 症状 | まず確認すること | この記事の該当部分 |
| --- | --- | --- |
| 充電だけされて、パソコンが反応しない | データ転送対応のケーブル、充電ポートの異物、USBポート | ケーブルとポート |
| iPhoneがWindowsパソコンに表示されない | Appleデバイスアプリ、ロック解除、信頼 | WindowsパソコンとiPhone |
| iPhoneがMacのFinderに表示されない | アクセサリの許可、信頼、Finderのサイドバー | MacとiPhone |
| 信頼の警告が出ない、または「信頼しない」を押した | 位置情報とプライバシーのリセット | 信頼の警告 |
| Androidスマホを挿してもファイルのウインドウが開かない | USBの使用方法、ロック解除 | Android |
| 認識はされるが、写真が一部しか見えない | iCloud写真のオリジナルのダウンロード | 認識された後 |

## 充電はできるのにファイルが見えないのはケーブルのせいですか?

その可能性があります。[Appleの「コンピュータでiPhoneが認識されない場合」](https://support.apple.com/ja-jp/108643)は、ケーブルがデータと充電の両方に対応している必要があると説明しています。[Googleのファイル転送の案内](https://support.google.com/android/answer/9064445?hl=ja)も、すべてのUSBケーブルがファイルを転送できるわけではないと書いています。充電用にだけ使っていたケーブルなら、別のケーブルに替えてみます。

2つの案内をまとめ、次の順で確認します。途中で認識されたら、残りは飛ばしてかまいません。

1. ケーブルを抜いて、挿し直します。
2. 接続したときにスマホが音や振動で反応するかを見ます。反応しなければケーブルを抜き、充電ポートに異物がないか確認します。
3. データ転送に対応した別のケーブルに替えます。
4. パソコンの別のUSBポートに挿します。
5. 別のパソコンに接続します。

Googleは、スマホを別のパソコンにつなぐとスマホ側のポートを、別のデバイスを自分のパソコンにつなぐとパソコン側のポートを確かめられると説明しています。別のパソコンでは認識され、自分のパソコンだけで認識しないなら、パソコンのポートや設定を疑います。

## WindowsパソコンがiPhoneを認識しないときは?

WindowsパソコンではAppleデバイスアプリでiPhoneを確認します。[Appleの案内](https://support.apple.com/ja-jp/108643)に沿った手順です。

1. Appleデバイスアプリを開きます。
2. USBケーブルでiPhoneをWindowsパソコンに接続します。
3. iPhoneのロックを解除します。
4. iPhoneに「このコンピュータを信頼しますか？」と表示されたら、「信頼」をタップします。
5. Appleデバイスアプリのサイドバーに、iPhoneが表示されるかを見ます。

それでも表示されない場合、Appleは次の項目を順に確認するよう案内しています。

| 確認すること | 内容 |
| --- | --- |
| ケーブルと接続 | 上のケーブルとポートの手順に沿って確認します |
| ソフトウェアの競合 | セキュリティソフトなど、ほかのソフトウェアが接続を妨げていないか見ます |
| Windowsのバージョン | 最新バージョンのWindowsか確認します |
| iOSのバージョン | 最新バージョンのiOSか確認します |

[Appleのアクセサリ接続の許可の案内](https://support.apple.com/ja-jp/111806)によると、iPhoneは初期設定ではロックを解除しないとパソコンと通信しません。ロックを解除しないと通信せず、充電されないこともあります。ロックを解除しても認識されないときは、ケーブルを抜き、ロックを解除した状態でつなぎ直します。

## MacがiPhoneを認識しないときは?

Macでは、FinderのサイドバーにiPhoneが表示されるはずです。[Appleの案内](https://support.apple.com/ja-jp/108643)に沿った手順です。

1. USBケーブルでiPhoneをMacに接続します。
2. Macに「アクセサリの接続を許可しますか？」と表示されたら、「許可」をクリックします。
3. iPhoneに「このコンピュータを信頼しますか？」と表示されたら、「信頼」をタップします。
4. FinderのサイドバーにiPhoneが表示されるかを見ます。

Finderのウインドウにサイドバーがなければ、メニューバーの「表示」から「サイドバーを表示」を選びます。それでも表示されなければ、ケーブルとポートを確認し、VPNやほかのセキュリティソフトが接続を妨げていないか見ます。macOSとiOSが最新かも確認します。

Macのアクセサリ許可の画面で「許可しない」を押した場合は、[AppleのMacのアクセサリ許可の案内](https://support.apple.com/ja-jp/102282)に沿ってつなぎ直し、許可します。

## 「このコンピュータを信頼しますか？」が表示されないときは?

[Appleの信頼の警告に関する案内](https://support.apple.com/ja-jp/109054)によると、信頼しないと選んだパソコンはiPhoneのコンテンツにアクセスできません。そのパソコンにつなぐたびに警告が表示されます。警告がまったく出ない場合や、間違えて「信頼しない」を押した場合は、位置情報とプライバシーの設定をリセットします。

1. 「設定」を開きます。
2. 「一般」をタップします。
3. 「転送または[デバイス]をリセット」をタップします。
4. 「リセット」をタップします。
5. 「位置情報とプライバシーをリセット」をタップします。

リセット後は、以前信頼したパソコンにつないでも、信頼するかどうかをもう一度聞かれます。「信頼」を押してもパソコンが受け付けないとき、Appleが案内する手順は次のとおりです。1つ試すたびに、つなぎ直してみます。

| 順番 | やること |
| --- | --- |
| 1 | パソコンのmacOSまたはAppleデバイスアプリを最新にします |
| 2 | iPhoneを取り外して、つなぎ直します |
| 3 | パソコンを再起動します |
| 4 | iPhoneを再起動します |
| 5 | 位置情報とプライバシーをリセットします |
| 6 | ネットワーク設定をリセットします |

ネットワーク設定をリセットすると、保存したWi-Fiネットワークとパスワード、モバイル通信の設定、VPNとAPNの設定もリセットされます。Wi-Fiのパスワードを先に控えておきましょう。

## PCがAndroidスマホを認識しないときは?

Androidスマホは、つないだだけでは充電されるだけのことがあります。[Googleのファイル転送の案内](https://support.google.com/android/answer/9064445?hl=ja)に沿ったWindowsの手順です。

1. スマホのロックを解除します。
2. USBケーブルでスマホをパソコンに接続します。
3. スマホで[このデバイスを USB で充電中]の通知をタップします。
4. [USB の使用]で[ファイル転送]を選びます。
5. パソコンにファイル転送のウインドウが開いたら、ファイルをドラッグします。
6. 終わったらWindowsからデバイスの接続を解除し、ケーブルを抜きます。

Googleは、この手順の一部はAndroid 14以上でのみ動作すると書いています。メニューの名前はメーカーやバージョンによって違う場合があります。

それでもファイルのウインドウが開かないとき、Googleが案内する確認項目です。

| 確認する側 | やること |
| --- | --- |
| パソコン | Windowsが新しいハードウェアを自動で検出する設定か見ます。パソコンを再起動します |
| スマホ | Androidのバージョンを更新します。スマホを再起動します |
| USB接続 | 別のケーブルに替えます。別のパソコンと別のデバイスでポートを確かめます |

このGoogleの案内が扱うのはWindowsとChromebookの手順だけです。MacでAndroidスマホを使う方法は、スマホのメーカーの案内を確認してください。

## 認識された後、iPhoneの写真を取り込むには?

iPhoneが表示されたら写真を取り込みます。[Appleの写真転送の案内](https://support.apple.com/ja-jp/120267)によると、Macは「写真」アプリの読み込み画面を使います。WindowsパソコンはMicrosoft StoreでAppleデバイスアプリを入れてから、Microsoftの「フォト」アプリで取り込みます。

| 状況 | Appleの案内 |
| --- | --- |
| iCloud写真をオンにしている | パソコンに取り込む前に、オリジナルのフル解像度の写真をiPhoneにダウンロードする必要があります |
| Windowsで写真がうまく開かない | 「設定」>「カメラ」>「フォーマット」で「互換性優先」を選ぶと、以降の写真とビデオはJPEGとH.264で撮影されます |
| Macに取り込む | 「写真」のサイドバーでデバイス名をクリックし、読み込みが終わってから取り外します |

「互換性優先」はその後に撮る写真にだけ適用されます。すでに撮った写真の形式は変わりません。MacとWindowsへ移す詳しい手順は[iPhone写真バックアップをiCloud以外で](/blog/ja/iphone-photo-backup)にまとめました。

## それでもPCがスマホを認識しないときは?

ケーブル、ポート、別のパソコンまで試しても認識しないなら、スマホ側の端子やハードウェアを疑います。Appleはこの場合、サポートに問い合わせて修理サービスを申し込む必要があるかもしれないと案内しています。Androidスマホはメーカーのサポート範囲を先に確認してください。

今すぐパソコンにつなげないなら、写真を移す別の方法もあります。iCloudとUSBの比較は[iPhoneバックアップをパソコンなしで](/blog/ja/backup-iphone-without-computer)にあります。USBメモリをiPhoneに直接挿して表示されないなら、[USBが突然認識しないときのデータ取り出し](/blog/ja/usb-data-rescue)の手順を見てください。

## パソコンなしでiPhoneの写真をUSBメモリに保存するには?

NextGenAIが作ったU-Saverは、一般的なUSBメモリに写真、ビデオ、連絡先を保存するアプリで、exFATかFAT32のUSBメモリを使い、iOS 26以降で動作します。U-SaverはApp Storeでの公開を準備しており、韓国での価格は4,900ウォンの買い切りです。U-Saverはメッセージ、アプリのデータ、iPhoneの設定は保存せず、U-Saverで保存したUSBメモリの内容は暗号化されません。項目別の手順は[iPhoneバックアップをUSBメモリに取る方法](/blog/ja/backup-iphone-to-usb)に、購入前の確認点は[U-Saverを使う前に確認したい6つのこと](/blog/ja/before-you-buy)にまとめました。

## PCがスマホを認識しないときのよくある質問

### 充電はできるのに、なぜパソコンにスマホが表示されないのですか?

ケーブルが充電専用か、AndroidならUSBの使用方法が充電になっている可能性があります。Appleはデータと充電の両方に対応したケーブルを使うよう案内しています。Androidは通知で「ファイル転送」を選んでください。

### 間違えて「信頼しない」を押してしまいました。

「設定」>「一般」>「転送または[デバイス]をリセット」>「リセット」>「位置情報とプライバシーをリセット」を押します。その後つなぎ直すと、信頼の警告がまた表示されます。

### WindowsパソコンでiPhoneを見るには、アプリが必要ですか?

Appleの案内は、WindowsパソコンでAppleデバイスアプリを開いてiPhoneを接続するよう説明しています。写真を取り込むときも、先にMicrosoft StoreでAppleデバイスアプリを入れるよう書いています。

### ロックしたままのiPhoneをつないでも認識されますか?

Appleの案内によると、iPhoneは初期設定ではロックを解除しないとパソコンと通信しません。ロックを解除してからつなぎ直してください。

### Androidで「ファイル転送」が見つかりません。

Googleは一部の手順がAndroid 14以上でのみ動作すると説明しています。Androidを更新し、スマホを再起動してみてください。メニューの名前が違う場合は、メーカーの案内を確認してください。
