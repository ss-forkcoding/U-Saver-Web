## 핵심 요약

아이폰 USB 메모리는 충전 단자에 꽂고 파일 앱에서 씁니다. 파일 앱의 둘러보기 화면에서 위치 목록의 USB 이름을 누르면 안의 파일이 열립니다.

USB 메모리는 데이터 파티션이 하나여야 합니다. 형식은 exFAT이나 FAT32를 쓰면 아이폰과 PC에서 함께 읽을 수 있습니다.

사진과 영상은 파일 앱에 보이지 않습니다. 사진 앱에서 USB로 내보내야 합니다.

USB 메모리는 복사가 끝난 뒤 뽑습니다.

"꽂았는데 아무 화면도 안 떠요." "USB 안의 파일은 어디서 봐요?" 아이폰에 USB 메모리를 처음 꽂은 분들이 가장 먼저 하는 질문입니다.

아이폰은 USB 메모리를 꽂아도 알림이나 창을 띄우지 않습니다. 파일 앱을 직접 열어야 USB 메모리가 보입니다.

## 아이폰 USB 메모리는 어떤 제품을 써야 하나요?

아이폰 USB 메모리는 단자, 파티션, 형식이 맞으면 쓸 수 있습니다. 아래 세 가지를 확인하세요.

| 확인 항목 | 조건 | 맞지 않을 때 |
| --- | --- | --- |
| 단자 | USB-C 아이폰은 USB-C 메모리, Lightning 아이폰은 카메라 어댑터 | 어댑터를 준비합니다 |
| 파티션 | 데이터 파티션 1개 | 파티션을 하나로 합쳐 포맷합니다 |
| 형식 | exFAT, FAT32, APFS, macOS 확장(HFS+) | 지원 형식으로 포맷합니다 |

조건의 출처는 [Apple의 외부 저장장치 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)입니다. NTFS는 Apple의 목록에 없습니다.

아이폰 전용으로 판매되는 일부 제품은 제조사 앱을 설치해야 파일을 열 수 있습니다. 제조사 앱이 필요한 제품인지 구매 전에 상품 설명에서 확인하세요. 윈도우 PC와 함께 쓴다면 exFAT이 편리합니다. FAT32는 4GB가 넘는 파일을 저장하지 못합니다.

## 아이폰 USB 메모리 사용법 4단계

### 1단계. 충전 단자에 USB 메모리를 꽂습니다

USB-C 아이폰은 USB-C 메모리를 바로 꽂습니다. Lightning 아이폰은 카메라 어댑터에 USB 메모리를 꽂은 뒤 어댑터를 아이폰에 연결합니다. 어떤 어댑터가 맞는지는 [아이폰 OTG 연결 조건](/blog/ko/iphone-otg-usb)에 정리했습니다.

### 2단계. 파일 앱의 위치 목록에서 USB를 엽니다

파일 앱을 열고 둘러보기를 누릅니다. 위치 목록에 보이는 USB 이름을 누르면 안의 폴더와 파일이 나옵니다. 위치 목록이 보이지 않으면 둘러보기를 한 번 더 누릅니다.

### 3단계. 파일을 복사하거나 옮깁니다

파일을 길게 누른 뒤 복사를 고릅니다. USB를 열고 빈 곳을 길게 누른 다음 붙여넣기를 고릅니다.

여러 파일은 오른쪽 위의 더보기 버튼에서 선택을 누른 뒤 고릅니다. 아래쪽의 이동 버튼으로 옮길 위치를 지정합니다.

### 4단계. 복사가 끝나면 USB 메모리를 뽑습니다

Apple 안내는 충전 단자에서 분리하는 방법만 설명합니다. 별도의 꺼내기 버튼은 안내에 없습니다. 복사 중에 뽑으면 일부 파일이 빠지거나 손상될 수 있으니 진행 표시가 사라진 뒤 뽑으세요.

## 사진과 영상은 파일 앱이 아닌 사진 앱에서 옮깁니다

아이폰 사진은 사진 앱에 보관됩니다. 사진 앱에서 고른 뒤 공유 메뉴로 USB에 저장합니다.

순서는 [아이폰 사진 USB로 옮기기](/blog/ko/iphone-photos-to-usb)에, 긴 영상을 옮기는 방법은 [아이폰 동영상 옮기기](/blog/ko/iphone-videos-to-usb)에 있습니다.

## 아이폰에서 USB 메모리가 보이지 않으면 무엇을 확인하나요?

파일 앱 위치 목록에 USB 이름이 없으면 아래 순서로 확인합니다.

| 순서 | 확인할 것 | 조치 |
| --- | --- | --- |
| 1 | 단자에 끝까지 꽂혔는지 | 어댑터와 USB를 다시 꽂습니다 |
| 2 | USB 형식 | PC나 Mac에서 형식을 확인합니다. NTFS라면 포맷합니다 |
| 3 | 파티션 수 | 파티션이 여러 개면 하나로 포맷합니다 |
| 4 | 전원 | 전원이 공급되는 허브나 어댑터를 연결합니다 |

포맷하면 USB의 자료가 모두 지워집니다. 자료가 들어 있다면 먼저 다른 곳에 복사하세요.

## USB 메모리를 정기 백업용으로 쓴다면

파일 앱과 사진 앱만으로도 파일을 옮길 수 있습니다. 다만 사진, 영상, 연락처는 앱마다 따로 저장해야 합니다. 항목별 순서는 [아이폰 USB 백업 방법](/blog/ko/backup-iphone-to-usb)에 있습니다.

NextGenAI가 만든 U-Saver는 USB 메모리를 꽂고 "모두 백업"이나 "사진만"을 고르면 저장을 시작하는 앱입니다. 처음 한 번은 아이폰의 파일 선택창에서 USB를 고릅니다. USB가 빠지면 앱은 10초 동안 기다리고 중단된 백업은 기록에서 이어서 진행합니다.

U-Saver는 App Store 출시를 준비하고 있으며 iOS 26 이상에서 씁니다. 가격은 4,900원이고 한 번 결제합니다. exFAT과 FAT32 USB를 쓸 수 있습니다. 메시지, 앱 데이터, 아이폰 설정은 저장하지 않고 USB의 내용은 암호화되지 않습니다. 구매 전에 [U-Saver를 쓰기 전에 확인할 여섯 가지](/blog/ko/before-you-buy)를 확인하세요.

## 아이폰 USB 메모리 자주 묻는 질문

### 아이폰 USB 메모리를 꽂아도 아무 반응이 없어요.

정상입니다. 아이폰은 USB를 꽂아도 창을 띄우지 않습니다. 파일 앱의 둘러보기 화면에서 USB 이름을 찾으세요.

### 아이폰에서 USB 메모리를 포맷할 수 있나요?

포맷할 수 있습니다. [Apple 안내](https://support.apple.com/guide/iphone/external-storage-devices-iph95baac91f/ios)는 파일 앱이나 Mac, PC에서 형식을 바꿀 수 있다고 설명합니다. 포맷하면 자료가 모두 지워집니다.

### USB 메모리를 꽂은 채로 충전할 수 있나요?

아이폰의 단자가 하나뿐이라 그대로는 함께 쓸 수 없습니다. USB-C 아이폰은 전원 공급 허브를, Lightning 아이폰은 Lightning to USB 3 Camera Adapter와 USB 전원 어댑터를 씁니다.

### USB 메모리에 저장한 파일은 안전한가요?

USB 메모리를 잃어버리면 다른 사람이 안의 파일을 열 수 있습니다. 중요한 자료는 다른 곳에도 사본을 두고 USB를 안전하게 보관하세요.
