## この記事の要点

iPhoneストレージ不足のときは、まず「設定」>「一般」>「iPhoneストレージ」で何が容量を使っているかを確かめます。原因を見て、削除するものと移すものを分けます。

アプリは「Appを取り除く」で、書類とデータを残したままアプリだけを削除できます。写真とビデオは、別のストレージにコピーを作ってから削除します。

写真アプリで削除した写真とビデオは、「最近削除した項目」に30日間残ります。すぐに空きを作るなら、そこからも削除します。

「ストレージがほぼいっぱいという通知が消えない」「写真を撮ろうとしたら空きがないと出る」「写真を消したのに空きが増えない」。iPhoneのストレージ不足でよく聞く声です。ストレージの確認方法から、削除する前にコピーを作る手順まで、Appleの案内に沿って説明します。

## iPhoneストレージ不足のとき、まず何を確認しますか?

[Appleのストレージ確認の案内](https://support.apple.com/en-us/108429)に沿った手順です。

1. 「設定」アプリを開きます。
2. 「一般」をタップします。
3. 「iPhoneストレージ」をタップします。[iPhoneユーザガイド](https://support.apple.com/guide/iphone/manage-storage-on-iphone-iph47c931112/ios)によると、画面の上に空き容量が表示されます。
4. 下のアプリの一覧で、容量を多く使っているアプリを確かめます。
5. アプリ名をタップすると、そのアプリが使う容量を詳しく見られます。

Appleは、キャッシュや一時データは使用量に含まれない場合があると説明しています。ストレージがほぼいっぱいという通知が出たら、おすすめを確認するか、ビデオやアプリなどを削除するよう案内しています。

## iPhoneストレージの画面の項目は何を表していますか?

[Appleの案内](https://support.apple.com/en-us/108429)では、ストレージを次の項目に分けています。どの項目が大きいかを見れば、どこから手をつけるか決められます。

| 項目 | 含まれるもの |
| --- | --- |
| App | インストールしたアプリとその内容、ファイルアプリの「このiPhone内」フォルダ、Safariのダウンロード |
| 写真 | 写真アプリにある写真とビデオ |
| メディア | 音楽、ビデオ、Podcast、着信音、アートワーク、ボイスメモ |
| メール | メールと添付ファイル |
| メッセージ | メッセージと添付ファイル |
| iCloud Drive | iPhoneにダウンロードしたiCloud Driveのファイル |
| その他 | Siriの音声、フォント、辞書、削除できないログとキャッシュ、システムデータ |
| システム | OSが使う容量。機種やモデルによって異なります |

その他とシステムは、自分で削除できないものがほとんどです。ふつうは、アプリ、写真、メッセージなど自分で作ったものから空きを作ります。

## iPhoneが表示するおすすめはどう使いますか?

「iPhoneストレージ」の画面の上に、おすすめが表示されることがあります。[Appleの案内](https://support.apple.com/en-us/108429)によると、「すべて表示」をタップして説明を読み、「有効にする」をタップしてオンにします。おすすめをタップすると、削除できるものを直接確認できます。

Appleは、ストレージが少なくなるとiPhoneが再ダウンロードできるものや不要なものを自動で削除すると説明しています。使っていないアプリや一時ファイルがこれにあたります。それでも足りないときは、次の方法で自分で空きを作ります。

## 「Appを取り除く」と「Appを削除」は何が違いますか?

アプリ名をタップした詳細画面で、2つの方法を選べます。[Appleの案内](https://support.apple.com/en-us/108429)によるものです。

| 方法 | 削除されるもの | 残るもの |
| --- | --- | --- |
| Appを取り除く | アプリが使う容量 | そのアプリの書類とデータ |
| Appを削除 | アプリと関連するデータ | ありません |

ときどき使うアプリなら、「Appを取り除く」が安全です。自動で取り除くなら、[iPhoneユーザガイド](https://support.apple.com/guide/iphone/manage-storage-on-iphone-iph47c931112/ios)のとおり「設定」>「App」>「App Store」で「非使用のAppを取り除く」をオンにします。取り除かれたアプリはホーム画面にクラウドのマーク付きで残り、タップすると再インストールされます。

## 写真とビデオはどう減らしますか?

写真の項目が大きいなら、写真とビデオを先に別のストレージへ移します。[Appleの写真のダウンロードの案内](https://support.apple.com/en-us/111762)に沿って、USBメモリにオリジナルを保存する手順です。

1. USBメモリをiPhoneに接続します。
2. 写真アプリでライブラリに移動します。
3. 「選択」をタップし、移す写真とビデオを選びます。
4. 共有ボタンをタップし、「未編集のオリジナルを書き出す」をタップします。
5. ファイルアプリがiCloud Driveで開いたら、戻るボタンをタップし、「場所」の下のUSBメモリを選びます。
6. 「保存」をタップします。

保存が終わったら、ファイルアプリでUSBメモリを開き、写真を数枚とビデオを1本開いてみます。コピーが開けることを確かめてから、iPhoneから削除します。画面ごとの手順は[iPhoneの写真をUSBに移す方法](/blog/ja/iphone-photos-to-usb)に、パソコンに移す方法は[iPhone写真バックアップをiCloud以外でする方法](/blog/ja/iphone-photo-backup)にまとめました。

USBメモリがFAT32なら、4GBを超えるビデオは保存できません。[Microsoftのファイルシステム比較表](https://learn.microsoft.com/en-us/windows/win32/fileio/filesystem-functionality-comparison)では、FAT32の1ファイルの最大サイズは4GiBです。長いビデオが多いなら、[exFATフォーマット方法](/blog/ja/format-usb-exfat)でUSBメモリを準備し、[iPhoneの動画をUSBに移す方法](/blog/ja/iphone-videos-to-usb)も参考にしてください。

## 写真を削除したのに空きが増えないときは?

[Appleの写真の削除の案内](https://support.apple.com/guide/iphone/delete-or-hide-photos-and-videos-iphb4defbde9/ios)によると、削除した写真とビデオは「最近削除した項目」に30日間残ってから完全に削除されます。30日を待たずに空きを作るなら、次の手順に進みます。

1. 写真アプリで「コレクション」をタップします。
2. 「ユーティリティ」の下の「最近削除した項目」をタップし、「アルバムを表示」をタップしてロックを解除します。
3. 「選択」をタップし、削除する写真とビデオを選びます。
4. ボタンをタップして表示されたメニューで「削除」をタップします。

ここで削除したものは元に戻せません。USBメモリやパソコンにコピーがあるか、もう一度確かめてから削除してください。

## iCloud写真をオンにしているときは何が違いますか?

[AppleのiCloud写真の案内](https://support.apple.com/en-us/108782)によると、iCloud写真がオンの状態で写真を削除すると、iCloudと、iCloud写真を使うすべてのデバイスからも削除されます。iPhoneの空きを作るためだけに削除すると、iCloudの写真も消えます。

iCloud写真を使い続けるなら、「iPhoneのストレージを最適化」をオンにする方法があります。iPhoneには容量を抑えた写真を置き、オリジナルはiCloudに置きます。「設定」>自分の名前>「iCloud」>「写真」>「iPhoneストレージ」で「iPhoneのストレージを最適化」を選びます。iOS 26以前では、「写真」の画面で直接「iPhoneのストレージを最適化」を選びます。

この設定をオンにすると、オリジナルがiPhoneにない場合があります。その状態でUSBメモリに書き出すと、オリジナルのダウンロードに時間がかかります。Appleは書き出す前にWi-Fiに接続するよう案内しています。iCloudの容量も足りずバックアップが止まっているなら、[iPhoneのバックアップができない・容量不足のとき](/blog/ja/iphone-backup-fails)もあわせてご覧ください。

## 写真のほかに何を削除できますか?

[iPhoneユーザガイド](https://support.apple.com/guide/iphone/manage-storage-on-iphone-iph47c931112/ios)は、容量を多く使うものとして次を挙げています。

| 項目 | やること |
| --- | --- |
| メッセージ | 不要な会話と添付ファイルを削除します |
| ダウンロードしたビデオ | TVアプリやストリーミングアプリで、見終わったビデオを削除します |
| ファイルと書類 | ファイルアプリで不要なファイルを削除します |
| App | 使っていないアプリを削除します |

メッセージの添付ファイルに残したい写真があるなら、先に写真アプリに保存してください。削除した会話は取り戻すのが難しくなります。

## 写真をUSBメモリによく移すなら

写真アプリから書き出す方法では、毎回写真と保存先を選ぶ必要があります。ストレージがいっぱいになるたびに移すなら、同じ作業をくり返すことになります。

NextGenAIが作ったU-Saverは、一般的なUSBメモリに写真、ビデオ、連絡先を保存するアプリで、exFATかFAT32のUSBメモリを使い、iOS 26以降で動作します。U-SaverはApp Storeでの公開を準備中で、韓国での価格は4,900ウォンの買い切りです。U-Saverはメッセージ、アプリのデータ、iPhoneの設定を保存せず、U-Saverで保存したUSBメモリの内容は暗号化されません。購入前に[U-Saverを使う前に確認したい6つのこと](/blog/ja/before-you-buy)をご確認ください。

## iPhoneストレージ不足のよくある質問

### iPhoneで何が容量をいちばん使っているか、どう確かめますか?

「設定」>「一般」>「iPhoneストレージ」を開きます。上で空き容量を確かめ、下の一覧でアプリごとの使用量を確認します。

### 「Appを取り除く」とデータは消えますか?

Appleの案内によると、「Appを取り除く」はアプリが使う容量だけを空け、書類とデータは残します。「Appを削除」はアプリと関連するデータをまとめて削除します。

### 写真を削除したのに空きが増えません。

削除した写真とビデオは「最近削除した項目」に30日間残ります。コピーを確かめてから、そこからも削除してください。

### 「その他」や「システム」も削除できますか?

Appleの案内によると、「その他」には削除できないログとキャッシュ、システムデータが含まれます。「システム」はOSが使う容量です。アプリ、写真、メッセージなど自分で作ったものから整理してください。

### USBメモリに写真を移したら、iCloud写真から削除してもいいですか?

USBメモリのコピーが開けることを確かめたなら、判断できます。ただし、iCloud写真がオンの状態で削除すると、すべてのデバイスから消えます。USBメモリが唯一のコピーになるので、なくさないよう保管してください。
