# 블로그 색인 회복 — 22편 보강과 재색인

## 목표와 성공 기준
- 목표: 남긴 22편이 다시 색인되고 2026-11-10~19 수준의 노출(일 300회 이상)을 회복한다.
- 성공 기준 (2027-01-31 판정):
  - GSC 사이트맵 `indexed`가 66건 중 30건 이상이다.
  - 핵심 5편의 `coverageState`가 "Submitted and indexed"다.
  - 일 노출이 7일 평균 100회 이상이다.
- 실패 판정: 2027-01-31에도 `indexed`가 0건이면 수동 조치를 다시 확인하고, 도메인 이전(C안)을 검토한다.

## 비목표
- 새 글 발행. 회복을 판정하기 전에는 새 글을 쓰지 않는다.
- 자동 발행기를 다시 켜는 일. `autopublish/enabled`는 `off`로 둔다.
- 앱 홈(`/ko`, `/en`, `/ja`) 문구 변경.

## 1단계 — 정리 배포 (2026-11-27)
- [x] 자동 발행을 중단했다(MacBook·Mac mini 모두 `enabled=off`, MacBook launchd bootout).
- [x] 64편을 삭제하고 커밋했다. 깨끗한 클론에서 빌드가 통과했다.
- [x] `ss-forkcoding` 계정으로 푸시했다(f4acab2).
- [x] 배포 뒤 지운 URL 3개는 404, 남긴 URL 3개는 200을 반환한다. 사이트맵은 75 URL(글 66 + 블로그 목록 3 + 사이트 6)이다.
- [x] GSC 「직접 조치」는 "감지된 문제 없음"이다(2026-11-27). 재검토 요청 대상이 아니고, 알고리즘 판정이 풀리기를 기다려야 한다.
- [x] GSC에 사이트맵을 다시 제출했다. 발견된 페이지 267 → 75로 반영됐다(2026-11-27).

## 2단계 — 핵심 5편 보강 (~2026-12-11)
대상은 노출 상위 5편이다: iphone-otg-usb, format-usb-exfat, iphone-sd-card-reader, iphone-flash-drive-guide, iphone-photos-to-usb.

- [x] 집필 지침을 `.claude/skills/blog-writing/SKILL.md`로 개정했다(im-not-ai humanize-korean v2.4.8 윤문 포함).
- [x] `iphone-otg-usb` 1차 보강(구조·문장·Apple 문서 재확인, ko 윤문 게이트 OK). 시험 환경 줄·실측·사진은 대기.

편마다 아래를 모두 넣는다.
- [ ] 실사용 근거: 실제 아이폰 모델, iOS 버전, 저장장치 제품명으로 직접 해 본 결과. 성공과 실패를 같이 적는다.
- [ ] 이미지 3장 이상: U-Saver 화면이나 파일 앱 화면, 연결 사진. 상태 표시줄은 지운 webp로 넣는다.
- [ ] 실측값 1개 이상: 예를 들어 사진 1,000장 복사 시간, 인식 성공 여부 표.
- [ ] "직접 시험하지 않았다"는 문장을 지운다.
- [ ] 틀을 깬다: "핵심 요약" + 질문형 H2 반복을 버리고, 글마다 독자의 문제 순서에 맞춰 구성한다. FAQ는 실제 검색어가 있는 글에만 둔다.
- [ ] ko부터 쓰고, en·ja는 그 나라 검색어로 다시 쓴다. 기계 번역을 그대로 쓰지 않는다.
- [ ] 수정한 날 GSC에서 URL 색인을 요청한다(하루 최대 10건).

## 3단계 — 신뢰 신호 (~2026-12-11, 2단계와 병행)
- [ ] 작성자를 사람으로 바꾼다. `src/content/seo.ts`의 `author`를 Person으로 바꾸고 이름·역할·소개 페이지를 단다.
- [ ] 글 머리에 작성자, 검수일, 시험 환경(기기·iOS) 한 줄을 표시한다.
- [ ] 글마다 다른 og 이미지를 쓴다(대표 실사용 사진).

## 4단계 — 나머지 17편 (~2027-01-08)
- [ ] 2단계 기준을 나머지 17편에 적용한다. 보강할 근거가 없는 글은 가까운 글에 합치고 301로 넘긴다.
- [ ] 합친 뒤 `llm-index.txt`와 내부 링크를 갱신한다.

## 모니터링
- [ ] 매주 금요일 GSC API로 사이트맵 `indexed`, 핵심 5편 `coverageState`, 일별 노출을 기록한다. 스크립트는 lesson에 적힌 조회 방식을 따른다.
- 피벗 트리거: 2단계 완료 4주 뒤에도 핵심 5편이 모두 "크롤링됨 - 현재 색인 생성되지 않음"이면, 나머지 보강을 멈추고 원인을 다시 진단한다.

## 리스크와 의존
- 실사용 근거(사진·실측)는 칸이 기기로 직접 만들어야 한다. AI가 대신 만들 수 없다.
- 사이트 단위 판정에서 회복하는 데 수개월이 걸릴 수 있다. 4주 안에 변화가 없어도 실패로 단정하지 않는다.
- 네이버 유입은 GSC와 별개다. 서치어드바이저에서 따로 확인한다.
