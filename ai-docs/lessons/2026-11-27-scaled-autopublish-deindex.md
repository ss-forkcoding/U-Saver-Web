# 대량 자동 발행으로 블로그 사이트 전체가 색인에서 빠졌다

## 증상
- GSC 노출이 11/19 394회에서 11/20 8회로 줄었고, 11/24에는 0회가 되었다. 평균 순위는 11/10 9.6위에서 11/16 19.3위로 내려갔다.
- 사이트맵은 267건을 제출했지만 색인은 0건이었다. 클릭 1위 글과 홈 `/ko`까지 "크롤링됨 - 현재 색인 생성되지 않음" 상태였다.
- 기술 결함은 없었다. 200, 자기 참조 canonical, robots 허용, noindex 없음을 확인했다.

## 원인 (추정. 수동 조치는 없음, 2026-11-27 GSC 확인 — 알고리즘 판정)
- launchd 발행기(`dev.khan.usaver-blog-publish`)가 5시간마다 ko·en·ja 글을 한 편씩 올렸다. 그래서 3주에 86편, 258페이지가 쌓였다.
- 주제가 아이폰 외장 저장장치에서 Switch, 드론, 라즈베리 파이까지 넓어졌다.
- 글 대부분이 "직접 시험하지 않았다"고 밝히고 공식 문서를 요약했다. 이미지는 0장이었고, 모든 글의 틀이 같았다(핵심 요약 → 질문형 H2 → FAQ).

## 교훈
- 사이트 단위 판정은 하루 만에 일어나고, 모든 글에 한꺼번에 적용된다.
- 발행 수가 늘수록 평균 순위가 내려가면 경고 신호로 본다.
- 직접 경험이 없는 요약 글은 공식 문서보다 높은 순위에 오르지 못한다.

## 적용 방법
- 자동 발행기를 다시 켜지 않는다. 새 글은 사람이 검수하고 주 1~2편으로 제한한다.
- 새 글에는 U-Saver 실사용 화면이나 기기별 실측 중 하나 이상을 넣는다.
- 주 1회 GSC API로 사이트맵 `indexed`와 핵심 URL의 `coverageState`를 확인한다. 노출이 7일 이동평균의 30% 아래로 떨어지면 발행을 멈춘다.
